# ゴールデンクロス 大綱

## テーマ
「人生のゴールデンクロスは、一度デッドクロスを経験した者だけが掴める」

## 全体構成：三代・十部構成
三人の主人公がそれぞれの「ゴールデンクロス」を目指し、前の者が倒れた後を次の者が継ぐ——リレー形式の叙事詩。

## 隠された真実（作品全体を貫く秘密）
- **翔は西村の実子である**。和代だけが知る出生の秘密。
- 西村は翔を我が子と確信しているが、関わる気はない。
- 誠一は生涯、翔を実子として愛した。真実を知らずに死んだ。
- 栞（誠一の実子）と翔（西村の実子）——同じ母を持つが父が違う。
- 翔がこの真実を知るのは第十部。すべての因縁が集結する時。
- 「俺の敵は…俺の父だったのか。」——血の連鎖を断ち切ることが、最終的なテーマとなる。

### 第一期：父親の物語

#### 第一部「上昇トレンド」（約4万字）
**主人公：誠一（42歳）**
- 順調に資産を増やし脱サラを決意。
- 和代とは職場恋愛で結婚。教育係→憧れ→恋愛の末の結婚。
- 当時の誠一は出世コースのバリバリ社員。厳しいが面倒見の良い先輩だった。
- 栞（高2）・翔（中2）との幸福な日常。
- 家族4人での幸せな食卓。株の話をする誠一を尊敬する栞。
- ゴールデンクロスを捉え、さらなる資産増加。「人生絶好調」。
- 西村は表面上祝福。退社の際、意味深なことを匂わせるが、誠一は気に留めない。
- **ほどなくして、匿名で一本のビデオテープが届く——**
- 第二部への架け橋。西村の策略は静かに、そして確実に動き出す。

【読者だけが知る真実（後日挿入されるフラッシュバック）】
- 十数年前——和代が入社し、誠一の教育期間が終わった頃。
- 西村が「誠一も来る」と嘘の誘い。睡眠薬。カメラ完備の自宅でのレイプ。
- 「処女です…やめてください…」——その懇願が逆に西村を興奮させた。
- 初回以降も西村は動画をネタに**定期的に脅迫**。金銭と体を奪い続ける。
- 誠一と付き合っている間も、結婚してからも、栞や翔が生まれてからも——関係は続いた。
- 翔が西村の子であることも、和代は知っている。
- 和代は十数年もの間、完全に西村の支配下にあった。
- この犯行と支配がすべての悲劇の起点。

#### 第二部「デッドクロス」（約7万字）
**主人公：誠一（42歳）**
- 会社を円満退職。専業トレーダーとして独立。
- 退社の際、西村は意味深な言葉を残すが、誠一は気に留めない。
- **ほどなくして、匿名でビデオテープが届く——**
- 再生した映像——和代が西村にレイプされている姿。『処女です…やめてください…』
- 誠一の精神が揺らぎ始める。妻への信頼が崩れる。
- 動揺した判断でトレードミス。大損。
- 西村は追い打ちをかけるように、**写真や映像を小出しに送り続ける**。
- 送られるたびに誠一の精神は蝕まれ、トレードが雑になる。含み損が膨らむ。
- 「投資はメンタル」——メンタルが崩れるとチャートも崩れる。
- 西村の策略（情報悪用・信用毀損）も重なり、負のスパイラルへ。
- 会社へ副業がバレ、退職金も失う。
- 資産をほぼ喪失。栞の進学問題・家族の生活費の危機。
- 夫婦崩壊。誠一と和代の間には埋められない溝。
- **追い打ちの一枚——翔が自分の子ではない証明。**
- 絶望のどん底へ。

#### 第三部「幕切れ」（約1万字）
**主人公：誠一・和代**
- トレードの損失が膨らみ、**自宅を手放す**。
- すべてを失った誠一は、もはや正常な判断ができない。
- **妻（和代）を殺す。**
- **その後、自分も首を吊る。**
- 帰宅した栞が両親の遺体を発見する。
- 西村の「完全勝利」。しかし——これは新たな連鎖の始まりでもある。

### 第二期：長女の物語

#### 第四部「迷子の移動平均線」（約5万字）
**主人公：栞 17歳→18歳**
- 両親の葬儀後、弟・翔と共に児童養護施設に預けられる
- 施設長に目を付けられ、いじめと嫌がらせの日々
- 「言うことを聞けば待遇を良くしてやる」と言われ、抵抗できずレイプされる
- 施設で弟と一緒にいられることだけが心の支えだった
- しかし翔だけが里親に引き取られることになる
- 一人取り残される栞。施設長のレイプは続く
- もう耐えられない——施設を飛び出す
- 渋谷でトーヨコキッズとなる。路上で生きるために立ちんぼを始める
- 父の遺したトレードノートを段ボールの中で発見
- 最初のトレード——わずかな金で、父が遺した銘柄を買う

#### 第五部「カスタマー」（約3万字）
**主人公：栞 18歳〜**
- 昼は図書館でトレードの勉強、夜は立ちんぼ
- 少しずつ結果を出し始める
- 父が負けた理由が「メンタルの崩壊」と理解する
- ある日、客の中に**父の同僚（西村・敵）**が現れる
- 西村は風の噂で栞が立ちんぼをしていると聞き、確かめに来た
- 長女は同僚から「父がなぜ追い詰められたか」の真相を知る
- 同時に母の過去（同僚との関係・ビデオ）の存在も知る
- 怒りと復讐心が芽生える

#### 第六部「共犯者」（約3万字）
**主人公：栞 + リョウ（ケツモチ）**
- リョウは栞の立ちんぼのケツモチ。シャブ中。
- 最初は「面倒を見てやる」と保護。実際は稼ぎの吸い上げ。
- 栞がトレードで結果を出し始め、リョウの支配から抜けようとする。
- リョウはそれを許せない——「お前は俺のものだ」
- 復讐計画（西村への）には最初乗り気だったが、金次第で揺れる。
- 栞とリョウの溝は決定的になる。

#### 第七部「再びのデッドクロス」（約2万字）
**主人公：長女 → 死亡**
- リョウとの関係が破綻。長女が別れを告げる
- 激昂した彼氏に殺害される
- 父親と同じく、這い上がった先で命を絶たれる
- 長男が姉の死を知る

### 第三期：長男の物語

#### 第八部「カオス・ブレイク」（約4万字）
**主人公：翔 14歳→10代後半**
- 両親の死後、姉・栞と共に施設へ
- 里親に引き取られる。新しい父は最初は優しかった
- しかしすぐに本性を現す——小児性愛者だった
- 繰り返しレイプされる。逃げ場のない地獄
- もう耐えられず、父を半殺しにする
- 少年院に入る
- 出院後、行き場を失い路上で生きる
- ぐれ、喧嘩に明け暮れる
- 格闘技に出会い、暴力を昇華させる
- 地下格闘技で頭角を現し、チャンピオンに
- 「這い上がれる」と思った矢先の試合で脊髄を損傷——下半身不随に

#### 第九部「ラスト・エントリー」（約1万字）
**主人公：長男 車椅子の生活**
- 「また叩き落された」——父と同じ、姉と同じ運命
- 車椅子の自分に未来を見出せず、死を決意する
- しかし死の直前に、姉の遺産と父のトレードノートを発見する
- 「父さん、姉さん…俺はこの連鎖を終わらせる」
- トレードの世界に足を踏み入れる決意

#### 第十部「ゴールデンクロス」（約10万字）
**主人公：翔（車椅子のトレーダー）**
- 格闘技で培った「読み」「メンタル」「リスク感覚」を武器に相場へ。
- 父・誠一のトレードノートを読み解き、敗因を完全に理解する。
- 姉・栞の遺産を元手に、ゼロから立ち上がる。
- 西村、リョウ——すべての因縁と対峙する時、翔は一つの真実を知る。
- **「西村……お前は、俺の」**
- 栞は誠一の子。翔は西村の子。同じ母を持ちながら、父が違う。
- 誠一は真実を知らずに翔を愛し、死んだ。
- 怒りと混乱の中で翔が出す答え——
- **復讐ではない。血の連鎖を断ち切ること。**
- 西村を法と市場の仕組みで追い詰める。
- 実の父を自滅させる——それが翔の選んだ「復讐の終わらせ方」。
- ラストシーン：
  車椅子の翔がモニターを見つめる。
  短期的移動平均線が長期線を抜ける——ゴールデンクロス。
  「父さん、姉さん……これがあなたたちの見ていた景色ですか」
  翔の人生に、初めてのゴールデンクロスが訪れる。

## 株式用語と人生の重ね合わせ
- **移動平均線**：人生の長期トレンド——短期的な上下に惑わされない
- **ゴールデンクロス**：節目の転機——絶望の先にある希望
- **デッドクロス**：最悪の局面——しかし底値は買い時
- **自律反発**：誰も助けてくれない底値からの回復
- **出来高**：人との繋がりの大きさ
- **メンタルと投資の相関**：心が壊れるとチャートも壊れる。格闘技のメンタルコントロールがここで活きる
- **複利**：小さな努力の積み重ねが、やがて大きなものを生む
- **損切り**：間違いを認めて前に進む強さ
