# 関係マップ

## 家族
```
桐生 誠一（父・主人公①）── 桐生 和代（妻）
         │
     ┌───┴───┐
桐生 栞（長女・主人公②）  桐生 翔（長男・主人公③）
```

## 敵
```
西村 健吾（同僚・敵）
  │
  ├── 誠一（トレード策略により破滅へ）
  ├── 和代（入社当時、強引な関係。ビデオを所持）
  └── 栞（風俗店に来店→真相を知られる）

加藤 リョウ（半ぐれ→栞の共犯者→殺害）
  └── 栞（共闘→搾取→殺害）

施設長
  └── 栞（施設でレイプ。翔が里親に出された後、脱走）

里親（養父）── 翔（里子として迎えられるが、繰り返しレイプされる）
  └── 翔が家出する直接の原因
```

## 連鎖
```
誠一（自死）→ 栞（殺害）→ 翔（唯一の生存者、連鎖を断ち切る）
```
