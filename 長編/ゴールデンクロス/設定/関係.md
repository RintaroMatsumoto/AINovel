# 関係マップ

## 家族（第一部〜第三部）
```
主人公（父）── 妻
  │
  ├── 長女
  └── 長男
```
- 主人公と妻：信頼と愛情で結ばれた夫婦。しかし妻だけが過去の秘密を隠す。
- 主人公と長女：父を尊敬。株の話を聞くのが好きだった。
- 主人公と長男：純粋な尊敬。父の背中を見て育つ。

## 隠された過去
```
同僚 ──── 妻（入社当時、強引な関係）
  │
  └── ハメ撮りビデオを所持
```
- 妻はこの過去を一度も話せずに自死を選ぶ

## 第二部以降
```
同僚 ──── 風俗店に来店 → 長女が真相を知る
  │
  ├── 父を追い詰めた元凶
  └── 長女の復讐対象へ

長女の彼氏（半ぐれ）── 長女（共闘→搾取→殺害）
  │
  └── 当初は復讐の共犯者。しかし金で歪み、長女を殺す
```

## 最終章
```
長男（唯一の生存者）
  │
  ├── 父の無念を継ぐ
  ├── 姉の無念を継ぐ
  └── 連鎖を断ち切る
```
