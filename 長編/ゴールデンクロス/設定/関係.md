# 関係マップ

## 家族
```
桐生 誠一（父・主人公①）── 桐生 和代（妻）
         │
     ┌───┴───┐
桐生 栞（長女・主人公②）  桐生 翔（長男・主人公③）
```

## 敵
```
西村 健吾（同僚・敵）── 全ての悲劇の起点
  │
  ├── 和代：「誠一も来る」と嘘の誘い→睡眠薬→自宅に連込み→カメラ完備の部屋でレイプ→ハメ撮り
  ├── 誠一：トレード策略＋和代のビデオ送付で精神的に破壊→自死
  └── 栞：立ちんぼの噂を聞き客として現れる→真相を知られる→復讐のきっかけに

加藤 リョウ（半ぐれ→栞の共犯者→殺害）
  └── 栞（共闘→搾取→殺害）

施設長
  └── 栞（施設でレイプ。翔が里親に出された後、脱走）

里親（養父）── 翔（里子として迎えられるが、繰り返しレイプされる）
  └── 翔が家出する直接の原因
```

## 連鎖
```
誠一（自死）→ 栞（殺害）→ 翔（唯一の生存者、連鎖を断ち切る）
```
