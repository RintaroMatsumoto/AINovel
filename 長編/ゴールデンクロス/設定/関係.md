# 関係マップ

## 表の家族
```
桐生 誠一（父）── 桐生 和代（母）
         │
     ┌───┴───┐
桐生 栞（長女）  桐生 翔（長男）
```

## 真実の血縁
```
西村 健吾 ──── 和代（十数年にわたる強制関係）
  │
  ├── 翔の実父（和代だけが知る真実）
  ├── 栞は誠一の実子
  └── 誠一は生涯、真実を知らずに翔を愛した
```
- 西村は翔が自分の子だと確信に近い認識を持っている。
- 翔は後にこの真実を知る。

## 敵
```
西村 健吾
  │
  ├── 和代：嘘の誘い→レイプ→十数年の脅迫支配。翔は西村の子。
  ├── 誠一：小出しのビデオで精神破壊→翔の真実で絶望→和代を殺害→自死。自分の子を孤児にした。
  ├── 栞：立ちんぼの噂を聞き客として現れる→真相を知られる→復讐のきっかけに
  └── 翔：自分の実子。しかし関わる気はない。

加藤 リョウ（ケツモチ・シャブ中）── 栞の共犯者→搾取→殺害

施設長 ── 栞（施設でレイプ。翔が里親に出された後、脱走）

里親（養父）── 翔（里子に。繰り返しレイプ→翔が半殺し→少年院）
```

## 連鎖
```
西村の犯行（十数年前）
  → 継続的支配（十数年）
  → 誠一破滅（小出しビデオ＋翔の真実）
    → 誠一、和代を殺害→自死
        → 栞・翔の地獄
          → 栞：トーヨコ→立ちんぼ→トレード→西村と再会→リョウに殺害
          → 翔：里親→少年院→地下格→不随→トレード→真実を知る
            → 血の連鎖を断ち切る——実父・西村を倒す
```
