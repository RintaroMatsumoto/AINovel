# 関係マップ

## 表の家族
```
桐生 誠一（父）── 桐生 和代（母）
         │
     ┌───┴───┐
桐生 栞（長女）  桐生 翔（長男）
```

## 真実の血縁
```
西村 健吾 ──── 和代（十数年にわたる強制関係）
  │
  ├── 翔の実父（和代だけが知る真実）
  ├── 栞は誠一の実子
  └── 誠一は生涯、真実を知らずに翔を愛した
```
- 西村は翔が自分の子だと確信に近い認識を持っている。
- 翔は後にこの真実を知る。

## 敵
```
西村 健吾
  │
  ├── 和代：嘘の誘い→レイプ→十数年の脅迫支配。翔は西村の子。
  ├── 誠一：小出しのビデオで精神破壊→翔の真実で絶望→和代を殺害→自死。自分の子を孤児にした。
  ├── 栞：立ちんぼの噂を聞き客として現れる→真相を知られる→復讐のきっかけに
  └── 翔：自分の実子。しかし関わる気はない。

加藤 リョウ（ケツモチ・シャブ中）── 栞の共犯者→搾取→殺害

施設長 ── 栞（施設でレイプ。翔が里親に出された後、脱走）

里親（養父）── 翔（里子に。繰り返しレイプ→翔が半殺し→少年院）
```

## 遺産相続の流れ（法的設定）
```
栞死亡（18歳・未婚・子なし）
  → 法定相続人：弟・翔のみ（民法889条）
  → 翔は15歳・少年院在院中
  → 家庭裁判所が「相続財産管理人」（弁護士）を選任
  → 管理人：証券口座・遺品（トレードノート含む）を保管・管理
  → 翔18歳（成年）になるが地下格闘技の世界で所在不明
  → 管理人、約2年間捜索
  → 翔20歳、タイトルマッチ直前に接触成功
```

## 連鎖
```
西村の犯行（和代18歳）
  → 継続的支配（17年間・和代22→39）
    → 誠一破滅（小出しビデオ＋翔の真実）
    → 誠一、和代を殺害→自死（栞14・翔11）
      → 栞・翔の地獄
        → 栞：施設→脱走→立ちんぼ→トレード→西村殺害→リョウに殺害（18歳）
        → 翔：里親→少年院→地下格→弁護士来訪→リング対峙（20歳）
          → ラストは未定
```
