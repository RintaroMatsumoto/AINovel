# 7次元文体アンケート（Dreampowers dp-set-style 由来）

> **⚠️ DayTrade の実際の文体は `novels/設定/文体プロファイル.md` に従うこと。本ファイルは参考資料。**

## 概要
作品全体の文体プロファイルを定義するための7次元アンケート。
各キャラの言語スタイル（7次元）と併用し、作品レベルの文体ベースラインを確立する。

**出典**: Dreampowers (skyfiredao) dp-set-style / GPL-3.0
**翻訳・改変**: AINovel プロジェクト用

## 使い方
- **Phase 2（核心設定再構成）** で使用
- character-designer agent が各キャラの7次元と同時にこのアンケートを実行
- 全キャラに共通する作品レベルの文体を定義後、各キャラの個別スタイルを定義する
- 結果は `docs/style.md` または AGENTS.md に保存

## 7次元アンケート

### Q1：語り距離（ナラティブディスタンス）

読者とキャラの距離感は？

- **A** 神の視点。冷静に俯瞰し、感情的な距離を保つ
- **B** 主人公に寄り添う。時々内心に入るが、長居はしない
- **C** 深く没入する。読者＝キャラ。感じることがそのまま読者の感覚
- または自分の言葉で説明

### Q2：文法リズム（シンタックスリズム）

どんな文のリズムが好みか？

- **A** 短文でキレがいい。リズムが速く、余計なものを削ぐ
- **B** 長短織り交ぜ、緩急をつける
- **C** 長文で重ねていく。包み込むような感覚
- または自分の言葉で説明

### Q3：感覚密度（センサリーデンシティ）

情景描写の濃さは？

- **A** 白眉。点到即止。読者の想像に委ねる余白を残す
- **B** キーシーンは細かく描き、繋ぎは簡素に
- **C** 五感で没入させる。読者がその場にいるかのように
- または自分の言葉で説明

### Q4：語彙階層（ボキャブラリーレジスター）

用語の好みは？

- **A** 口語的。地に足がついている。友達と話すような感覚
- **B** 書き言葉だが平易。衒学がない
- **C** 典雅。格調を重んじる
- または自分の言葉で説明

### Q5：比喩戦略（メタファーストラテジー）

比喩やイメージの使い方は？

- **A** ほぼ使わない。出来事そのもので語る
- **B** 要所で使う。感情のキーポイントで差し込む
- **C** 頻繁に使う。詩的な意図とイメージの重層を追求する
- または自分の言葉で説明

### Q6：感情表現（エモーショナルエクスプレッション）

キャラの感情をどう伝えるか？

- **A** 動作と細部で暗示する。読者自身に感じ取らせる
- **B** 行動描写と内心独白が半々
- **C** 大量の心理描写で内心を直接見せる
- または自分の言葉で説明

### Q7：会話比重（ダイアログレシオ）

会話がストーリーに占める割合は？

- **A** 会話は最小限。地の文が主で、会話は必要な時だけ
- **B** 地の文と会話が均衡。互いに推進する
- **C** 会話が主。シーンは対話で進行する
- または自分の言葉で説明

## スタイルプロファイル（出力テンプレート）

アンケート結果を以下の形式で保存する:

```markdown
# 文体プロファイル

## スタイルタグ
[簡潔な概括。例：冷徹白眉 / 詩的没入 / 口語会話志向]

## 7次元パラメーター
| 次元 | 設定 | 値(1-3) |
|------|------|---------|
| 語り距離 | [選択肢の文章] | [1-3] |
| 文法リズム | [選択肢の文章] | [1-3] |
| 感覚密度 | [選択肢の文章] | [1-3] |
| 語彙階層 | [選択肢の文章] | [1-3] |
| 比喩戦略 | [選択肢の文章] | [1-3] |
| 感情表現 | [選択肢の文章] | [1-3] |
| 会話比重 | [選択肢の文章] | [1-3] |

値の意味: 1=A, 2=B, 3=C。カスタム回答はAIが最も近い値にマッピング。

## 実行可能な文体指示
[機械的にチェック可能なルール。例:]
- 1段落5文以内。短く切ってリズムを作る
- 3〜4段落ごとに最低1つの視覚または触覚イメージ
- 比喩のソースは自然界（水・植物・天気）に限定
- 「彼は感じた」「彼は思った」等の心理フィルター語を使わない
- 平均文長15〜25字
- 会話パート比率40%〜60%

## 錨定作者
[最も近い1〜2人の参考作者とそのスタイル特徴]

## 禁止領域
[現在の文体と衝突する書き方。例:]
- 大量の心理独白禁止（語り距離=遠）
- 四字熟語の連積禁止（語彙層級=口語）
- 3段落以上会話なしの連続禁止（会話比重=高）
```
