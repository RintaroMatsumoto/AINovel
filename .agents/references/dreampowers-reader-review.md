# 読者視点テスト（Dreampowers dp-review-reader 由来）

## 概要
アウトラインや設定を知らない「冷読み読者」の立場から、章の体験を評価する。
著者視点の品質チェック（禁則語・標点・字数）とは別に、消費者の立場で検証する。

**出典**: Dreampowers (skyfiredao) dp-review-reader / GPL-3.0
**翻訳・改変**: AINovel プロジェクト用

## 使い方
- **Phase 5（品質チェック）** で consistency-checker agent が実行
- 各章の品質チェック完了後、冷読みモードで4次元評価
- 結果を `追跡/読者テスト.md` に記録

## 冷読みの原則

以下の情報に**アクセスしない**:
- アウトライン（今後の展開を知らない）
- 世界観設定の完全版（本文で既に明かされたもののみ知っている）
- キャラ設定の完全版（行動と会話から分かることのみ）
- 伏線管理ファイル（何が伏線か知らない。後で気づくだけ）
- 著者の意図

**知っていること**: 公開済みの章の累積テキストのみ。

## 4次元評価（各1-5点）

### 次元1：ページターナー力（翻頁欲）

**質問**: この段落／この章を読んだ後、読者は続きを読みたいと思うか？

チェック項目:
- **章末のフック**: 最後の段落に未解決の緊張や約束があるか？
- **中盤の謎**: 章の中盤に読者を引き続ける未回答の問いがあるか？
- **情報の約束**: 「これを読めばXが分かる」という感覚があるか？
- **未解決の質問数**: 章の終わりで読者の頭の中に「まだ分からないこと」が2〜4個あるか？

評価基準:
| 点数 | 意味 |
|------|------|
| 5 | 「もう一章だけ絶対読む」 |
| 4 | 続きは読みたいが、一旦離れられる |
| 3 | 特に止めたいとも続けたいとも思わない |
| 2 | ここで離脱する可能性が高い |
| 1 | ほぼ確実に読むのをやめる |

**閾値**: ≤2 の場合は高優先度修正。

### 次元2：認知負荷（認智負荷）

**質問**: 読者は混乱したり、情報に圧倒されたりしていないか？

チェック項目:
- **新概念密度**: 本章で導入された未経験の用語・設定・ルールはいくつか？
- **文脈なし要素**: 突然登場する名前・場所・用語で、以前に説明がないものはあるか？
- **情報密度の分布**: 1シーンに詰め込まれすぎている情報はないか？
- **前提知識のギャップ**: 読者が知っているはずのないことを前提にしていないか？

量的基準:
- 最初の500字以内に3つ以上の未説明の新要素 → 認知過負荷
- 1シーン内で2つ以上の新概念 → 危険域
- 連続3段落に既知のアンカー（既出キャラ・場所・感情）がない → 読者漂流

評価基準:
| 点数 | 意味 |
|------|------|
| 5（最高負荷） | 非常に高い。読者は何度も読み返す必要がある |
| 4 | 明らかに負荷が高い。一部段落の読み返しが必要 |
| 3 | 1〜2箇所で一瞬止まる |
| 2 | 軽い負荷。スムーズに読める |
| 1（最低負荷） | 負荷ゼロ。すべての情報が自然に入ってくる |

**注意**: 低い点数が良い。1が理想。

### 次元3：共感検証（共感検証）

**質問**: 読者はキャラの状況を感じ取れるか？キャラの運命を気にかけるか？

チェック方法: 各キーとなるプロットポイントで「なぜこれを気にする必要がある？」テスト:
1. 読むのを止めて、知っている情報だけで「このキャラは今何を望んでいる？」を一文で言えるか？
2. 「李明は娘の手術費を守りたい」→ 具体的で明確 = 共感チャネルが開いている
3. 「李明は問題を解決したい」→ 曖昧で空虚 = 共感チャネルが未構築
4. 「このキャラがなぜこれをしているのか分からない」→ 共感失敗

チェック項目:
- **動機の透明性**: キャラの行動理由が既存テキストから推測できるか？
- **感情のアンカー**: 読者がキャラと同じ感情を共有した瞬間が、各章に最低1回あるか？
- **目標の可視性**: キャラが何を追い求めているか、読者に見えているか？
- **代償の認知**: キャラが失敗したら何を失うか？代償が具体的であればあるほど共感が強い

評価基準:
| 点数 | 意味 |
|------|------|
| 5 | 読者がキャラの運命にハラハラする。感情が完全に同期 |
| 4 | キャラの状況を理解し、気にかける |
| 3 | 状況は理解できるが、感情的な距離がある |
| 2 | キャラの状況にほとんど関心が持てない |
| 1 | キャラが何をしているのか理解できない |

### 次元4：リズム感（節奏感受）

**質問**: 読者は主観的にこの章のリズムを快適に感じるか？

2つの確認文:
1. **「この段落、飛ばしたい？」**: 該当する場合、その段落は冗長。情報の重複、感情の停滞、描写過多、または細部の緊張不足が原因
2. **「え、今何が起きた？」**: 該当する場合、その部分は性急。必要な遷移の省略、感情反応の欠落、情報圧縮過多が原因

チェック項目:
- 「飛ばしたい」と思わせる段落をすべてマーク。理由を記載
- 「え、何が起きた？」と思わせる箇所をすべてマーク。理由を記載
- 全体のリズムが章の種類（導入/山場/消化）に合っているか？
- リズムの単調さ：全章が同じ速度で進んでいないか？

評価基準:
| 点数 | 意味 |
|------|------|
| 5 | 完全に没入。リズムの存在すら意識しない |
| 4 | 全体的に快適。一部の段落でわずかに違和感 |
| 3 | 明らかな冗長/性急な箇所があるが、全体としては許容範囲 |
| 2 | リズムが頻繁に問題を起こす。没入が何度も中断される |
| 1 | 持続して読めない。繰り返し没入が破られる |

## 特殊シナリオ

### 連載初章
- ページターナー力の比重を2倍にする
- 最初の300字以内に最低1つの謎または約束が必要
- 最初の500字以内に共感できるキャラの瞬間が必要
- ページターナー力 ≤3 で不合格

### 山場（クライマックス）の章
- リズム感の比重を2倍にする
- 「飛ばしたい」段落は山場では絶対禁止
- 感情のピークが本当に衝撃的か？平坦に流れていないか？

### 繋ぎの章
- 認知負荷の許容値を下げる（読者はここで最も忍耐が弱い）
- 繋ぎの章で大量の新設定を入れない
- 認知負荷 ≥4 で不合格
- ページターナー力下限3。それ以下は「繋ぎ」が「無駄」になっている
