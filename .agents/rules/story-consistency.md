# Story Consistency Rules

設定・構成・追跡ファイルを変更する際に従うべき一貫性ルール。

## Rules

1. **設定変更時は必ず追跡/を確認**：キャラ設定や世界観ルールを変更した場合、追跡/配下の伏線.md や時間線ファイルを確認し、既存の伏線と矛盾しないことを担保する。

2. **新規キャラ追加時は独立ファイルを作成**：主要キャラには個別の設定ファイルを作成し、関係.md（存在すれば）も更新する。

3. **時間線変更時は同期更新**：時間の前後関係（イベント発生時点）を変更した場合、時間線.md も忘れずに更新する。

4. **設定変更は文脈.md に記録**：重要な設定判断はすべて追跡/文脈.md の「最近の判断」セクションに記録する。

5. **一貫性チェックは grep を使う**：記憶に頼らず、grep で検証する。よく使うチェックコマンド：
   - キャラ属性：`grep -rn "キャラ名" 設定/ 本文/ | grep "属性キーワード"`
   - 時間線：`grep -rn "第.*日\|.*後\|過ぎた" 本文/`
   - 世界観：`grep -rn "世界観キーワード" 設定/ 本文/`
   - 伏線状態：`grep -rn "伏線#" 追跡/`

6. **水増し検出シグナル**（出現したら警告）：章全体で会話に新情報がない、同一感情が3段落以上続く、キャラの回想に新しい視点がない、2章連続で衝突がない。

7. **伏線債務の追跡**：伏線の設置と回収のバランスを数値化する。
   ```
   CC = status=active の伏線数 - status=resolved の伏線数
   ```
   - CC = 0：伏線の収支が完全にバランスしている
   - CC > 0 かつ ≤ 2：物語上の負債は管理可能
   - CC > 2：**警告。伏線負債が過重**。新規伏線の設置を一時停止し、回収を優先する
   
   CCは各章の品質チェック時に再計算し、`追跡/伏線.md` に記録する。

## Examples

### Correct
```
橘誠の資産額を「6000万円」に変更した場合：
1. 追跡/伏線.md に資産額に依存する伏線がないか確認
2. 追跡/文脈.md を更新: [2024-05-05] 橘誠の資産額を6000万円に変更
3. 時間線ファイルがあれば、第45章の時点と矛盾しないか確認
```

### Wrong
```
設定/キャラ/橘誠.md の資産額を直接書き換え、関連ファイルを一切確認しない。
結果：第20章の「橘誠の資産は3000万円」という伏線と矛盾が生じる。
```
