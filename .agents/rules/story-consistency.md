# Story Consistency Rules

設定・構成・追跡ファイルを変更する際に従うべき一貫性ルール。

## Rules

1. **設定変更時は必ず追跡/を確認**：キャラ設定や世界観ルールを変更した場合、追跡/配下の伏筆.md や時間線ファイルを確認し、既存の伏線と矛盾しないことを担保する。

2. **新規キャラ追加時は独立ファイルを作成**：主要キャラには個別の設定ファイルを作成し、関係.md（存在すれば）も更新する。

3. **時間線変更時は同期更新**：時間の前後関係（イベント発生時点）を変更した場合、時間線.md も忘れずに更新する。

4. **設定変更は上下文.md に記録**：重要な設定判断はすべて追跡/上下文.md の「最近の判断」セクションに記録する。

5. **一貫性チェックは grep を使う**：記憶に頼らず、grep で検証する。よく使うチェックコマンド：
   - キャラ属性：`grep -rn "キャラ名" 設定/ 本文/ | grep "属性キーワード"`
   - 時間線：`grep -rn "第.*日\|.*後\|過ぎた" 本文/`
   - 世界観：`grep -rn "世界観キーワード" 設定/ 本文/`
   - 伏線状態：`grep -rn "伏線#" 追跡/`

6. **水増し検出シグナル**（出現したら警告）：章全体で会話に新情報がない、同一感情が3段落以上続く、情景描写が500字を超えて話が進まない、キャラの回想に新しい視点がない、2章連続で衝突がない。

## Examples

### Correct
```
沈栀の霊力レベルを「第六層」に変更した場合：
1. 追跡/伏筆.md に霊力レベルに依存する伏線がないか確認
2. 追跡/上下文.md を更新: [2024-05-05] 沈栀の霊力レベルを第六層に変更
3. 時間線ファイルがあれば、第45章の時点と矛盾しないか確認
```

### Wrong
```
設定/キャラ/沈栀.md の霊力レベルを直接書き換え、関連ファイルを一切確認しない。
結果：第20章の「沈栀の霊力は第三層」という伏線と矛盾が生じる。
```
