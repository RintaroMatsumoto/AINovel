# Story Outline Rules

構成ファイルのルール。

## Rules

1. **巻構成の必須項目**：各巻構成（構成_*.md）には以下が必須：
   - 該当巻の目標（主人公が巻終了時に到達する状態）
   - 感情リズム（何章ごとに大きな感情転換点を入れるか）
   - 感情弧（巻全体の感情の起伏）
   - 人物弧（主要キャラの成長・変化）
   - 伏線配置（巻内で張る伏線と回収予定時期）
   - キーとなる反転（巻内で最低1つの反転）

2. **各章計画の必須項目**：各章計画（第XXX章_計画.md）には新版「章設計図」が必要。旧フィールドも互換性のために保持：
   - 旧フィールド：本章の中核イベント、字数目標、目標感情、章頭フック、本章の感情ピーク、章末フック
   - 内容概要（五段式）：起因 / 展開 / 転換 / 山場 / 結末
   - プロット構成（複数線）：主線進行 / 副線進行 / イベント線・タスク線 / 感情線・関係線 / 論理線
   - 人物関係と登場順：実際の出現順にキャラ/勢力/キーアイテムを列挙し、人物関係の変化を記述
   - プロット詳細：プロットポイント列に「誰が何をした + 機能タグ」を書き、代償の顕在化 / 利益の獲得を明示
   - 結末設定とフック：収束状態、未解決問題、次章への推進力、章末フック

3. **段階的書き込み**：構成は段階的に書く——最初に骨格（キーイベントと感情ピーク）、その後セクションごとに詳細を埋める。一度に全詳細を書かない。

4. **本文との同期**：一章の本文を書き終えたら、該当章計画の「実際の完了状況」を更新する。

5. **章頭フックは以下のタイプから選択**（完全な技法は `../skills/story-setup/references/agent-references/hooks-chapter.md`）：
   謎かけ会話開始 | 閃前断片 | カウントダウン開始 | ミステリアスな独白 | コントラスト場面 | 未完了動作開始 | イメージ予兆

6. **章末フックは以下のタイプから選択**（完全な技法は `../skills/story-setup/references/agent-references/hooks-chapter.md`）：
   突然の暴露 | 緊急危機 | 未完了動作 | 身分の反転 | 二者択一の難題 | ミステリーアイテム/手がかり | カウントダウン | 約束/脅威 | 奇怪な消失 | 隠された意味 | イメージフック | エコーフック | 余白フック

7. **各章に感情変化が必要**：章計画には感情の起点→終点を明記（例「平穏→衝撃→怒り」）。2章連続で感情変化がない = 調整必要。

8. **旧版計画との互換性**：既存の旧版計画に「内容概要/プロット構成/人物関係/プロット詳細/結末設定」がなくても、欠落を理由に続行を妨げない。ただし新規作成・補完・改訂時は新版設計図に従う。資料から確定できない副線・関係変化・代償/利益は `[未確定]` と記載し、捏造してはならない。

9. **6つのアイアンルール（情報開示ペーシング）**：各章計画で以下を遵守する：
   1. **先に謎、後に説明** — 各世界観要素はまず謎として現れ、少なくとも1〜2シーン経ってから説明する。読者は「これは何だ？」と思ってから答えを得る。
   2. **先に感覚、後に体系** — キャラはまず世界の要素を感覚で体験（見る・聞く・感じる）。その後で背後にあるルールを理解する。ナレーションによる直接説明は禁止。
   3. **既存を拡張し、新規を増やさない** — 既に導入した概念を深めることを優先する。新しい概念より「既存の概念の新しい側面」を示す。
   4. **概念予算** — 第1章の新概念は最大3つ（0でも可）。以降の各章は最大2つ（0でも可）。各シーンで説明する既存概念は最大1つ。3000字につき最低1つの未解決の問いを残す。
   5. **ナレーション解説禁止** — 世界観情報は以下の手段でのみ伝える：a) キャラの会話（自然に、講義調でなく） b) キャラの行動（やって見せる） c) キャラの観察（発見を通じて） d) 衝突による暴露（矛盾が真実を暴く）。禁止：ナレーション大段落。「周知の通り…」。ガイド役キャラ。心内独白による設定想起。
   6. **必要に応じて開示** — 世界観詳細は現在の対立に役立つ時のみ開示する。Deborah Swiftテスト：「この情報は今、何を引き起こしている？何もないなら削除」。

10. **五問ゲート（書く前の最終確認）**：各章の執筆前に以下の5問をチェックする：
    1. 本章はいくつの新概念を導入する？（概念予算上限以内か？）
    2. 本章はいくつの既存概念を説明する？（各シーン最大1つ）
    3. 本章はいくつの未解決の問いを残す？（3000字につき最低1つ）
    4. すべての世界観情報はキャラの行動/会話/観察を通して伝えられているか？
    5. 「今起きていない」情報はないか？

## Examples

### Correct — 完全な巻構成
```
# 構成_第1巻.md
## 本巻目標
橘誠が資産3000万円から5000万円に突破し、専業トレーダーに加入する。
## 感情リズム
5章ごとに大きな感情転換点（突破/反転/真相判明）
## 感情弧
抑圧→どん底→覚醒→爆発→余韻
## 人物弧
橘誠：忍耐から能動的反撃へ
## 伏線配置
- 伏線#3：古鏡の破片（第8章で設置、第2巻で回収）
- 伏線#7：師匠の正体（第12章で設置、第3巻で回収）
## キー反転
第18章：専業トレーダーの首領は実は橘誠の生き別れた兄だった
```
全ての必須項目が揃い、伏線の回収計画が明確。

### Wrong — 必須項目不足の巻構成
```
# 構成_第1巻.md
## 本巻目標
橘誠が専業トレーダーに加入する。
## 感情リズム
5章ごとに大爽点。
```
感情弧・人物弧・伏線配置・キー反転の4項目が不足。
