# Story Narrative Rules

ディープリーディング・対比分析・設定ファイルにおけるナラティブルール。

## Rules

1. **設定のクロスチェック**：設定を新規追加・変更する場合、既存設定との矛盾をクロスチェックする。方法：既存設定ファイルのキーワードをgrepで確認し、衝突がないことを確認する。

2. **言語スタイルの一貫性**：キャラクターの会話は、当該キャラの言語スタイルアーカイブ（口調、語彙の癖、感嘆符の使用頻度など）に一致させる。

3. **世界観ルールの明確化**：力体系、社会ルールなど「可能」と「不可能」を明確に設定ファイルに記録し、本文でも一貫して遵守する。

4. **謎には文書化された「真の答え」が必要**：設定されたすべての謎・ミステリーは、追跡/ または 設定/ ファイルに明確な真の答えを記録する。曖昧なままにしてはいけない。

5. **キャラの動機と関係は内的に自己矛盾しない**：キャラの行動は設定された動機に従わねばならず、関係の変化には合理的なトリガーイベントが必要。

6. **AI口調の禁止**（レッドライン）：
   - 章末の総括・昇華・教訓的締めの禁止（「彼はようやく理解した……」「この夜は誰も眠れなかった」）
   - 「彼は感じた／思った」による直截的な感情描写の禁止。身体反応で代替する（「手のひらが汗で濡れていた」＞「彼は緊張していた」）
   - 2段落以上の純粋な心理活動の禁止。動作・会話を交えること
   - 万能比喩の禁止（「波のように」「稲妻のように」）。使うなら日常的な具体比喩に
   - 全キャラの話し方を同一にしてはならない。各キャラは7次元の言語スタイルアーカイブに従う（口癖、リズム、情報の好み、立場、身分による語彙、性格と口調、距離感の変化）

7. **会話の三機能テスト**：各会話を削除して確認——プロットは進むか？ 期待感は残るか？ 感情は伝わるか？ 三つすべてNO＝水増し、削除。

## Examples

### Correct — 設定のクロスチェック
```
新規設定：霊力レベルは九層に分かれ、最高は第九層「破境」。
実行手順：
1. grep 設定/ ディレクトリ内の全ファイルで他の霊力体系がないか確認
2. grep 追跡/伏筆.md の「霊力」キーワードで矛盾する伏線がないか確認
3. 追跡/上下文.md を更新：[2024-05-05] 新規霊力九層体系を追加
```
新規設定追加前に既存設定と伏線を能動的に検索し、矛盾を回避する。

### Wrong — 設定未クロスチェック
```
設定/世界ルール.md に直接「霊力レベルは十層」と追加。
結果：既存設定ファイルには「霊力最高九層」とあり、矛盾が生じる。
かつ追跡/伏筆.md に「九層」設定に依存する伏線が存在する。
```
既存設定を確認せずに新規追加したため、世界観に矛盾が生じる。

### Correct — 謎は文書化された真の答えを持つ
```
本文第15章に記述：密室の古い鏡に見知らぬ顔が映る。
追跡/伏筆.md 記録：伏線#12（第15章 古鏡の見知らぬ顔）→ 真の答え：沈栀の前世の記憶の残留投影。回収予定：第38章。
```
各謎は追跡ファイルに明確な真の答えと計画的な回収タイミングを持つ。

### Wrong — 謎が文書化されていない
```
本文第15章に記述：密室の古い鏡に見知らぬ顔が映る。
追跡/伏筆.md に記録なし。
第40章まで書いた時点で、この謎を忘れるか、既存記録と矛盾した説明をしてしまう。
```
謎が文書化されていないため、忘れられたり自己矛盾を起こしたりする。
