# 題材フレームワーククイックリファレンス

> **用途**：拆文と大綱作成時に対照して使用。あなたは熟練した網文構造アナリストです。以下のルーティングテーブルに従い対応フレームワークを選択し、構造比率と感情ビートを厳守してください。

## 拆文の尺度として使用する場合

本ファイルは元々執筆側のプレイブックであり、書き方は「どう書くか」です。`story-short-analyze` で拆文する際は**对照尺度**として使用します——拆文の動作は、原文を本ファイルが記述する標準パターンと比較し、該当作品がどのパターンを使用しているか、どの程度実践できているかを特定することです。本ファイルに従って新作を書くのではありません。

読者視点の判断：本ファイルが記述するのは、番茄小説短編 / 故事会 / 追妻 / 世情 / 重生 / 虐渣 など通俗短編業界の工業標準テンプレートであり、拆文レポートの「再利用可能な構造 / 反転設計 / 題材公式」などのセクションの对照ソースです。

---

## 題材選択ルーティング

以下の条件に従い対応フレームワークを迅速に特定します。まず大分類を判断し、次に具体的なバリエーションを確認します。

| ストーリーの核が... | このフレームワーク | 備考 |
|---|---|---|
| 男性が女性を傷つけ、去ってから後悔するが取り戻せない | **追妻火葬場** | 女性が出て行った後に戻らないのが核心 |
| 前世で無惨に死に、重生して情報格差で復讐する | **重生復讐** | 敵役は階層的に重ねる |
| パートナーの浮気/企み、独立への覚醒 | **不倫/恋愛** | 発覚プロセスにサスペンスが必要 |
| 奇人/悪人が善人を虐げ、悪に報いが来る | **世情** | 大事件より細部描写で見せる |
| ヒロインが虐げられ死亡、男主が死後悔いる | **死者文学** | 核心は「間に合わない」 |
| 特殊な出会い、男主の甘やかし寵愛 | **霸総/甘寵** | 甘さの密度が粘着性を決める |
| 底辺から成り上がり、レベルアップして戦う（都市+武道） | **都市高武** | 金銭駆動+段階的マップ |
| 落ちこぼれ/落魄天才、修仙世界で頂点を極める | **仙侠/玄幻** | 力体系が明確でなければならない |
| 独自のチート/創造的設定が核の売り | **脳洞文** | 核心のネタがレースを決める |
| 主人公に才能がなく、慎重な駆け引きで生き残る（修仙） | **凡人流** | 利害の秤がコアパターン |
| 穿越/重生して歴史的岐路で運命を変える | **歴史/架空歴史** | 情報格差＝最大のチート |
| 芸能界で才能を披露し、周囲が驚愕 | **文芸/芸能界** | 反応連鎖がコアの書き方 |
| ユーザーが明確な目標 IP、プラットフォームが許可し、最近のサンプルが有効 | **同人流** | 「既知の世界＋新変数＋名场面書換」構造のみ抽出。具体的 IP 一覧は保持しない |
| プレイヤーがルールダンジョンに引き込まれ生存をかける | **ルール怪談** | チートは合理的な外見で包む |
| 主人公が長生し、時の移ろいを見届ける | **長生流** | 凡俗の時期が最も面白い |
| その他（西幻/新媒体/コメディ/無限流/懸疑/高武/後悔流） | **その他題材クイックリファレンス** | 各々要点あり、必要に応じて参照 |
