# 出力テンプレート

`story-short-analyze` の出力テンプレート定義。

## 分解レポートテンプレート

```markdown
# {作品名} 分解レポート

> このレポートは story-short-analyze パイプラインにより自動生成されました。

## 基本情報
- 作品名：{作品名}
- 著者：{著者}
- 文字数：{文字数}
- 題材：{題材フレームワーク分類}
- 総合スコア：{S/A/B/C}

## ストーリー核
{100〜200 字の内容要約＋コア反転}

## 構造分析
- 起：{段落}
- 承：{段落}
- 反転：{段落}
- 結：{段落}

## 感情曲線
{グラフ/説明}

## キャラ分析
{主要キャラの簡潔な分析}

## フック分析
{冒頭フック + 章末フックの分析}

## 市場分析（オプション）
{題材の市場パフォーマンス + 改善提案}
```

## プロットノードテンプレート

```json
{
  "nodes": [
    {
      "セクション": 1,
      "機能": "導入/発展/反転/結末",
      "コアイベント": "",
      "感情": ""
    }
  ]
}
```
