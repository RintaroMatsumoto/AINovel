# 題材別ライティング公式

各題材の標準的なライティング公式と構造テンプレート。

## 追妻火葬場

```
導入（女主の決意）→ 回想（男主の傷害）→ 離脱（女主の離別）→ 男主の後悔 → 追妻 → （男主の失敗）→ 結末（離別 or 再会）
```

### 文字数配分
- 導入〜離脱：25%
- 男主の後悔〜追妻：50%
- 結末：25%

### 感情曲線
女主の苦しみ（下降）→ 決意（底）→ 男主の後悔（上昇）→ 追妻の苦しみ（ピーク）→ 結末（余韻）

## 重生復讐

```
重生（情報格差確立）→ 前期布局 → 第一段階の敵を破壊 → 中期発展 → 第二段階の敵を破壊 → 最終ボス → 結末
```

### 文字数配分
- 重生〜前期布局：20%
- 敵の破壊（各段階）：60%
- 結末：20%

### 爽点リズム
小爽点 → 中爽点 → 小爽点 → 大爽点 → 最大爽点

## 霸総甜寵

```
特殊な出会い → 強制的な同棲/契約 → 男主の寵愛 → 女主の動揺 → 外部の障害 → 感情の確認 → 結末
```

### 文字数配分
- 出会い + 強制同棲：30%
- 寵愛 + 動揺：40%
- 障害 + 確認：20%
- 結末：10%

## 世情

```
善人の抑圧（詳細に書く）→ 我慢の限界 → 善人の反撃/外部の介入 → 悪人の報い → 結末（正義の回復）
```

### キーポイント
- 抑圧の詳細が爽点の強さを決める
- 報いの方法が読者の満足度を決める
- 善人の我慢に理由を持たせる（家族のため等）
