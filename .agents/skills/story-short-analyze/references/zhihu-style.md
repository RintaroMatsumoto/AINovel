# 知乎塩言ストーリースタイル参考

> 知乎塩言ストーリーを書く/分析する際に読み込む。まず塩言のスタイル特徴を確認し、次にチェック項目で1つずつ对照する。

## 判定ルーティング

| シーン | この部分を使用 | 操作 |
|------------|-----------|------|
| 塩言ストーリーを書く | 塩言コアスタイル特徴 + タイプ感情パターン | 一人称、`「」` 会話、短文に厳格に限定 |
| 塩言ストーリーを分析する | 分析時の塩言チェック項目 | 視点/フォーマット/句式/反転位置を1つずつチェック |
| プラットフォームの差異を比較 | プラットフォームスタイル差異 | 知乎 vs 番茄 vs 小红书 3列比較 |

## 塩言コアスタイル特徴

| 特徴 | ルール |
|------|------|
| 視点 | 一人称に限定、全知描写は出現しない |
| 会話フォーマット | `「」` を使用、独立した段落、発言者タグは簡潔 |
| 句式 | 短文主体、一文一情報、長い複文を避ける |
| 排版 | 段落頭に全角スペース2つ、段落間に空行なし、章間に1空行 |

## 分析時の塩言チェック項目

| チェック項目 | 説明 |
|--------|------|
| 視点一貫性 | 終始一人称、視点の跳躍がないか |
| 会話フォーマット | 統一 `「」`、引用符の混用なし |
| 句式密度 | 短文比率 >70% |
| 口語度 | 書面腔/翻訳腔の残存がないか |
| 感情リズム | 明確な感情曲線があるか（塩言は感情の引きを最も重視） |
| 反転位置 | 70-85% の位置か（塩言標準位置） |
| 章末フック | 各章末にフックがあるか |

## 塩言タイプと感情パターン

| タイプ | コア感情 | 典型的反転 |
|------|----------|----------|
| 虐恋 | 割り切れない思い | 彼は実は彼女を愛していた |
| 重生 | 爽快感の解放 | 今世では同じ過ちを繰り返さない |
| 懸疑 | 考えれば考えるほど怖い | 犯人はすぐそばにいる |
