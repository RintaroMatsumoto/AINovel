# 出力契約

`story-short-analyze` パイプライン出力の品質契約。各フェーズの出力形式と検収基準を定義する。

---

## 契約原則

- 各フェーズの出力は次のフェーズの入力として使用可能
- 出力形式はバージョンアップによる破壊的変更を避ける
- 出力内容は再現可能（同じ入力 → 同じ出力）

---

## Phase 1 出力契約

### 基本情報

```json
{
  "作品名": "",
  "著者": "",
  "出典": "ファイルパス / URL / 直接テキスト",
  "読み取り日時": "ISO 8601",
  "全文文字数": 0
}
```

### 原文保存

`材料/元テキスト.md` に全文を保存。Markdown フォーマット保持。
