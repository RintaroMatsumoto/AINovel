# サスペンスフック技法

サスペンス型フックの設計技法。

## サスペンスの基本構造

```
情報隠蔽 → 部分暴露 → 読者の推測 → 更なる情報 → 完全暴露
```

### 情報隠蔽の原則
- 早すぎる完全暴露を避ける
- 各暴露は次の疑問を生む
- 読者の推測は常に真実より少し遅れる

## サスペンスのタイプ

### 情報サスペンス
読者が真実を知りたいと思わせる。
手法：
- 重要な情報を明かさない
- 断片的な情報で想像させる
- 誤った方向に誘導する

### 運命サスペンス
読者がキャラの運命を気にかけさせる。
手法：
- キャラを危険にさらす
- 選択の余地のない状況を作る
- 時間制限を設ける

### 関係サスペンス
読者がキャラ間の関係の進展を気にかけさせる。
手法：
- 誤解を利用する
- 身分の秘密を利用する
- 三角関係を利用する

## サスペンスフック配置

- 段落最後にサスペンスを残す
- 章末に未解決のサスペンス
- ストーリー前半で謎を提示し、後半で回答
- サスペンスの答えは予想外だが合理的
