# キャラ関係と感情線操作マニュアル

## 拆文の尺度として使用する場合

本ファイルは元々執筆側のプレイブックであり、書き方は「どう書くか」です。`story-short-analyze` で拆文する際は**对照尺度**として使用します——拆文の動作は、原文を本ファイルが記述する標準パターンと比較し、該当作品がどのパターンを使用しているか、どの程度実践できているかを特定することです。本ファイルに従って新作を書くのではありません。

読者視点の判断：本ファイルが記述するのは、番茄小説短編 / 故事会 / 追妻 / 世情 / 重生 / 虐渣 など通俗短編業界の工業標準テンプレートであり、拆文レポートの「再利用可能な構造 / 反転設計 / 題材公式」などのセクションの对照ソースです。

| キャラ目標と関係線 | キャラ目標の独立性 + 関係線設計 |

## 人物関係タイプ

表でキャラ間の関係タイプを特定し、原則に従って実行します。

| 関係タイプ | 定義 | 機能 | 例 |
|---------|------|------|------|
| 衝突型 | 双方の利益/理念が対立 | 緊張を生み、プロットを推進 | 宿敵、競争相手 |
| 同盟型 | 双方に共通目標がある | 助力を提供、絆を生む | 戦友、師弟 |
| 親密型 | 感情的なつながり | 弱点を作り、感情の支点を提供 | 恋人、家族、兄弟 |
| 権威型 | 上下/支配関係 | 圧力を生み、主人公の行動を制限 | 師匠、上司、監視者 |
