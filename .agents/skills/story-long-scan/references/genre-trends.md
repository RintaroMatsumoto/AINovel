# 網文題材トレンドと流派参考
題材選択、流派執筆の要点、スキャン技術のクイックリファレンス。

## 脳洞文創作

### インスピレーションから成書まで

1. アイデアを得る（チートの原型/画面/切り口）
2. 可能性を評価（純粋なオリジナル？市場の下地あり？）
3. 題材とマッチング（既知の題材に入れて効果を見る）
4. コア売りを抽出（感情ギャップ/期待感に変換できるか）
5. ストーリーの原型を整理（枠組み/チート/切り口）
6. 執筆して検証

### チートの創新

基本＝条件を満たす→フィードバックを得る。変形：多条件一フィードバック / 段階的フィードバック / 確率的フィードバック / フィードバック重ね合わせ可

### 長期連載方法

1. コア売りから多角度を見つけ、異なる矛盾パターンを帰納、各パターンで1〜2巻執筆
2. 枠組みの重ね合わせ：多角度を交錯させ、数百万字を循環的に支える
3. 枠組み+小プロットの循環：大目標→中目標→小目標→細綱

### フォロワー＝皮の張り替え

コア設定を丸ごと借りて、使い慣れた題材に変更。チート系は全題材と互換性あり。同題材のフォロワーは基本感情を保持し別角度に変更。

## 追読モジュール

1. 爽点の核心：爽点の前に期待/危機/抑圧を敷く。爽点自体が読者の予想を上回る
2. 章末フック：章末にサスペンス/新情報/感情ギャップ
3. 段階的爽点：小爽点を積み重ねて大爽点へ

## 流派執筆要点

### 凡人流
- 核心パターン：主人公が慎重に駆け引き、情報格差を利用、段階的に突破
- 読者の期待：主人公が策士、一歩一歩確実に進む
- 爽点設計：段階的突破＋情報格差の優越感

### システム文
- 核心パターン：システムが明確な目標とフィードバックを提供
- 注意点：システムだけに頼らず、システムを触媒として主人公自身の成長を促す

### 大奉打更人式
- 核心パターン：探偵要素と仙侠の結合、詭異な雰囲気＋ユーモア
- 構造特徴：各ユニットに独立した謎解き＋伏線、大BOSSが全体を貫く

### 情報格差文
- 重生/穿越を利用した情報格差が売り
- 注意点：情報格差を段階的に消費、一気に全部使わない
