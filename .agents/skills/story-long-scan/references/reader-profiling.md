# 読者ペルソナシステム

## 9 次元ペルソナ

| 次元 | 内容 | 例 |
|------|----------|------|
| プラットフォーム | 起点/番茄/晋江/知乎/七猫 | 起点＝課金ヘビー、番茄＝無料・地方都市 |
| タグ | 題材タグが読者の期待を決定 | 「システム文」を見て成長リズムを期待 |
| 読書量 | 低読書量と高読書量で耐性が異なる | 高読書量読者はパターンを認識、低読書量読者はパターンに敏感 |
| 性別 | 男性向け女性向けで審美が大きく異なる | 男性向けは爽を重視、女性向けは感情を重視 |
| 年齢 | 16-25 vs 25-35、代入する役割が異なる | 05後大学生 vs 90後社会人 |
| 地域 | 一線都市 vs 地方都市マーケット | 北上広深 vs 三四線都市 |
| 学歴 | 文体とロジックへの要求に影響 | 大学生 vs 中学中退 |
| 階層 | 底辺/中間層/富裕層 | どんな逆転が共鳴するかを決定 |
| 社会的役割 | 学生/ママ/サラリーマン/フリーランス | どんな日常に没入感があるかを決定 |

ペルソナ組み合わせ例：「起点＋古代官場＋皇位継承＋文抄＋高読書量＋女性＋05後＋二線都市＋大学生＋中間層」→ リズム速、権謀爽、感情線甘いが馬鹿甘ではない、文化梗は新しめ

## ペルソナ連想要素法（70/20/10）

読者の共鳴を構築する 3 層比率：

- **70% ノスタルジー要素**：読者が似た経験をしたシーン
- **20% 現在の生活**：読者が直面している現在のプレッシャー
- **10% 話題のホットトピック**：今流行りのネタと話題
