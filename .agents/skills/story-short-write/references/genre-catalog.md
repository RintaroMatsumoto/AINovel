## ショートドラマ題材

### 感情類（女性読者向け）

**家庭倫理／嫁姑**
- 経典設定：虐められ妻 → 覚醒 → 離婚 → 逆襲
- 爽点設計：公の場での対決（結婚式や高級レストランで真実を暴く）
- 感情フック：義実家の侮辱、夫の不理解、子供の絆

**妻追い火葬場／離婚後**
- 経典設定：離婚後、男主が女主の本当の価値に気づく → 追いかけて復縁を懇願
- 爽点設計：女主に優秀な追求者が現れる、男主が酸っぱくなる
- 感情フック：男主の冷酷な態度と後の後悔のギャップ

**契約結婚／先婚後愛**
- 経典設定：利益のための結婚 → 徐々に真実の愛に
- 爽点設計：男主が女主を密かに守る
- 感情フック：契約の期限が来た時の選択

**穿越／重生／古風**
- 経典設定：現代女性が古代に穿越 → スキルを活かして生き残る
- 爽点設計：現代知識で古代を圧倒
- 感情フック：身分のギャップを乗り越えて一緒になる

**年下／身分差恋愛**
- 経典設定：年下男性 × 年上女性、部下 × 上司
- 爽点設計：年下男性が年上より成熟しているギャップ
- 感情フック：周囲の反対や身分の違い

**ミステリー／復讐**
- 経典設定：女主が復讐のために接近 → 真実を知る過程で男主の本当の姿を知る
- 爽点設計：真相が明らかになる瞬間の反転
- 感情フック：愛と憎しみの間の揺れ動き

### 逆襲類（男性読者向け）

**赘婿／隱藏身分**
- 経典設定：主人公が実は凄い → 軽視される → 適切なタイミングで見せつける
- 爽点設計：軽視している人たちを前に身分や実力を暴露
- 感情フック：忍耐の過程で妻や義家族の態度

**神医／鑑宝／特殊能力**
- 経典設定：主人公が特殊能力を身につける → 軽視される環境で驚くべき才能を発揮
- 爽点設計：助ける相手の驚きと感謝
- 感情フック：能力が制限されることへの見返り

**武道／修仙／無双**
- 経典設定：主人公が絶対的な武力を持つ → 圧倒的に進む
- 爽点設計：一拳で敵を倒す爽快感
- 感情フック：敵の過小評価と驚愕

### 軽快類

**軽コメディ／日常**
- 経典設定：日常生活のユーモアやミス
- 爽点設計：ドタバタ劇の過程や意外な結末
- 感情フック：キャラの可愛さや成長

**SF／ファンタジー設定**
- 経典設定：未来世界や異世界の新しい設定
- 爽点設計：高設定下で予期せぬ展開
- 感情フック：設定自体の面白さ

## 火熱題材の重要要素

| 要素 | 説明 | 影響度 |
|--------|------|--------|
| 身分情報差 | 正体を知っているのは読者だけ、キャラは知らない | ★★★★★ |
| 公の場での対決 | 敵対者が大勢の前で面目を失う | ★★★★★ |
| 逆転の切り札 | 主人公が予想外のタイミングで真実を明かす | ★★★★★ |
| 多重反転 | 見かけはAだが実はB、さらにC | ★★★★ |
| 感情の引き裂き | 愛する人からの誤解や裏切り | ★★★★ |
| キャラの成長 | 主人公の明らかな変化や成長 | ★★★ |

## すぐ使える題材判断

### 市場判断

まず題材の市場ポテンシャルを確認：
- 経典題材を選ぶか創新題材を選ぶか？
- この題材の競争はどれほど激しいか？
- この題材の読者層は明らかか？
- 題材選びの参考に競合分析結果があるか？

### クイック創作適性判断

| 質問 | 選択方向 |
|------|----------|
| 感情の動きを書きたい？ | 感情類（女性向け） |
| 逆襲の爽快感を書きたい？ | 逆襲類（男性向け） |
| 軽快なスタイルを書きたい？ | 軽コメディ・日常 |
| 世界観や設定で勝負したい？ | SF・ファンタジー |
| 現在流行っているものに乗りたい？ | 上の市場人気表を参照 |

### 創作前の必須確認

- [ ] この題材の目標読者層は明らかか？
- [ ] この題材のコア爽点は何か？
- [ ] この題材の経典パターンは何か？それを壊すか踏襲するか？
- [ ] 自分の得意な書き方はこの題材に合っているか？
