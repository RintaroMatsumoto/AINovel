# キャラクター基礎設計

> 主人公／脇役／敵役を設計する際に読み込む。まず判断ルートを見て、適切なテンプレートを選び、ステップに従って操作する。character-designer の主な出力参考。

---

## 判断ルート

| 設計対象 | 使用するテンプレート | 参照章 |
|------------|-----------|-----------|
| 主人公 | 主人公カードテンプレート | 第1節 |
| 脇役 | 脇役カードテンプレート | 第2節 |
| 敵役 | 敵役階層表 → 敵役確立四要素 → 敵役性格四段階法 | 第3節 |
| キャラの動機 | 動機連鎖テンプレート → 動機衝突類型 | 第4節 |
| キャラの塑造／深化 | 塑造方法クイック確認（四層法／執念法／反復点／階層展示等） | 第5節 |
| 主人公の特殊問題 | 格／成長／レッドライン／トーンが高すぎる／身份と金手指 | 第6節 |
| 敵役塑造の深化 | 敵役の演出／人設の主人公化 | 第7節 |

## 第1節：主人公カード

### 記入テンプレート

```
名前：
性別：
キャラポジション：（一言で主人公のストーリー上の機能を説明）
身份タグ：（例：ダメ大学生、元特殊部隊員、落ちぶれた皇子）
外見特徴：（3-5個のキーワード、記憶に残るもの）
   例：痩せて高い、いつも古いジャケット、左手に傷跡、だらしない目つき
性格キーワード：（3-5個、必ず矛盾面を持つ）
   例：口は悪いが心は優しい、冷たく見えるが実際は身内を守る、衝動的だが底线はある
核心目標：（全編の終点で何を達成するか）
核心動機：（達成すべき理由——感情駆動、理性駆動ではない）
致命的弱点：（キャラを失敗させる性格上の欠陥、能力上の欠陥ではない）
口癖／象徴的動作：（読者が瞬時に認識するタグ）
```

### 設計ポイント

- 動機は感情レベルでなければならない——「母親の復讐」は「最強になる」より優れる
- 弱点は必ずキープロットで主人公の失敗を引き起こすものでなければ、弱点ではない
- 外見と口癖は読者の記憶アンカーであり、必ず書く必要がある

## 第2節：脇役カード

### 記入テンプレート

```
名前：
性別：
キャラ機能：（導師／味方／情報源／犠牲品／鏡像対照）
主人公との関係：
核心特性：（1-2個のキーワード）
象徴的特徴：（一言で読者に記憶させる）
退場方法：（いつ／どのようにストーリーから退出するか）
```

### 設計ポイント

- 各脇役に明確な機能が必要——機能のないキャラは登場させない
- 脇役の退場は能動的に計画し、書きながら忘れてはいけない
- 同一シーンの脇役は台詞のある者を3人以内にする

## 第3節：敵役設計

### 3.1 敵役階層表

敵役の登場篇幅に応じて対応する階層を選び、表の要求に従って設計する。

#### 小敵役（1-5章）

| 次元 | 要求 |
|------|------|
| 機能 | 単一の小さな弧線の障害 |
| 設計 | 1-2個の鮮明な特徴即可（横柄／欲深／弱い者いじめ） |
| 退場 | 敗北するか暴露され、さっぱりと |

#### 中敵役（10-30章）

| 次元 | 要求 |
|------|------|
| 機能 | 一卷の主要な敵手 |
| 動機 | なぜ主人公と敵対するのか（「純粋な悪」ではいけない） |
| 手段 | 武力／謀略／資源 |
| 格 | 少なくとも主人公に一度勝ち、読者が歯がゆく思うほどに |
| 退場 | 主人公に正面から敗北させ、爽快感が必要 |

#### 大ボス（一卷または数卷）

| 次元 | 要求 |
|------|------|
| 機能 | 一つの段階の核心矛盾を代表する |
| 人物弧 | 完全な人物弧線、自身の目標と論理を持つ |
| 衝突 | 主人公と理念の衝突がある（利益衝突だけでなく） |
| 対決 | 少なくとも一場、主人公を絶体絶命に追い込む |
| 側面 | 読者が「恨みきれない」側面がある |
| 退場 | 儀式感のある最終決戦 + 余韻のある幕切れ |

#### 最終ボス（全編）

| 次元 | 要求 |
|------|------|
| 機能 | 全編の核心矛盾の具現化 |
| 伏線 | 第一章から存在する |
| 対立 | 主人公の目標／動機と直接対立し、ストーリーのテーマの反対を代表する |
| 実力 | 主人公を圧倒し、主人公が変革しなければ勝てない |
| 信念 | 信念を持ち、純粋な狂人／怪物ではない |

### 3.2 敵役設計鉄則

- 敵役の知能／実力が主人公の価値を決める——敵役が弱い = 主人公が勝っても意味がない
- 敵役の行動には内在的論理がなければならない（彼の視点から見て筋が通る）
- 敵役の知能を下げて主人公に勝たせてはいけない

### 3.3 敵役確立四要素

順に操作、どれも欠かせない：

1. **実力展示**——登場時に実力や手段を示す
2. **動機の信頼性**——敵役の視点から見て行動が筋が通っている
3. **現実の脅威**——少なくとも主人公に一度勝つ
4. **最終意図のタイミング**——本当の目的はキーとなる反転ポイントまで取っておく

### 3.4 敵役性格確立四段階法

| 段階 | 操作 |
|------|------|
| 1. 敵役にも夢がある | 敵役の目には彼が自身の物語の主人公 |
| 2. トラウマ的過去を掘る | 誰が育てた？誰が愛した？誰が傷つけた？何の苦痛を避けている？ |
| 3. 性格欠陥を磨く | 逆境で積極的特性を発動せず、欠陥を磨く——「優位性」自体が致命的欠陥 |
| 4. 敵役は主人公の鏡 | 敵役の長所が主人公の弱点を映し出し、両者が完全に相反する = 出会うたびに摩擦 |

### 3.5 敵役の存在感を高める鍵

- 障害は敵役の人設から来るもので、故意に主人公に障害を作るのではない
- 敵役演出の公式：明確な動機 → 動機が行動を駆動 → 行動が障害を形成 → 障害の強度は敵役の存在感に由来
- 敵役が異常に強い時、主人公は「高度」「知的」「予想外」に破らなければならない

## 第4節：動機設計

### 4.1 動機連鎖テンプレート

```
起因（Cause）    → キャラが何を経験したか
意図（Intent）   → キャラが何をしたいか
制約（Constraint）→ 何が彼を妨げているか
リスク（Risk）     → 失敗の代償は何か
```

**例**：
```
起因：母親が仇敵に殺害された
意図：犯人を見つけて復讐する
制約：犯人は当代の権臣で、主人公はただの平民
リスク：復讐に失敗すれば皆殺し、成功すれば現在の生活全てを失う
```

### 4.2 動機連鎖設計ポイント

- 起因は具体的でなければ——「いじめられた」では不十分、「衆人環視の中で平手打ちされた」でなければ
- 制約は強力でなければ——さもなければ主人公が一路圧倒して緊張感がない
- リスクは現実的でなければ——読者は主人公が本当に重要なものを失う可能性があると信じなければならない
- 動機はプロットに応じて変化してもよいが、急変してはいけない

### 4.3 動機衝突類型

キャラに内的葛藤が必要な場合、下表から一種の衝突型を選ぶ：

| 類型 | 定義 | 例 |
|------|------|------|
| 目標 vs 道徳 | したいこととすべきことの衝突 | 復讐したいが無辜を巻き込みたくない |
| 感情 vs 利益 | 感性と理性の葛藤 | 相手が頼りないと知りながらも手放せない |
| 短期 vs 長期 | 目の前の利益と遠大な目標の矛盾 | 妥協して命を守る vs 原則を貫いて未来に賭ける |
| 自己 vs 他人 | 個人の欲求と他者の期待の衝突 | 平穏な生活を望むが家族の使命を背負っている |

## 第5節：キャラ塑造方法クイック確認

### 5.1 キャラ塑造核心原則

**主人公の行動三必須**：
1. **理解可能でなければならない**——読者は主人公がなぜそうするのか理解できなければならない
2. **共感可能でなければならない**——主人公の思考に読者は没入できなければならない
3. **受容可能でなければならない**——主人公の価値観を読者は受容できなければならない

**表示は告知に優る**：
- キャラの目的 → 行動で示し、ナレーションで説明しない
- キャラの行動 → 具体的な動作と決定、形容詞の堆積ではない
- キャラの態度 → 会話と反応で示し、心理独白ではない

### 5.2 人物特性を表示する方法

| 方法 | 操作 | 例 |
|------|------|------|
| 敏感性 | 弱点に触れ、反応の仕方を見る | 慌てふためく／慌てて逃げる／注意をそらす＝異なる性格 |
| 逃避 | 回避行動を示して弱点を示唆 | キャラの「しないこと」は「したこと」より深層の性格を明かす |
| 正→欠の順 | まず魅力的特性を示し、次に欠点を明かす | 読者が先にキャラを好きになれば、欠点を許容できる |

### 5.3 四大性格属性

| 属性類別 | 定義 | 設計ポイント |
|---------|------|---------|
| 道徳属性 | 善悪の信念 | 他の性格形成に影響 |
| 達成属性 | 目標達成を推進 | 道徳属性と一致し、目標に奉仕 |
| 相互作用属性 | 他者との交流方式 | 最も数量の多い積極的特質 |
| 身份属性 | アイデンティティ感 | 個性の基本的構成要素を定義 |

選択技巧：一つの特性を主要特性とし、他は補助とする。

### 5.4 キャラ塑造四層法

| 層 | 方法 |
|------|------|
| 共感作用 | 冒頭でキャラを増やしすぎず、まず読者に主人公を理解させ期待を持たせる |
| 最小特徴（タグ） | 主人公は内から外へ、脇役は外から内へ塑造（タグ付け） |
| キャラの不誠実 | 言うこと≠思うこと、挙動≠態度、日常と弁当はキャラを深化させる二極 |
| キャラのスポットライト | 脇役は主人公と強い関連性を持たなければならず、脇役が主人公を圧倒する時は新脇役を塑造して光彩を奪う |

### 5.5 人物塑造と人物真実

| レベル | 定義 | 例 |
|------|------|------|
| 人物塑造（顕型） | 読者が第一眼で見る特性 | 外見は可愛いロリータ |
| 人物真実（潜在） | キャラの内在的真实の姿 | 実際は冷血な殺し屋 |
| 価値取向（内隱） | キー選択時に決定作用を果たす価値観 | 道義と野心の間で野心を選ぶ |

操作ポイント：価値取向は最初から明かさず、キー選択時に自然に露見させる；人物真実の開示が遅いほど、劇的緊張が強まる。

### 5.6 人設階層展示法

| 層 | 操作 |
|------|------|
| 第一層 | 読者に類型モデルを伝える（ロリ／お姉さん／人妻） |
| 第二層 | 特徴タグを貼る（巨乳／長脚／小麦色の肌） |
| 第三層 | 性格の原因を探る（家庭／内在的衝動） |
| 第四層 | 打破——可愛くて天然ボケだが実は全てを知っている、人設が即座に昇華 |

記憶の深化：反復語彙を惜しまない。幼稚すぎると思う？実は記憶を深めている。

### 5.7 人物経験三線時間法

| 時間線 | 内容 |
|--------|------|
| 過去 | 生い立ち背景、遭った変故、性格の成因 |
| 現在 | 主人公との関係位置、現在の相互作用パターン |
| 未来 | 強くなる動機や危機を生む（先生が誘拐される／ヒロインが捕まる／敵役の正体暴露） |

### 5.8 脇役執念設定法

読者にサブ脇役を素早く認識させる：

- キャラに一つの執念を与える → 全ての行動／趣味／性格が執念を中心に展開
- 毎回執念に合致する必要はなく、執念と矛盾することを書かなければ十分で、キー時に明かす
- 極端すぎる執念 → 「親しみやすい」小さな詳細を加える → 読者の同意を得やすくする
- 適用：サブ脇役、頻繁に登場する主要脇役には不向き

### 5.9 人物行動反復点設計

長編で歪まないためのキー手法：

- 一人の人物行動特性を掴んで繰り返し書く
- 構築方法：読者がどのタイプを好きかを確定 → 行動に具体化 → 異なるシーンで反復
- 人物の見どころ + 核心の見どころ = 階層感、両者の循環で差別化を生む
- 敵役／脇役にも反復する見どころが必要で、読者に愛される敵役は読者の新鮮感を増す

### 5.10 人設に沿って行動を書く

行動、言語、思考は全て人格に沿って展開する。プロットの都合でキャラに人設に合わない行動をさせる必要がある場合 → 先にプロットを修正し、人設を変えない。

### 5.11 人が事件を押す vs 事件が人を押す

| 駆動方式 | 特徴 |
|---------|------|
| 人が事件を押す | プロットは人物の性格／動機／選択の自然な結果であり、人物弧光を深化させる |
| 事件が人を押す | 外部事件が平衡を破り、本当の自分を露呈せざるを得なくする |

行き詰まった時 → 人物動機から方向を探り、無理にプロットを編まない。

## 第6節：主人公の特殊問題

### 6.1 主人公の格

- 主人公には格が必要——これは読者の没入基盤
- 知能を下げるような内心劇や下品な言葉を書きすぎない
- 主人公は完璧でなくてもよいが、軽蔑されるような存在であってはならない

### 6.2 主人公の成長

- 成長は実力だけでなく、精神と選択にも現れる
- 毎回の成長にはトリガーイベントと内省的思考が必要
- ネット小説の主人公の成長は必須ではない：冒頭から価値観の完成した正常な人の方が没入しやすく、安定した人設自体が魅力

### 6.3 主人公レッドライン

以下の類型の主人公は絶対に書いてはいけない：

| 禁止 | 理由 |
|------|------|
| 聖母型主人公 | 読者は痛快さを求め、道徳説教ではない |
| 無脳戦闘機械 | 感情的な共鳴を生みにくい |
| 内核が邪悪 | 読者が没入できない |
| 愚か／聖母でミスをする | 読者が許せない |
| 自暴自棄 | いじめられるより読者に嫌われる |

### 6.4 主人公のトーンが高すぎる場合

**危険信号**：
- 成長の余地を失う——能力／地位／資源が天井に達する
- プロットに緊張感がなくなる——「雑魚を切り刻む」の繰り返しに陥る
- 読者が追う動機を失う

**化解方法**：
- **勢いを抑え人を抑えない**——勢いと期待は抑えるが、主人公自身の能力や尊厳は抑えない
- **次元の差を残す**——ある面では強くても、他の次元は短板である
- **過剰収穫法**——見かけ上の収穫は大きいが、主人公が計算するとさらに大きいことがわかる

### 6.5 主人公の開幕人設

- 人設は選択を通じて確立される。開幕で主人公に選択をさせなければならない
- 知略型の幕開けは暴力型より人設が立ちやすい
- 読者は「賢いが普通の」主人公に没入しやすく、「最初から無敵」の主人公ではない

### 6.6 主人公の二つの身份と二つの金手指

| 次元 | 定義 | 作用 |
|------|------|------|
| 顕性身份 | 社会的身份／職業+状態 | 前期の矛盾を集め、必ず絶えずアップグレードまたは変更 |
| 潜在身份 | 非凡な生まれ来历 | 中后期の矛盾を集める |
| 顕性金手指 | システム／玉飾り／前世の記憶 | 冒頭で獲得し全編を貫く |
| 潜在金手指 | 主人公の性格 | 主人公を普通と違わせるものが金手指 |

**最良の写法**：前期は金手指で格を上げる → プロット進行に伴い徐々に人設を明確に
**人設と全編の氣質**：主人公の人設は世界の基調と合致しなければならず、四つのポイントが高度に統一される：社会的身份+生まれ+金手指+性格

### 6.7 性格単一欠陥型主人公+動物仲間体系

主人公の性格を意図的に単一にする場合 → 読者の没入排斥感を低減 → 少なければミスも少ない → 没入感を最大限度に高める。

**問題**：性格が単一すぎる → 精彩さに影響 → ストーリーを進めにくい
**解法**：無関心型主人公に3-5匹の動物仲間を配备し、それぞれ異なる性格にする。

| 仲間類型 | 機能 |
|---------|------|
| バカ可愛い型 | 笑い担当、主人公がヘマをするのは不適だが動物なら可 |
| 賢く口が悪い型 | 言い換え担当、主人公が言うべきでないことを代弁し、主人公の格を保持 |
| 正直バカ型 | ギャップ萌え担当 |
| 奇特能力小心型 | 能力補完担当 |

### 6.8 核心感情と表現欲の平衡

- 欲求の内核は変わらず、変わるのは形式のみ
- 一段のプロットを書いた後、読者の立場で核心から逸れていないか検証する
- 主人公がすごくなったら必ず何かを得なければならず、払うだけで報われないのはダメ
- 表現欲が旺盛な時が最も逸れやすい——能動的にチェックする必要がある

### 6.9 勢いを抑え人を抑えない：矛盾の正しい來源

**誤った做法**：敵役に理由もなく主人公を狙わせる。背後に論理が成立しない。

**正しい做法**：敵役は自身の目的を持ち、行動が客観的に主人公の困境を引き起こすが、意図的に主人公個人を狙ったものではない。

**矛盾連鎖**：敵役の目的 → 主人公の所属集団を抑圧する（勢いを抑える） → 主人公が覆す → 底辺は依然として無感覚 → 主人公が路径を変更 → 新しい衝突が自然に発生

核心：全ての人は自分が欲しい利益に駆動され、背後には異なる価値観があり、さらに深くは育った環境、最も深層は世界観。

## 第7節：敵役塑造の深化

### 7.1 敵役塑造核心原則

- 古典的敵役には必ず完全な世界観と論理的に自己完結した価値観がある
- 同じ外部事件が異なる人に起きると異なる変化を生む——外因と内因の共振
- 敵役の塑造は外部事件だけで、内在的価値観と内在的論理が欠けてはならない

### 7.2 敵役人設の主人公化写法

**伝統的問題**：マップチェンジ後、元の敵役がペースについていけなくなる → 新しい敵役が記号化する

**解法**：
- 敵役を主人公として書く
- 「脇役が主人公を引き立てる」に加え「脇役が脇役を引き立てる」
- マップチェンジの正しい処理：新しいマップで旧キャラの価値を引き立てるのであり、旧キャラの無力さで新マップの難易度を引き立てるのではない

## 品質チェックリスト

キャラ設計完了後、項目ごとにチェック：

### 主人公チェック

- [ ] 動機は感情レベルである（「最強になりたい」といった空話ではない）
- [ ] 致命的な弱点があり、キープロットでミスを引き起こす
- [ ] 外見に記憶点がある（3-5個のキーワード）
- [ ] 口癖や象徴的動作がある
- [ ] 格がオンライン——読者に軽蔑されない
- [ ] レッドラインに触れていない（聖母／無脳戦闘機械／内核邪悪／愚かなミス／自暴自棄）
- [ ] 核心目標と全編の主线が一致している

### 脇役チェック

- [ ] 明確な機能がある（導師／味方／情報源／犠牲品／鏡像対照）
- [ ] 核心特性が1-2個のキーワードで概括できる
- [ ] 読者が記憶する象徴的特徴がある
- [ ] 退場方法が計画されている
- [ ] 同一シーンに台詞のある脇役が3人以内

### 敵役チェック

- [ ] 階層表に従って設計され、篇幅と階層が一致する
- [ ] 登場時に実力や手段を示した
- [ ] 動機が敵役の視点で筋が通っている
- [ ] 少なくとも主人公に一度勝つ（中敵役以上）
- [ ] 知能を下げて勝たせていない
- [ ] 大ボスは理念の衝突がある（利益衝突だけでない）
- [ ] 最終ボスは第一章から伏線がある

### 動機チェック

- [ ] 起因が具体的（「いじめられた」といった曖昧な言い方ではない）
- [ ] 制約が強力（主人公が一路圧倒できない）
- [ ] リスクが現実的（読者が主人公の重要喪失を信じる）
- [ ] 動機の変遷に鋪墊があり、急変しない

### 塑造チェック

- [ ] キャラの目的が行動で示され、ナレーションで説明されていない
- [ ] 行動／言語／思考が人設に沿って展開し、プロットのために人設を変えていない
- [ ] 主要キャラに行動反復点があり、長編の一貫性を維持
- [ ] 脇役と主人公に明確な関係があり、主人公の風頭を奪わない
- [ ] 人物真実／価値取向がキー選択時に自然に露見する
