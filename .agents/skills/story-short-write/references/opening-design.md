# 開篇設計マニュアル

> 短編開篇の設計原則、経典開篇方式、よくある失敗パターンについて。

---

## 開篇のコア原則

### なぜ開篇が最も重要なのか

読者は最初の200字で離脱するかどうかを決める。

**開篇の三つの目的**：
1. 読者を引きつける（最初の200字以内に）
2. 核心情報を提示する（誰が、何を、なぜ）
3. 期待感を確立する（読者にこの先を読ませる理由を与える）

### 開篇の黄金配分

```
フック : 情報 : 感情 = 4 : 3 : 3
```

- 40%のスペースでフックを設計（最も魅力的な部分を前に出す）
- 30%のスペースで必要な情報を提示（背景、ルール、人物関係）
- 30%のスペースで感情の基盤を築く（読者にキャラを気にかけさせる）

## 七つの経典開篇方式

### 1. 反転式開篇

認識を覆す一文で読者を引き込む。

```
私はずっと普通の家庭に生まれたと思っていた——母が息を引き取るまで。
```

**操作**：反転には衝撃が必要。普通の反転では読者の注意を引けない。
**適した題材**：サスペンス反転、身分逆転、家庭倫理

### 2. 衝突式開篇

強い対立で読者を直接引き込む。

```
「お前みたいな人間が、この家にいる資格はない。」
義母の平手打ちが私の頬に鋭く当たった。
```

**操作**：衝突の理由を簡潔に説明する。説明しすぎない。
**適した題材**：妻追い火葬場、家庭倫理、贅婿逆襲

### 3. 疑問式開篇

好奇心を刺激する疑問で読者を引き込む。

```
もしあの日に戻れるなら、私は絶対にドアを開けなかっただろう。
```

**操作**：疑問は具体的でなければならない。漠然とした疑問では読者は入り込めない。
**適した題材**：サスペンス、重生、すべての題材に応用可能

### 4. 状況式開篇

強い臨場感のある状況で読者を引き込む。

```
血。周り一面、血だった。
彼女は冷たい床に横たわり、目は見開かれていた。
```

**操作**：状況説明よりも、臨場感のある描写で読者をその場にいるかのように感じさせる。
**適した題材**：サスペンス、ホラー、クライム

### 5. 対話式開篇

核心的な対話で読者を引き込む。

```
「離婚しよう。」
彼は顔を上げもせず、淡々と言った。
```

**操作**：対話は情報量が多くキャラの性格を表すものに。無駄な挨拶は避ける。
**適した題材**：感情類、家庭倫理

### 6. 感情式開篇

強い感情で読者を引き込む。

```
その日、私は23歳の人生で一番つらい瞬間を味わった。
```

**操作**：感情は真実味があり共感できるものに。読者に「私も似たような経験がある」と思わせる。
**適した題材**：感情類、成長物語、人生感悟

### 7. 情報式開篇

核心設定やルールを最初に提示する。

```
2042年、人間の感情を「貸し出す」ことができるようになった。
あなたが幸せを感じている間、あなたの幸せは一時的に他人のものになる。
```

**操作**：設定の核心的な魅力を最初に伝える。説明臭くならない。
**適した題材**：SF、ファンタジー設定、穿越

## 開篇で避けるべきこと

### 絶対禁止

| 誤った開き方 | 理由 | 改善方法 |
|----------|------|----------|
| 天気描写から始める | 当たり障りがなく退屈 | 真っ先に核心情報を出す |
| 環境描写から始める | 読者は主人公に興味がある | 主人公から書き始める |
| 背景説明から始める | 情報過多で読者が混乱 | 情報は分散して出す |
| 前書きから始める | 読者はすぐに本文が読みたい | いきなりストーリーに入る |
| キャラ紹介から始める | ショーではなくテル | 行動や対話で人となりを見せる |

### 開篇の基本的な確認

- [ ] 最初の200字に核心的な魅力があるか？
- [ ] 読者に「それからどうなるの？」と思わせているか？
- [ ] 主人公の初期状態は明確か？
- [ ] 最初の対立は確立されているか？
- [ ] 情報の出し方は自然か？（説明くさくない）
