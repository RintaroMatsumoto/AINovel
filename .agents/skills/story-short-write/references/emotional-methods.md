# 感情設計方法：三板斧 + 引き合いリズム + 失敗モード

> 感情の橋段を設計する時に読み込む。まず判断ルートで戦略を選び、次に三板斧で具体的段落を設計する。

---

## 判断ルート

| 感情設計シーン | この戦略を使う | ジャンプ先 |
|---------------|-----------|----------|
| キャラの絆を確立（読者に関係を信じさせる） | 絆の敷設（第一斧） | 三板斧 §1 |
| 感情の引き裂き（ギャップ／ズレ／裏切り） | 感情の引き裂き（第二斧） | 三板斧 §2 |

## 感情虐め三板斧

### 第一斧：絆の敷設（前1/3）

**目標**：具体的な物品／数字／詳細で関係の質感を確立し、読者に関係が真實だと信じさせる。

**方法**：
- 具体的な数字で時間感を確立：「交際八年」「昏睡五年」「七年の月日」
- 具体的な物品で感情を担う：金の鍵（姉の誕生日プレゼント）、帳簿の数字（借金返済記録）、木の馬（父王が削った）
- 繰り返し動作で習慣を確立：毎日一碗の粥、二週間に一度の見舞い、毎年冬に凍えて眠れない

**案例**：
- 『二十年遅れ』：二十年の帳簿の数字（八万）で母娘関係の重みを確立
- 『仏前で君を祈る』：昏睡五年、神仏に祈る詳細、中学から始まった片思い
- 『皇弟が幼子を虐める』：七年の人質生活の具体的苦難（雪の上に跪く、平手打ちを食らう、腐った飯を食べる）

**核心**：絆が具体的であればあるほど、後の引き裂きが痛い。「彼らはとても愛し合っている」という抽象的な描写を使ってはいけない。

---

### 第二斧：感情の引き裂き（中後段）

**目標**：ギャップを生み、読者が恨むべきだと思った → 間違っていたと発見させる（またはその逆）。

**方法**：
- **ギャップ法**：まず温かい一面を示し、残酷な真実で打ち砕く
- **ズレ法**：キャラAはキャラBを守っていると思っているが、実際には傷つけている
- **遅延真実法**：キー情報を読者が最も期待しない時に明かす

**案例**：
- 『義兄が道を尋ねてミルク代を』：母は表面的に弱く可怜だが、実際にはずっと姉を操って金を要求 → 金の鍵は偽物（金メッキの銅）→ ギャップで引き裂き
- 『皇弟が幼子を虐める』：王氏は表面的に優しい（手炉を送る、薬を煎じる）→ 実際には薬を盛って先皇后を狂わせる → 心を刺す言葉で追い詰める
- 『重生した弟』：弟は彼女を深く愛している → 彼女は詐欺師 → 妊娠は偽り → 電詐园区に騙される

**核心**：引き裂きの力は鋪墊の厚さに依存する。良い絆の敷設がなければ、引き裂きは根のない木。

---

### 第三斧：余韻の鈍痛（结尾）

**目標**：大泣き大騒ぎを使わず、静かな詳細で読者の防线を打ち抜く。

**方法**：
- 日常動作で大きな感情を担う：粥を食べさせ続ける、服を畳む、振り返らない
- 物品の詳細で余韻を生む：壊れた金の鍵、木の馬、血の付いた指輪
- 「しない」で余白を生む：説明しない、振り返らない、涙を流さない

**案例**：
- 『皇弟が幼子を虐める』：「彼は私が磨いてとても滑らかにした木の馬を手に取った……彼の手にぴったりだった。」
- 『義兄が道を尋ねてミルク代を』：「私の携帯はずいぶん静かになった。長い間私を悩ませていた面倒が、一瞬でとても小さく小さくなった。」
- 『準嫁の採点』：「養子縁組の手続きを終えた後、彼女は初めてこの見知らぬ家に足を踏み入れた……わかっていた、今回は間違っていなかったと。」

**核心**：最良の余韻は大泣きではなく、「読んだ後も長く忘れられない」こと。

## 感情引き合いリズム設計

### 基本リズム曲線

```
温かい → 残酷 → 善意 → 真実 → 許し → 間に合わない → 諦め → 詳細の一撃
```

全ての物語が完全な曲線をたどるわけではない。題材に応じてサブセットを選択：

| 題材 | 典型リズム | 核心引き合い |
|------|----------|----------|
| 世情／爽文 | 虐め → 忍耐 → 爆発 → 見舞い | 感情反発が速く、見舞いの密度が高い |
| 感情／虐め | 甘い → 破綻 → 挽回 → 错过 | 遅い鋪墊、後勁が強い |
| 古言／復讐 | 忍耐 → 布石 → 暴露 → 報い | 設定簡潔、暴力美学 |
| サスペンス／推理 | 平静 → 不安 → 真実 → 驚き | 情報差で不安を生む |
| 年代／家族 | 誤解 → 衝突 → 真実 → 和解 | 世代間衝突、時代の質感 |

### 引き合い原則

1. **3-5小節ごとに一回の感情転向**（一路虐め続けたり一路爽快なままではいけない）
2. **各転向にトリガーイベントが必要**（理由なく感情を変えてはいけない）
3. **最後の転向が结尾の余韻の基調を決める**
4. **爽文は迅速な反発を許容、虐文はより長い鋪墊が必要**

## 題材別の感情戦略差異

### 世情／爽文

- 感情反発速度：速い（辱めを受けてから2-3節以内に見舞う）
- 見舞い密度：3-5節に一度
- 敵役の横柄度：遞増（最初は小さな横柄、最後は大きな横柄）
- 结尾基調：痛快、溜飲が下がる
- 案例：『準嫁の採点』— 採点制で対抗、鉄箱の零点、絶縁

### 感情／虐め

- 絆の詳細密度：高（前1/3で深い絆を確立）
- ギャップ設計：先に暖かく後に冷たく、先に甘く後に苦く
- 余韻技法：静かな结尾 + 物品詳細
- 结尾基調：切ない、諦め
- 案例：『義兄が道を尋ねてミルク代を』— 金の鍵の真実 → 偽りの愛 → 自立

### 古言／復讐

- 設定簡潔原則：人物関係を明確にし、複雑な世界観を作らない
- 暴力美学写法：見舞いは直接的で、泥沼化しない
- 切り札のタイミング：最後の1/4で最大の切り札を明かす
- 结尾基調：溜飲が下がる、因果応報
- 案例：『皇弟が幼子を虐める』— 一声で二十棍打たせる → 真実を調べる → 后を廃す

### サスペンス／推理

- 情報差の布石：読者は知っているがキャラは知らない、またはその逆
- 排除法構造：可能性を段階的に排除し、最後に真実だけを残す
- 動機暴露リズム：まず何をしたかを明かし、次になぜしたかを明かす
- 结尾基調：考えれば考えるほど怖い、なるほど
- 案例：『重生した弟』— 重生設定 + 詐欺師の身份 + 電詐园区

### 年代／家族

- 世代間衝突の処理：味方せず、双方の苦しみを示す
- 時代詳細の質感：時代特有の物品／習慣で質感を確立
- 和解のリズム：急いで和解させず、まず双方に十分傷つかせる
- 结尾基調：温かさの中に遗憾を帯びる
- 案例：『義兄が道を尋ねてミルク代を』— 親子関係 → 金の鍵の真実 → 断絶

## よくある失敗モード

| 失敗モード | 識別方法 | 修正方向 |
|----------|----------|----------|
| **平坦すぎる** | 連続5+節に感情転向がない | 意外な事件や新しい情報を挿入 |
| **急ぎすぎる** | 重大な転向にたった1節の鋪墊 | 転向に少なくとも3節の鋪墊を与える |
| **偽の虐め** | 読者が心痛がらず、ただ見ていて辛いだけ | 絆の敷設が具体的かチェック |
| **断絶** | 前半と後半が別の物語のよう | 伏線／物品／テーマで貫く |
| **尻すぼみ** | 反転後2000字もまだ説明している | 反転後500字以内に収める |
| **人設崩れ** | キャラのキー行動が以前の人設に合わない | 人設を振り返り、行動論理の一貫性を確保 |
