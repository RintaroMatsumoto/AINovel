# 章フック設計マニュアル

> 毎章の結末フックの設計と、章のリズム制御について。

---

## コア原則

### なぜフックが必要か

短編は特に次へのクリック率が重要。良いフックは読者が次の章をクリックしたくなるかどうかを決める。

**良いフックの三要素**：
1. 当然の帰結——前の鋪墊に基づいている
2. 予想外の方向——読者の予想を裏切る
3. 続きが気になる——強い好奇心や感情の動きを残す

### フック設計の黄金比

```
鋪墊 : フック = 8 : 2
```

章全体の80%で情報や感情を溜め、最後の20%でフックを放出する。フック自体も短く簡潔に、一文で核心を突く。

---

## フックの七つの形式

### 1. 対話式フック

未知の情報や意外な真実を台詞で提示する。

```
「実は…もう結婚してるんだ。」
```

**操作**：台詞だけで説明は不要。台詞の含む情報量で読者を惹きつける。

### 2. 状況式フック

新しい事件や意外な状況で章を締めくくる。

```
その時、急ブレーキの音が聞こえた。
```

**操作**：状況に強い緊張感や意外性を持たせ、読者に続きを気にさせる。

### 3. 疑問式フック

章末に疑問を投げかけ、読者の好奇心を刺激する。

```
あの日、私はなぜ彼を信じてしまったのだろう？
```

**操作**：疑問は具体的かつ核心的でなければならない。ぼんやりした疑問では読者は興味を持たない。

### 4. 反転式フック

章末に認識を覆す情報を提示する。

```
私はずっと母が事故で死んだと思っていた——今朝まで。
```

**操作**：反転には前の鋪墊が必要。前の章の手がかりで支える。

### 5. 感情式フック

強い感情のぶつかりで章を締めくくる。

```
彼は私の手をしっかり握り、声は少し震えていた：「…ごめん。」
```

**操作**：感情の真実性が最も重要。感動させようとしないこと。

### 6. 選択式フック

キャラが決断を迫られる場面で締めくくる。

```
「今、二つの選択肢がある…」
```

**操作**：選択肢の結果を明かさない。読者にキャラの状況を心配させる。

### 7. チェーン式フック

事件の連鎖反応が始まったところで終わる。

```
それは単なる始まりに過ぎなかった。
```

**操作**：連鎖反応の規模を暗示し、読者の期待感を高める。

---

## フックの等級

| 等級 | 定義 | 効果 | 使用頻度 |
|------|------|------|----------|
| 特大フック | 核心反転/重大秘密暴露 | 読者がすぐに次の章をクリック | 章の1/5 |
| 中フック | 新しい事件発生/感情高まり | 読者が続きを読むことを期待 | 章の3/5 |
| 小フック | 情報提示/疑問提示 | 章のリズム緩急を調整 | 章の1/5 |

---

## フック設計実戦技法

### 情報差フック

読者だけが情報を知っていて、キャラは知らない（またはその逆）ことで緊張感を生む。

**操作**：
1. 読者にキャラが知らない情報を知らせる
2. キャラの行動を通じて情報に近づく
3. 情報が暴露されそうになったところで章を終える

### タイムリミットフック

時間的制約が生む緊迫感で章を締めくくる。

```
あと三時間しかない。
```

**操作**：時間の切迫感 + 行動の困難さ = 強い期待感

### 感情反転フック

感情の急転直下で章を締めくくる。

```
ようやく真実を知った彼女は、微笑んでいた。
```

**操作**：感情的反転は意外性があり、かつ前の鋪墊に合致している必要がある。

## 避けるべきフックの書き方

| 誤った書き方 | 問題点 | 改善 |
|----------|----------|------|
| 説明不足のフック | 読者が何が起こったか理解できない | フックの前に必要な情報を出す |
| 誇張しすぎたフック | 期待が大きすぎて実際の内容が追いつかない | フックは節度を守る |
| 使い古されたフック | 読者が飽きている | 定番フックに新しい切り口を加える |
| 放置されたフック | フックを出したまま回収しない | すべてのフックに回収を計画する |
| フックの多用 | 連続フックで読者が疲れる | 章の間に緩急をつける |

---

## フック回収原則

1. すべてのフックは回収されなければならない
2. フックの回収時期は明確に計画する（何章後か）
3. フック回収時に、前の手がかりを振り返って示す
4. 一つのフックを回収する時に、新しいフックを仕込む
