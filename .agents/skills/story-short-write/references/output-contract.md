# 創作契約——約束と実現

> 創作における契約（約束と実現）の概念と応用。物語の信頼性と満足度を高める。

---

## 契約とは

### 核心概念

**契約** = 作者が読者に対して行う約束。この物語が何についての話で、読者にどのような体験をもたらすか。

物語を読み始めるとき、読者は暗黙の期待を抱く：
- タイトルから内容を推測する
- 最初の段落で文章の質を判断する
- 最初のシーンで題材と方向性を決定する

これらの期待こそが契約である。

### 契約の三層

| 層 | 時間 | 内容 |
|------|------|------|
| 外層 | 読む前 | タイトル、表紙、推薦文——読者の最初の期待を形成 |
| 中層 | 最初の200字 | スタイル、視点、リズム——読み続けるかどうかの判断基準 |
| 内核 | 最初のシーン | 題材の核心、感情の基調、対立の方向——物語の本質的な約束 |

---

## 契約の四分類

### 1. 感情契約

約束する感情体験：爽快、感動、切なさ、温かさ、怖さ…

```
例：「虐め→見舞い」の感情体験を約束する（爽快）
   「甘い→別れ」の感情体験を約束する（切なさ）
```

**実現方式**：感情弧線を通じて約束された体験を実現する。

### 2. 題材契約

約束する題材の核心的な面白さ：身分逆転、復讐成功、謎解き反転…

```
例：「本当の身分を暴露する爽快感」を約束する
   「真犯人を暴くスリル」を約束する
```

**実現方式**：題材の核心メカニズムを通じて約束された面白さを実現する。

### 3. リズム契約

約束するリズム体験：速い爽快、緩やかな情感、緊張と緩和の連続…

```
例：「一章ごとに爽点がある」爽快リズムを約束する
   「起伏のある感情リズム」を約束する
```

**実現方式**：章構造と感情弧線を通じて約束されたリズムを実現する。

### 4. 結末契約

約束する結末の方向性：Happy Ending / Bad Ending / 開放的結末

```
例：「悪者は必ず罰せられる」という正義の結末を約束する
   「感情の決着がつく」結末を約束する
```

**実現方式**：結末設計を通じて約束された結果を実現する。

## 契約履行の原則

### 契約一貫性の原則

契約は一度確立されたら変更してはいけない。契約を変えるなら、読者に明確なサインが必要。

- 感情契約が爽快から切なさに変わるときは、予告が必要
- 題材契約が逆転から感情に変わるときは、移行が必要
- 結末契約がBEからHEに変わるときは、鋪墊が必要

### 契約強度の原則

契約が明確であればあるほど、読者の期待は強くなり、実現時の満足度も高まる。

```
弱い契約：この物語は面白いかもしれない
強い契約：「虐め→見舞い」の爽快感をこの物語で体験できる
```

### 契約実現の原則

契約は必ず実現されなければならない。実現されない契約 = 読者の裏切り。

契約の実現は完全一致である必要はなく、予想を超える形であればなお良い。

---

## 契約の実戦応用

### 開篇の契約確立

| 開篇方式 | 確立する契約 | 実現方式 |
|----------|----------|----------|
| 反転式 | 物語は覆る真実について | 多重反転構造 |
| 衝突式 | 強い対立がある | 対立解決過程 |
| 疑問式 | 好奇心を満たす | 段階的な謎解き |
| 感情式 | 深い感情体験 | 感情弧線の完成 |

### 契約実現のタイミング技術

- 契約の実現が早すぎる = 読者は続きを読まない
- 契約の実現が遅すぎる = 読者は忍耐を失う
- 各章は少なくとも一つの小さな契約を実現すべき
- 章末の契約は次の章で実現すべき（フック設計）

### 契約違反の警告

以下の状況は契約違反に当たる：

| 違反状況 | 例 | 影響 |
|----------|------|------|
| 題材の途中変更 | 感情文が突然SFに | 読者が混乱して離脱 |
| 感情基調の不一致 | 爽文が突然虐めに | 読者が期待と異なると感じる |
| リズムの崩壊 | 爽文が突然もたつく | 読者が飽きる |
| 結末の変更 | HEを約束してBEを書く | 読者が裏切られたと感じる |
| ルールの破綻 | 設定のルールを無視した展開 | 読者がご都合主義と感じる |
