# 経典題材写作公式

> 各題材写作時の構造公式と実戦テンプレート。

---

## 妻追い火葬場

### 標準テンプレート（12000字）

```
第一段：結婚破裂（0-10%、1200字）
  - 女主が男主の冷たさ/誤解に耐えきれず離婚を申し出る
  - 男主が軽率に承諾 or 離婚届にサイン
  - 女主が傷ついて家を出る
  
第二段：女主覚醒（10-30%、2400字）
  - 女主が離婚後の新しい生活を始める
  - 女主の本当の価値が徐々に明らかに（仕事/家柄/容姿の変化）
  - 優秀な異性が現れ女主を追いかける
  
第三段：男主後悔（30-50%、2400字）
  - 男主が女主の本当の状況を知る
  - 男主が過去のミスに気づき後悔し始める
  - 男主が女主との復縁を試みる
  
第四段：追いかけ復縁（50-80%、3600字）
  - 男主が女主を取り戻そうとする過程
  - 女主が冷淡に応じる/拒否する
  - 男主の追求過程での困難と障害
  
第五段：結末（80-100%、2400字）
  - 追いかけ復縁成功 or 女主がついに離れる
  - 男主の最終的な悔悟
  - 感情の決着
```

### キーポイント

- 離婚原因は単純すぎず、男主が完全な悪人にならないこと
- 女主の覚醒は合理的な過程を経て、一夜で人が変わらない
- 追いかけ復縁過程の男主の後悔は十分にリアルに
- 結末は溜飲が下がるか余韻を残すか、作品の基調に合わせる

## 赘婿/身分逆転

### 標準テンプレート（12000字）

```
第一段：最低状態（0-10%、1200字）
  - 主人公が軽蔑されている状態の展示
  - 妻の家や周囲の軽蔑の態度
  - 主人公が耐え忍ぶ理由の提示
  
第二段：最初の逆転（10-25%、1800字）
  - 最初の小さな身分/能力の暴露
  - 関係者の疑念が生まれ始める
  - 本当のつながりをほのめかす
  
第三段：能力展示（25-50%、3000字）
  - 主人公の実力を見せつける場面
  - 周囲の認識が変わり始める
  - 新しい敵や困難が現れる
  
第四段：公の場での対決（50-75%、3000字）
  - 最大の敵との直接対決
  - 本当の身分/実力を完全に暴露
  - 敵の絶望と後悔
  
第五段：結末（75-100%、3000字）
  - 主人公が最高の地位を得る
  - 妻の家の態度が一変
  - 最終決戦の余韻を解消
```

### キーポイント

- 軽蔑される鋪墊は十分にリアルに。読者が主人公に同情するため
- 暴露シーンは公の場での対決が最適。観客の反応で爽快感を倍増
- 逆転は段階的に。一度に全てを明かさない
- 結末は敵の絶望的な表情を書くこと

## 穿越/古代設定

### 標準テンプレート（12000字）

```
第一段：穿越と立ち位置（0-10%、1200字）
  - 現代から古代へ
  - 元の身体の状況を引き継ぐ
  - 最初の衝突
  
第二段：生存と順応（10-30%、2400字）
  - 新しい環境に適応
  - 現代の知識で問題を解決
  - 最初の支持者を得る
  
第三段：成長と勢力拡大（30-55%、3000字）
  - 自分の勢力を発展させる
  - 敵との衝突の激化
  - 知識差の爽点を解放
  
第四段：クライマックス（55-80%、3000字）
  - 最大の危機
  - 決定的な局面での知識逆転
  - 敵を打ち負かす
  
第五段：結末（80-100%、2400字）
  - 新しい世界での地位確立
  - 感情の決着
  - 現代に戻るか古代に留まるか
```

### キーポイント

- 穿越理由は合理的に。説明にこだわりすぎない
- 現代知識の使い方は考証が必要。あまりに荒唐無稽にしない
- 古代社会のルールを尊重。王法や身分制度を無視しない
- 感情線は自然に。初対面で一目惚れしない

## 重生復讐

### 標準テンプレート（12000字）

```
第一段：重生と覚醒（0-10%、1200字）
  - 前世の悲惨な結末
  - 重生後の最初の反応
  - 復讐目標の決定
  
第二段：先制攻撃（10-30%、2400字）
  - 未来情報で敵の最初の策略を破る
  - 小さな復讐を果たす
  - 資源と勢力を集める
  
第三段：布石（30-55%、3000字）
  - 敵にとって代わる基盤を築く
  - 前世の敵を一つずつ特定
  - 取り巻きを片付ける
  
第四段：全面対決（55-80%、3000字）
  - ラスボスとの対決
  - 前世の最大の秘密を暴露
  - 復讐を完遂
  
第五段：新生（80-100%、2400字）
  - 復讐完了後の人生の方向性
  - 感情と人間関係の再構築
  - 未来への展望
```

### キーポイント

- 前世の結末は十分に惨めに。読者が主人公に感情移入するため
- 先見の明を利用した爽点の密度を高く
- 敵は愚かすぎず。聰明な敵を倒すほど爽快感が増す
- 重生後の人生は復讐だけじゃない。新しい感情や生活が必要

## サスペンス反転

### 標準テンプレート（12000字）

```
第一段：事件発生（0-10%、1200字）
  - 異常な出来事や奇妙な手がかり
  - 主人公の基本的な状況
  - 最初の疑問
  
第二段：調査と推理（10-35%、3000字）
  - 手がかりを集める過程
  - 初めての偽りの結論（読者は真実だと思う）
  - 新たな証拠が偽りの結論を覆す
  
第三段：多重反転（35-65%、3600字）
  - 二度目の反転（真相だと思う）
  - またも覆る
  - 真犯人と思われる人物が現れる
  
第四段：真実暴露（65-85%、2400字）
  - 最後の手がかりを発見
  - 意外な犯人の暴露
  - 動機の完全な説明
  
第五段：結末（85-100%、1800字）
  - 事件の後始末
  - 関係者の最終的な運命
  - 考えさせられる余韻
```

### キーポイント

- 反転前の鋪墊は緻密に。急に結論を変えない
- 各反転は新しい証拠で支える。キャラの性格を理由に反転させない
- 第三段階までに真犯人の手がかりを密かに仕込む（読者が二度読みした時に発見できる）
- 犯人の動機は単純すぎず。人物設定と一致していること
