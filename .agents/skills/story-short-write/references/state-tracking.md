# 状態追跡と全編貫通設計

> 短編創作時の状態追跡と全編貫通設計に用いる。

---

## 状態追跡とは何か

状態追跡 = 各段階のキャラの状態、情報、感情を記録する。矛盾を防ぎ、プロットの前後一貫性を確保する。

### 追跡が必要な理由

- キャラの行動と性格の一貫性を保証する
- 設定の矛盾を防止する
- 感情弧線の完全性を確保する
- 伏線が確実に回収されるようにする

## 全編貫通設計

### テーマ貫通線

全編に一つのコアテーマを設定し、各プロットポイントでこのテーマを異なる形で表現する。

```
例：テーマ「自己の目覚め」
  開始：女主が男主に依存（テーマの否定）
  中盤：女主が自立を模索（テーマの探求）
  結末：女主が完全に自立（テーマの実現）
```

### 物品貫通線

ある物品を通じて全編を貫き、感情やテーマを象徴させる。

```
例：「指輪」
  開始：結婚指輪 → 愛情の象徴
  中盤：指輪を外す → 感情の破綻
  結末：指輪を川に捨てる → 完全な解放
```

### 場面貫通線

ある場面設定を複数回出現させ、その意味の変化を表現する。

```
例：「天台」
  第1回：男主と女主の出会いの場所（憧憬）
  第2回：男主が女主を傷つける場所（絶望）
  第3回：女主が立ち直る場所（新生）
```

### 台詞貫通線

キャラの繰り返しの台詞を通じて感情の変化を表現する。

```
例：「大丈夫」
  開始：女主が男主に「大丈夫」と言い続ける（我慢）
  中盤：女主がもう「大丈夫」と言わない（覚醒）
  結末：男主が女主に「大丈夫」と言う（立場の逆転）
```

## 全編貫通設計のチェック

- [ ] 全編に少なくとも一つの貫通要素があるか？
- [ ] 貫通要素が各段階で異なる意味を持っているか？（変化がないものは不要）
- [ ] 貫通要素の変化がキャラの成長と一致しているか？
- [ ] 貫通要素に読者が気づき、感情移入できるか？
- [ ] 貫通要素の結末がテーマと一致しているか？
