# 会話設計操作マニュアル

> 会話シーンを書く時に読み込む。まず判断ルートで会話モードを選び、操作命令で品質を制御する。

---

## 判断ルート

| 会話シーン | このモードを使う | 操作 |
|-------------|---------|------|
| 主人公の碾压／見舞い | 压制モード | 相手が長広舌 → 主人公が一言で返す |
| 主人公が切り札を出す／反転 | 反転モード | 相手が横柄 → 主人公が一言事実 → 相手沈黙 |
| 関係破綻／心が死ぬ | 心死モード | 会話が次第に短くなる：弁解から → 沈黙 → 「好きにしろ」 |
| 日常的相互作用／人設立て | 日常モード | 他の人物に衝突に関与させ、主人公一人で独白させない |
| 群衆の驚き／弾幕 | 弾幕モード | 遞進：普通の人の驚き → 専門家の分析 → 特殊身份者の反応 |
| 情報展示／世界観 | 情報埋め込み | キャラの語氣で情報を包み込み、機械的に設定を陈述しない |
| 感情の引き合い／虐め | 感情推進 | 上昇下降を交互に、鋸引きのように期待を引き上げる |

### 会話モード選択の補足

| 会話類型 | よくある問題 | 修正操作 |
|----------|---------|---------|
| 問答式（全体が一問一答で尋問のよう） | 一方が能動的に話し、他方が反応を与える形式に変更；反応は動作／表情／心理で可 |
| 衝突式（礼儀正しすぎて迫力不足） | 五段階で遞進：婉曲拒否→友好的人道→命令否定→PUA式→直接侮辱 |
| 日常会話（無機能な水になりがち） | 機能は人設を立てること；人を巻き込める衝突は主人公に独白させない |
| 多人会話（混乱／無栄養） | 書く前に各キャラの機能を計画：情報提供者／感情増幅器／衝突製造者 |

## 会話核心ルール

各会話は以下の少なくとも一つを担わなければならない。そうでなければ削除：

1. **プロットを推進**：新しい情報を漏らす、事件の発展を推進
2. **期待感を増加**：起こることを暗示、サスペンスを生む
3. **人設を展示**：言語風格を通じてキャラの性格を伝える

### 絶対禁止

| 禁止 | 理由 |
|------|------|
| 脇役が無条件で主人公を褒める | 偽物 |
| 互いに読者の既知情報を説明する | 水増し |
| 大きな段落の説明文的会話 | 退屈 |
| 全てのキャラの話し方が同じ | ぼやける |
| 会話で人物を説得する | 現実で誰も数言で説得されない。突発状况で代替 |
| 感情を書き終えたら方向が変わった | 感情分割に戻る必要あり |

## 権力ゲーム会話

### ルール

会話の長さ = 権力地位。掌握者は話が短く冷静、受動的者は話が多く感情的。

### 压制モード

構造：相手の長広舌（3-5行）→ 主人公の一言返答。

```
「お前、自分が何様だと思ってる？言っておくが、この家ではお前に発言権はない！嫁いで来たその日から自分の立場をわきまえるべきだ。」
「出て行け。」
```

### 反転モード

構造：相手が横柄（2-3行）→ 主人公が切り札を出す（1行の事実）→ 相手沈黙。

```
「お前に何の資格があって干渉する？これは俺の家の金だ。好きに使う。」
「お前の母さんの通帳だ。暗証番号は俺の誕生日だ。」
```

### 心死モード

構造：会話が次第に短くなり、弁解から沈黙へ、そして「好きにしろ」。

```
「聞いてくれ、あの日はお前が思ってるようじゃなかったんだ。」
「うん。」
「本当だ、証明できる。」
「好きにしろ。」
```

### 操作命令

- 掌握者／主人公が切り札を出す時：会話 ≤ 10字、動作描写を加えない
- 压制される側：会話 ≥ 20字、動作描写可（拳を握る／唇を噛む／立ち上がる）
- 二人の会話時：短文の方 = 権力上位、長文の方 = 権力下位

## 潜台詞と議題

### 潜台詞ルール

- キャラの本当の動機は決して台詞に浅く書いてはいけない
- 現実の人は話す時に自分に言い訳をする。キャラも同じ
- 各台詞に同時に設計する：キャラの動機（キャラ自身も気づいていない可能性あり）とキャラの言い訳

### 会話議題

- 各キャラは会話に入る時に自身の議題を持つ：この会話から何を得たいか
- 二人のキャラの議題の衝突こそが緊張感の來源
- 双方の議題が一致（同じ立場）= 反復、意味を失う

### 語氣は三要素で決まる

関係 × 場面 × 目的 = 語氣

| 場面 | 特徴 | 適した内容 |
|------|------|----------|
| 私的（一対一） | 深く、感情が透けて見える | 内心の告白、密議、告白 |
| 公的 | 体裁を考慮、言葉遣いを控える | 衝撃が必要な時に打破可（公の場での対決など） |
| 知人（友達／同門） | 深さは両者の中間 | 軽い相互作用と情報交换 |

私的な話を公の場で言うからこそ衝撃がある。会話で完全に表現できない内容は、動作、表情、環境で補う。

## 感情推進会話

### 強い感情の会話

- 命令式+否定式が最も読者の感情を刺激：「私の言っていることがまだわからないのか？」
- 最強の話術：「あなたのため」という名目で、一言一言は关心だが、一言一言が嫌悪、非難、厭悪
- 直接否定は婉曲な暗示より傷つく

### 感情の連続性

キャラの感情は連続的で、循序漸進的。怒りから喜びへ：怒る → あまり怒らない → 怒らない → 喜ぶ。各変化は事件のトリガーに対応する必要がある。飛び越しは不可。

### 感情四段階法（どれも欠かせない）

1. 事件に遭遇（平衡状態の喪失）
2. 感情的反応（外在表現：動作、表情、言語）
3. 内心の思考（思考がなくても「思考なし」と書き、無謀さを表現）
4. 行動を取る（前三步の結果に基づき応答）

### 会話を平坦にしない三つの考え方

- 会話自体がある核心的駆動力を提供／強化する（期待、爽快感、サスペンス）
- 情報交流がある理由で妨害され、妨害が駆動力をもたらす可能性
- 展開が突然読者の予想を外れる（ただし合理的で人設に合致する必要あり）
- 長い会話を期待点と爽快点の間に挟む：読者は爽快点を見るために中間の会話を我慢する

## 情報展示と世界観の引出

- 大量の情報を会話で展示すると冗長になる。一部の情報はプロット、心理描写、ナレーション、環境、動作に転化する
- キャラの語氣と立場で情報を包み込み、機械的に設定を陈述しない
- 設定は使う時に少し出すだけでよく、完全に原因結果を説明する必要はない

### 情報の引き合い例（「主人公の新作が大ヒットした」の場合）

| キャラ | 台詞 | 機能 |
|------|------|------|
| 甲 | 成績が…と聞いたけど | サスペンスで期待を引く |
| 乙 | 絶対誰も見てないよ！ | 下降 + 期待を引く |
| 甲 | 成績がとても良いらしい | 上昇 + 期待を引く |
| 乙 | 初日登録が一万三？ | 核心情報を露呈 + 爽快点達成 |

上昇と下降を交互に、感情は鋸のように期待を引き上げる。

## 人物言語の差別化

各キャラは自身の話し方を持つべき。会話の時にキャラが何を言うかわからなくなる → 人設が曖昧。類似の人設の話し方をまとめる。

| 差別化次元 | 操作 |
|------------|------|
| 口癖と慣用語 | 各主要キャラに象徴的な用語を与える |
| 話すリズム | 長広舌 vs 短文連打 |
| 情報偏好 | 技術型は専門用語、江湖人は隠語 |
| 立場固定 | あるキャラは常にある角度から発言（悲観派／楽観派／現実派） |
| 身份が言葉遣いに影響 | 老人／少年／貴族／市井、身份が違えば言葉遣い、自称、敬語謙譲語が異なる |
| 性格が語氣に影響 | 知略型は含みがある；無謀型は思ったことを言う；冷静型は言葉が正確、時折の感情流露が却って衝撃的 |
| 進捗が態度に影響 | 初対面／熟知／对立／親密、関係段階で語氣と情報量が異なる |

## 弾幕／群衆会話

三大核心作用：プロット推進（主人公の知らない情報を漏らす）、期待感増加（サスペンス、推測）、感情演出（群衆の驚き／興奮／怒りが読者に伝染）。錦上添花であり、主线を代替しない。

### 設計された弾幕 vs 設計されていない

- 設計なし：「うわーすごい」だけ、単調で無駄
- 設計あり：普通の人の驚き → 専門家の分析 → 特殊身份者の反応 → 感情昇華

### 操作ポイント

- 異なる人格化語氣、全て同じ味わいではいけない
- 短小精悍、各エントリは一言の核心情報を超えない
- 遞進を活用：最初の驚きから徐々に全貌を認識
- 「反転」キャラが出現可能：一見通行人の一言が全員の認識を変える
- 毎章書く必要はなく、キーとなる爽快点／燃える点／涙点の前後に集中して使用

## リズム制御

### 大量の会話でリズムを維持

- 人物の性格を示す語氣助詞を「簡潔に」と削除しない
- 会話段落の間に動作描写、環境変化、心理活動を挿入してリズムを調整
- 緊張段落の会話は短く、緩和段落はやや長く可
- キー情報は会話の冒頭か末尾に置き、中間は感情の引き合いに使う

### 動作と表情の処理

- 各会話に意図的に表情／動作を付けると文章が機械的になる
- 動作と表情はキーの転換点で使用するのが最も効果的で、毎回必要ではない
- 語氣が平坦なシーン（お茶を飲む、散歩）は微細な動作と沈黙で雰囲気を示す

### 会話の呼吸感

- 連続した複数ラウンドの会話の後は「息継ぎ」が必要。環境描写やキャラの心理を挿入
- 適度な停止（動作描写、改行、短文）は連続出力より緊張感がある
- 「本当にそう思うのか？」は長文説明より圧迫感がある

---

## 篇幅制御

### 会話過多時

- 読者の既知情報の会話は叙事で一言で要約：「アリスはアンナに町に来た理由を話した。アンナは聞いて眉をひそめた」
- 突発状況で代替できる会話段落は直接置換
- 語氣助詞を削除すると乾燥する = 会話自体に情報量が不足。書き直しが必要

### 会話過少時

- 他の人物の会話で表現できることは、主人公にナレーションで平坦に述べさせない
- 脇役を衝突と会話に参加させるが、新人物には主线の戏份を配置する必要あり

## ネタで会話を充填

### ネタ式 vs 普通

- 普通：「兄弟、落ち込むなよ。お前が今日まで一歩一歩来たのを見てきた。この程度の挫折が何だ？元気出せ！」
- ネタ式：「兄弟、落ち込むなよ。俺は信じてる。お前はいつか頭を落とし、落とした頭を…あれ？あの言葉、何だっけ？兄弟、意味わかるよな…」
- ネタ式は「言えないが意味は伝わる」状態で面白さを生む

### 操作

- 会話にネタや下ネタを溶け込ませ、全体の面白さを効果的に向上
- 特に主人公や重要な脇役の突出した会話は、ネタで記憶点を強化するのに適する
- あるネタを盛り上がり点として使用し、段落全体のプロットをこのネタの達成を中心に設計

## 品質チェック

### 三大自己チェック項目（一つ該当で改善必要）

- [ ] 大量の情報を全て会話で展示する必要があるか
- [ ] 会話が問答式の一問一答か
- [ ] 会話に依存してプロットや人物変化を推進する習慣があるか

### 核心命令チェック

- [ ] 権力ゲーム：掌握者の会話 <= 10字 / 压制される側 >= 20字、明確な压制／反転／心死のパターンがあるか
- [ ] 潜台詞と議題：各キャラが会話に入る時に自身の議題を持ち、本当の動機が台詞にない
- [ ] 人物差別化：キャラ名を隠した時に誰が話しているか区別できるか（7次元差別化）
- [ ] 弾幕遞進：普通 → 専門 → 特殊身份、階層感があるか
- [ ] 会話がプロットを推進：各会話終了時、プロットが一歩前進したか
- [ ] 篇幅制御：単回会話が全節の40%を超えないか、情報密度が十分か

### 会話品質の検証

- 会話自然度チェック：一文ごとに会話が自然な口語交流のようか、書面化された問答稿でないか
- 会話の结尾が次のリズム変化を示唆しているか
