# 品質チェックリスト

> 短編書き上がり後の品質チェックリスト。書く前の準備段階と書き終えた後の品質チェックに用いる。

---

## 書く前の検討

### 創作構想検討

- [ ] ターゲット読者層を明確にしたか？
- [ ] この題材の市場ポテンシャルは？
- [ ] 経典題材を使うかイノベーションをするか？
- [ ] 核心的な爽点は確定したか？
- [ ] 感情弧線は設計したか？

### 準備の確認

- [ ] プロットアウトラインはあるか？
- [ ] キャラクター設定はあるか？
- [ ] 書きたい感情基調を決めたか？
- [ ] 書く前に参考作品を見たか？

---

## 書き終えた後の品質チェック

### 物語構造

- [ ] きちんとした起承転結があるか？
- [ ] プロットの転換点は合理的か？
- [ ] 各段落に目的があるか？（推進プロット/人物設定/サスペンス設置）
- [ ] 冗長な段落はないか？
- [ ] 結末は前の約束を果たしているか？

### リズム制御

- [ ] 一章（1500-2000字）は設定範囲内か？
- [ ] 章タイトルは行数カウントに入っていないか？
- [ ] 1呼吸＝10-15行単位になっているか？
- [ ] 段落の長さに変化があるか？（短文＋長文のバランス）
- [ ] 叙事段落≤120字か？会話段落≤100字か？動作段落≤60字か？
- [ ] 緊張と緩和が交互に来ているか？
- [ ] 情報密度の配分は適切か？

### フック

- [ ] 章末にフックがあるか？
- [ ] フックは前の鋪墊に基づいているか？
- [ ] フックは予想外の方向を向いているか？
- [ ] フックは読者に続きを読みたいと思わせるか？

### サスペンス

- [ ] サスペンスは合理的に設置されているか？
- [ ] サスペンスの答えは合理的か？
- [ ] サスペンスは回収されているか？
- [ ] サスペンスの強度は適切か？

### 会話

- [ ] 各キャラクターに話し方の違いがあるか？
- [ ] 会話は自然か？
- [ ] 会話に機能があるか？（プロット推進/設定/感情表現）
- [ ] 権力関係は会話に現れているか？
- [ ] 会話に緩急リズムがあるか？

### 感情表現

- [ ] 感情の描き方に奥行きがあるか？
- [ ] 読者の感情を動かせるか？
- [ ] 感情の表現は自然か？（押し付けがましくない）
- [ ] 感情弧線は完全か？

### 世界観と設定

- [ ] 設定の矛盾はないか？
- [ ] ルールは一貫しているか？
- [ ] 設定情報の出し方は自然か？

### 言辞表現

- [ ] 形容詞に頼りすぎていないか？
- [ ] 描写は具体的か？
- [ ] 文は流暢か？
- [ ] 使い古された表現やテンプレート表現はないか？
- [ ] 一人称の主語は明確か？（主語の省略による混乱を避ける）

### 反転

- [ ] 反転の前に手がかりを埋めたか？
- [ ] 反転は意外だが合理的か？
- [ ] 反転の回収は完全か？

### 結末

- [ ] 物語の結末は完全か？
- [ ] 結末の感情基調は作品全体と一致しているか？
- [ ] 結末は「書きっぱなし」になっていないか？

---

## 修正優先度

| 問題の種類 | 優先度 | 対応 |
|----------|----------|------|
| 構造の問題 | 最優先 | ストーリーラインの調整 |
| リズムの問題 | 優先 | 段落と章の調整 |
| 表現の問題 | 通常 | 修辞と描写の改善 |
| 細部の問題 | 低優先 | 語句の調整 |
