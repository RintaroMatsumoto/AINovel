# サスペンスと期待感設計

> サスペンス設計と期待感制御の技法に用いる。

---

## サスペンスの基本

### サスペンスの三要素

1. **読者が知っている**——物語内の人物が知らない情報（情報差で緊張を生む）
2. **読者が知りたい**——好奇心を刺激する未回答の疑問
3. **読者が心配している**——キャラへの感情移入が生む不安

三要素のうち最低二つが揃えば、効果的なサスペンスが成立する。

### サスペンスの強度公式

```
サスペンス強度 = 情報差の大きさ × 結果の重要度 ÷ 答えが出るまでの距離
```

- 情報差が大きいほど、読者は緊張する
- 結果が重要であるほど、読者は気にする
- 答えに近づくほど、緊張感は高まる

---

## 九つのサスペンスモデル

### 1. 情報の遅延

キャラや読者の知らない情報を保留する。

**操作**：読者に情報の存在を知らせるが、内容は明かさない。
**効果**：読者が情報を知りたくてたまらなくなる。

### 2. 身分の謎

あるキャラの本当の身分を隠す。

**操作**：キャラの行動は示すが、身分や背景は明かさない。
**効果**：「この人物は一体何者だ？」という好奇心を持続させる。

### 3. 動機の謎

キャラの本当の目的を隠す。

**操作**：キャラの行動は示すが、その目的は明かさない。
**効果**：「なぜ彼はこうするのか？」という疑問を持続させる。

### 4. 多重解釈

一つの事実に複数の解釈を可能にし、読者に推測させる。

**操作**：証拠を複数の方向に解釈できるように提示する。
**効果**：読者が自分で推理し、参与感を高める。

### 5. 逆時間

結果を先に示し、原因を後から明かす。

**操作**：まず衝撃的な結果を示し、徐々に原因を明らかにする。
**効果**：「なぜこんなことになったのか」という疑問が持続する。

### 6. 保留の謎

核心の秘密を最後まで隠す。

**操作**：設定や人物の背景に関する核心秘密を章ごとに少しずつ明かす。
**効果**：長期間読者の好奇心を維持する。

### 7. 偽りの安全

読者に危険がないと思わせるが、実際には危険が迫っている。

**操作**：まず安全な雰囲気を作り、その中に危険の兆候を忍ばせる。
**効果**：のちの反転インパクトを強める。

### 8. 選択の苦しみ

キャラが難しい選択を迫られる。

**操作**：二つの悪い結果の間で選ばせる選択肢を提示する。
**効果**：読者にキャラと一緒に選択を考えさせる。

### 9. 知っているけど言えない

あるキャラが秘密を知っているが、何らかの理由で明かせない。

**操作**：知っているキャラの行動や言葉に秘密がにじみ出るが、明かせないもどかしさを書く。
**効果**：読者のいらだちが期待感に変わる。

## 期待感の持続技法

### チェーン式サスペンス

一つのサスペンスが解決すると、すぐに新しいサスペンスが生まれる。

```
サスペンスA解決 → サスペンスB出現（A解決の結果）→ B解決 → C出現...
```

**注意**：チェーンの各環節に十分な鋪墊が必要で、唐突に出てこない。

### 階層式サスペンス

表面上のサスペンスの背後に、より深いサスペンスが隠れている。

```
表面的な疑問：誰が何をしたか？
　　　　↓（解決）
より深い疑問：なぜそうしたのか？誰が操っているのか？
　　　　↓（再解決）
核心の疑問：すべての背後にいる真の黒幕は誰か？
```

### 並列式サスペンス

複数のサスペンスを同時に進行させる。

```
ラインA：身分の謎
ラインB：動機の謎
ラインC：未来の危機
```

**注意**：ライン数は3つを超えない。超えると読者が混乱する。

---

## サスペンスの強度制御

| 強度レベル | 特徴 | 使用頻度 |
|----------|------|----------|
| 強 | 生死に関わる、全編の核心秘密 | 1-2個 |
| 中 | 重要な選択と変化 | 3-4個 |
| 弱 | 日常的な小さな疑問 | 適宜 |

---

## サスペンスの回収原則

1. サスペンスの回収時期は明確で、先延ばしにしない
2. サスペンスの答えは意外だが合理的に
3. サスペンス回収時に前の手がかりを示して伏線を回収する
4. 一つのサスペンスを回収する時、新しいサスペンスを仕込む
