## 三層タグギャップ人設法

### 三層構造

| 階層 | 名称 | 意味 | 例 |
|------|------|------|------|
| 第一層 | 身份タグ | 外界から見た身份 | 豪門の捨てられた妻 |
| 第二層 | 表現タグ | キャラが外界に見せる行動 | 忍耐強く、従順 |
| 第三層 | 内核タグ | キャラの本当の内心 | 冷静、計画的、着実に進む |

### 実行命令

1. キャラに三層タグを記入し、三層の間にギャップを作る——ギャップ = 立体感
2. 身份タグと表現タグは類似してもよい（ステレオタイプを強化）が、内核タグは反転させる
3. ギャップが大きいほど、キャラの「カードを切る瞬間」の衝撃が大きい
4. 各重要キャラには少なくとも一層のギャップが必要
5. 行動対比でギャップを示し、直接描写しない：

```
身份タグ：豪門の捨てられた妻
表現行動：罵られても言い返さず、追い出されても反抗しない
内核行動：こっそり録音、証拠収集、事前に財産を移す
```

---

## 三層タグ行動ギャップ発展

関係が第三層（親密関係）に入ると、キャラは第一、二層の関係でできた行動が逆にできなくなる。

| 関係段階 | できる行動 | できない行動 |
|----------|---------|-----------|
| 身份タグ期（陌生人） | からかう、冷たい、距離を保つ | — |
| 表現タグ期（知り合い） | 以前の行動パターンを継続 | — |
| 内核タグ期（親密） | 本当の自分をさらす | 以前のからかい／冷たさができなくなる |

### 実行命令

1. キャラが現在どの関係段階にいるかチェック
2. 行動ギャップ自体が人設の一部であり、必ずプロットに書く
3. 「行動退化 = 感情深化」で緊張感を生む——身份タグ期に主人公をからかうのが好きだったギャルが、親密関係に入ると逆に告白できなくなる
4. キャラが親密段階でも初期の行動を維持させてはいけない。さもなければギャップが無効になる

## 人設関連階層（強／中／弱関連）

| 階層 | 定義 | 機能 | 数量要求 |
|------|------|------|---------|
| 強関連 | プロットの方向性と核心ネタの爽快ポイントに直接影響する設定 | 人物の衝突、プロット推進 | 各キャラ少なくとも3個 |
| 中関連 | 脇役の強関連設定、主人公の風頭を奪わない | 脇役に機能性と認識性を提供 | 適量 |
| 弱関連 | 人物の厚みを豊かにする個人的嗜好設定 | キャラのリアリティと記憶点を増加 | 制限なし |

### 実行命令

1. 主人公の実力、金銭、人脈、背景などプロットに影響する属性を強関連に分類
2. 強関連が各キャラ少なくとも3個あるかチェック
3. 「ケーキが好き」「美人を見るのが好き」などを弱関連に分類し、人設を豊かにするためだけに使用
4. 弱関連が主役を奪わないようにする——強関連こそプロットを延伸する核心

## 人設実行ルール

人設 ≠ 人物設定表。

- 人物設定表 = 身長、外見、家庭背景などの情報の寄せ集め（外在情報）
- 人設 = キャラの「魂／特殊人格」を中心に展開する機能的设计
- 人設の使命：劇的緊張と感情の引き合いに奉仕し、人格で行動を駆動し、プロットに無理やり押されるのではない

**チェック**：書いた人物設定が身長体重と趣味だけで、「魂／特殊人格」の機能的设计がない場合は、やり直し。

## 脇役機能化設計

### 核心原則

1. 脇役の能力と特性はプロットと密接に関連しなければならない
2. 脇役は主人公を引き立てるために書く——脇役の能力は主人公のために使われ、脇役の困境脱出は主人公の助けによる

### 複合型脇役——ホワイトグローブ役

| 機能 | 説明 |
|------|------|
| 主人公の代弁 | 主人公が言うのに適さないことは、彼が言う |
| 主人公の代わりに強気に | 主人公が出すべきでない強気は、彼が出す |
| 絶対的擁護 | 主人公の利益を侵害する者には断固反撃 |
| 粗中有細 | 敵役の策略を録音し再生して大衆の支持を得る |
| 適時搞笑 | 正のフィードバックを出力し続け、緊張を緩和 |

**設計原則**：光环は主人公より少し弱く、風頭を奪わない；印象的な登場；主人公への疑問には第一时间で反論。

### 立体人物 vs 平面的な人物

1. 全てのキャラを立体化する必要はなく、まず機能性を見る
2. 平面的なキャラは神秘性を保ち、むしろより恐ろしく／より強力になる
3. 「浄化は三分弱く、黑化は三倍強く」——達人が立体化されると弱くなる
4. 必要な道具があればその道具を設計し、全てのキャラを立体化しない

### 人設ギャップ六次元法

| ギャップ対 | 操作 |
|--------|------|
| 表面性格 vs 内在性格 | 笑顔の虎／口が悪いが心は優しい |
| 外見 vs 表面性格 | 怖そうに見えて実は柔らかい |
| 外見 vs 内在性格 | 優しそうに見えて実は辛辣 |
| 身份 vs 生活方式 | 豪門の子弟が地下室に住む |
| 身份 vs 趣味特技 | 殺し屋が華道に秀でる |
| 身份 vs 内在性格 | 軍人が内心文芸的 |

### 実行命令

1. 脇役設計時、まずその機能を確定（主人公の代弁／強気に出す／搞笑／情報提供）
2. 六次元ギャップから1-2次元を選んで脇役にタグ付け
3. 脇役の光环を制御し、主人公を超えない
4. 機能性脇役は無理に立体化しない

## 脇役人設論理

1. 「正劇逆書」——表向きは正しい行動の背後に敵役の動機がある
2. 脇役感情保護殻：表向きは冷酷無情だが、実は深層の感情に駆動されている
3. 人設崩れ回避：キャラの行動選択は確立された人設論理に合致しなければならない
4. まず題材の「タグ人物」をそのまま使用する——成熟した題材の人設キャラは市場の試練を経ている

## 人設を際立たせる方法

### 実行命令

1. 輝くポイントを掴む——キャラの最も突出した特性を見つけ、集中して火力を注ぐ
2. 行動で人設を示し、ナレーションで説明しない（例：出所後、卑屈にも傲慢にもならず、利益を主張し、老練さを示す）
3. ギャップの衝突で緊張感を生む
4. ギャップで緊張感を引くことは読者をふるいにかける。尺度を制御する——ギャップが大きすぎると一部の読者を遠ざける

## 高EQ／賢い人物の橋段写法

### 実行命令

1. 高EQは具体的なプロットの中での振る舞いで示し、ナレーションで褒めない
2. 表情を読む、臨機応変、場を制御する具体的なシーンを書く
3. 高EQの振る舞いは古典的ネット小説の成功事例パターンを参考にし、各橋段には少なくとも「読者が気まずいと思ったが主人公が化解した」反転を含む
4. 各橋段には少なくとも一つの「反転」——読者は気まずくなると思ったが、主人公が完璧に化解する

---

## 脇役を期待のハブにする（人物クリップ）

### 実行命令

1. 一人の脇役を「任務基地」に選ぶ——一人の人物が複数の短期および長期の期待を同時に担う
2. 主人公が事件を解決して格好をつけるたびにその人物を訪ね、新たな格好つけを始める
3. 各プロット単位終了後、同一人物を利用して新しいプロットを展開
4. 人物が退場する時に大きな利益をもたらし、「偶然の収穫がもっと大きい」で読者の「損失回避」心理を転換させる

## 群像執筆法

### 実行命令

1. 各キャラの登場には機能が必要で、無駄があってはならない——機能の不明なキャラは登場させない
2. キャラ間の関係には階層が必要（案内人、敵手、仲間、障害）
3. 異なるキャラには異なる話し方と行動特徴が必要
4. 行動を通じて、ナレーションではなく、キャラの特徴を示す

### 脇役の記号化描写

1. 1-2個の突出した特徴を掴んで鮮明なタグを作る（口癖／象徴的動作／極端な性格）
2. タグ化で読者に素早く記憶させ、筆墨を使いすぎない
3. 機能性脇役には明確な機能が必要：プロット推進、主人公の引立て、情報提供

### キャラ使用のリズム

1. 人気キャラの登場頻度は3-5章に一度に制御し、期待感を保持し飽きさせない。毎回の登場には新しい情報か新しい機能が必要
2. 読者の興味がないキャラは諦めるべきで、自然に「退場」
3. 「キャラがキャラを連れてくる」で新キャラを導入——愛情の継続

### キャラプール編織法

1. キャラがキャラを連れてくる：ヒロインが好かれる → ヒロインの両親／姉／親友を書く → 愛情が新キャラに継続
2. 網のように編んでいく → すぐに尽きることのないキャラプールができる
3. 各新キャラに一つのタグを貼り、全て鮮明に

## 人設深化法

### 実行ルール

先に現在のプロジェクトが「物語深化」と「人設深化」のどちらに適するか判断：

| 条件 | 優先方向 | 実行動作 |
|------|------|------|
| 主线がすでに複雑、多勢力、多反転 | 人設深化 | 物語構造をシンプルに保ち、人物の欲望、ギャップ、関係相互作用で新鮮さを生む |
| 主线が直線的すぎ、人物は已に鮮明だが事件不足 | 物語深化 | 障害、目標変化、情報差、または代価を増加させ、機能のない新キャラは追加しない |
| 短編／軽量篇幅 | 人設深化 | 1-2個の強い人設タグで衝突を駆動し、大世界観を敷かない |
| 長編のキー巻／クライマックス巻 | 両者結合 | 物語を一次元アップグレードし、同時にキー人物関係に可視的変化を発生させる |

### 実行手順

1. シンプルで古臭い物語構造を取る
2. 人物に「劇的要素」を加える——対象読者が楽しめる設定
3. 数人の人物の相互作用の循環で持続的なプロットを生む

### 循環写法（単純なプロットでも5章以上書ける）

- 第1章：主人公が格好をつける → 叔父がさらに切迫
- 第2章：叔父が女生を追い詰める → 恋人が脅迫と誘惑を手伝う
- 第3章：女生が主人公に近づく → 恋人が陰でほくそ笑む
- 第4章：女生が帰って泣き訴える → 恋人が偽りの慰めをしつつ陰で楽しむ
- 第5章：復命して報酬を受け取る → 女生が恋人が報酬にあまり喜んでいないことに気づく

## 人物塑造技巧

### 女性キャラ塑造（男性向け）

1. 読者が好きなのはヒロインのタグ（高貴優雅、白い肌に長い脚）であり、外見描写ではない
2. ステレオタイプを利用する：吸血鬼=高貴優雅+外見秀麗、特に説明しなくても読者はわかる
3. ネット小説では美貌が最も安い資源——外見描写に多く筆墨を使わない
4. 性格設定は極端化可能：ツンデレの極致、主人公への深い愛情、自身の利益を考慮しない
5. 性格の一貫性を保持：設定後は言行が常に一致する

### 主人公はミスをしても良いが、尺度を把握する必要がある

| 許容できる | 許容できない |
|--------|---------|
| 不可抗力や情報差によるミス | 愚かさや聖母心によるミス |
| — | 実力に見合わないミス（最強の者が雑魚のために愚かなミス） |

### 主人公人設の内外ギャップ

1. 表面と内心のギャップを設計可能（例：表面はスケベだが内心は孤独）
2. ギャップ感がキャラの深みと面白さを増し、豊富なプロット衝突の可能性を提供

### 敵役の本質

敵役 = 主人公と立場が異なり、利益が相反する人。敵役に自身の考えと追求を与え、純粋な悪を書かない。

### ヤリチン人設写法

1. 冒頭から主人公の人設を明確に伝え、穿越前後で一貫させる
2. 「又当又立」を避ける——前に主人公がスケベだと描いていないのに、後で突然追いかけると読者は反感を持つ
3. 明確な人設 = このタイプの人を受け入れる読者を選別 = 期待管理

## 人物記憶点法

1. 各人物には少なくとも一つの性格面が特に突出している
2. ある特徴を特に突出させることで初めて記憶点になる
3. 目標：プロットが進まなくても、数人の人物が座って話しているだけで、読者が興味深く読める

---

## 金手指が人設を拘束する法

### 実行命令

1. 金手指は主人公に超能力を与えるだけでなく、主人公の性格を合理化することが目的
2. 金手指のルールで行動を拘束 → 脇役の反応が自然にイメージを形成 → 主人公の品格を直接描写する必要がない
3. 道徳的爽快感（最高級の爽快感）を追求：主人公を行動面で読者が心から敬服する「生ける聖人」にする

---

## ネタ中心の人設塑造

### 実行命令

1. 単一タグ「殺伐果断」「熱血」は曖昧すぎる → 具体的なネタでキャラを建設 → 読者に強い記憶点を生む
2. 例：脇役が主人公の成功を見るたび → 羨ましく嫉む → 「お前、マジで死ねばいいのに」 → 強い記憶点+面白さ
3. 良い人設 + 平凡な金手指 + ありふれたパターン → 予想外の魅力を発揮することもある

## 九次元人設フレームワーク

| 次元 | 内容 | 要点 |
|------|------|------|
| 基本情報 | 前身今生／外見特徴 | 人物から長期の期待感を確立 |
| 性格 | ギャップ人設 | 成長弧線の鋪墊 |
| 嗜好習慣 | 金銭欲／色欲／殺人後の供養 | 強い記憶点として繰り返し強調 |
| 人間関係 | 関係網が複雑なほど衝突を生む | 関わる重要人物は皆実力と背景を持つ |
| 背景 | 家族／出身／成長環境 | — |
| 成長弧線 | 下記三階段参照 | — |
| 対比ギャップ | 悪人vs善人／医師の救死扶傷→銃を担いで人を殺す | — |
| 価値観の態度 | 異なる身份地位で見方が異なる | 態度=行動目標 |
| 人物小伝 | 典型的な重要な物語 | 凝縮された生い立ち経験 |

### 人物成長弧線（三階段）

| 段階 | 核心 | 対応 |
|------|------|------|
| 小我（幼年） | 自分を偽装し、他人の目に映る自分になりたい | 動機 |
| 自我（青年） | 本当の自分、両者の間で苦しむ | 態度 |
| 他我（成熟） | 他人の目に映る自分が追い求める目標になる | 価値観 |

感情公式：満足（承認）→ 打撃（同情）→ 懷疑（共鳴）→ 心痛（共感）

## 人設関係四段階タグ

| 段階 | 理解度 | 表現 |
|------|---------|------|
| 相遇（陌生人） | 外見しか知らない | 警戒／距離を保つ／防御 |
| 相识（通行人） | 初步的な理解、底线は不明 | 顔色をうかがう／お世辞 |
| 相知（親友） | 性質と底线を知る | 下ネタ／本音を漏らす／悩みを打ち明ける |
| 相恋（恋人） | 内心の傷跡を理解 | 独占欲が強い／喋り続ける／無条件に尽くす |

## 職場思考でネット小説の関係構造を理解する

### 実行ルール

ネット小説の本質：ある「職場」で徹底的に爽快になった後、別の「職場」に行く。

### 共性と差異

| 共性次元 | 説明 |
|---------|------|
| 階層 | どの環境にも上下関係がある |
| 互助 | 同級間の協力と互恵 |
| 互害 | 同級間の競争と排斥 |

| 差異次元 | 説明 |
|---------|------|
| 協力方式 | 環境により協力パターンが異なる |
| 資源類型 | 環境により争う資源が異なる |
| 個体能力 | 主人公の独特な優位性 |

### 実行手順

1. 主人公に「職場環境」を設計する（学校／宗門／会社／軍隊）
2. 階層関係を設置する（上司／同級／部下／敵手）
3. 階層関係を利用して自然に矛盾と衝突を生む
4. 主人公がこの環境で徹底的に爽快になった後、より大きな「職場」に移る

## 没入感構築法

### 実行ルール

- 没入感維持ルール：リズムと感情連鎖が途切れない。途切れの兆候=読者が現実の論理でプロットを判断し始める
- 読者が現実の論理で判断し始めたら = リズムに問題がある
- 核心は感情連鎖が途切れないこと

### 実行方法

| 方法 | 做法 | 効果 |
|------|------|------|
| 共感の入口 | 日常生活のよくある事件を使用 | 瞬間的に距離を縮める |
| 詳細のリアリティ | 生活感のある詳細を填充 | 世界のリアリティを強化 |
| 猫を救うプロット | 冒頭のプロットで主人公の人設のある側面を強調 | 読者が素早く慣れ没入 |
| 共感の前提 | キャラに本当の一面（弱点／困境）をさらけ出させる | 読者に保護欲を生む |
| 合理化された痛点 | 「金欠」のような誰もがわかる困境 | 天然の共感 |

### 共感の三階層

1. **表面共感**：経験が類似
2. **深層共感**：感情が類似
3. **同一感**：価値観が一致

### 没入感を破壊する行動（避ける）

- キャラが読者に理解できない選択をする
- 大きな段落の設定説明が叙事を中断する
- リズムが鈍くて感情連鎖が途切れる
- 主人公の価値観が対象読者から大きく逸脱する

---

## 安全感と核心感情の把握

1. 異なる題材の読者は安全感に対する要求が異なる。まず題材を確認する
2. 極道流などの緊張感題材：安全感を最大にすると = 危機感が消える = 核心感情がズレる——主人公に強力な後ろ盾を与えない
3. 主人公に随时に危機を解決できる強力な後ろ盾を設置することを禁止——後ろ盾の存在は切迫感を弱めてはいけない。このルールに違反した場合は「後ろ盾過度」とマークする
4. 精力に限りがある時、プロットが常に第一であり、世界観は加点要素に過ぎない

## 品質チェックリスト

キャラ設計完了後、項目ごとにチェック：

- [ ] キャラに三層タグ（身份／表現／内核）があり、少なくとも一層のギャップがあるか
- [ ] 強関連設定が3個以上あるか
- [ ] 人設が機能的设计か、外見情報の堆積のみか
- [ ] 脇役に明確な機能があるか、主人公の風頭を奪っていないか
- [ ] 各キャラに少なくとも一つの記憶点があるか
- [ ] 脇役の登場に全て機能があり、無駄がないか
- [ ] 異なるキャラに異なる話し方と行動特徴があるか
- [ ] 主人公のミスが許容範囲内か
- [ ] 敵役に自身の論理と追求があり、純粋な悪ではないか
- [ ] 人設の言行が前後一致し、崩れていないか
- [ ] 没入感の感情連鎖が連続し、設定説明で中断されていないか
- [ ] 安全感が題材要求に適合しているか（緊張題材では主人公に強すぎる後ろ盾を与えない）
- [ ] 高EQの橋段が具体的なプロットで示され、ナレーションで褒められていないか
