# 創作技法マニュアル

> 短編創作時の表現技法をまとめたもの。描写技法、修辞技法、リズム技法を含む。

---

## 描写の三層

良い描写は三層から構成され、それぞれが異なる機能を果たす。

```
第一層：事実層（何が起こったか）
第二層：感覚層（五感で何を感じたか）
第三層：感情層（この場面がどんな感情を伝えるか）
```

### 三層の応用例

```
第一層だけ：彼女は泣いた。
　　　　　　→ 読者は「泣いた」という事実を知るが、感じるものはない

第一層＋第二層：彼女の涙がこぼれ落ち、スカートに染みを作った。
　　　　　　　　→ 読者は涙の跡を「見て」、もう少し感じられる

三層完成：彼女の涙がこぼれ落ち、スカートに染みを作った。
　　　　　彼女はそれを拭こうともしなかった。
　　　　　→ 具体的な描写＋行動の中の感情
```

### 描写の厚みと薄さ

| 場面タイプ | 描写の厚み | 説明 |
|----------|----------|------|
| キー場面 | 厚め | 三層完成、時間をかけて書く |
| つなぎ場面 | 薄め | 事実層だけで十分、早く過ぎ去らせる |
| 感情場面 | 中程度 | 感覚層＋感情層、読者に感じさせる |
| 爽快場面 | 薄め | 主に行動と効果、テンポを速く |
| 感情場面 | 厚め | 感情層中心、余韻を残す |

## 修辞技法

### 対比

二つの状態を並べ、その差で感情を強調する。

```
操作：キャラのA時とB時を並べて書く
例：「一年前、彼女はまだ彼の腕の中にいた。
　　一年後、彼女は彼の墓の前に立っていた。」
効果：時間の残酷さを感じさせる
```

### 呼応

前後に同じ要素を出現させ、その意味を変化させる。

```
操作：前半のある要素を後半で再び出現させ、異なる状態を示す
例：「彼は三年ぶりにそのドアを開けた。
　　前にここを出た時は二人、今戻ってきた時は一人だった。」
効果：時間の流れと変化を感じさせる
```

### タメと爆発

情報を抑えてから解放する。

```
操作：重要な情報を抑え、蓄積した後に一気に放出する
例：
  彼は何も言わなかった。（タメ）
  ただ目の前の書類を差し出した。（タメ）
  その書類のタイトルは——（タメ）
  「離婚届」だった。（爆発）
効果：爆発の瞬間の衝撃を最大化する
```

### 反復

同じ言葉やパターンを繰り返し、感情を強調する。

```
操作：キーワードや構文を繰り返し使う
例：「忘れられない。彼の最後の笑顔が。
　忘れられない。彼が最後に言った言葉が。
　忘れられない。あの日の雨が。」
効果：感情を段階的に押し上げる
```

### 省略

全てを書かず、読者の想像に委ねる。

```
操作：重要な情報を意図的に省略し、空白を残す
例：「彼は振り返らずに去っていった。その後、何が起こったのか——
　　私は知らない。」
効果：読者に想像の余地を与え、余韻を残す
```

## リズム技法

### 短文連打法

短い文を連続して打ち、切迫感や強い感情を表現する。

```
操作：主語＋述語の短文を連続させる。修飾語は最小限に
例：「彼は来た。彼女を見た。微笑んだ。そして倒れた。」
効果：切迫感や強い感情の爆発を表現する
```

### 長短結合

長文と短文を交互に使用し、リズムに変化をつける。

```
操作：長文で情報や感情を敷設し、短文の連打で爆発させる
例：「彼女は彼の目を見つめ続けた。その目はかつてのように温かくはなく、
　　代わりに見知らぬ冷たさが満ちていた。その目は、彼女ではない別の誰かを
　　映していた。ようやく、彼女は悟った。
　　彼はもう、彼ではない。」
効果：情報から感情への自然な移行
```

### 改行のリズム

改行でリズムを制御する。

| 意図 | 改行方式 |
|------|----------|
| 切迫感 | 改行を少なく、段落を長く |
| 余韻 | 改行を多く、段落を短く |
| 強調 | 一言だけで一行 |
| 思考 | 適度な改行、読者に考えるスペースを |

## 視点制御

### 一人称の技法

- 「私」の視点から外れた情報は書かない
- 「私」の性格に合わない言葉遣いは使わない
- 「私」の感情の変化が読者の感じる変化と同期している

### 三人称限定

- 各シーンの視点人物を固定する
- 視点人物が見聞き感じる範囲を超えない
- 視点の切り替えは空白行で区切るか、章節で区切る

### 視点距離の制御

```
近い距離：主人公の内心を直接書く（〜思った、〜感じた）
中距離：主人公の行動や台詞を通じて感情を示す
遠い距離：客観的に出来事だけを書く
```

視点距離を変えることで感情の強さを制御できる。

## 情景融合

感情と景色の描写を一体化させる。

```
操作：キャラの感情を環境描写に投影する
例：
  悲しい：窓の外はどんよりと曇っていた。
  嬉しい：窓の外の日差しは暖かかった。
  焦り：時計の秒針が一段と大きく聞こえた。
  孤独：街は賑わっていたが、私とは関係がなかった。
```

注意：情景融合は使いすぎない。情感が強く出る場面だけで十分。

## 節約の技法

### 「言う」の省略

台詞以外の方法で台詞の意味を表現する。

```
書かない：「彼は怒って言った。「出て行け」」
書く：彼はドアを指さした。「出て行け」
```

### 「感じる」の省略

直接的な感情語を使わず、行動で感情を表現する。

```
書かない：「彼女はとても悲しんだ」
書く：「彼女は唇を噛みしめ、涙が目に溜まっていた」
```

### 「思う」の省略

直接内心を書かず、行動や台詞で思考過程を示す。

```
書かない：「彼女は彼を信じるべきか迷った」
書く：「彼女は彼の目をじっと見つめた。
　　——やがて、うなずいた。」
```

## よくある表現上の問題

### 形容詞の濫用

```
問題：泣ける話、感動的な場面、美しい景色
改善：読者に泣かせる話、心を打つ場面、目を奪う景色
```

### 副詞に頼る

```
問題：非常に悲しむ、とても速く走る、完全に忘れる
改善：涙をこぼす、風のように駆ける、記憶から消える
```

### テンプレート表現

```
問題：涙が止まらない、胸が張り裂ける、目の前が真っ暗になる
改善：より具体的で個性的な表現を探す
```
