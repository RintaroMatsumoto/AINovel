## 段落規範

### 段落内の句読点

| 記号 | 規範 |
|------|------|
| 読点 | 会話が多く感情が濃い章では、読点を多めに使ってリズムを遅くし、感情を重厚に。戦闘や慌ただしい章では読点を減らし、リズムを速くする |
| 疑問文 | 連続疑問文で焦りを表現できるが、多用は避ける。一回の高ぶりは一回の疑問で十分 |
| 感嘆文 | 感嘆符は厳選して使う。多用は感情を薄める |
| 三点リーダー… | 省略/沈黙/余韻を示す。多用は避ける |
| 長セリフ内の改行 | 長セリフ（40字超）は適宜改行し、意味グループで区切る |

### 段落長さ規範

| 内容 | 段落長さ | 説明 |
|------|---------|------|
| 叙事段落 | ≤120字 | 情報量が多すぎたり少なすぎたりしない |
| 会話段落 | ≤100字 | 30-60字を推奨、読点でリズムを制御 |
| 動作描写 | ≤60字 | 短文で連打、画面感を強める |
| 感情曲線 | 短文 + 適度な改行 | リズムが速く、感情が凝縮される |

**段落末の処理**：重要な情報や感情的な爆発点は段落末に置く。段落末の大爆発は読者に次に進む動機を与える。段落末は疑問文で締めくくることができ、連続疑問は避ける。

### シーン転換処理

- 時間/空間の変更は1-3行の空白行で区切り、特殊記号は使わない
- シーン転換は見出しや特殊記号を使わず簡潔に。単一改行で識別する
- 同一シーン内の自然な区切りは改行のみ使う
- 節の切れ目は連続性を保つ必要がある。各区切りが次の区切りを導くよう、期待感を内包する

## 章節構造設計

### 一章の核心理念

- 一章は一つの約束（プロット目標を完全に果たす）
- 一章は開始、発展、転向（フック）、結尾の四部分を含む
- タイトルは2-4文字、章の内容を簡潔に要約し、過度なネタバレはしない。良いタイトルはあまり明かさない
- 每章1500-2000字（ネット小説）、章タイトルは行カウントに入れない。一章で一つの爽点/燃点/サプライズを完了する

### 開篇設計

- 章タイトルの後の第一文はフックでなければならず、章タイトルの即時展開でなければならない
- 第一行で読者を掴む、核心情報/衝突/反転で始める
- 章の冒頭は前に書かれた問題を再提起し、連続性を形成する

### 結尾設計

- 結尾は次の章への期待感を生む、問題を提起するか反転を予告する
- 一章は結尾から次の章へつなぐ各節で構成される
- 章末はフックで締めくくり、読者にページをめくらせる。爽文は高潮後に速やかに收束し、余韻を引きずらない

### 一人称書式規範

- 一人称の長編は視点が完全に一人称に制限され、神視点になってはいけない
- 三人称の長編は視点を統一し、同じ段落で視点が飛躍しない

### 視点衝突処理

もし視点の衝突が生じた場合：

1. 視点移動は読み手に混乱を生じさせる。一人称（私）を使う時は、動作の主体を明確にし、主語の省略による混乱を避ける
2. 三人称限定（彼/彼女）を使う時は、各シーンの視点人物を固定し、見聞き感じる内容が視点人物の感知範囲を超えないようにする
3. 一人称と三人称の混用は避ける。単一長編で視点類型を途中で変えない

## 節奏制御規範

### 基本節奏ユニット：一呼吸

一呼吸 = 10-15行（テキスト量に応じて調整）。各呼吸に一つの小さな機能を持たせる：
- 情報放出（読者の認識を更新）
- 感情蓄積（押し）
- 爽点解放（引き）

三呼吸で一つの小さな段を構成し、段の転換に小さな期待/サプライズを配置する。

### 節奏配分原則

| 段階 | 情報密度 | 感情強度 | 節奏速度 |
|--------|----------|----------|----------|
| 開篇 | 中 | 中-高 | 快 |
| 鋪墊 | 高 | 低-中 | 中 |
| 爽点解放 | 低 | 高 | 快（短文+段落） |
| 余韻 | 低 | 中 | 遅 |
| 移行 | 中 | 低-中 | 中 |

### 五感描写節奏原則

- 描写はプロットの展開に合わせて入れ、数千字の景色描写だけの段落は避ける
- 五感描写は感情基調と調和すべき：悲しい場面の雨は冷たく、嬉しい風は暖かい
- 五感情報は戦闘や慌ただしい章では簡潔に、感情章ではやや多く

### 緩急結合原則（三呼吸法の応用）

3-5段落の緊迫した展開の後には、1-2段落の緩和を入れる：
- 緊張後の緩和は適度な「空白」を生み、緊張を倍増させる
- 緊張し続ける文章は読者が疲れる。ただ緩いだけの文章は読者が眠くなる

一つの爽快な爆発の後には、感情の収束段落が必要で、すぐに次の展開に進んではいけない。収束段落はキャラの感情変化を示したり、爆発の余韻を環境描写で間接的に示したりできる。

### 交差叙事

複数視点の交差、時間線の交差——情報を引き伸ばすことができ、各線のつなぎ目に期待感が生まれる。基本的な交差方式：

- POV（人物ごとの視点）の切り替えは「事件の同時性を確保」し、各視点で「部分情報」を明かし、読者に全体像を推測させる
- 双線並行：A線はB線の結果を作り、B線はA線の原因を作る——情報交換をつなぎ目に配置する
- 交差叙事の各線の分量はバランスを取る。主線が70-80%を占め、副線の切り込みは短く簡潔に

## 開篇構造規範

### 全体的構造

**黄金三章は一つの約束の完了と次の約束の始まりである**：第一章で最初の爽点を解放し、第二章で新しい衝撃を生み、第三章で世界観と主要な対立を拡大する。読者は第一章で約束を感じる必要があり、第二章で小さな爽点（爽/燃/虐/甜）を解放し、第三章で物語が確実にこの方向に進むと感じる必要がある。

開篇の核心問題：なぜこのキャラなのか？なぜこの時間なのか？——第一章の目的は読者にこのキャラと物語に関心を持たせることである。

### 配分と節奏

**全体的に10-12段（12000字）を仮定**：

| 段階 | 位置 | 機能 | 節奏 |
|------|--------|------|------|
| 第一段 | 0-10% | 核心フック：反転/衝突/サプライズ | 速い |
| 第二段 | 10-30% | バックグラウンド引出 + 小さな爽点1 | 中 |
| 第三段 | 30-50% | 深い衝突 + 小さな爽点2 | 中→速い |
| 第四段 | 50-70% | 大きな反転/爽点解放 | 速い |
| 第五段 | 70-90% | 余韻/鋪墊/小さなサプライズ | 遅→中 |
| 第六段 | 90-100% | 結尾フック（次の章を導く） | 中 |

### 最小要件

- 第一段（0-10%、約1200字）以内に核心フックが現れる
- 第二段（10-30%）以内に世界観の基本的ルールと主人公の初期状態が確立される
- 第三段（30-50%）以内に主要な対立構造が形成される
- 第四段までに物語の核心方向が確立される

## 結尾分析規範

### 結尾の五種方式

| 方式 | 操作 | 読後感 |
|------|------|--------|
| 応報式 | 善悪それぞれに応報、悪人には罰を | 溜飲が下がる、安心 |
| 開方式 | 意図的に未解決の問題を残し、読者に想像の余地を | 余韻、考えさせる |
| 反転式 | 最後の瞬間に読者の認識を覆す真実を明かす | 驚き、タイトルを振り返らせる |
| 情感式 | 静かな詳細や動作で強い感情を担う | 感動、長く忘れられない |
| 呼応式 | 開篇から戻る、物品/場面/台詞を呼応 | 閉じた丸い感じ、構造美 |

### 結尾書くときの注意

- 急ぎすぎない。良い結尾は鋪墊が必要で、突然の終わりは読者が消化不良を起こす
- 結尾を引きずらない。反転後は速やかに收束する
- 結尾は前の約束に応えるべきで、突然新しい設定を持ち出さない
- 結尾の基調は全編と一致する
- 結尾は開篇と呼応し、最初に敷いた伏線を結末で回収する

## 書式原則

### 見出し規範

- `#` は作品タイトルのみ使用。各節は `##` を使用
- 第一層の節タイトルは `##`。タイトルには句読点を使わず、2-4字を推奨
- 必要に応じて `###` で細分化する
- 内部文書のタイトルと注釈は `**太字**` を使用

### リンク

- 内部文書同士の相互参照は、ルートからの相対パスを使用
- リンク名は簡潔に、長すぎない

### リスト規範

- 物品リストは箇条書き
- 手順と設計書の箇条書きは、必要ならサブリストを入れる
