## 人物関係類型

表を確認してキャラ間の関係類型を決定し、原則に従って実行する。

| 関係類型 | 定義 | 機能 | 例 |
|---------|------|------|------|
| 衝突型 | 双方の利益／理念が对立 | 緊張感を生み、プロットを推進 | 宿敵、競争相手 |
| 連盟型 | 双方に共通目標がある | 助力を提供し、絆を生む | 戦友、師弟 |
| 親密型 | 感情的な繋がり | 弱点を作り、感情的な支点を提供 | 恋人、家族、兄弟 |
| 権威型 | 上下／支配関係 | 圧力を生み、主人公の行動を制限 | 師匠、ボス、監視者 |

**実行ルール**：
- 各重要関係に少なくとも一回の試練を配置する（裏切り／犠牲／誤解）
- 関係には変化の弧が必要（敵から味方、味方から敵）
- 全ての関係が「良い良い」の一枚岩であることを禁止
- 関係の機能はプロットに奉仕しなければならず、甘さ／虐めのためだけに存在してはいけない

## 感情流人設核心法

感情流ではプロットが人設に奉仕する——各プロットは人物を豊かにするか感情の発展を推進しなければならず、そうでなければ無効なプロットである。

### 構築手順

1. **人設核心を確定**：最初に脳裏に浮かんだキャラの特徴を書き留める（例：「皇位に就きたい皇子」「病弱な皇子」）
2. **核心を中心に発散**：なぜこの核心なのか？過去の経験は？環境の影響？性格の成因？
3. **プロット線を延伸**：核心に付随するプロットは必ず書く（目標がある→目標線；傷がある→治癒線）

### 実行ルール

- ありふれたプロットでも豊かな人設があればパターン感から脱却できる
- 両方の主人公に輝く点と独立した変化のルートが必要で、一人だけが際立ちもう一人が薄れてはいけない
- ハイライトは格好つけに等しくない——読者にキャラを印象づける全ての瞬間がハイライトであり、痛徹心扉の瞬間も含む
- 人生は恋愛だけではない——キャラの心は恋愛を望むが、人生は恋愛だけではいけない。恋愛だけのキャラは立たず、非常に薄い

## 男性向けと女性向けの愛情線底層論理差異

**先に対象読者層を確定し、それから対応する論理を選択する。両者は混同してはいけない。そうしないと読者は「違う」と感じる。**

### 男性向け愛情線論理

| 次元 | 説明 |
|------|------|
| 核心 | 「外在要素展示」——主人公と相手が一緒にいることで二人の外在要素がどれだけ優れているかを示す |
| 三種核心論理 | 「彼女が自分のものだったらな」→「こんなに優秀な人が自分のものだ」→「こんなに優秀な人が好きになってくれるなら、自分はもっと優秀だ」 |
| 傍観者の考え | 「こんなに優秀な女性を得られるなんて、羨ましい」（「恋愛って甘いな」ではない） |
| ヒロイン | 複数の女性キャラが主人公を好きであることが望ましく、多ければ多いほど主人公が優秀であることを示す |
| 相手の本質 | 「トロフィー」——全ての動機の根本的目的は勝利 |

男性向けの感情線を書く時は「優秀さを示す」ことを中心に事件を設計する。

### 女性向け愛情線論理

| 次元 | 説明 |
|------|------|
| 核心 | 「繋がり」——二人の間の唯一で、壊れず、最も優先される感情的な繋がり |
| 繋がりの要求 | 「あなたは私の外見や富や才能のためではなく、私が私だから私を愛している」 |
| 純潔性 | 繋がり形成後は徐々に外在要素の影響を捨てるべき |
| 双方 | 初恋+両者潔白が最良——繋がりの純潔性と唯一性を保障 |
| 傍観者の考え | 「彼らの恋愛は甘いな、羨ましい」 |

女性向けの感情線を書く時は「繋がりの深化」を中心に事件を設計する。

## 穿書／穿ゲーム役割選択法則

### 満たすべき条件

- 叙事主人公は原世界にかなり精通している必要がある（最も核心的な期待感の來源）
- 熟知した世界に穿越したことを確定し、一言二言で説明し、一章を超えてどこにいるかわからない状態にしてはいけない
- 穿越後に強い劇的要素または強い矛盾を持つ役割を選択しなければならない（例：悪役の女脇役に穿越）

### 情報差設計

- 原世界の基礎の上に適度に情報差を設計し、叙事主人公に探索の余地を提供
- 原世界の知識を使ってバグを突き、超過収益を得ることができる

## 修羅場収拾策略

修羅場の本質は一種の矛盾である。対抗の烈度を制御し、愛情線の対象の間に調停不可能な矛盾を生じてはいけない。

| 収拾方法 | 操作 |
|---------|------|
| 事業線に関連付ける | 愛情線の対象たちの嫉妬を「誰が主人公の事業線への貢献が大きいか」の競争に転化させる |
| 事業線の突発事件を挿入 | 対抗が白熱した時、突発事件で全員を内戦から一致団結して外に対抗するよう切り替えさせる |
| 一筆で流す | 最大二人が互いに気に入らず、二言三言嘲るだけで過ぎ去らせ、非常に抑制的 |

## 純真キャラ塑造の落とし穴回避

### 六つの必避の落とし穴

1. ヒロインのミスは意図的であってはならず、できないとわかっていながらしてはいけない
2. ヒロインのミスは道徳に違反してはいけない——純真で最も重要なのは子供のような高い道徳感
3. 道徳的高みから他人を非難してはいけない（道徳的嫌がらせ行為）が、自分はできていない
4. 道徳的嫌がらせ行為でチームメイトと矛盾した後、チームメイトに謝らせて彼女を褒めさせてはいけない
5. 正しい做法：より高い道徳基準を持つ → 行いが基準に合致する → そのために異彩を放ち少し愚かに見える
6. 成長線を書くことも可：彼女が非難した人の立場に座ってみると、あのやり方が既に最良の選択だったとわかる

### 逆用法

純真な敵役を塑造する時、上記六点を全て彼女に加え、読者が一目で嫌悪するようにする。

## 人設変更の双方向反転法

愛情線で関係が変化する時の人設調整方法。

### 核心思路

- 最良の変化は二人とも変わることであり、変化後が偶然にも以前の二人の間の対応関係と逆になる
- 変化は適当な変更ではなく、元の人設を基にした部分的な変更であり、元の人設と密接に関連する

### 実行ルール

- 人設の変化は「愛が山と海を隔てる」段階以降に起こる（特に最大の障害に直面した後）。新たな矛盾を設計せず、甘い展開だけにする
- 本当の障害は既に前で解決されており、この時読者が最も切実に望むのは多くの甘い展開
- 甘い展開は実質的なCP行動と細やかな世話で愛情を表現し、「愛してる」式の工業的な甘さであってはならない

## キャラ行動の自己一致チェック

### 第一步：外部強制を排除

キャラの行動が単にプロットをある方向に進めるためのものかどうかをチェックする。もしキャラが「たまたま」プロットを推進することをしたが、自身の動機がない場合は、「人設偏移」とマークし、その行動にキャラレベルの合理的な理由を補充しなければならない。

### 第二步：感情目標確認

各段落を書く前に三つの要素を明確にする：
1. 本段の目標感情：このプロットで読者に何を感じさせるか？
2. キャラの性格特徴がその感情をサポートするか：キャラの設定属性が自然にこの感情方向に導くか？
3. キャラの行動が使命の位置づけに合致するか：キャラの本段の行動が物語における機能的位置づけと一致するか？

### 第三步：人設行動の推論

キャラの既に設定された属性（経験／性格／目標／現在の状態）からシーンでの行動を推論する：
- このシーンでのキャラの2-3の可能な反応をリストアップ
- 各反応とキャラの既存の行動パターンの一致度を評価
- 最も人設に合致し、かつ最も劇的緊張のあるものを選択

### 第四步：感情一致性の検証

キャラの表現する感情の核心とシーンの目標感情が一致するかチェックする。一致しない場合はキャラの行動またはシーンの目標感情を調整し、出力内容が感情次元で自己一致するようにする。

**二つの実行路径**：
- 路径A：先に目標感情を決める → 人設に従ってキャラ行動を推論 → 一致性を検証
- 路径B：先に人設に従ってキャラ行動を推論 → シーンの目標感情を逆推 → 一致性を検証

## 脇役攻略バッファ

脇役の主人公に対する態度の変化過程 = 主人公が脇役を攻略する過程であり、大きな期待感と爽快感を伴う。

### バッファ類型

オンラインオフライン、背後での議論、遠距離、地位格差、親密度格差、信頼度、情報差など。

### 操作手順

1. 常にバッファを存在させる
2. 巻綱の中から事件の転換点（5〜7個）を選び出す
3. 各転換点で脇役の状態と主人公に対する態度の変化を記す
4. 攻略がキーポイントに達するたびに、脇役の態度変化を明確に書く
5. 態度変化自体が情緒変動と期待感を生む

### 実行ルール

- 脇役はNPCのように立って主人公のトリガーを待ってはいけない
- 脇役には自身の行動が必要で、脇役の視点から事件を引き出す
- 正面キャラも同様：主人公と同じ立場の者も自身の行動と動機を持つべき

## キャラの身份認識差を利用して衝突を生む

同じキャラに対する異なる人の「声望」は動的に変化し、一定の値ではない。

| 視点 | 重視すること | 男主への評価 |
|------|----------|-------------|
| 世俗視点 | 家柄の釣り合い、リスク耐性 | 総合条件のマッチ度 |
| 男主自身 | 金を稼いで家族を養う+感情 | 相対的な釣り合い |
| ヒロイン視点 | 感情+一途+愛 | 気にかければ釣り合う |
| 金持ちの息子 | 外見家柄のマッチ度 | 自分の方が釣り合う |
| 通行人 | 総合条件の比較 | ヒロインは金持ちの息子と結婚すべき |

**操作ポイント**：
- 同じキャラに対する異なる人の評価の差 = 天然の矛盾衝突の來源
- 恋愛文の核心的な爽点の一つ：異なる次元の評価差

## 亦敵亦友の関係

最も魅力的な人物関係類型。

### 実行ルール

- 前提：両方のキャラ自体に魅力が必要で、そうでなければ無理に五分五分にしたただの張り付き
- 核心：高度な認可 + 絶対的な衝突 → 互いに認め合う → どちらかの魅力が欠ければ全て無意味
- 本当の宿敵 = 相互に認め合うものであり、他人がそう言うからそうなのではない

## 競争者の位置づけと家族線の用法

### 競争者（ナマズ効果）

- 位置づけ：男主／ヒロインに緊張感と圧力を与える → 攻略の進捗を推進
- プロット設置の重点は「盛り上がり前」 → 鋪墊の段階
- 盛り上がり後のプロット継続にはあまり効果がない → 延命手段ではない

### 家族線の四つの方向

| 方向 | 作用 | 使用タイミング |
|------|------|---------|
| 男方の助力 | 金銭地位権力を提供 | 盛り上がり前に発揮 |
| 男方の抵抗 | 障害を設置して主人公に認可させる | 前後どちらでも使用可 |
| 女方の助力 | 安らぎの感情補給ステーション | 盛り上がり前に発揮 |
| 女方の抵抗 | 親が同意しない→認可のために努力 | 前後どちらでも使用可 |

助力は主に盛り上がり前、抵抗は前後どちらでも使用でき、抵抗の方が効果的。

## 男性向け恋愛文の書き方攻略

### 読者はなぜ恋愛文を読むのか

| 価値 | 來源 |
|------|------|
| 情緒的価値 | 「必要とされる、気にかけられる」という感情の空白を埋める |
| 自尊的価値 | ヒロインの条件が良い→連れて歩くと顔が立つ→脇役が羨む |
| 高身份ヒロインの理由 | より強い格好つけの道具 + より大きな自尊の満足 |

### 核心技法：恋愛を升級文として書く

- 曖昧で引っ張り合う過程が最も魅力的
- 好感度プログレスバー：一歩ごとの進展 = 升級文の中の一つの「レベル」
- 各事件は一回の「升級」→ 衝突、化解、理解、共鳴を通じて好感を上昇させる

### 好感度アップグレード路径

通行人 → 良い人（おばあさんの横断歩道を助ける） → 正直勇敢な良い人（挺身而出） → 良い友達（家庭環境の困境を理解する） → 好きだが自覚なし（特殊なきっかけで互いの知られざる一面を見る）

### キー原則：主人公は積極的に追わない

- 現在の男性向け読者は「犬」のような人設を普遍的に嫌う
- 好感の推進は男主自身の優秀な資質が引き寄せるものであり、積極的に追うのではない
- 男主がヒロインを助けるのは手軽なことであり、意図せずに行う → ヒロインはそのために彼を覚える

### 感情アップグレードの非対称性

- 二つのプログレスライン：表面的社会的関係（通行人→友達→カップル）+ 実際の感情的好感度
- 二つのラインは並行して進んではいけない → 一方が速く一方が遅い → 豊富な矛盾衝突を生む
- 感情線が社会線より速い → 輝夜大小姐モード（双方の好感度はMAXだが口が硬くて告白しない）
- 社会線が感情線より速い → 婿入り／擇天記モード（表面上は夫婦だが実際の好感度はゼロ）

### ヒロインが主人公に良くすることを書く

| ヒロイン類型 | 尽くし方 |
|---------|---------|
| 自信過少で内向的 | こっそり助けて物を差し入れるが、見つかるのを怖がる |
| ツンデレ型 | 心を込めて弁当を作るが、口では「作りすぎたからついでに持ってきた」 |
| 率直で活発 | 堂々とプレゼントを贈るかストレートに告白 |

### 対比を活用する

| 対比類型 | 操作 |
|---------|------|
| 時間線対比 | ヒロインが主人公を初めて知った時 vs 慣れた後の態度変化 |
| ダブルスタンダード | 他の人には頭を触らせないが主人公は可 → 特殊な地位を強調 |
| 情報差 | 男女の二重身份（オンライン vs 現実）→ 暴かれた時の反応への期待 |

## 好感度体系（汎用フレームワーク）

### 四段階

萍水相逢 → 恋愛喜劇 → 愛は山と海を隔てる → 大団円

### 好感度 × 関係段階対照表

好感度（負／零／半／満） x 関係段階（熟知／探り／曖昧／確認）

段階一致原則：**低い方に合わせる**。好感度が届いていても関係段階が届いていなければ = 行動が唐突。

### CP行動の三類閾値

| 行動類型 | 閾値 | 説明 |
|---------|------|------|
| 許容行動 | 半好感+ | 積極的親密、妥協、補償を与えなければ犬になる |
| 特別待遇行動 | 半好感+ | 主権、信頼、犠牲、特待、慰め |
| 関連行動 | 双方半好感+ | 黙契、共有、同伴 |

好感度不足時に許容行動を書く = 脂ぎった／セクハラ感。

### 5セットの感情線構造テンプレート

| テンプレート | 核心 |
|------|------|
| 好感度変化 | 上昇／下降／既に下降 → 各々の処理路径 → 余韻 |
| 利益 | パートナーによる利益を享受 = 愛情線格好つけの核心 |
| 嫉妬 | 複数キャラが主人公のために嫉妬、主人公が他人に嫉妬するのではない |
| 発展停滞 | 妨害→解決試行→解決→余韻 |
| 犬糧 | CPの日常的相互作用 |

## キャラ目標の独立性と関係線設計

### 主人公目標の独立性原則

- 主人公の目標は自分自身に属するものでなければならない → 「他人の目標を達成するのを助ける」ではいけない → そうしないと主人公が脇役／道具になる
- 正しい做法：他人の目標を主人公自身の目標に転化する（反乱鎮圧=自分の利益を守る／認可を得る／資源を獲得する）
- 自己チェック方法：適当に一章を見る → 主人公は能動的に何を追求しているか → もしなければ → 主人公は他人の駒になっている

### 感情線の階層設計

- 感情の推進は線形ではなく、アップグレードノードがあるべきで、各ノードが一つのプロットの盛り上がりに対応する
- 社会的関係線 vs 実質的感情線のズレで緊張感を生む
- 最適なリズム：感情は先に遅く後で速く → 前期に鋪墊して好感を蓄積 → 後期に集中爆発 → 盛大な儀式にマッチ

### 脇役の機能的位置づけ

| 類型 | 機能 | 使用タイミング |
|------|------|---------|
| 競争者（ナマズ型） | 圧力を生み主人公の行動を推進 | 盛り上がりノード前 |
| 助力型の親友 | 資源／感情的サポートを提供 | 盛り上がり前に発揮 |
| 抵抗型の親友 | 認可しない→条件を設置→主人公が克服→認可を得る | 前後どちらでも使用可 |

## ビッチ／ネガティブキャラ

- プロットを推進できるが慎重に使用する
- このキャラに代替不可能性があるか確認する
- 主人公が強い時、どのキャラも正のフィードバックに変わる
- 主人公が弱い時、ネガティブキャラは読者に恨まれる

## 品質チェックリスト

キャラ関係／感情線设计完了後、項目ごとに確認：

- [ ] **関係類型が明確**：各重要関係が衝突／連盟／親密／権威のいずれかに分類されている
- [ ] **関係に弧がある**：各重要関係が少なくとも一回の試練または変化を経験している
- [ ] **人設に核心がある**：主人公人設に明確な核心特徴と発散根拠がある
- [ ] **目標の独立性**：主人公の目標が自分自身に属し、他人の目標達成を助けるものではない
- [ ] **好感度の一致**：CP行動が現在の好感度段階に一致している（低い方に合わせる）
- [ ] **読者群に合っている**：男性向けは「優秀さを示す」で事件を設計、女性向けは「繋がりの深化」で事件を設計
- [ ] **脇役に行動がある**：脇役はNPC式に立ってトリガーを待つのではなく、自身の行動と動機を持つ
- [ ] **バッファが存在**：脇役攻略過程で常にバッファを維持し、転換点で態度変化を記す
- [ ] **修羅場が制御可能**：多角関係で対象間に調停不可能な矛盾がない
- [ ] **甘い展開のタイミングが正しい**：「愛が山と海を隔てる」以降は新しい矛盾を設計せず、実質的なCP行動の甘さだけを出す
- [ ] **キャラは恋愛だけではない**：キャラの人生には恋愛以外の内容があり、薄っぺらい感情の道具ではない
