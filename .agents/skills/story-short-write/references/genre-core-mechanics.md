# 題材核心メカニズムと爽点公式

> 短編創作時の題材核心メカニズム分析と爽点公式。

---

## 題材核心メカニズム

### 身分情報差

正体を知っているのは読者だけ、作中のキャラは知らない。

- **操作**：主人公の本当の身分は読者だけが知っていて、敵役や周囲は軽蔑している
- **爽点解放**：適切なタイミングで本当の身分を暴露、敵役が一変
- **バリエーション**：
  - スキル情報差：読者は主人公の実力を知っている、周囲は知らない
  - 関係情報差：読者は二人の本当の関係を知っている、周囲は知らない
  - 背景情報差：読者は事件の真実を知っている、周囲は知らない

### 感情逆転

愛する人からの誤解や裏切り。

- **操作**：女主（あるいは男主）が男主（あるいは女主）に深く愛されている/信頼されていると思っている → 実は利用されている/騙されている
- **爽点解放**：女主が覚醒/逆襲
- **核心**：逆転前に十分な鋪墊が必要。できるだけ長く読者を「騙す」

### 多段階進化

敵が段階的にアップグレード。

- **操作**：解決するたびに、より大きな背景の敵が現れる
- **爽点解放**：各段階で敵を徹底的に打ち負かす
- **核心**：敵のアップグレードは合理的な理由が必要。急に出てこない

## 爽点の三層選択

### 第一層：身分爽点（最も経典）

身份情報差を利用して爽点を解放：
- **暴露爽点**：読者のみが知っている正体を暴露
- **逆転爽点**：軽蔑されている主人公が一発逆転
- **仰天爽点**：敵対者が真実を知った瞬間の衝撃

### 第二層：感情爽点（最も余韻が強い）

感情の変化に重点を置き、読者の感情を揺さぶる：
- **逆境からの立ち直り**：主人公が逆境から這い上がる過程
- **裏切り後の覚醒**：信頼していた人の裏切りを経ての覚醒
- **後悔の涙**：男主/女主が間違いに気づくがもう遅い

### 第三層：能力爽点（最も直接的）

主人公の実力を通じて爽点を解放：
- **実力展示**：実力を見せる場面の爽快感
- **スキル披露**：特別なスキルを披露する場面
- **知識碾压**：知識や経験で敵を圧倒する

## 爽点設計の三公式

### 公式一：先抑後揚

```
爽点強度 = 抑えの深さ × 揚げの急峻さ
```

抑えが深ければ深いほど、解放時の爽快感が強い。

### 公式二：対比製造

```
爽点強度 = 事前の期待 × 実際の効果の差
```

期待が大きいほど、爽点の威力が強い。

### 公式三：情報差爆発

```
爽点強度 = 情報差の大きさ × 暴露の意外性
```

読者だけが知っている秘密が暴露されると、爽快感が爆発する。
