# 段落フック設計マニュアル

> 段落単位のフック設計と段落末の期待感制御に用いる。

---

## 段落フックの役割

短編は読み手が段落ごとに読み進める。良い段落末フックは、読者が思わず「あと一行」とスクロールしたくなる。

### 段落フックの三つの基本機能

1. **期待感を生む**：次に何が起こるかを予感させる
2. **好奇心を刺激する**：情報を一部明かして一部を隠す
3. **感情を動かす**：感情の動きで読者を惹きつける

---

## 段落末フックの七つの技法

### 1. 情報の遅延

操作：重要な情報の一部を明かし、核心は隠す。

```
彼はやっと真実を話した——真実は、私が想像していたものとは全く違っていた。
```

効果：読者が核心情報を知りたくなるように誘導する。

### 2. 疑問の提出

操作：段落末に疑問を投げかけ、答えを与えない。

```
もしあの時、あの選択をしていなかったら、今の私はどうなっていただろう？
```

効果：読者が答えを考えながら読み進める。

### 3. 意外な反転

操作：段落の最後に読者の予想を覆す情報を提示する。

```
彼は振り返って微笑んだ——その微笑みは、今まで見たこともないほど冷たかった。
```

効果：読者に驚きを与え、続きを読ませる。

### 4. 感情の高まり

操作：感情のピークで段落を切り、余韻を残す。

```
「どうして…私を裏切ったの？」声が震えていた。
```

効果：読者に感情的な衝撃を与え、キャラの運命を気にかけさせる。

### 5. 行動の中断

操作：キャラの行動が途中で終わるところで切る。

```
彼女はドアノブに手をかけた。その時——
```

効果：最も強力な期待感を生む。「次はどうなる？」と読者に思わせる。

### 6. 対比と落差

操作：段落の冒頭と最後に落差を作る。

```
外は陽がさんさんと降り注いでいる。けれど私の心は、零下にあった。
```

効果：雰囲気の落差で読者に印象を残す。

### 7. 答えを言わない

操作：キャラの内心の決断や気づきを完全には書き切らない。

```
その瞬間、私はすべてを理解した。彼がなぜそうしたのか、なぜ今なのか——
```

効果：読者が自分で推測する余白を残す。

## 段落フックの密度制御

| 段落タイプ | フック使用頻度 | フック強度 |
|----------|----------|----------|
| 鋪墊段落 | 低 | 弱〜中 |
| 推進段落 | 中 | 中 |
| クライマックス段落 | 高 | 強 |
| 転換段落 | 中 | 中〜強 |
| 結末段落 | 高 | 強 |

---

## よくある誤りと修正

| 誤った書き方 | 問題 | 修正方法 |
|----------|------|----------|
| 毎段落フックを使う | 読者が疲れる | 鋪墊段落ではフックを減らす |
| フックが合わない | 期待外れに終わる | フックの内容を実際に起こることと一致させる |
| フックの出しっぱなし | 回収されないフック | 各フックに回収計画を立てる |
| フックが長すぎる | もたつく | フックは短く簡潔に、1-2行で |
