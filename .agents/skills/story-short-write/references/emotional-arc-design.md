# 感情弧線操作マニュアル
> 物語を書く時に弧線を選び、リズムを制御し、感情を動かすためのクイック操作マニュアル。

## 判断ルート表

| 書きたい感情効果 | 選ぶ弧線 | キーポイント |
|------------------|-----------|----------|
| 虐めてから逆転 | V形 | 谷底60-70%、癒しが急速に回復 |
| 甘い後に死（BE） | 逆V形 | 高点40-50%、落下は上昇より速く |
| 多反転で予想不可 | W形 | 各ピークは前より高い、上限3起伏 |
| 段階的見舞いアップグレード | 遞進形 | 下落なし、階段のように上へ |
| 忍耐後の大爆発 | 遅延満足 | 前70-80%を鋪墊、最後に集中爆発 |
| 结尾で覆す | 急転形 | 70-80%で急カーブ、前の手がかりが振り返って筋が通る |

二つの弧線を重ねる可（「遅延満足 + 急転」など）、二つまで。

## 六種弧線クイック確認

### 一、V形弧線（虐 -> 癒し）

```
感情
10 |          *
 9 |         / \
 7 |        /   \
 6 |       /     *  癒し高点
 1 |  *  虐谷底
    +------------------> 進捗
      0%  40%  70%  100%
```

操作要点：
- 谷底を60-70%に置き、癒しは急速に回復。结尾感情は起点より高く
- 谷底は十分深く、転換は突然に、癒しは引きずらず、谷底に1-2シーン留まったら転換

| 題材 | 虐の部分 | 癒しの部分 |
|------|----------|------------|
| 重生復讐 | 前世で虐げられる | やり直して逆転 |
| 破鏡重圓 | 別れの苦しみ | 再び一緒に |
| 家族感動 | 誤解／負い目 | 和解／真実を知る |
| 成長癒し | どん底の遭遇 | 再び立ち上がる |

字数配分（12000字）：開始10% -> 下降30% -> 谷底15% -> 転換10% -> 癒し上昇25% -> 高点収束10%

### 二、逆V形弧線（爽 -> 反転 -> 低谷）

```
感情
10 |     *
 5 | *     \
 1 |        *  BE着地点
    +------------------> 進捗
      0%  30%  60%  100%
```

操作要点：
- 高点を40-50%に置き、反転後急速に落下
- 落下速度は上昇より速くなければならず、BE结尾に甘さを加えない

| 題材 | 爽の部分 | 落下の部分 |
|------|----------|------------|
| BE虐恋 | 甘い／幸せ | 真実／別離 |
| 職場転落 | 昇進／成功 | 罠と発覚 |
| 友情裏切り | 親密無間 | 背後での策略 |
| 信頼崩壊 | 深く信じる | 騙された真実 |

字数配分（12000字）：開始10% -> 上昇35% -> 顶点10% -> 反転5% -> 落下30% -> 低谷収束10%

### 三、W形弧線（多起伏）

```
感情
10 |       *           *
 5 |  *         \ /
 4 |             *
    +--------------------> 進捗
      0%  20%  40%  60%  80%  100%
```

操作要点：
- 少なくとも二つの波峰と一つの波谷、通常三起伏
- 各峰は前より高く、最終峰は80-90%
- 起伏の間に休息スペースが必要、上限3起伏

| 題材 | 説明 |
|------|------|
| 多反転サスペンス | 毎回予想したと思ったらまた反転 |
| 妻追い火葬場 | 繰り返し引き合い、毎回仲直りしたと思ったらまた問題 |
| 商戦駆け引き | やり取り、毎回勝ったと思ったらまた逆転 |

字数配分（15000字、3起伏）：開始+第1峰25% -> 第1谷10% -> 第2峰25% -> 第2谷10% -> 第3峰20% -> 収束10%

### 四、遞進弧線（逐步アップグレード）

```
感情
10 |                     *
 7 |             * /
 5 |       * /
 3 | * /
    +--------------------> 進捗
      0%  25%  50%  75%  100%
```

操作要点：
- 下落があってはならず、階段のように一歩一歩上へ
- 最高点は85-95%、中間は小さな勝利のみ、事前に解放しない

| 題材 | 遞進方式 |
|------|----------|
| 見舞い爽文 | 一人ずつ見舞う、各回が前より激しい |
| 層層揭秘 | 真実が一層ごとに前より衝撃的 |
| 逆襲逆転 | 各ステップの逆転が前より大きい |

字数配分（10000字）：圧迫20% -> 第1段階反撃20% -> 第2段階反撃25% -> 第3段階反撃25% -> 収束10%

### 五、遅延満足弧線（長鋪墊 -> 爆発）

```
感情
10 |                       *
 5 |              *--------|
 3 |       *------         |
 1 | *------                |
    +-------------------------> 進捗
      0%  20%  40%  60%  80%  100%
```

操作要点：
- 前70-80%を压制／鋪墊、最後20-30%に集中爆発
- 鋪墊段階の各段落に情報量と緊張感が必要で、退屈であってはならない
- 压し方は多様に、爆発は密集に、爆発後は速やかに収める

| 題材 | 压す部分 | 爆発の部分 |
|------|----------|------------|
| 復讐爽文 | 忍耐、弱さを装う、虐げられる | 一度に逆転、全面清算 |
| 身份揭秘 | 実力を隠す／身份を隠す | 本当の身份暴露、全场震惊 |
| 長線布石 | 主人公が暗躍 | 全ての駒が同時に着実 |

字数配分（12000字）：初期压制20% -> 深層鋪墊25% -> 最大圧力15% -> 爆発発動5% -> 集中爆発25% -> 収束10%

### 六、急転弧線（70-80%で急カーブ）

```
感情
10 |                *  急転後の新高/低点
 8 |           *--/
 3 |      /
    +-------------------------> 進捗
      0%   30%   70%  80%  100%
```

操作要点：
- 前70-80%は正常弧線、70-80%で突然方向転換
- 急転は1-2段落のみ、前に埋めた手がかりは振り返って筋が通らなければならない

| 題材 | 前半 | 急転後 |
|------|--------|--------|
| 考えれば考えるほど怖い | 温馨な日常 | 恐ろしい真実が浮かぶ |
| 身份ズレ | Aの視点で叙事 | 実はB |
| 動機反転 | 愛だと思っていた | 実は恨み／利用 |

字数配分（10000字）：偽の印象を確立35% -> 偽の印象を押し上げ30% -> 偽の印象の高点10% -> 急転5% -> 真実展開15% -> 新感情収束5%

## 中段加圧四手段

1. **公開への昇格**：私的な傷害を公の場に移す（家族会食、会社会議、ライブ、式典）
2. **二重裏切り**：既知の一層の裏切りにもう一層を加える（経済的裏切り、名誉的裏切り、立場反転、証拠改竄）
3. **代価加速**：行動しない代価が絶えず上昇（機会喪失、公の場での辱め、他人への連累）
4. **戦略的沈黙**：主人公が一時的に反撃せず、沈黙自体が持続的に加圧（他人の誤読、敵役の更なる放縦）

## 期待感管理六法則

1. **期待最大化の法則**：爽点が来る直前が全編の最高緊張位置。滿足されようとしてされない時、読者の需要が最大。
2. **情報順序操作**：先にどの情報を植え付けるかで、読者は先入観を持ってその方向に考える。情報順序の制御 = 読者期待の制御。
3. **期待遞増法**：基底期待に絶えず詳細を追加し、より具体化された欲求ギャップを注入。追加する詳細は核心ネタと一致しなければならない。
4. **期待中断禁止**：次の期待が立ち上がる前に、現在の期待を絶対に終えてはいけない。旧期待が間もなく実現する時、新期待の種は既に植えられていなければならない。
5. **下降プロット安全原則**：感情が下降する時、鍋は他人のもの、功績は主人公のもの。下降中に読者に安全感を与えなければならない（可能な解法／潜在的な収穫）。
6. **爽点遞増対比**：連続爽点は段階的に遞増。次元：影響範囲（個人->集団->社会）、暴露深度（表面->本質->覆す）、身份落差（通行人->大物->全场震惊）。

## 感情核心公式

各シーンを書く時に三層の感情を分離する：
1. キャラ自身の感情（キャラが感じるもの）
2. テキストが伝える感情（テキストが読者に感じさせるもの）
3. 読者が実際に感じる感情（読者の本当の体験）

同一シーンの三層は完全に異なりうる：キャラは泣き、テキストは煽り、読者は爽快。

例：ヒロインが公衆の面前で婚約破棄され、必死に涙をこらえる——キャラ：屈辱；テキストは彼女の口元にまだ笑みがあると書く（キャラ：強がる）；読者は彼女の代わりに溜め込み、後の見舞いを待つ（読者：爽前の蓄力）。

## 前反応-再現-後反応感情構造

虐め／悲壮／遗憾類のシーンに使用。順に三ステップを実行：

1. **前反応**：読者に事前に悪い結果を知らせ、その後美しいものを描写する（読者予知法）
2. **再現**：悪い結果が実際に起こる
3. **後反応**：主人公が真情を流露し、変化する（怒り／必死／奮起）

操作例：ある人が一日後に死ぬと知っている -> 彼女に美しい体験をさせる（買い物、花火を見る） -> 彼女が実際に死ぬ -> 主人公が怒りに燃える

---

## 以小搏大感情構造

熱血／逆襲類のシーンに使用。順に四ステップを実行：

1. **前反応**：弱者の苦しみを鋪墊し、対比で強化する（現在の弱さ vs 以前の強さ）
2. **再現**：強者が来る、「君たちの苦しみを知っている。私が来た」
3. **後反応**：弱者側が救われる
4. **士気如虹**：全体の勢いが転換

## 衝突中の感情階層と死の賭け

### 死の賭けを選択

| 賭け類型 | 適用シーン | 操作要点 |
|----------|----------|----------|
| 肉体的死 | 恐怖怪異文 | 主人公が強すぎる時、賭けは必ず事業の死に転換しなければならない。さもなければ全編崩壊 |
| 事業の死 | 職場競爭、修仙門派爭い | 失敗 = 全てゼロ |
| 心理的死 | 感情崩壊、信念破滅 | 感情的衝撃が最も深く、優先的に感情線に使用 |

一つを主要賭けとして全編を貫き、他は補助としてプロットを推進。

### 接着剤で緊張感を維持

对立する双方は簡単に逃げられないようにする。四種の接着剤：殺人理由（系列唯一性による必然的衝突）、仕事の責務、道徳的責任（親戚の危機）、実体的場所（コピー密室）。

### 長線維持ルール

- 第一卷の結末はあまりに完全であってはならない——完全解決はその後の追読動機を殺す
- 一つの面倒を解決すると同時に次の面倒を仕込まなければならない
- 後期になるほど、感情的緊張は大きくなければならない

## 「そうあるべきではない」に基づく感情駆動

- 「そうあるべきではない」が最も根本的な感情駆動力——誣告、不公正、弱い者いじめを書くと、読者は生得的に「そうあるべきではない」という思いを抱く
- 核心的感情論理：爽快になりたければ、先に不愉快でなければならない；公平を望めば、先に不公平でなければならない；強くなりたければ、先に強くなくてはならない
- 「未解決」も強い駆動力
- 良い題材は、人々の惋惜や変えたいという願望を引き起こす特性を持たなければならない

## 理念矛盾の感情爆発力

- 理念の争いは利益の争いより読者の深層共感を引き起こす
- 少量のキーシーンで十分で、大量の筆墨は必要ない
- 理想主義と現実の衝突は、脇役を神レベルに塑造する手法
- 理念への同意 = 人設への同意 = 読者の感情的投入
- 主线に理念型キャラを織り交ぜ、彼らの追求と犠牲で全編の感情上限を引き上げる

## 感情動員の三層方法

三層：**長期的感情投入**、**短期的イベント衝突**、**シーン描写**。三者は重畳可能で、核心は前二層。

### 長期的誘導三ステップ

1. **共感爆弾を投じる**：キャラが最も共感を引きやすい感情的アンカーを見つける（夢、憎しみ、恐怖）
2. **読者を目撃者にする**：キャラの貢献と苦闘を示し、各ステップに収穫を伴う
3. **読者を参加者にする**：十分な鋪墊と詳細を通じて、運命共同体感を生む

### 短期的感情誘導

短期は独立したイベント衝突に依存する。**複雑なプロットより率直な衝突の方が共感を引きやすい**。

二種のイベント類型：
- **プロットを推進するイベント**：読者にキャラの处境への同意を生ませる
- **人物の性格を塑造するイベント**：読者にキャラの思想性格への同意を生ませる

開篇は人物の性格を塑造するイベントを選ばなければならない——先にキャラという人に同意してから、キャラのことを気にする。

### 感情代入の罠

読者が主人公に未だ代入していない時：主人公の弱さは同情を引き起こすが、**敵の弱さも同じく同情を引き起こす**。読者がまだ同意を確立していない時、敵を可怜に書いてはいけない。

### 感情文筆技法

- **短文** = 果断熱血（リズムが速く、感情密度が高い）
- **感情語**：突然、猛然、眩しい——切迫感を生む
- **動作語**：引き、払う、残す——画面感が強く、感情が外化
- **修飾語**：正確に抑制的に形容詞を使い、堆積しない
- **高階ルール**：キャラの行動を通じて感情を暗示し、直接描写しない。**楽しさで悲しみを書く**：キャラが最も悲しい時に楽しそうにする、感情的緊張がより強い（死にに行く人が最も悲しいのは泣くことではなく、とても楽しそうにしていること）

## 男頻恋愛文の感情設計

### 二大核心需要

- **感情的価値**：読者は愛に飢えており、小說の中で美しく優秀な女性が自分を認めてくれることで、感情的空缺を埋める
- **自尊的価値**：校花／女社長を連れて登場し、周囲が羨み嫉む

### 恋愛を升級文として書く

- 「好感度プログレスバー」を設定（通行人->良い人->友達->好きだが自覚なし->…）
- 最も読者を惹きつけるのは一緒になる結果ではなく、曖昧で引っ張り合う過程
- 内外の障害を作って二人が一緒になるのを妨げ、障害克服を通じて感情を深める

### 感情アップグレードの非対称性

二つのプログレスラインは並行して進んではいけない：
- **感情が社会関係より速い**：双方の好感は既にMAXだが口が硬くて告白しない
- **社会関係が感情より速い**：穿越で既に妻／婚約者がいる、好感度ゼロから徐々に上げる

### キー禁忌と技法

- 男主は積極的に追わない、犬にならない——自身の優秀な資質でヒロインの注意を引く
- 事業線は欠かせず、ヒロインは主人公の事業に積極的役割を果たす
- ヒロインが主人公に良くすることを書く、人設に応じて尽くし方を設計（自信過少型はこっそり薬を差し入れ、ツンデレ型は口が硬くて弁当を作り、率直型は堂々とプレゼントを贈る）
- **対比法**：時間線対比（前後の態度変化）+ ダブルスタンダード（他人 vs 主人公）
- **情報差で期待を引く**：二重身份（ネット上の身份 vs 現実の身份）、読者は正体暴露時の反応を期待

## 感情動員の統一視点

> 一段を書いて物足りない／読者フィードバックが平淡な時に使用。

### 究極公式

**平静 -> 動員 -> 解放 -> 爽**

| 技法 | 動員 | 解放 | 結果 |
|------|------|------|------|
| 格好つけ見舞い | 敵役が横柄 | 主人公が碾压 | 爽 |
| ヘイト集め | ネガティブ感情 | 悪人が罰を受ける | 爽 |
| 先抑後揚 | 打撃 | 爆発 | 爽 |

### 実操作要点

- 各シーンに記す：読者の現在の感情はどの段階か；次のステップは動員か解放か
- 動員のみで解放なし = 読者は息苦しくて読むのをやめる
- 解放のみで動員なし = 爽快感が平淡で力がない
- 動員の程度が解放の爽快度を決める：ヘイトをどれだけ集めたかで、見舞いがどれだけ爽快か

## 期待感維持の底層メカニズム

> 目標を書いたが読者が関心を持たない／六法則を使ったが効果が悪い時に使用。

### 期待感 vs 目標

- **目標** = キャラが何をするか（宝物を見つける、魔王を倒す）
- **期待感** = 読者の目標達成後の見通しに対する予想
- 目標あって期待なし = 読者は結果を気にしない。目標を期待に転化しなければならない

### 確定型 vs 不確定型期待

- **確定型**（爽文）：読者は主人公が勝つと知っている、「どう勝つか」を書く（過程の創意 > 結果のサスペンス）
- **不確定型**（サスペンス）：読者は結果を知らない（結果のサスペンス > 過程の体験）
- 爽文は「ネタバレ」を怖がらない——期待は過程にあり結果にないから

### サスペンスの開環と閉環

- **開環** = ギャップを生む（問題／サスペンスを提起）
- **閉環** = ギャップを埋める（問題に答える／明かす）
- **入れ子開環** = 一つの期待を閉環すると同時に新しい期待を開く（閱讀の連続性を維持）
- ルール：一つの期待を閉環する時、次の開環が既に稼働していなければならない

### 感情線のギャップ

感情線に障害がない = 期待がない = 無駄 = 無意味。ギャップを設定しなければならない。

ギャップの來源：身份の差、家族の反対、誤解、使命の衝突。

## 品質チェックリスト

感情弧線を書き終えたら項目ごとにチェック：

### 弧線選択とリズム
- [ ] 弧線の類型は書きたい感情効果に合致するか？（判断ルート表と照合）
- [ ] キー転換点は正しい進捗位置か？（V形谷底60-70%、逆V高点40-50%、急転70-80%）
- [ ] 字数配分は選択した弧線の割合要求に合致するか？

### 動員と解放
- [ ] 各シーンで現在が「動員」か「解放」の段階か明確か？
- [ ] 動員のみで解放がない段落がないか？（息苦しくて読むのをやめる）
- [ ] 解放のみで動員がない段落がないか？（爽快感が平淡）
- [ ] 連続爽点は段階的に遞増しているか？（影響範囲／暴露深度／身份落差）

### 期待感
- [ ] 各目標は既に読者の期待に転化されているか？
- [ ] 一つの期待を閉環する時、次の開環は既に稼働しているか？（期待中断禁止）
- [ ] 感情線に障害が設定されているか？（障害なし = 期待なし）

### 感情代入
- [ ] 開篇は人物の性格を塑造するイベントを使ったか？（先に人に同意、次に事を気にする）
- [ ] 読者が未だ主人公に代入していない時、敵を可怜に書くのを避けたか？
- [ ] 下降プロットで読者に安全感を与えたか？（鍋は他人のもの、功績は主人公のもの）

### 長線維持
- [ ] 一つの面倒を解決する時、同時に次の面倒を仕込んだか？
- [ ] 後期になるほど感情的緊張が大きくなっているか？
- [ ] 死の賭けは一つを選んで全編を貫いているか？
- [ ] 対立する双方に接着剤があり、簡単に逃げられないか？
