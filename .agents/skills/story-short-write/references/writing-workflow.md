# 執筆ワークフロー

> 短編創作の全フロー。準備、執筆、改稿を含む。

---

## クイックスタート

### 1. 構想フェーズ

- **題材を選ぶ**：読者層と市場を分析し、題材を確定する
- **コア爽点を確定する**：この物語の核心的な魅力は何か？
- **感情弧線を設計する**：読者にどのような感情体験をしてもらいたいか？

### 2. プロットフェーズ

- **五段構造を設計する**：各段階の字数配分を計画する
- **人物アーカイブを作る**：主要人物の性格と動機を書き出す
- **フックを設計する**：章末のフックを計画する

### 3. 執筆フェーズ

- **一気に書き上げる**：第一章を中断せずに書き終える
- **字数目標を達成する**：12000字前後
- **品質を確認する**：自己チェックリストで確認する

### 4. 改稿フェーズ

- **構造調整**：プロットの論理とリズムをチェックする
- **表現の洗練**：言葉の表現を洗練し、冗長なところを削除する
- **最終品質チェック**：品質チェックリストですべてを確認する

---

## 執筆前の準備

### 題材の決定

1. 書きたい題材の方向性を決める
2. この題材の市場の可能性を分析する
3. この題材のコア爽点を確定する
4. 経典パターンを参考にするか、イノベーションを起こすかを決める

### プロットの設計

1. 構造：五段構造を設計し、各段階の字数を計画する
2. 核心爽点：各段階に配置する爽点を計画する
3. 感情弧線：弧線類型を選び、キー転換点を計画する
4. フック：章末のフックを計画し、期待感を持続させる
5. サスペンス：サスペンスの設置と回収を計画する

### 人物の設定

1. 主人公の性格特徴を決定する
2. 主人公のキャラクター成長ラインを設計する
3. 主要人物の性格と役割を決定する
4. 敵役の類型と動機を決定する
5. 人物関係図を設計する

---

## 執筆過程

### 執筆原則

1. **一章一爽点**：各章に少なくとも一つの小さな爽点を配置する
2. **フックを残す**：結末はフックで締め、読者に続きを読ませる
3. **情報の分散**：設定や背景情報を章ごとに分散させる
4. **リズムの変化**：緊張と緩和を交互に配置する
5. **感情表現**：感情は具体的な行動で表現し、抽象的な言葉で書かない

### 字数管理

| 段階 | 字数 | 機能 |
|------|------|------|
| 第一段 | 0-10%（1200字） | 核心フック、人物の紹介 |
| 第二段 | 10-30%（2400字） | 情報の敷設、小さな爽点 |
| 第三段 | 30-50%（2400字） | 深い対立、反転の敷設 |
| 第四段 | 50-80%（3600字） | 大きな爽点の解放、クライマックス |
| 第五段 | 80-100%（2400字） | 結末、余韻 |

### 執筆のリズム

```
持続執筆時間：25-45分/回
休息時間：5-10分
目標字数/回：2000-3000字
```

## 改稿過程

### 構造改稿

1. タイムラインの論理的な問題をチェックする
2. プロットの転換点が合理的か確認する
3. 各段落が物語全体に貢献しているか確認する
4. 緩急のリズムを調整する

### 表現改稿

1. 冗長な部分を削除する
2. テンプレート表現を修正する
3. 会話の自然さを調整する
4. 修辞技法を追加する（対比／呼応／繰り返し）
5. 描写の厚みを調整する

### 細部の修正

1. 文字や記号の誤りをチェックする
2. 用語の統一をチェックする
3. 設定の矛盾をチェックする
4. 人物の性格の一貫性をチェックする

---

## 改稿のいくつかのマインドセット

- 完璧主義にならない。ネット小説は速さ勝負、すべての作品が名作になるわけではない
- 他人の意見を聞くが、すべてに従う必要はない
- 一つの作品で時間をかけすぎない。完成したらすぐに次の作品へ
- 実戦を通じて学ぶ。理論だけで完璧になることはない
- 良い作品は書いて改稿してこそ生まれる。一発勝負は期待しない
