## 最強毒物句式（出現即修正、最優先）

網文で最も毒性の高い AI 句式。一度身につくと繰り返し出現する。Gate A 初回スキャンで必ずヒット：

| 毒度 | 句式 | 誤用例 | 修正方法 |
|------|------|--------|---------|
| ★★★★★ | "不是A，（而）是B" / "不是A，不是B，（而）是C"（"而"省略可、省略でもヒット扱い） | "他不是冷漠，而是绝望" | B を直接書くか、より自然な表現に |
| ★★★★ | "，带着……" 万能連用修飾語 | "他笑了一下，带着一丝不易察觉的嘲讽" | 短文に分割するか動作に置き換え |
| ★★★★ | "声音不大，却带着一种……的力量" | "她声音不大，却带着不容置疑的力量" | 声の特徴または動作を直接書く |
| ★★★★ | "他/她知道……" | "他知道这一切都来不及了" | 行動で認知を示す |
| ★★★ | "仿佛/犹如/宛若……一般" | "仿佛能穿透一切一般" | 削除または白描 |
| ★★★ | "眼中闪过一丝……" / "嘴角勾起一抹……" | "眼中闪过一丝悲伤" | 彼はうつむいた / 彼は笑ったが目までではなかった |
| ★★★ | "心中涌起一股……" / "心头一震" | "心中涌起一股暖流" | 身体反応で表現 |
| ★★ | 章末予告 "他不知道的是……" | "他不知道的是，更大的风暴即将来临" | 具体的なフック（物・出来事）で締め、漠然とした予告を避ける |

> ★★★★★ に 1 箇所でも該当 → AI臭が強い強い証拠。★★★★ に 2 箇所以上該当 → 中程度と判定し再スキャン。

**句読点**：本文（地の文・会話とも）でダッシュ `——`/`—`、二重ハイフン `--`、省略記号による間の使用を禁止。句点、読点、短文、または動作による区切りに変更する。会話のダッシュは例外としない。塩言「」引用符はこの限りではない。

## 一级禁用語（出現即置換）

### 様態類
仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约

### 動作類
深吸一口气、缓缓、不禁、微微、轻轻、淡淡

### 表情類
眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩

### 心理類
心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得

### 判断類
不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认

### 形容類
坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷

### 転移類
不由自主、情不自禁、自然而然

## 二级禁用語（高頻度出現時置換）

### 文脈依存語（高頻度または怠惰な使用時のみ処理）
突然、好像、瞬间（キャラの口語、実際の急変、時間圧縮、視点の不確定時は保持可）

### 書き言葉 → 口語化

| 書き言葉 | 口語への置換 |
|--------|-----------|
| 瓦解 | 消失 / 散了 / 没了 |
| 无名火 | 烦躁 |
| 往我心上捅刀子 | 心烦意乱 |

### 総括句式
- "他/她终于明白..."
- "他/她这才意识到..."
- "此刻，他/她..."
- "一切...都..."
- "原来..."

### 排比句式
- 同一構造の排比が 3 文以上連続
- "有的...有的...有的..."
- "一边...一边...一边..."

### 昇華句式
- "这一刻..."
- "他知道..."
- "她明白..."
- "这就是..."

## 禁用句式テンプレート

| 句式 | 例 | 問題点 |
|------|------|------|
| "不是A，而是B" | "他不是冷漠，而是绝望" | 最毒；B を直接書く |
| "...，带着..." | "他说，带着一丝无奈" | 万能連用修飾語 |
| "声音不大，却带着……" | "她声音不大，却带着不容置疑的力量" | AI が好む声音描写 |
| "仿佛能...一般" | "仿佛能穿透一切一般" | 文語調 |
| 会話タグの高密度/定式化 | "好的，他说道" | 普通の"说"は保持可。高頻度または定式化時は処理 |
| "他/她感到..." | "她感到一丝失落" | 示さずに伝える |
| "他/她意识到..." | "他意识到事情不对" | 直接的な告知 |
| "眼中闪过一丝XX" | "眼中闪过一丝悲伤" | テンプレート化 |
| "嘴角勾起一抹XX" | "嘴角勾起一抹冷笑" | テンプレート化 |
| "心中涌起一股XX" | "心中涌起一股暖流" | テンプレート化 |

## 比喩分類（デフォルト全削除）

"像/如/仿佛/犹如/宛若" を含む比喩は AI 生成の強いシグナル。デフォルトで全削除。分類は識別用：

| 比喩カテゴリ | 例 |
|---------|----|
| 動物類 | "像一头被抛弃的野狗" |
| 物品/現象類 | "像一把刀" "脸色惨白得像这漫天的雪" |
| 状態類（陳腐表現） | "梨花带雨" "如沐春风" |
| 抽象類 | "像命运的齿轮" "像上辈子的尘埃" |
| 仮定類 | "力道大得像是要把骨头捏碎" |

対応：比喩を直接描写／動詞／名詞／作用／結果／事実に変更。例 "脸色惨白得像这漫天的雪" → "脸色惨白"。

> 例外は SKILL.md Gate B の deslop 原始戦略が管理（"生活的・キャラ付随の比喩は保持可"）。本表はスキャン用であり、例外判定は行わない。

## 置換戦略クイックリファレンス

| 原文タイプ | 置換方法 | 例 |
|----------|----------|------|
| 抽象的感情語 | 具体的動作 | "紧张" → "手在抖" |
| "感到XX" | 外化表現 | "感到愤怒" → "攥紧拳头" |
| 形容詞の積み重ね | 白描 | "美丽动人的笑容" → "她笑了" |
| 書面表現 | 口語化 | "不容置疑" → "就是" |
| 説明的描写 | 余白を残す | "他因为害怕而..." → "他退后一步" |
| 連続排比 | 最強の1つを残す | 3 文排比は 1 文に |
| 総括昇華文 | 直接削除 | "这一刻，她终于明白了..." → 削除 |
| "不是A，而是B" | B を直接書くか自然な表現に | "他不是冷漠，而是绝望" → B を直接書く |
| 冗長修飾（形容詞/限定詞/量詞/指示代名詞） | 削除 | "白色的药片" → "药片"；"手里那截链子" → "链子"；"飞驰的汽车" → "车" |
