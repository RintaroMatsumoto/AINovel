# 起点中文網品質ルーブリック

## 評価基準

| 指標 | PASS 基準 | FAIL 基準 |
|------|----------|----------|
| 爽点密度 | 3000 字ごとに ≥1 回の感情ノード（成長/打顔/獲得） | 連続 5000 字で感情ノードなし |
| 成長リズム | 50 章ごとに等級/実力突破 | 100 章で成長なし |
| チート使用 | 毎章でチートに言及または使用（システム/指輪/功法） | 連続 5 章でチートに言及なし |
| 日更対応 | 大綱が 4000 字/日のリズムをサポート（各章 2000 字、1 日 2 章） | 日更計画なし、章の長さが不規則 |
| フック密度 | 各章末にサスペンス/フックあり | 連続 3 章で章末フックなし |
| キャラ存在感 | 主人公が毎章登場し推進 | 連続 2 章で主人公が登場しないか推進なし |
| 追読率 | 章末フック + 感情の連続性 → 追読率推定 >30% | 連続 3 章フックなし、または感情断裂 → 追読率推定 <15% |

## 使用方法

- story-review の story-architect 視点が本基準を参照
- advisory only、blocking しない
- ユーザーは閾値をカスタマイズ可
