# 番茄小説品質ルーブリック

> **[DayTradeでは不使用]** このルーブリックは中国の番茄小説プラットフォーム向けです。DayTrade は文学小説であり、本ルーブリックの「重生」「爽点密度」「アルゴリズム親和性」等の基準は適用されません。レビュー時は `story-review/SKILL.md` の DayTrade 内蔵ベンチマークが使用されます。

## 評価基準

| 指標 | PASS 基準 | FAIL 基準 |
|------|----------|----------|
| 冒頭の魅力 | 最初の 3 段落に衝突/サスペンス/フックを含む | 最初の 3 段落が純粋な描写/背景紹介 |
| 読者維持 | 各章末に「ページをめくる原動力」（サスペンス/反転/新情報） | 連続 3 章で章末にページをめくる原動力なし |
| 題材一致 | 内容がタグタイプに合致（甘寵/逆襲/重生等） | タグタイプから 3 章以上逸脱 |
| アルゴリズム親和性 | 短文段落、速いリズム、高情報密度 | 大段落、遅いリズム、低情報密度 |
| 感情ノード | 1000 字ごとに感情の起伏あり | 連続 2000 字で感情が平坦 |
| 完読率推定 | 3 章のフック有効 + リズムがだれない → 推定完読 >40% | 最初の 3 章にフックなし、または連続しただれ → 推定完読 <20% |

## 使用方法

- story-review の story-architect 視点が本基準を参照
- advisory only、blocking しない
- 番茄アルゴリズムは速いリズムと強い感情を好む
