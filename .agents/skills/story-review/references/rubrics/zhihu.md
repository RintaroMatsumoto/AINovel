# 知乎塩言ストーリー品質ルーブリック

## 評価基準

| 指標 | PASS 基準 | FAIL 基準 |
|------|----------|----------|
| 一人称 | 全文で「私」視点を使用 | 三人称を使用（複数視点設計の場合を除く） |
| 感情の引き | 各段落に感情変化あり（期待→失望→驚き等） | 連続 3 段落で感情変化なし |
| 反転設計 | 少なくとも 1 つの有効な反転あり（前文に伏線あり） | 反転なし、または反転に伏線の裏付けなし |
| 結末の余韻 | 結末に思考の余地/感情の余韻あり | 結末が完全に閉じており余韻なし |
| フォーマット準拠 | 段落は短文主体（長短/疎密の変化あり）、空行なし、会話フォーマット正しい | 全編同一長さ、または連続超長段落/空行/会話タグ |
| 冒頭フック | 最初の文に情報量あり（動作/衝突/サスペンス） | 最初の文が純粋な描写/背景 |
| 文字数制御 | 8000〜13000 字（塩言標準） | 超過または不足 |
| 冒頭離脱率 | 最初の文に動作/衝突/サスペンスあり → 離脱率推定 <30% | 最初の文が純粋な描写/背景 → 離脱率推定 >50% |

## 使用方法

- story-review の story-architect および character-designer 視点が本基準を参照
- advisory only、blocking しない
- 塩言ストーリーは一人称の没入感と感情の引きを重視
