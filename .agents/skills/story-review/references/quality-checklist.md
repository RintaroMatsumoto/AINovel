# 品質チェックリスト

`story-review` 全審査員共通の品質チェックリスト。DayTrade（村上文体）対応済み。

---

## 汎用チェック項目（全審査員必須）

### 基本仕様遵守
- [ ] 文体仕様に違反していないか（例：段落間の空行、引用符の不統一）
- [ ] 一人称視点に違反していないか（視点がブレていないか）
- [ ] 計画書の文字数制限に違反していないか
- [ ] 禁則語が出現していないか（`banned-words.md` 参照）

### 会話品質
- [ ] 情景描写だけでページを埋めていないか
- [ ] セリフで表現できる内容を地の文で説明していないか
- [ ] セリフがキャラの個性を反映しているか
- [ ] 沈黙と間が活かされているか

### 要素間の整合性
- [ ] 本章のプロット進行が計画書と矛盾していないか
- [ ] キャラの状態が一貫しているか（前章の状態と矛盾しないか）
- [ ] 時間線に矛盾がないか（前章の時間と繋がるか）

---

## DayTrade 固有チェック項目（DayTrade プロジェクトの場合）

### 村上文体チェック
- [ ] 内省は抑制され、具体的過程として書かれているか（「思った」「感じた」の空虚な一語要約禁止）
- [ ] 内省に身体反応が伴っているか（「手が震えた」「喉が渇いた」等）
- [ ] 回想は境界マーク（`***`等）・空行を使わず、知覚トリガー（光・音・温度・身体感覚）から自然に滑り込んでいるか
- [ ] 回想からの帰還も自然か（現在の動作や時間経過で自然に戻る）
- [ ] 滲み出し層（百合子の過去）は誠の語りから動詞の時制・光の質の変化だけで自然に滲み出しているか
- [ ] 章末は総括・教訓・哲理を避け、イメージ・断片・静かな動作で閉じているか

### 語り手の声
- [ ] 誠（40歳）：抑制された長文。数字で世界を把握。封筒の進行で文体が質的に変化しているか
- [ ] 栞（14→18歳）：二重言語——お嬢様言葉とストリート。父のノートを読む時だけ誠の文体
- [ ] 翼（11→30歳）：各フェーズで声が変わる。幼少期＝怯え、少年院後＝怒りと身体、半身不随後＝静かな内省

### 情報開示
- [ ] 情報は分割開示されているか（1章で全真実を明かしていないか）
- [ ] 誠の誤解と読者の真実の二層構造（劇的アイロニー）が機能しているか
- [ ] 三層対応表（封筒 × 回想 × 滲み出し層）が本章の設計と一致しているか

### 取引手法・ノート
- [ ] 禁止語（信用取引、二階建て、追証、ナンピン、建玉、レバレッジ、信用枠、委託保証金、維持率、強制決済）が出現していないか
- [ ] 禁止表現（「○パーセントの損切りライン」等の数値＋取引判断）が出現していないか
- [ ] 祖父のノートの具体的文言が引用されていないか（存在と効果だけを描く）

## AI 臭チェック項目

- [ ] 「まるで〜のようだ/ように」構造が過剰でないか
- [ ] 「少し〜」「いくぶん〜」「やや〜」程度を表す修飾語が多すぎないか
- [ ] 「しかし」「だが」「そして」等の接続詞で段落が始まっていないか
- [ ] 「〜を感じた」「〜ように思えた」心理動詞が多すぎないか
- [ ] 各段落が「主体＋述語＋目的語」の完全な構造になっていないか（リズムが単調）
- [ ] 環境描写が無意味な細部描写になっていないか
- [ ] 「彼/彼女/それ/この/あの」の指示語が多すぎないか
- [ ] 全文の句読点が「〜、〜。」の繰り返しパターンになっていないか
- [ ] 段落冒頭の主語が多様か（毎回主語から始まっていないか）
- [ ] 感動詞・擬声語・口語的破格が不足していないか（文面が整いすぎていないか）
- [ ] 章末まとめ体（「彼はついに理解した…」「新しい章が始まった…」）がないか
- [ ] 万能比喩（「波のように」「稲妻のように」）がないか

## ストーリー構造

- [ ] 本章の位置づけ：{ストーリー上の役割}
- [ ] 本章の感情リズムは：{緊張/弛緩/昇温/下降}
- [ ] 本章末に引きがあるか（DayTrade：余韻型章末であること。クリフハンガーではない）
- [ ] DayTrade：三層対応表の整合性は取れているか

---

## キャラクター

- [ ] キャラは本章で行動したか（受動的でないか）
- [ ] キャラのセリフはその人らしいか
- [ ] キャラの状態に変化があれば、合理的なトリガーがあるか
- [ ] キャラの心理変化は十分に表現されているか（不自然な反転をしていないか）
- [ ] DayTrade：語り手の声がキャラクターの言語スタイル定義に一致しているか

---

## プロット

- [ ] 本章のイベントは前章の結果か（因果関係があるか）
- [ ] 本章のイベントは自然に次章を導いているか
- [ ] 本章で新しい伏線があれば、意図的に設置されているか
- [ ] 本章で回収された伏線があれば、自然に処理されているか
- [ ] 本章の情報量は適切か（多すぎず少なすぎず）
