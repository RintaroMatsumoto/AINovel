# 品質チェックリスト

`story-review` 全審査員共通の品質チェックリスト。汎用チェック項目と特定次元のチェック項目をカバー。

---

## 汎用チェック項目（全審査員必須）

### 基本仕様遵守
- [ ] 文体仕様に違反していないか（例：段落間の空行、引用符の不統一）
- [ ] 一人称視点に違反していないか（視点がブレていないか）
- [ ] 計画書の文字数制限に違反していないか
- [ ] 禁則語（一级/二级）が出現していないか（`banned-words.md` 参照）

### 会話駆動
- [ ] 情景描写だけでページを埋めていないか
- [ ] 心理描写だけでページを埋めていないか
- [ ] セリフで表現できる内容を地の文で説明していないか
- [ ] セリフがキャラの個性を反映しているか

### 要素間の整合性
- [ ] 本章のプロット進行が計画書と矛盾していないか
- [ ] キャラの状態が一貫しているか（前章の状態と矛盾しないか）
- [ ] 時間線に矛盾がないか（前章の時間と繋がるか）

---

## AI 臭チェック項目

`anti-ai-writing.md` の手法に従いチェック：

- [ ] 「まるで〜のようだ/ように」構造が過剰でないか
- [ ] 「少し〜」「いくぶん〜」「やや〜」程度を表す修飾語が多すぎないか
- [ ] 「しかし」「だが」「そして」等の接続詞で段落が始まっていないか
- [ ] 「〜を感じた」「〜ように思えた」心理動詞が多すぎないか
- [ ] 各段落が「主体＋述語＋目的語」の完全な構造になっていないか（リズムが単調）
- [ ] 環境描写がインテリアコーディネートのようになっていないか（無意味な細部描写）
- [ ] 「彼/彼女/それ/この/あの」の指示語が多すぎないか
- [ ] 全文の句読点が「〜、〜。」の繰り返しパターンになっていないか
- [ ] 段落冒頭の主語が多様か（毎回主語から始まっていないか）
- [ ] 感動詞・擬声語・口語的破格が不足していないか（文面が整いすぎていないか）

---

## ストーリー構造（構造審査員）

- [ ] 本章の位置づけ：{ストーリー上の役割}（例：伏線設置、爽点放出、移行）
- [ ] 本章は全体構造の中で：{導入/発展/反転/クライマックス/結末}
- [ ] 本章は期待を構築しているか、爽点を放出しているか、移行を完了しているか
- [ ] 本章のリズムは：{緊張/弛緩/昇温/下降}
- [ ] 本章末に引きがあるか
- [ ] 引きの強度（1-10）：{スコア}
- [ ] 爽点があれば：その前に期待/危機/抑圧の伏線が敷かれているか
- [ ] 章末の引きが次章への期待を最大化しているか

---

## キャラ（キャラ審査員）

- [ ] キャラは本章で行動したか（受動的でないか）
- [ ] キャラのセリフはその人らしいか
- [ ] キャラの状態に変化があれば、合理的なトリガーがあるか
- [ ] キャラの心理変化は十分に表現されているか（不自然な反転をしていないか）
- [ ] 脇役が機能しているか（単なる情報伝達役になっていないか）
- [ ] 新キャラは明確な第一印象を与えているか

---

## プロット（プロット審査員）

- [ ] 本章のイベントは前章の結果か（因果関係があるか）
- [ ] 本章のイベントは自然に次章を導いているか
- [ ] 本章で新しい伏線があれば、意図的に設置されているか
- [ ] 本章で回収された伏線があれば、自然に処理されているか
- [ ] 本章の情報量は適切か（多すぎず少なすぎず）
- [ ] 本章のテンポは：{速い/中程度/遅い}、ストーリーの要求に合っているか

---

## 検出問題の報告フォーマット

```markdown
### [{カテゴリ}] {問題の簡単な説明}
- **所在**：{段落位置/行数}
- **問題の詳細**：
  {問題の具体的な説明}
- **改善提案**：
  {修正方法の提案}
```
