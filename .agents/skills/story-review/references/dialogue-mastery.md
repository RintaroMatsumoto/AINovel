# 対話技術分析

`story-review` 審査員の対話技術分析方法と評価基準。

---

## 対話品質評価体系

### 1. 自然さ
| レベル | 説明 |
|-------|------|
| 優秀 | リアルな会話のリズムで、言い淀み・省略・反復があり、書き言葉的でない |
| 良好 | 基本的に自然だが、ところどころ書き言葉的 |
| 不合格 | 明らかに書き言葉的で、登場人物の話し方が皆同じ |

**チェックポイント：**
- 話し言葉と書き言葉の区別（「しかし」「なお」等の接続詞を多用していないか）
- 語気助詞の使用（〜ね、〜よ、〜か）
- 言い淀み/省略（日常会話では完璧な文にならない）

### 2. 個性化
| レベル | 説明 |
|-------|------|
| 優秀 | セリフだけで誰が話しているか判別でき、各キャラに固有の話し方がある |
| 良好 | セリフに一定の違いがあるが、時々混同する |
| 不合格 | 全キャラの話し方が同じ |

**チェックポイント：**
- 語彙の選択（教養のあるキャラと無教養なキャラの語彙の差）
- 句長（せっかちなキャラは短文、考え込むキャラは長文）
- 口癖や話題の好み

### 3. 情報量
| レベル | 説明 |
|-------|------|
| 優秀 | 対話がプロットを推進し、キャラを表現し、自然に情報を伝えている |
| 良好 | 対話が情報を伝えているが、やや作為的 |
| 不合格 | 対話が情報ダンプになっている（複数の情報を一気に説明） |

**チェックポイント：**
- 情報ダンプ（会話なのに全部言い切っている）
- 空疎な対話（やってもやらなくても同じ）
- 不自然な尋問（聞かれた側が当然知っていることを聞く）

### 4. 地の文とのバランス
| レベル | 説明 |
|-------|------|
| 優秀 | 対話と地の文が有機的に絡み合い、リズムが良い |
| 良好 | 対話と地の文が基本的にバランスが取れている |
| 不合格 | 地の文が多すぎる/対話が多すぎる |

## 典型的な対話問題

### 問題一：情報ダンプ
```
「知ってる？実はね、あの人は君の実の父親で、20年前に……」

```
**改善：**
- 情報を複数回の対話に分散させる
- 一度に全部説明せず、伏線とともに徐々に明らかにする
- 読者に推測や発見の余地を残す

### 問題二：セリフの書き言葉化
```
「しかし、このような事態は我々の予想を超えている」

```
**改善：**
- 「でも、これは想定外だよ」
- 語気助詞、省略、言い淀みを追加する

### 問題三：セリフタグの乱用
```
「行こう」と彼は言いながら立ち上がった。
「どこへ？」と彼女は眉をひそめて尋ねた。
「あそこだ」と彼はあごで示した。

```
**改善：**
- 大半のセリフはタグを省略（誰のセリフか文脈で判別できる場合）
- 「言う」「尋ねる」以外の動詞を使う
- 地の文での行動描写で誰のセリフかを示す

### 問題四：不自然な呼称
```
「おい、田中太郎よ、お前はなぜ昨日の会議に来なかったのだ」

```
**改善：**
- 自然会話ではフルネームを連呼しない
- 呼称は親密度やシーンの状況に合わせる
- 一人称視点なら「彼/彼女」や名前で呼ぶ

## 対話書き方の原則

1. **各セリフは3つの機能のうち1つ以上を果たすべき**：キャラを表現する／プロットを推進する／情報を伝える
2. **セリフは可能な限り短く**：長セリフは分割し、聞き手の反応を挟む
3. **セリフの語尾は多様に**：常に句点で終わらず、疑問・感嘆・省略を使い分ける
4. **言外の意味を残す**：全部言い切ると浅い、言わないことのほうが深みがある
5. **一人称の語りとセリフを区別する**：語り手の口調がセリフに混入しないように
