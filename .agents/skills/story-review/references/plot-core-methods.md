# プロットコア手法

`story-review` プロット審査員の分析方法。ストーリー構造の合理性、感情転換点の配置、伏線の設計を評価する。

---

## 分析フレームワーク

全体的なスコアリング方法については `quality-rubric.md` を参照。

### 1. 構造整合性分析

計画に基づき、各章の機能が計画と一致しているかチェック。

**チェックポイント：**
- 各章は全体構造の中で期待される役割を果たしているか
- 章間の接続に断裂がないか
- DayTrade：三層対応表（封筒 × 回想 × 滲み出し層）は正しく実装されているか

### 2. 因果連鎖分析

各主要イベント間の因果関係を検証。

**手法：**
- 各章の主要イベントに対して「なぜこのイベントが起きたか」の原因をたどる
- 原因が前章にない、または合理的でない → 断裂点とマーク
- 各イベントに自然な結果があるか確認（結果が放置されていないか）

### 3. 感情転換点分布分析

全感情転換点をリストアップし、強度・密度・タイプ分布を評価。

**基準：**
| 指標 | 良好 | 要注意 |
|------|------|--------|
| 転換点密度 | 1〜2 章ごとに小さな感情転換、3〜5 章ごとに大きな転換 | 5 章以上感情変化がない |
| 強度変化 | 感情強度が徐々に高まる（または逆V形に従う） | 感情が平坦、または唐突な跳躍 |
| タイプ分布 | 内省 + 発見 + 喪失 + 静寂が混在 | 単一タイプのみ |
| 転換点前の準備 | 転換点ごとに十分な伏線・内的蓄積がある | 転換点が唐突に出現 |

### 4. リズム分析

全体的な緊張と弛緩のリズムを評価。

**手法：**
- 各章の緊張度を 1〜10 で記録
- 連続する高緊張区間の長さを評価（3 章を超える高緊張持続は読者の疲労につながる）
- 弛緩区間の長さを評価（2 章超の連続弛緩は読者の離脱につながる）
- DayTrade：逆V形の情緒アークが正しく進行しているか

---

## DayTrade 固有のチェックポイント

### 三層対応表の整合性

| 層 | チェック内容 |
|----|------|
| 封筒層 | L1〜L6 の進行が破壊キャンペーン表と一致しているか。空白月（11月）は正しく配置されているか |
| 回想層（誠） | 各封筒に対応する誠の回想が自然にトリガーされているか。回想が幸福な記憶→汚染される記憶へと変化しているか |
| 滲み出し層（百合子） | 滲み出し①〜④が正しい章（Ch3/4/5/7）に配置されているか。読者のみが真実を知る情報非対称が維持されているか |

### 劇的アイロニーの進行

- Ch3：読者が初めてレイプの真実を知る分岐点。ここから全回想が「汚染された記憶」に変わる
- Ch4〜5：誠の幸福な記憶の裏で、読者だけが脅迫の継続を知る二重構造
- Ch7：読者が托卵の真実を知り、誠がまだ知らないまま最終章へ
- Ch8：誠が告白を「信じなかった」→ 読者の複合的感情（誠への怒り＋百合子への哀しみ）

## 典型的な問題と改善の方向性

### 問題一：感情転換点空白区間
- **症状**：連続する章に感情変化がない
- **改善**：
  - 中間に小さな感情転換を追加（例：新しい情報の開示、記憶のフラッシュバック）
  - 封筒がない期間（空白月）は不安の自壊的加速で感情線を動かす

### 問題二：感情強度曲線がフラット
- **症状**：感情の強度に変化がなく、クライマックスが中盤より弱い
- **改善**：
  - 前期の感情強度を抑え、後期の強度を上げる
  - DayTrade：逆V形に従い、プロローグの幸福（ピーク）→ 各封筒で徐々に降下 → Ch8で破滅

### 問題三：伏線回収漏れ
- **症状**：設置された伏線に回収がない
- **改善**：
  - 回収位置を追加するか、未回収の伏線を削除する
  - 伏線の回収を後続のプロットに組み込む
  - 削除できない伏線は後続巻への伏線としてマーク

### 問題四：因果断裂
- **症状**：イベントに合理的な原因または結果がない
- **改善**：
  - 原因となるイベントを追加するか、原因を前方の章に遡らせる
  - イベントに自然な結果を追加する
