# キャラ関係分析

`story-review` キャラ審査員の分析方法、キャラ関係のネットワーク分析と評価基準。

---

## キャラ関係分析フレームワーク

### 1. 関係ネットワークの構築

全キャラ間の関係を系統的に整理：

```json
{
  "キャラA — キャラB": {
    "関係タイプ": "血縁/恋愛/師弟/敵対/友人/ビジネス",
    "関係の詳細": "父と子、確執がある",
    "力関係": "Aが優位/Bが優位/対等",
    "感情ベクトル": "A→B: 憎悪 / B→A: 畏怖",
    "変化の方向性": "敵対→和解/蜜月→決裂"
  }
}
```

### 2. 関係の合理性チェック

- 各関係に合理的な形成原因があるか
- 関係の変化に十分な伏線とトリガーがあるか
- 関係がキャラのコア動機と矛盾していないか

### 3. 感情ベクトル分析

各キャラ間の感情の方向性と強度を分析：

- 双方向の感情が一致しているか（相思相愛/一方的/ねじれ）
- キャラの行動が感情ベクトルと一致しているか
- 感情ベクトルの変化が合理的か

## 典型的なキャラ問題

### 問題一：キャラが平面的
- **症状**：キャラに多面性がなく、単一の属性やラベルのみ
- **改善**：
  - 相反する性格特性を追加（例：冷酷だが妹には優しい）
  - キャラの背景や過去を追加
  - キャラに弱点や矛盾を持たせる

### 問題二：キャラの行動が動機と矛盾
- **症状**：キャラの行動と設定された動機が合わない
- **改善**：
  - 行動の前に合理的な心理変化を追加
  - 動機を再設定するか、行動を調整する
  - 極限状況下の行動でも合理性を持たせる

### 問題三：脇役の機能が単一
- **症状**：脇役が情報伝達やプロット促進のためのみに存在
- **改善**：
  - 脇役に独立した動機や目標を持たせる
  - 脇役と主人公の相互作用を増やす
  - 脇役にも成長弧を持たせる

### 問題四：キャラ関係の変化が唐突
- **症状**：関係の変化に十分な伏線がない
- **改善**：
  - 小さな伏線を積み重ねて関係変化を準備する
  - 変化前に関係の緊張を示すシーンを追加する
  - 第三者や外部イベントで関係変化を促進する

## 一人称視点のキャラ表現

### 語り手の自己表現
- 語り手は自分をどう見ているか（自己認識）
- 語り手と実際の行動のギャップ（無自覚な特徴）
- 語り手が他者をどう描写しているか（投影）

### 他者を通じた語り手の表現
- 他者の語り手に対する評価
- 他者との対比で浮かび上がる語り手の特徴
- 他者との関係性が語り手の別の側面を引き出す

### 一人称の制約
- 語り手の知らない情報は表現できない
- 語り手の主観は必ずバイアスがかかる
- 語り手の認知の限界がサスペンスや反転を生む
