# 品質評価ルーブリック

`story-review` の各 review agent が審査時に使用する統一評価基準。DayTrade（村上文体）対応済み。

---

## 評価体系

### 7 次元評価

| 次元 | 重み | 評価基準（1-10） | 説明 |
|------|------|-----------------|------|
| ストーリー構造 | 20% | 構成の完全性、リズムの合理性、感情転換点の配置 | ストーリーに明確な起承転結があるか、リズムが弛まないか |
| キャラ造形 | 18% | キャラの立体感、成長弧、動機の合理性 | キャラに血肉が通っているか、行動に動機があるか |
| 対話品質 | 15% | 対話の自然さ、個性化、沈黙と間 | 対話がキャラに合っているか、説明文が長すぎないか |
| 文体の質 | 15% | 叙述視点の一貫性、文長リズム、AI 臭の有無 | 文体が安定しているか、村上文体の場合は自然な時間交差と激しい感情表現が両立しているか |
| 感情深度 | 12% | 感情リズム設計、没入感、内省の質 | 読者の感情を動かせるか、内省が具体的過程として書かれているか |
| 伏線設計 | 10% | 伏線設置・回収の完全性、緻密さ | 伏線に回収があるか、整合性は取れているか |
| 文体戦略適合性 | 10% | プロジェクトの文体プロファイルへの適合度 | 設定された文体方針に合っているか |

### 評価レベル

| レベル | 総合スコア | 説明 |
|-------|-----------|------|
| S | ≥ 90 | 傑作、ほぼ修正不要 |
| A | 80-89 | 良作、微調整でリリース可 |
| B | 70-79 | 可、中程度の修正が必要 |
| C | 60-69 | 不合格、大規模な修正が必要 |
| D | < 60 | 大幅な書き直しが必要 |

---

## 次元別詳細説明

### ストーリー構造

| レベル | 基準 |
|-------|------|
| 9-10 | 構造が緻密で、感情転換点の配置が的確、リズムが絶妙 |
| 7-8 | 構造が完全、感情リズムが合理的、配置が良好 |
| 5-6 | 構造に不備がある、感情転換点が不均等、リズムに問題がある |
| 3-4 | 構造が混乱、転換点が少ないまたは配置ミス、リズムが単調 |
| 1-2 | 構造が不完全、転換点がほぼない、リズムが破綻 |

### キャラ造形

| レベル | 基準 |
|-------|------|
| 9-10 | キャラが立体的で、性格が明確、成長弧が自然で説得力がある |
| 7-8 | キャラが明確で、動機が合理的、成長弧がある |
| 5-6 | キャラに個性があるが、厚みが足りない、成長弧が弱い |
| 3-4 | キャラが平面的、動機が弱い、成長弧がない |
| 1-2 | キャラが記号的、行動の動機が不明瞭 |

### 対話品質

| レベル | 基準 |
|-------|------|
| 9-10 | 対話が生き生きとして個性的、情報量が適切、沈黙と間を活かしている |
| 7-8 | 対話が自然で、ある程度の個性がある |
| 5-6 | 対話が平凡、個性が足りない、やや説明過多 |
| 3-4 | 対話が不自然、情報量が多すぎる/少なすぎる |
| 1-2 | 対話が機械的、キャラの区別がつかない |

### 文体の質

| レベル | 基準 |
|-------|------|
| 9-10 | 文体が安定し洗練されている、リズム感が強く、AI 臭がまったくない |
| 7-8 | 文体が安定、基本的なリズムがある、軽微な AI 臭のみ |
| 5-6 | 文体にばらつきがある、リズムが平凡、中程度の AI 臭 |
| 3-4 | 文体が不安定、リズムが単調、明らかな AI 臭 |
| 1-2 | 文体が大きく乱れている、リズムがない、強い AI 臭 |

### 感情深度

| レベル | 基準 |
|-------|------|
| 9-10 | 内省が深く具体的で、感情の起伏が自然で没入感が強く、読後に余韻が残る |
| 7-8 | 感情の流れが自然で、内省に具体性があり、一定の没入感がある |
| 5-6 | 感情の起伏が平坦、内省が表面的 |
| 3-4 | 感情設計が不十分、内省が空虚な一語要約に留まる |
| 1-2 | 感情の起伏がなく、読者を退屈させる |

### DayTrade 固有チェック（プロジェクトが DayTrade の場合に追加）

| チェック項目 | 説明 |
|------|------|
| 自然な時間交差 | 回想と現在の境界がマークなしで交差しているか。動詞の時制・知覚（光・音・温度・身体感覚）をトリガーに自然に移行しているか |
| 自然な回想 | 境界マーク（`***`等）を使わず、知覚をトリガーに過去へ滑り込んでいるか |
| 滲み出し層 | 誠の語りから百合子の過去へ、動詞の時制と光の質の変化だけで自然に移行しているか |
| 章末の余韻 | 総括・教訓・哲理を避け、イメージ・断片・静かな動作で閉じているか |
| 取引手法禁止 | 禁止語・禁止表現が出現していないか |
| 祖父のノート | ノートの具体的文言が本文中に引用されていないか |
| 語り手の声 | 誠＝理論派・封筒により語りが断片化／栞＝二重言語／翼＝身体感覚→内省——声が一貫しているか |
