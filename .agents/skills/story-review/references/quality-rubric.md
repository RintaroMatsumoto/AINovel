# 品質評価ルーブリック

`story-review` の各 review agent が審査時に使用する統一評価基準。品質チェックリスト（`quality-checklist.md`）と併用する。

---

## 評価体系

### 7 次元評価

| 次元 | 重み | 評価基準（1-10） | 説明 |
|------|------|-----------------|------|
| ストーリー構造 | 20% | 構成の完全性、リズムの合理性、爽点分布 | ストーリーに明確な起承転結があるか、リズムが弛まないか |
| キャラ造形 | 18% | キャラの立体感、成長弧、動機の合理性 | キャラに血肉が通っているか、行動に動機があるか |
| 対話品質 | 15% | 対話の自然さ、個性化、情報量 | 対話がキャラに合っているか、説明文が長すぎないか |
| 文体の質 | 15% | 叙述視点の一貫性、句長リズム、AI 臭の有無 | 文体が安定しているか、AI 生成文特有のパターンがないか |
| 感情共鳴 | 12% | 感情リズム設計、没入感、爽点効果 | 読者の感情を動かせるか、爽点が的確か |
| 伏線設計 | 10% | 伏線設置・回収の完全性、緻密さ | 伏線に伏線回収があるか、整合性は取れているか |
| 市場適合性 | 10% | ターゲット読者層への適合度、トレンドマッチング | 対象読者の好みに合っているか、商業的可能性はあるか |

### 評価レベル

| レベル | 総合スコア | 説明 |
|-------|-----------|------|
| S | ≥ 90 | 傑作、ほぼ修正不要 |
| A | 80-89 | 良作、微調整でリリース可 |
| B | 70-79 | 可、中程度の修正が必要 |
| C | 60-69 | 不合格、大規模な修正が必要 |
| D | < 60 | 大幅な書き直しが必要 |

## 次元別詳細説明

### ストーリー構造

| レベル | 基準 |
|-------|------|
| 9-10 | 構造が緻密で、爽点配置が的確、リズムが絶妙、一章たりとも無駄がない |
| 7-8 | 構造が完全、爽点配置が合理的、リズムが良好 |
| 5-6 | 構造に不備がある、爽点配置が不均等、リズムに問題がある |
| 3-4 | 構造が混乱している、爽点が少ないまたは配置ミス、リズムが単調 |
| 1-2 | 構造が不完全、爽点がほとんどない、リズムが破綻 |

### キャラ造形

| レベル | 基準 |
|-------|------|
| 9-10 | キャラが立体的で、性格がはっきりしており、成長弧が自然で感動的 |
| 7-8 | キャラが明確で、動機が合理的、成長弧がある |
| 5-6 | キャラに個性があるが、厚みが足りない、成長弧が弱い |
| 3-4 | キャラが平面的、動機が弱い、成長弧がない |
| 1-2 | キャラが記号的、行動の動機が不明瞭 |

### 対話品質

| レベル | 基準 |
|-------|------|
| 9-10 | 対話が生き生きとして個性的、情報量が適切、地の文とのバランスが良い |
| 7-8 | 対話が自然で、ある程度の個性がある |
| 5-6 | 対話が平凡、個性が足りない、やや説明過多 |
| 3-4 | 対話が不自然、情報量が多すぎる/少なすぎる |
| 1-2 | 対話が機械的、キャラの区別がつかない |

### 文体の質

| レベル | 基準 |
|-------|------|
| 9-10 | 文体が安定し洗練されている、リズム感が強く、AI 臭がまったくない |
| 7-8 | 文体が安定、基本的なリズムがある、軽微な AI 臭のみ |
| 5-6 | 文体にばらつきがある、リズムが平凡、中程度の AI 臭 |
| 3-4 | 文体が不安定、リズムが単調、明らかな AI 臭 |
| 1-2 | 文体が大きく乱れている、リズムがない、強い AI 臭 |

### 感情共鳴

| レベル | 基準 |
|-------|------|
| 9-10 | 感情の起伏が激しく、没入感が強く、爽点が的確で読後に余韻が残る |
| 7-8 | 感情の流れが自然で、爽点が的確、一定の没入感がある |
| 5-6 | 感情の起伏が平坦、爽点効果が弱い |
| 3-4 | 感情設計が不十分、爽点が刺さらない |
| 1-2 | 感情の起伏がなく、読者を退屈させる |

### 伏線設計

| レベル | 基準 |
|-------|------|
| 9-10 | 伏線が緻密、回収が自然、複数の伏線が絡み合う |
| 7-8 | 伏線に回収がある、基本的に整合性が取れている |
| 5-6 | 伏線はあるが、回収が不完全または強引 |
| 3-4 | 伏線設置が乱雑、回収がない、矛盾がある |
| 1-2 | 伏線設計がほぼない |

### 市場適合性

| レベル | 基準 |
|-------|------|
| 9-10 | ターゲット読者層のニーズに完全に合致、トレンドに合っている |
| 7-8 | ターゲット読者層の好みに合致、一定の商業的可能性 |
| 5-6 | ターゲットがやや不明確、市場競争力が弱い |
| 3-4 | ターゲット読者層とミスマッチ、商業的可能性が低い |
| 1-2 | 市場価値がほぼない |
