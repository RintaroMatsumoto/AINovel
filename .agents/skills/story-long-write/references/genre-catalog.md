# 題材カタログ

各題材のコア爽点プランと実戦テンプレート。

> 題材選定の際は、`genre-readers.md` で読者の心理と期待を把握してから、本カタログと照らし合わせて爽点配置を最適化してください。

---

## 玄幻

| 爽点 | 実戦テクニック |
|------|---------------|
| 血脈/覚醒 | 身分の落差 → 血脈覚醒 → 周囲の態度の急変、二段階開示で効果を最大化（まず低い身分を開示、次に高い身分を開示） |
| 昇級/突破 | 障壁の蓄積 → 臨界点 → 一気に突破。突破の瞬間は天地の異変を伴うと効果的 |
| 遺跡/秘境 | 秘境のルール → 奪宝 → 反転。秘境のルールは「制限」であり、強者の妨害を避け、同等の競争を生む |
| 師弟/パートナー | 師の継承 → 弟子の成長。師弟関係は単なる能力伝授でなく、感情的なつながりも必要 |

**一般的な落とし穴**：
- 前の段階の爽点パターンを次の段階で使い続ける
- 設定が複雑すぎる（読者が理解するのに時間がかかる設定を冒頭で入れすぎない）
- 側面のプロットが長すぎる（核心物語を圧迫する）

**タイトルのコツ**：
- 「我がXXX」「XXXがXXXになった日」「XXX覚醒」などの定式化を避ける
- タイトルはサスペンスを示す
- タイトルは作品のトーンを反映する

## 都市

| 爽点 | 実戦テクニック |
|------|---------------|
| 逆襲/成り上がり | 底辺状態 → チャンス → 逆襲。爽点の前に十分な期待値をためる（蔑み、圧迫） |
| 神医/鑑定 | 特殊能力で問題解決 → 身分開示。神医＋都市の組み合わせは爽点密度が高い |
| ビジネス/権謀 | 盤面の分析 → 配置 → 逆転。ビジネス爽点は交渉の過程を具体的に |
| 恋愛/日常 | 出会い → すれ違い → 甘やかし。恋愛の爽点は「日常の中の異変」に注意 |

---

## 歴史/架空歴史

| 爽点 | 実戦テクニック |
|------|---------------|
| 知識差/技術移転 | 現代知識→古代の応用→局面逆転。技術移転は具体的な過程が必要（原材料、製作方法、応用例） |
| 権謀/駆け引き | 盤面の分析→相手の読み→一網打尽。権謀爽点は「計算の過程」を見せることが重要 |
| 戦争/戦略 | 兵力配分→戦術応用→戦果拡大。読者に具体的な戦術の細部を見せることで爽快感を高める（地の利、タイミング、兵站など） |
| 文化/文明 | 知識の蓄積→文化の衝突→世界観。文化の爽点は「認められる感覚」が中核 |

## 科幻（SF）

| 爽点 | 実戦テクニック |
|------|---------------|
| メカ/強化 | 改造→戦闘→強化。メカ爽点は「アップグレードの具体的なパラメータ」が必要 |
| AI/システム | システム授与→任務完了→報酬入手。システム爽点はルールが簡潔であればあるほど良い |
| 宇宙/航行 | 探索→資源争奪→勢力闘争。宇宙題材は「異種族のデザイン」と「宇宙のルール設定」で新規性を出せる |
| 終末/生存 | 危機→資源争奪→生存基盤。終末爽点は「生存圧力」の設計が重要 |

---

## 競技（スポーツ）

| 爽点 | 実戦テクニック |
|------|---------------|
| 成長/昇級 | 新人→ステップアップ→トップ対決。成長過程は具体的な競技シーンが必要 |
| 試合/対抗 | 対決→反転→勝利。試合描写は「戦術の細部」と「観客の反応」を交互に |
| チーム/友情 | 集結→衝突→団結。チーム爽点は「各キャラの機能」が重要 |
| トレーニング/突破 | 苦しい練習→技術の向上→限界突破。トレーニングシーンは実感が必要 |

## ライトノベル

| 爽点 | 実戦テクニック |
|------|---------------|
| 部活/学生会 | 日常→事件→結束。部活爽点は「キャラの掛け合い」が中核 |
| 超能力/学園 | 能力覚醒→任務遂行→成長。超能力学園は「能力のルール設定」が肝 |
| 恋愛/ラブコメ | 出会い→誤解→距離が縮まる。ラブコメは「テンポ」が命 |
| ファンタジー/異世界 | 召喚→探索→冒険。異世界は「世界観設定」を最初に見せすぎない |
