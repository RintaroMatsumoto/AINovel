# プロット核心技法

## 連続性追跡とリズム管理

### 連続性追跡法

長編創作において伏線と状態を追跡するための3つの実用的手法：

**1. 伏線チェーン法**

伏線を独立したイベントとしてではなく、チェーンとして扱う：

```
伏線A（設置）→ 伏線Aの強化（深化）→ 伏線Aの予兆（回収前のシグナル）→ 伏線Aの回収（開示/反転）
```

各段階間の間隔を記録する。長すぎる = 読者が忘れる。短すぎる = 効果が弱い。

**2. 状態更新トリガー**

各章の執筆後にチェックする固定的なトリガーポイント：
- 本章でどのキャラの状態が変わったか？ → `追跡/キャラ状態.md` を更新
- 本章でどの伏線が進んだか？ → `追跡/伏線.md` を更新
- 本章の出来事は時間線に影響するか？ → `追跡/時間線.md` を更新

**3. 一貫性チェックリスト**

各章執筆後：
- キャラの言動は設定と矛盾していないか？
- 設定は前文と矛盾していないか？
- 能力バランスは崩れていないか？
- 時間線は論理的に成立しているか？

### リズム管理——問題と解決策

| 問題 | 症状 | 原因 | 解決策 |
|------|---------|------|---------|
| 読者が離脱 | 章ごとに読了率が低下 | 感情ピーク密度が低すぎる／感情ピークが繰り返し | 感情ピーク密度を高める／感情ピークのタイプを変える |
| 中だるみ | 読者が「まだこの話？」と感じる | 感情ピークサイクルが長すぎる／感情ピークが単一 | 短サイクル感情ピークを追加／感情ピークの蓄積と解放 |
| 感情ピーク疲れ | 感情ピークが来ても興奮しない | 感情ピークパターンの繰り返し | 感情ピークのタイプを変える／感情ピークのペースを変える |
| 期待値崩壊 | 読者が結末を予想できてしまう | 情報差が不足 | 新たな情報差を導入／伏線の層を追加 |
| 設定過多 | 読者が「何の話だか」わからなくなる | 設定が複雑すぎる／設定を説明しすぎる | 設定を簡略化／設定の開示を分散 |
| 展開が遅い | 読者が「まだ進まないの？」と感じる | ページを割きすぎている | 各段落の機能をチェック／無駄な部分を削除 |

## 伏線とパラレルライン

### 伏線の相互運用

複数の伏線が交差することで、強力な物語の推進力を生み出す：

| 伏線の交差タイプ | 方法 |
|----------------|------|
| 収束型 | 複数の伏線が一点に収束 → 1つの爆発 |
| 連鎖型 | 伏線Aの回収が伏線Bを引き起こす |
| 対比型 | 伏線Aと伏線Bが互いに暗示し合う/隠し合う |
| 多面型 | 同じ設定を異なる角度から見せ、徐々に全貌を明らかにする |

### パラレルラインの同期

パラレルラインがある場合、各ラインの進捗を同期する：

| 進捗段階 | ラインA | ラインB | 同期方法 |
|----------|--------|--------|---------|
| 同時開始 | 強度5 | 強度5 | 交互に章を進める |
| ライン合流 | 強度8 | 強度4 | ラインAを主に、ラインBを補助に |
| ライン分岐 | 強度3 | 強度9 | ラインBを急展開、ラインAは保留 |

## 戦闘シーン設計

ネット小説の戦闘は身体とルールの情報から構成される。

身体には体格、体重、筋肉量、骨格、脂肪分布などが含まれる。ルールには選択肢と制限——何ができるか、何が制限されているかが含まれる。

身体情報の提供：

```
戦闘開始前に、参加者の身体的特徴を示す。
ヒット→ダメージの伝達を明確に書く。
身体の一回一回の変化を記録する。
```

**戦闘シーンの実戦ガイド**：

1. 重心（キャラの移動方向と体勢を決定する）
2. 体勢（キャラの次の動作を決定する）
3. 攻撃範囲（戦闘の距離感を決定する）
4. 筋力属性（攻撃力を決定する）

これらの4つの要素を常に読者に明示することで、戦闘シーンは画面感と緊張感を獲得する。

戦闘シーンのリズム：短文、1-3文で1段落、動詞の密度が高い。手を抜かない。読後にキャラの位置と動作を正確に思い出せるのが良い戦闘。

また、戦闘シーンでは言語をコントロールする必要がある。読み手は戦闘シーンを読むときかなり速く読む。術語、代名詞、方位詞の選択は一貫性を保ち、誤解を避ける。言語が複雑すぎると、読者は「誰がどうした」という情報を処理するのが遅くなる。
