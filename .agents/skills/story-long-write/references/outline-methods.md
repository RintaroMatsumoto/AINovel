# アウトライン手法

標準的なアウトライン手法。

---

## アウトラインの3層構造法

物語の設計を3層に分け、段階的に詳細化する。後続の各層は前の層の詳細化であり、矛盾してはいけない。

### 第1層：全書鳥瞰

**機能**：一目で概要がわかる

**内容**：
```
全書タイトル：
全書タイプ：
中央値の長さ：
叙事構造（直線的/マルチライン/群像劇）：

メインストーリーの説明（100-200字）：
世界観設定の概要：

核心的な感情体験：

読者のターゲット層と読み手の特定：

全書の核心的な対立（全書を最後まで貫く）：
各巻の位置づけと目標：
```

**作成時期**：プロジェクト開始時

### 第2層：巻ごとの詳細アウトライン

**機能**：各巻の設計と節奏の配置

**内容**：
```
巻タイトル：
章の範囲：
字数目標：
本巻の位置づけ（伏線/展開/転換/収束）：

本巻の核心対立（本巻全体を貫く一本の線が明確）：
中心的な出来事/反転：
本巻の感情ベース/節奏：

章の構成（各章1-2文で説明）：
第X章：内容
第X章：内容

各巻の必須要素の確認：
```

**作成時期**：各巻の起筆前

### 第3層：章詳細アウトライン（細綱）

**機能**：各章の詳細な設計

**内容**（`artifact-protocols.md` 参照）：
```
核心イベント：
字数目標：
目標感情：
章首フック：
爽点設定：

展開過程：
設定の開示：
節奏のコントロール：

章末フック（引き）：
期待値管理：
```

**作成時期**：各章の執筆前

## アウトラインの反復

| 段階 | 方法 | 反復回数 | 節約時間のヒント |
|---------|------|--------------------|-----------------------|
| プロジェクト全体 | 一度決めたら基本的に変更しない。大きな変更は後続の各層に影響を与える | 1-2回 | 第1層アウトラインは30分で決定し、過度に推敲しない |
| 巻全体 | プロットに大きな変更があれば更新。各層間の一貫性に注意 | 2-3回 | 節奏に集中し、細部にこだわりすぎない |
| 単章 | 執筆前に詳細化。執筆中に新たなアイデアが出たら随時調整 | 必要に応じて | 細綱の深さは状況に応じて調整。執筆がスムーズなら簡略化可能 |

**アウトラインの修正原則**：
- 下位層の変更は上位層に影響し得る（細部の変更がプロットの方向性全体を変える場合）
- 上位層の変更は下位層の更新を必要とする（巻アウトラインの変更は章の調整が必要）
- 矛盾はすべて第1層で統一する

## 章節の対立と起伏の配置

各章/各巻に「起承転合」を持たせ、単調なストーリー展開を避ける：

| 段階 | 章/巻内の機能 | 字数割合 |
|-------|-------------|---------|
| 起 | 問題の提示/状況の説明 | 10-20% |
| 承 | 展開の深化/対立の激化 | 30-40% |
| 転 | 情報の反転/状況の急変 | 20-30% |
| 合 | 暫定的な解決/新たな伏線 | 10-20% |
