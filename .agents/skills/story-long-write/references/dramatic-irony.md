# 劇的アイロニーの設計

> DayTrade 用。GoldenCross 巻の核心技法。1Q84 型——読者は誠と同時に真実を知り、誠と一緒に誤解する。

## 定義

劇的アイロニーとは、読者が登場人物よりも多くの情報を持っている——あるいは**持っていない**——状況を指す技法。本作では1Q84型を採用：読者は誠と**同時に**真実を知る。百合子の過去は独立した回想章ではなく、封筒を通して誠が知るのと同じタイミングで、誠の内省の自然な流れの中で少しずつ明かされる。

## 本作での使い方

### 基本構造（1Q84型）

```
封筒が届く → 誠は写真を見て困惑する
     ↓
誠の内省 → 封筒の内容から過去を断片的に思い出す（境界マークなし、自然な回想）
     ↓
読者は誠と同時に知る。「これはレイプの記録なのか」「なぜ今」
     ↓
誠の誤解 → 読者も誠も、真実の全体像を知らない。一緒に迷う
     ↓
次の封筒 → 新たな情報層。前の封筒で築いた「理解」が覆る
     ↓
L8→問い詰め→百合子が16年ぶりにすべてを語る→誠は信じない→百合子自死
     ↓
読者：誠と一緒に打ちのめされる。誠が信じなかったことの重みを共有する
```

### DeepLove型と1Q84型の違い

| | DeepLove型（旧設計） | 1Q84型（新設計） |
|---|---|---|
| 読者の情報 | 百合子回想で**先に**真実を知る | 誠と**同時に**知る |
| 読者の感情 | 歯がゆさ「誠、違うんだ！」 | 戸惑いと発見「これは何を意味するんだ」 |
| 回想の位置 | 封筒と封筒の間の独立章 | 封筒を読んだ誠の内省の中に自然に溶け込む |
| 百合子の声 | 独立した回想シーン | 誠の記憶として、誠の一人称の枠内で語られる |
| 最終的な衝撃 | 「知ってたのに止められなかった」 | 「信じなかった。取り返しがつかない」 |

### 情報開示のタイミング

読者は誠と同時進行で以下の層を知る：

| 封筒 | 誠が知ること | 読者が共有する戸惑い |
|:--:|------|------|
| L1 | 職場の写真。百合子18歳。なぜ今 | 「これは誰が撮った？ なぜ送ってきた？」 |
| L2 | 寝室の写真。服を脱がされて | 誠と一緒に不安になる。「何が起きている」 |
| L3 | 全裸＋血痕。初めてじゃなかった | 誠と一緒に衝撃。「これは不倫か、それとも——」 |
| L4 | 別の日付。一度じゃない | 誠と一緒に疑念が深まる |
| L5 | 交際期間中の日付。付き合っている間も | 誠と一緒に怒りと混乱。「百合子は一体——」 |
| L6 | 妊娠中の裸。栞は誰の子 | 誠と一緒に恐怖。「俺の娘じゃないのか」 |
| L7 | 先週の日付。今も続いている | 誠と一緒に絶望。「まだ——今も——」 |
| L8 | 録音「今日は危険日だから」 | 誠と一緒に破滅。「栞は——金子の——」 |

**最終局面（L8後）**：百合子が16年ぶりにすべてを語る——誠は信じない。読者も誠と一緒に「信じるべきか、信じないべきか」迷う。そして百合子が死に、誠が後を追う。読者は誠と一緒に取り返しのつかなさを引き受ける。

### 効果

- **「俺も間違えたかもしれない」**：読者は誠と一緒に誤解する。誠を責められない。自分も同じ過ちを犯したかもしれないという重み
- **封筒ごとの発見の連続**：1Q84が「空気さなぎ」の真実を複数章で分割開示したように、封筒8通それぞれで異なる層が剥がれる
- **再読時の衝撃**：2周目は「あの写真はレイプの記録だった」と知って読む。すべてのシーンが別の意味を持つ

### 注意点

- 回想は誠の記憶の範囲内で。誠が知らない情報（百合子の内心、金子の意図）は書かない
- 誠が気づく前に読者に気づかせる「先回り」をしない。1Q84型の鉄則
- 封筒の内容と誠の内省を有機的に繋ぐ。封筒＝情報のトリガー、内省＝情報の消化
