# 劇的アイロニーの設計

> Golden Cross 用。FIRE 巻の核心技法。

## 定義

劇的アイロニーとは、読者（観客）が登場人物よりも多くの情報を持っている状況を指す技法。情報の非対称性によって緊張感と没入を生む。

参考：atwiki「シナリオ技法」より。

## 本作での使い方

### 基本構造

```
百合子回想 → 読者は真実を知る（レイプ、脅迫、栞の実父）
     ↓
   封筒 → 誠は写真だけを見て「不倫」と誤解する
     ↓
  読者：「違うんだ、彼女は被害者なんだ」と言いたくても言えない
     ↓
  L8→問い詰め→百合子の告白を誠は信じない→百合子自死
     ↓
  読者：取り返しがつかない。やるせなさ
```

### 情報開示のタイミング

1. 百合子回想①（L2〜L3の間）：入社〜レイプ。読者は「写真はレイプの記録だ」と知る
2. 百合子回想②（L4〜L5の間）：誠との出会い、動画で脅され続けた日々
3. 百合子回想③（L5〜L6の間）：妊娠、栞が金子の子、潜伏

読者は誠より**常に一歩先を行っている**。誠が封筒で知ったことを、読者は回想で数章前に知っている。

### 効果

- **見ているしかできない歯がゆさ**：読者は誠に「違う」と言えない。ただ見守るしかない
- **逆V形弧線の強化**：読者は「このままでは取り返しがつかない」と知りながら、逃避できない
- **再読時の衝撃**：SP（百合子視点）を読んだ後、FIRE の全シーンが別の意味を持つ

### 注意点

- 回想は説明ではない。読者が「今、誠に起きていること」と過去を結びつける感情の接続が必須
- 開示しすぎない。百合子の回想にも「まだ語りきれない沈黙」を残す。SP ですべてが明らかになる
- 誠の一人称と百合子回想の切り替えは明確に。読者が混乱しない境界設計が必要
