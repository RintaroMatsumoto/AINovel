# リズム設計

爽点リズムと段落リズム。

---

## 爽点リズム

### 爽点周期

爽点は満足度曲線で構成される：期待 → 蓄積 → 解放 → 休止。

```
期待（読者が結果を予想）→ 蓄積（読み進める）→ 解放（爽点爆発）→ 休止（新たな期待へ）
```

### 3種の爽点サイクル

| サイクル | 期間 | 機能 |
|---------|----------|---------|
| ミクロサイクル | 1段落-数段落 | 節奏を形成し、単調さを避ける |
| メソサイクル | 1-3章 | 読者の期待値コントロール |
| マクロサイクル | 1巻-数巻 | 感情弧線の段階的ピーク |

## 段落リズム

### 段落の変化

| シーン | 段落長 | リズム |
|-------|---------|--------|
| 戦闘 | 短い（1-3文） | 速い |
| 日常 | 中程度（3-5文） | 穏やか |
| 推理/調査 | やや長い（5-8文） | ゆっくり |
| 感情 | 中程度（3-5文） | 状況により変化 |
| 設定説明 | 短い（1-2文）に分割 | 読者が内容を消化しやすいように |

### 長短のリズム変化

**原則**：長短を交え、リズムを変化させる

戦闘シーンのリズム：
```
接戦（短段落）→ 膠着（中段落）→ 反転（短段落）→ 勝利（やや長い）
```

### 節奏の緊迫と緩和

ネット小説の章では、段落と節奏の変化がシーンのトーンに奉仕すべき：

```
緊迫した戦闘：段落が短い（少ない字数）、動詞の密度が高い
↓
会話による情報：段落が長い（ページの空白が減る）
↓
感情の高ぶり：段落がまた短くなる
↓
余韻と次の伏線：段落がやや長い
```

**キーポイント**：
- 段落の長短で節奏を自然にコントロールし、章の終わりはフックで「期待値」を残す
- 段落は急に長くなったり短くなったりせず、読書に「呼吸」を感じさせる
- 重要な爽点やサスペンスの前で、段落を短くしてリズムを速める（ページをめくる感覚を生む）
