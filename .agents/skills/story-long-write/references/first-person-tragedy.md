# 一人称悲劇の書き方

> Golden Cross 用。誠の一人称で読者の感情を同期させ、壊す技法。

## 一人称の特性

### 強み
- 読者は主人公の目を通して世界を経験する。感情の同期が強い
- 「知らないことは書けない」制約が情報制限の自然な仕掛けになる
- 読者の視野を狭め、主人公の誤解に巻き込める

### 制約
- 主人公が知らない情報は書けない（他のキャラの内面、別の場所の出来事）
- 回想シーンは主人公の記憶の範囲内に限られる
- 主人公が死ぬと物語が終わる（→第2巻からは栞の一人称に切り替わる）

## FIRE での実践

### 誠の声の変化（破壊を文体で表現する）

| 段階 | 文体 | 例 |
|------|------|-----|
| ピーク（幸福時） | 落ち着いた短文。数字と論理。「まず」「次に」 | 「やった。十年だ」 |
| L1〜L3（不安・動揺） | 疑問符が増える。一文が短くなる | 「なぜだ。なぜ今」 |
| L4〜L6（恐怖・破裂） | 比喩が消える。無機質に。数字だけ | 「含み損が300万。信用枠はまだある」 |
| L7〜L8（崩壊） | 句読点が乱れる。壊れた羅列。一文が単語に | 「違う違う違うちがう」 |
| 最後（底） | 「終わりだ」一言のみ。すべての語彙を失う | 「…………」 |

### 読者との距離

- 読者は誠に最も近い視点で読む。しかし百合子回想で一歩先の情報を持つ
- この距離のねじれが「劇的アイロニー」を生む
- 読者は誠に感情移入しながら、誠の判断に同意できない——それが「歯がゆさ」

### 誠に書かせてはいけないこと

- 自分の感情を「感じた」「思った」で説明すること（身体反応で代替）
- 章末の総括・教訓（「彼はようやく理解した…」）
- 他のキャラの内心を推測しすぎること（誠は人の心を読めない）
