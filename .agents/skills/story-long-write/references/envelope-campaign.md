# 破壊キャンペーンの設計

> Golden Cross 用。2026-06-22 確定。設定ファイル `novels/設定/世界観/破壊キャンペーン.md` を reference 化したもの。

## 基本情報

| 項目 | 内容 |
|------|------|
| 期間 | 約9ヶ月（月1通・全8通、9ヶ月目に心中） |
| 開始 | 誠の退社後 |
| 差出人 | 匿名（金子は最後まで明かさない） |
| 戦略 | 写真だけで不倫に見せる。レイプ動画は送らない |
| 素材 | 百合子18→20歳の約2年分 + 7ヶ月目の新規素材 |

## リズム設計

- 毎月1通。一定のリズムが誠の日常を蝕む
- 封筒の合間に百合子回想を配置し、読者の情報優位を作る
- 封筒が過激化するにつれて章のテンポも加速する
