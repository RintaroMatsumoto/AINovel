## 情報分割開示（多崎つくる型）

> 参照：村上春樹『色彩を持たない多崎つくると、彼の巡礼の年』——16年前の絶縁の理由を一人ずつ訪ねて段階的に解明する構造。

封筒8通を**情報の層**として設計する。各封筒で新たな層の真実が剥がれ、読者は誠と**同時に**知る。

| 封筒 | 誠が知る情報層 | 読者の体験 | 誠の文体段階 |
|:--:|------|------|:--:|
| L1 | 百合子の若い頃の姿が誰かに撮られていた | 「なぜ今、退社した途端に」——小さな違和感の始まり | ピーク |
| L2 | 寝室。百合子が誰かの前で服を脱がされている | 誠と一緒に不安になる。何かが進行している | 困惑 |
| L3 | 行為の証拠。初めての相手は自分ではなかった | 誠と一緒に衝撃を受ける。過去の妻を知らなかった | 動揺 |
| L4 | 一度ではない。継続的だった | 疑念が深まる。「これは不倫なのか、それとも——」 | ショック |
| L5 | 自分と付き合っている間も続いていた | 誠と一緒に裏切られた感覚。怒りと混乱 | 疑念 |
| L6 | 妊娠中も。栞は自分の子ではない可能性 | 誠と一緒に恐怖。「俺の娘じゃないのか」 | 恐怖 |
| L7 | 今も続いている。14年経った今も | 誠と一緒に絶望。「まだ——今も——」 | 絶望 |
| L8 | 音声。16年前の「今日は危険日だから」 | 誠と一緒に破滅。すべてが決定的に壊れる | 破滅 |

### 開示の設計原則

- **1通で全てを明かさない**。各封筒は1つの情報層だけを追加する
- **累積効果**：L1〜L3は「過去の話」だが、L5で「今も」に変わる。時間軸が過去から現在に迫る
- **最後の一撃は聴覚**：L1〜L7が視覚（写真）、L8だけ聴覚（録音）。違う感覚でとどめを刺す。金子の計算された戦略
- **読者は二層で知る**：百合子視点の章で読者は誠より**先に**レイプの真実を知る。誠視点の章では誠と**同時に**封筒を開け、誠の誤解を追体験する。この二層の情報差が最も強力な劇的アイロニーを生む

## リズム設計（改訂）

- 毎月1通。一定のリズムが誠の日常を蝕む
- **封筒の直後に誠の内省を配置**。封筒の衝撃がトリガーとなり、自然な回想が始まる（境界マークなし）
- 回想の長さは封筒の衝撃度に**反比例**——L1〜L2は軽い回想、L3〜L5は構造的回想（2,000〜3,000字）、L6〜L8は回想が短くなる（誠の精神が過去を維持できなくなる）
- 封筒が過激化するにつれて、誠の内省の質が変わる——「理論による理解」→「数字による自己正当化」→「崩壊」
- 回想と回想の間には日常の章を挟む。連続して回想を入れない
