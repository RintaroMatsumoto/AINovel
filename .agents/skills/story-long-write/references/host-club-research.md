# ホストクラブ調査報告書

## 研究サマリ
ホストクラブは、男性従業員（ホスト）が女性客に飲食・会話などの接待を提供する接客系風俗店。2005年時点で市場規模約8,584億円、歌舞伎町を中心に全国約980店舗（2023年歌舞伎町のみで約300店、数千人在籍）。給与は完全歩合制が基本で、売上の50〜60%がホストの取り分。前科・学歴不問のため、社会のレールから外れた人々の「駆け込み寺」として機能している。客層の9割以上が風俗嬢で、ホストクラブは「歌舞伎町の食物連鎖の頂点」と称される。売掛（ツケ）制度と暴力団との歴史的関係が業界の暗部を形成する。

## キー発見

### 1. ホストクラブの基本構造

#### 給与体系
- **基本歩合制**: 売上の50〜60%がホストの取り分（柏原2003, ゆら2005）。福利厚生なし。
- **最低保証制度**: 売上が一定水準に達しない新人には日給5,000〜8,000円の最低保証（ゆら2005）
- **1997年「ロマンス」革命**: それまでの最低保証+諸手当から、客の支払いの50%をホスト取り分とする制度が導入され一世を風靡（石井2020）
- **給与体系の二面性**:
  - ホストが客から直接小遣いとして受け取る「裏引き」は1997年以降ほぼ消滅
  - ホストは店舗に対して「場所代を払う自営業者」的立場で、労働契約として認定されたのは2015年の東京地裁判決以降
- **売上至上主義**: 店舗は「ホストクラブにとってお客様はホストである」という経営哲学のもと、ホスト間の競争を煽り、自腹を切ってでも売上上位を目指させる（手塚マキ, Smappa!Group会長）

#### 売掛（うりかけ）・ツケの仕組み
- **売掛の定義**: 後日精算を前提とした売上＝客にとっての借金。業界の根幹をなすシステム。
- **回収責任**: 客が支払えない場合、その客をつけたホストの給与から差し引かれる。ホストが店舗に借金を抱える構造。
- **悪循環**: 客が売掛を払いに来店→新たに売掛を作ってしまう（佐々木チワワ 2022）
- **高飛び**: 売掛が数百万円以上になると、客もホストも逃亡。内勤従業員が連れ戻しに向かう。
- **規模**: 売掛の一般的な相場は数十万円。それを超えるには店舗と客の間の信頼関係が必要。
- **法規制**: 1995年東京地裁判決で、店舗が一方的に客の売掛をホストへの貸付金にすることは無効と判断。2024年4月から歌舞伎町ホストクラブは売掛全面禁止の方針（ただし遵守は不完全）。
- **回収手段**: チェーン店では法律に詳しい社員+顧問弁護士で差し押さえまで実施。店舗は客の本人確認書類コピーを用いて追跡。

#### 源氏名制度と店舗ランク
- **源氏名（げんじな）**: ホストは本名ではなく「源氏名」で活動。キャラクター性を演出する命名が一般的。
- **店舗ランク（ヒエラルキー）**:
  - 幹部: エグゼクティブプロデューサー → 代表取締役 → 取締役 → 総支配人 → 支配人 → 主任 → 副主任 → 幹部補佐 → ホスト長 → キャプテン
  - 若手: 一般ホスト
  - 新人: 入店直後
- **ナンバー制度**: 売上や指名数の多いホストを上位から「ナンバー」と呼ぶ。競争により「ナンバー落ち」も発生。店内の客に見えない位置に貼り出される。
- **永久指名制**: 一度指名したホストを原則変更不可。トラブル時と離職時のみ変更可能。この制度がホスト側に主導権を与え、客が売上でホストの歓心を買おうとする逆転現象を生む。

#### 新人〜No.1までのキャリアパス
1. **入店**: スカウト・求人サイト・友人紹介・体験入店。前科・学歴不問。売上さえ出せばよい。
2. **新人期間**: キャッチ（街頭での客引き）を任されることが多い。日給保証あり。売上が出なければ短期間で脱落。
3. **指名獲得**: 外見・会話術・色恋営業で固定客を掴む。永久指名を得る。
4. **ナンバー入り**: 月間売上上位に食い込む。誕生日イベントが最大の稼ぎ時。
5. **幹部昇進**: 売上+店舗運営能力で主任・支配人などに。給与に役職手当が加算。
6. **独立**: 実績を積んだホストが自分の店を持つ。成功例と失敗例が混在。

### 2. ホストの日常と営業

#### 1日の流れ
- **開店前（夕方〜深夜）**: メール営業（LINE等で客に連絡）、SNS発信、同伴出勤の調整
- **開店（深夜0時〜1時、実態として）**: 風営法では午前0時までだが、主客である風俗嬢の退勤が午前0時のため、実質的に深夜営業が常態化
- **営業中（〜朝5時頃）**: 
  - 指名客の接待（会話・飲酒・カラオケ）
  - ヘルプ（他のホストの客を繋ぐ）
  - シャンパンコール・シャンパンタワーなどの演出
  - 新規客獲得
- **閉店後（朝〜昼）**: 
  - アフター（客と食事・カラオケ。ラブホテルでの性行為に至るケースも）
  - 送り（客を見送る）
  - 締め日の場合はラストソングなどの特別演出

#### 同伴・アフター・送りの実態
- **同伴（どうはん）**: ホストと客が一緒に来店。客がホストの分の代金も支払う。店外デートの延長。
- **アフター**: 営業終了後に一緒に店を出て、食事・カラオケ・ホテルなどへ。金額はホスト次第。
- **送り**: 閉店後に客を見送る。送り指名という制度あり。
- **2割返し**: 客が店舗で使った金額の2割をホストから客にリターンとして提供する慣行。売上の水増しと客の囲い込みの手段。

#### 色恋営業の手法とグレーゾーン
- **基本戦略**: 客に「恋愛感情」を抱かせ、疑似恋愛的関係を構築。客は「彼女」ではなく「姫」と呼ばれる。
- **メール営業**: LINE等で定期的に連絡し、感情的な依存を形成。
- **エース制度**: 一つのホストに対して最も支払額が多い客が「エース」。ホストから優遇され、他の客から嫉妬と羨望の対象に。競争心を煽り消費を促進。
- **イベント**: 誕生日イベント（実際の誕生日とは別に設定し、2回稼ぐ）、クリスマス、バレンタイン、周年祭、コスプレデーなど。
- **店舗ぐるみの連携**: 指名ホストとヘルプがLINEで連携し、客に金を使わせる（NHK「ねほりんぱほりん」2022年放送で描写）
- **劇場型接客**: シャンパンコール（ホスト全員が集まって歌・掛け声で盛り上げる）とシャンパンタワー（数十万円〜100万円規模の演出）が消費を加速。
- **グレーゾーン**: 
  - 売掛を使い切れず、風俗業への転職を斡旋・強要（違法：売春防止法）
  - ホストと「同棲」や「恋人関係」に発展するケース
  - 2023年の「頂き女子りりちゃん事件」を契機に社会問題化
  - 2025年風営法改正で、恋愛感情を利用した営業が禁止対象に

#### 売上ノルマとペナルティ
- **ノルマ**: 明示的なノルマより「ナンバー制度」による競争圧力が支配的。
- **ペナルティ**: 
  - 客の売掛未回収 → ホストの給与から差し引き（店舗への借金化）
  - 売上が出ない → 脱落（最低賃金では生活不可）
  - 他店の客を取る → 罰金・解雇
  - 「高飛び」（逃亡）→ 内勤が連れ戻し。店舗によっては暴力団経由で追跡。

### 3. ホストと裏社会の接点

#### スカウト・送り屋との関係
- **スカウト**: 路上やSNSで新人ホスト・女性客を勧誘。ホストクラブへの人材供給源。
- **送り屋（風俗斡旋）**: 売掛を抱えた女性客を風俗店に「送り込む」仕組み。ホスト→スカウト→風俗店のトライアングル。
- **キックバック**: ホストが客を風俗に紹介すると紹介料を得る。
- **2025年法改正**: スカウトへのキックバック（風俗斡旋の紹介料）が禁止、違反で罰金・拘禁刑。

#### 半グレ・暴力団との距離感
- **歴史的関係**: 1980〜90年代、歌舞伎町では暴力団なしに商売不可。ホストクラブは好むと好まざるとに関わらず暴力団と関係あり。
- **みかじめ料**: 暴力団の縄張りで商売するための「用心棒代」。支払わないと店舗破壊・嫌がらせ。
- **トラブル解決**: 暴力団が関与する場合は別途費用発生。
- **現代**: 2003年以降の「歌舞伎町浄化作戦」で警察の取り締まり強化。ホストクラブ協力会結成で暴力団との断絶を図ったが、完全ではない。
- **店舗による温度差**: 手を切りたい店舗と、いまだに関係を維持する店舗が混在。

#### 売掛トラブル・借金の実態
- **客の借金**: 売掛未払い→親への請求・風俗への転職強要・犯罪行為。過去には殺人未遂事件も（遊興費未払いの客に生命保険をかけ自殺させようとした）。
- **ホストの借金**: 客の売掛が回収不能→店舗への借金→高飛び→連れ戻し。
- **闇金融の関与**: 2000年代、売掛を払えない客に闇金融が融資。債権回収業者が本人確認書類から居場所を特定し、親への請求か売春させて回収。
- **第6トーアビル**: ホストクラブが多数入居し、複数の女性が飛び降り自殺した「呪われたビル」として知られる。2022年時点で屋上は施錠。

#### 店を追われるケース
- **喧嘩・トラブル**: 客・他店ホスト・暴力団とのトラブルで解雇・退店。
- **売上不振**: ナンバー落ちから復帰できず自然消滅。
- **高飛び（逃亡）**: 売掛の支払い不能で逃走。
- **独立失敗**: 実績を積んで独立するも経営難で廃業。2008年リーマンショックで「イブ」など多数が閉店。
- **警察の摘発**: 風営法違反（深夜営業）・売春防止法違反などで営業停止→閉店。

### 4. 元少年院上がりのホスト像

#### 元受刑者がホストになるケースのリアリティ
- **極めて現実的**: 「ホストは店舗に迷惑を掛けず売上さえ出せば、前科の有無や学歴、経験は問われない」（木島由晶 2009）。社会学ではホストクラブが転職の「駆け込み寺」として機能していると指摘。
- **業界の受け皿性**: 冬月グループホールディングス創業者も「学歴のない者やホストしかできない社会的弱者も少なくなく、ホストクラブは雇用の受け皿」と述べている。
- **歴史的裏付け**: 創業者・愛田武も「ホストクラブは社会のレールから外れた人々にとっての拠り所」と明言。元受刑者・家出・ドロップアウト組が集まる場所。
- **伝統的風土**: かつては「アンダーグラウンドでないと働けない人間が社会復帰を目指す場所」で、ホスト同士でもプライベートに踏み込まない文化があった。

#### 先輩（黒崎徹）が翼を導く流れの説得力
- **説得力あり**: 以下の要素が自然な導線を形成する:
  1. 少年院出院者の行き場のなさ → ホストクラブの「受け皿」性
  2. 先輩がすでにホスト業界にいる → 紹介・体験入店のルートは極めて一般的
  3. イケメン・高身長という外見的優位 → スカウトの目に留まりやすい
  4. 喧嘩慣れした度胸 → 夜の街でのサバイバル能力
- **先輩の立ち位置**: 元売れっ子→疲弊という変化はリアル。ホストの寿命は短く、20代半ばでピークを過ぎるケースが多い。体力・精神の消耗、アルコール依存、将来への不安が「疲れ」の要因。

#### 翼の「イケメン高身長」設定とホスト適性
- **外見の重要性**: エアーグループ会長・桐嶋直也は「美男子だけを集めたホストクラブ」を売りに成功。外見は集客の最重要要素の一つ。
- **高身長の優位性**: 「オラオラ系」接客や威圧感を演出する上で身長は武器。ホストの広告写真や「男メニュー」での見栄えも重要。
- **適性の複合要素**: 外見だけでは売れない。会話術・色恋営業・酒の強さ・根性が必要だが、翼の「サバイバー」としての資質（少年院で培った精神力、ストリートでの生存本能）がむしろ強みになりうる。

#### 喧嘩に明け暮れて問題児→店を追われる展開のリアリティ
- **リアリティ高**: 以下の要素が裏付ける:
  1. ホスト同士の派閥争い、他店との客の奪い合い→暴力沙汰は日常的
  2. 過去にはホストクラブ同士の抗争・暴力団とのトラブルで殺人事件も（赤城山射殺事件：ナンバー1ホストが暴力団に拉致・銃殺）
  3. みかじめ料未払いで店舗破壊も発生
  4. 売掛トラブルが暴力沙汰に発展
  5. 独立ブーム期（2003年以降）は「短期間で金を稼ぐために暴力沙汰や詐欺が横行」
  6. 店舗の秩序を乱すホストは「店を追われる」→高飛びや自然消滅が一般的
- **翼のパターン**: 元少年院+格闘経験→腕力に自信→トラブルで相手を半殺し→店に迷惑→追放。極めてリアル。

### 5. 翼の傲慢化の描写への示唆

#### 短期間で売上を叩き出し「天狗」になる過程
- **現実のスピード感**: イケメン+若さ+カリスマ性があれば、数ヶ月で新人→ナンバー入りは可能。売れるホストの特徴として、上昇志向が強く、競争を楽しむ性格が挙げられる。
- **天狗になるメカニズム**:
  1. 年上の女性（風俗嬢）が自分に何十万・何百万と金を落とす体験 → 自己価値の爆発的増大
  2. 店舗内でのナンバー上昇 → 先輩ホストからの一目置かれ、後輩への指導権
  3. 「姫」からの称賛・貢ぎ物 → 自己愛の肥大化
  4. 金銭感覚の麻痺（後述）→ 「何をしても許される」全能感
  5. 「強い男性と弱い女性」を誇張表現する業界構造（木島2009）→ 翼の元々の「支配欲」を増幅
- **描写ポイント**: 少年院での「底辺」体験からの反転。最底辺から一夜で「王様」になった落差が傲慢を加速させる。

#### 女遊びが激しくなる実態
- **業界の実態**: ホストと客の性的関係は日常的。アフターでのラブホテル利用、同棲に至るケースも。タブーではあるが「禁止」ではない。
- **翼のケース**: 若さ+外見+売れっ子ステータスで女性客が殺到。「選ぶ側」の立場になったことで、女性への敬意が失われる。→ 後の「半身不随になって初めて本当の愛情を知る」という人物弧への対比として機能する。
- **「趣味の女」**: ホストが本命の恋人にはしないが、金も使わずに相手をする女性。複数の女性を同時にキープするのがホストの常套手段。

#### 金銭感覚の崩壊——ホストの金の使い方
- **収入規模**: 新人でも月数十万円、ナンバークラスで月数百万〜一千万円超。2021年には年間5億2,000万円（月平均4,300万円超）の個人売上記録。売上の50〜60%が本人取り分。
- **金の使い道の実態**:
  1. **自腹営業**: ナンバー競争に勝つため自腹でボトルを入れる（「ホストクラブにとってお客様はホスト」）
  2. **見栄の消費**: 高級車・ブランド品・後輩への奢り
  3. **飲み代**: 同業付き合いで他のホストクラブに通うホストも（2022年前後のホスト界隈では趣味をホストクラブ通いと称する者も）
  4. **整形**: ホスト間での美容整形ブームも発生
- **崩壊のメカニズム**: 現金収入→貯蓄習慣なし→収入が増えれば支出も比例以上に増える→「メタボ家計」的悪循環。夜の街での生活は金が湯水のように消える。
- **翼への応用**: トレーダーとしての「数字の世界」に戻る伏線として、ホスト時代の「金の使い方の愚かさ」が後悔の対象になる。

#### 「店で喧嘩、町で喧嘩」のリアリティ
- **極めてリアル**: ホスト業界には常に暴力と隣り合わせの文化がある:
  - 客の奪い合いからの他店ホストとの喧嘩
  - 売掛トラブルからの客・その関係者とのもつれ
  - みかじめ料未払い・トラブルでの暴力団の介入
  - 「オラオラ系」接客スタイル自体が威圧的
  - ホスト同士の派閥争い・権力闘争
- **翼の特殊性**: 格闘経験があるため「単なるホストの喧嘩」ではなく、一方的に相手を叩きのめす→過剰防衛・重傷事件に発展→警察沙汰→店を追われる。

### 6. 物語への応用

#### 翼の源氏名「キメラ」の説得力
- **ホストの源氏名の傾向**: キャラクター性を表現。和風（頼朝・零士）・洋風（流星・陽生）・コンセプト系など多様。ゲーム・アニメ由来も不自然ではない。
- **「キメラ」の二重の意味**:
  1. **ドラクエ由来**（表の意味）: 先輩が命名。若者のサブカルチャーアイコンとして自然。
  2. **キメラ（合成獣）の本義**（裏の意味）: 翼のアイデンティティの本質——少年院上がりで、ホストで、格闘家で、最終的に車椅子トレーダーになる「つぎはぎの人生」。複数の顔を持つ怪物。
- **先輩命名の説得力**: 先輩がドラクエ好きで、翼の異質さ（少年院上がり+イケメン+喧嘩の強さ=「混ざってる」感）を「キメラ」に喩えるのは自然。また先輩自身が「ホストの世界に疲れている」からこそ、翼の「異物感」に惹かれたという深層も。

#### 先輩の「売れっ子→疲弊」への変化
- **ホストの燃え尽き**: 
  - アルコール過剰摂取による身体の消耗
