## 写作四要点

### 要点一：「それで？」基本法
各段落の文章は読者の心の中の「それで？」に答えなければならない。一つの情報を書いたら、すぐに次の情報でつなぐ。

### 要点二：間接描写法
正面描写は铺垫に過ぎず、側面反応が爽点である。脇役が餅を食べる食べ方、奪い合う様子を書く方が、「この餅は宇宙一」と乾いて書くより百倍効果的。

### 要点三：核心感情を中心に全プロットを設計
書き始める前に目標読者の核心的感情ニーズ（認められたい/復讐/恋愛/昇級）を確定し、すべてのプロット、人設、対立をこの弦に沿って演奏する。

### 要点四：マクロミクロ一体把握
マクロで全体のリズムと感情の流れを把握し、ミクロで各段落の文字の詳細と緊張感を把握する。

## 写作基礎技法

### 白描
白描 = 最小限の字 + 最も正確な情報と感情。正確な動詞と名詞で直接画面を描き、読者に余白の想像空間を与える。

### 五感描写法
- 少なくとも二から三種の感覚を動員（視覚/聴覚/触覚/嗅覚/味覚）
- 「何を見たか」だけでなく「何を感じたか」を書く
- 五感は感情に奉仕しなければならない——恐怖時は寒さ、暗さ、静けさを；興奮時は明るさ、速さ、響きを

### 動的描写は静的描写に優る
- 人物の特徴は動作と反応で示し、形容詞を積み上げない
- 例：皆が彼女を見た時、話し声が知らず知らず小さくなった
- 環境は長大に铺陳せず、キャラの行動の中で散りばめて点描する

### 会話描写の要点
- 各発言は少なくとも一つを満たす：プロットを推進 / 人設を示す / 対立を作る
- 口調、動作、省略でサブテキストを暗示
- 日常の口語で、書面腔にしない

### シーン切り替えと転換
- 類似物/類似五感/類似感情で転換
- 時間跳躍：動作や物品で接続
- 空間跳躍：音や光の影で接続

### カメラとショット思考
- 各段落 = 一つのカメラ、明確な「撮影対象」がある
- カメラタイプ：遠景（環境/雰囲気）-> 中景（人物関係）-> 近景（表情/詳細）-> 特写（重要アイテム/感情）
- 速いリズム：短文、短段落、高密度の動作、素早い切り替え
- 遅いリズム：長文、環境描写、心理活動、静止カメラ

### 没入感の構築
- 主人公の目標は明確で読者が共感できる
- 主人公の行動の動機を読者が理解できる
- 叙述の立場は必ず主人公側に立つ

### 人設深化 vs 物語深化
- 物語深化：複雑な陰謀、多層の推理——上限は高いが難易度も高い
- 人設深化：人物関係と相互作用の中にドラマ性を見出す——より取り掛かりやすい
- 核心は読者に「面白いものを見に来た」と思わせること——人物の化学反応自体が十分に面白い

### 高情商/聰明人キャラの造形
- 行動で聰明さを示し、ナレーションで彼が聰明だと言わない
- 実例の核心ロジックを抽出し、ネット小説の文脈に適応させる（論理的骨格を保持し、具体的な詳細を置換）

## 行文検収二文字訣

### 第一字：順

| 引っ掛かりタイプ | 解決策 |
|----------|------|
| 「了」字の引っ掛かり | 不要な「了」の使用頻度をコントロール |
| ネタの引っ掛かり | 目標読者層が知っているネタのみ使用 |
| 情報欠落の引っ掛かり | 適時必要な情報を補う |
| 伏線の距離が遠すぎる引っ掛かり | 開示前に前文を簡潔に提示 |

### 第二字：準
どんな感情にどんな味を書くか——熱血は熱血に、温かみは温かみに、恐怖は恐怖に。

| 感情 | 鍵 | 逆シグナル |
|------|------|----------|
| 悲壮 | 犠牲に重みがあり、代償がリアル | キャラが死んでも読者が無感覚 |
| 温かみ | 日常の細部の中の気遣い | わざとらしい感動演出 |
| 恐怖 | 未知とコントロール不能感 | 血腥な描写の積み重ね |
| 熱血 | 宣言感 | 空虚なスローガンに铺垫なし |

## カメラ式写作法

全知視点を忘れろ。あなたは主人公の後ろにいるカメラだ。読者は主人公が見るものしか見えない。

### 核心原則
1. 見える/聞こえる/嗅げる/触れられるものだけを書き、「彼は心の中で考えた」「彼は感じた」とは書かない
2. 各会話はプロットを推進、人物を造形、または情報を伝達する
3. 動作で説明を代替：「彼はとても緊張している」->「彼の手が震えている」
4. スマホ画面優先：短文、動作/情報の変化で改行、読んで引っかかる時は段落を分割

### 高危険リスト

**高危険視点**
- 全知叙述：「この時の彼はまだ知らなかった、三日后に…」
- 神の視点：「もし彼女が真実を知ったら…」
- 心理分析：「彼の心の奥底では実は…」

**高危険語彙**
仿佛、犹如、一丝、一抹、深吸一口气、缓缓、不禁、眼中闪过、嘴角勾起、眉头微皱、不容置疑、不易察觉（「好像」は文脈で判断、機械的に置換しない）

**高危険句式**
- 「…，带着…」（例：彼が言った、かすかな無念を帯びて）
- 会話タグ密度が高すぎる/定式化タグ -> 高頻度時は動作や表情で代替、普通の「言った」は保持可
- 「彼/彼女は知っている…」 -> 直接示し、説明しない
- 陳腐な表現/万能比喩 -> 生活感のある比喩または白描に変更

### 代替技法

| 禁止 | 代替 |
|------|------|
| 彼は緊張を感じた | 彼の手が震えている |
| 彼女はとても悲しい | 彼女は背を向け、肩が微かに震えた |
| 高頻度の定式化会話タグ | 動作、口調、または上下文で承継；普通の「言った」は保持可 |
| 彼は深く息を吸った | 彼は灰皿にタバコを押し消した |
| 彼女の目に一瞬の驚きがよぎった | 彼女の手が空中で止まった |

### 会話写作規範
各会話は少なくとも一つを満たす：プロットを推進 / 人物を造形 / 緊張感を作る

**会話形式**
- 動作で長い会話を中断
- 各発言は3文以内
- 高頻度/定式化会話タグを避ける；普通の「言った」は保持可、機械的繰り返しや口調が単一の場合のみ動作/上下文で代替

**会話感情五段階向上**
1. 客観的事実の陳述
2. 客観的陳述 + 提案
3. 主観的非難
4. 主観的非難 + 強制命令
5. 主観的非難 + PUAで自己向上（最強）

### 三機位法

| 機位 | 視点 | 内容 | 機能 |
|------|------|------|------|
| 機位1 | 近景 | 主人公の動作、表情、心理 | 主線を推進、読者の没入 |
| 機位2 | 遠景 | 脇役の反応、環境変化、見物人 | 情報面を拡大、コントラストを生む |
| 機位3 | ナレーション | 設定の補充、背景の説明 | 適時必要な情報を補充 |

機位交替原則：核心は1と2、機位3は散りばめる。設定はすべて対立から引き出す。

## 文章構成要素

### 核心分類
- **画面感**：人+環境（静/動）、高清カメラのように忠実に記録
- **思想**：計画/目標/愚痴/推測/分析などの内心活動
- **感情**：画面感と思想の中に隠し、直接書かない
- **ナレーション**：身世の背景/設定/人物関係/回想、可能な限り簡潔に

### 感情表現階層（低から高）
1. 最低：直接「XXが怒った/悲しんだ/喜んだ」と書く——感情を教えて、読者は感じない
2. 低：思想で表現「XXが心の中で罵った」
3. 中：表情で表現「XXの顔色が青ざめた」
4. 高：動作で表現「XXが突然拳を握り締め、爪が肉に食い込んだ」

核心：感情から遠い表現ほど高級 = 側面描写。

### 環境インタラクション（環境描写核心）
インタラクションのない環境描写は書く価値がない。
- 物理的インタラクション：梨の花が鼻先に落ちてくしゃみ / 雪山でぶるぶる震える / 川の水で顔を洗う
- 精神的インタラクション：食べ物で人物関係を比喩 / ご飯を食べさせる=親密 / 食卓のナイフで魚を切る=脅迫
- 題材インタラクション：仙侠は天を覆う鲲鹏を書く / 武侠は匹夫の怒り血を五歩に飛ばすを書く

## 文体三要素と水分コントロール

### 文体三要素
- **正確さ**：一語で言い表せるなら一文使わない、動詞の選択が画面感を決める
- **リズム**：句式の長短を交替、連続する三短文の後は長文を、その逆も
- **画面感**：五感を動員し、「見た」だけを書かない

### 水分コントロール
- 水分 = プロットを推進せず人物も造形しない内容
- 合理的な「水」：伏線铺垫/雰囲気醸成/キャラの相互作用
- 有害な水：既知情報の繰り返し/無意味な環境描写/キャラの独り言
- 検証法：この段落を削除しても読者が困惑しない -> しない = 水

### 長編ネット小説の文体の取捨
長編は精巧な文体を必要とせず、可読性と流暢さが必要。文体の目標：読者に字を読んでいることを忘れさせ、直接画面を見させる。

## 文体全面解析と環境インタラクション法

### 文体重要度の段階的差異

| 段階 | 重要度 | 説明 |
|------|--------|------|
| 小学生の文体 | 10点 | 基礎ができていなければ、何も語れない |
| 基礎合格 | 5点 | 合格後、短板は構造と選材 |
| 精品レベル | 7点 | 精器間で文体の差が現れ始める |
| 万訂 | 10点 | トップ作品の文体は核心競争力 |

判断：成績が良いが文体が悪い -> 文体の向上は費用対効果が極めて高い；成績が悪いが文体が良い -> 選材とプロットを補う。

### 一筆多用
一段の文章が同時に複数の機能を担う：
- 環境インタラクション + 人設 + 感情線 = 一筆三用
- 設定をプロットに融入：世界観を小話で散りばめる
- 伏線を埋める：表面情報の下に隠された情報を隠す
- コンパクトなリズム：退屈な背景設定を面白い小さなプロットに隠す

### 構造の簡略化
「X級構造」の核心は「細分化」：一言の主線 -> 細分化 -> 巻綱 -> 細分化 -> 章綱 -> 細分化 -> 本文。順方向推論より逆方向推論の方が効率的。

## 文体の本質と階層

### 三項目出力チェック
- **選材**：目標読者、題材の境界、核心セールスポイントが明確か
- **プロット設計**：大纲/巻綱/章綱が持続的に目標感情を生み出せるか
- **文体**：本文が具体的な動作、会話、物品、リズムで感情を実現しているか

本文の問題が選材やプロット設計に由来する場合、文を磨くだけでは不十分。対応するアーティファクトに戻って修正する。

### 感情表現の階層（低から高）

| 階層 | 書き方 |
|------|------|
| 最低 | 直接「XXが怒った」と書く |
| 低 | 思想で表現「XXが心の中で罵る」 |
| 中 | 表情で表現「顔色が青ざめた」 |
| 高 | 動作で表現「突然拳を握り締め、爪が肉に食い込んだ」 |

核心：感情そのものを書かず、感情が引き起こす外的表現を書く。

## 視点選択と叙述

### ネット小説でよく使われる視点

| 視点 | 特徴 | 適用 |
|------|------|------|
| 第三人称限定 | 主人公の視点に追随 | 最も一般的、没入感が最強 |
| 第一人称 | 「私」が叙述 | サスペンス、日常文 |
| 第三人称客観 | 外部行動のみを書く | 群像劇 |
| 跳躍視点 | 異なるキャラ間で切り替え | 情報差を生む |
| 神の視点 | 全知全能 | 伝統文学、ネット小説では稀 |

### 使用の要点
- ネット小説で最も推奨されるのは第三人称限定視点
- 跳躍視点は主に「読者は知っているが主人公は知らない」情報差を作るために使用
- 視点切り替えには明確な区切り記号が必要
- 第一人称は慎重に——情報量が制限され、後半の展開が困難

### 抽象と具体のバランス
- パターンは共通性であり、各本の個性こそが読者が残る理由
- 良いネット小説の文体 = 平易な言葉で読めて、核心まで削ぎ落とした感情を動かす動作と会話
- 良いネット小説の文体：一見平易な言葉、よく見るとレベルが高い

## 毒点解析と回避

### 五大毒点方向

| 方向 | 回避方法 |
|------|----------|
| 主人公造形 | 叙述の立場は主人公側に立つ；主人公の行動には必ず正のフィードバックがある |
| 題材の地雷ポイント | 目標読者層を理解し、敏感な話題を避ける |
| 雰囲気没入感 | 雰囲気感はネタより百倍重要（面白い文は除く） |
| 期待の破壊 | リズムを把握し、適時満たすか新たな期待を導入 |
| 題材の選択 | 三五千均訂の作品を参考にし、トップ作品ではない |

### 核心原則
- 主人公は愛しい存在：叙述の立場は必ず主人公側に立つ
- 読みどころを明確に：毒点は題材によって変化し、すべての読者ではなく目標読者にアピール
- 期待管理：連続して読者の期待を壊すと信用危機を招く
- 冒頭は簡潔に：第一章で重要な要素を示す

## 黄金三章＝トーン設定と期待管理

黄金三章 = 「実物が画像と一致するか」の検証、読者の期待に迅速に応える。

### 公式
不安な状況 + 早急に向上すべき地位 + 希望に満ちた金手指 + 展望できる明るい未来

### トーン設定三層
1. 感情の雰囲気
2. 物語の方向性
3. 価値観の傾向

### 二種の書き方
- 没入感路線：素早く主人公に没入
- 期待感路線：冒頭に危機を創造

ルール：黄金三章を意識しすぎるとトーンへの破壊が大きい。無理に追求しない。

### 読者を引き留める核心：絶え間ない期待
- 主人公が得ようとしているがまだ得ていない -> 期待感が最も高い -> 追読が最も多い
- 得た後に追読はすぐに下降 -> 解決策：得る前に別のフックを仕掛ける -> 循環
- 一冊の本は常に二つ以上の期待線を維持

## 品質チェックリスト

各段落/各章を書き終えた後、項目ごとにチェック：

- [ ] **段落コントロール**：動作/情報の変化で段落を区切り、読んで引っかからない
- [ ] **高危険語スキャン**：「仿佛/犹如/一丝/不禁/眼中闪过/嘴角勾起」などのテンプレート表現を控える
- [ ] **高危険句式スキャン**：定式化会話タグ/「他感到」/「带着一丝XX」などが過剰でない
- [ ] **感情の表現**：直接「彼は怒った/悲しんだ/緊張した」と書かず、すべて動作/表情で代替
- [ ] **会話の有効性**：各会話は少なくともプロット推進/人物造形/緊張感生成のいずれか
- [ ] **五感の動員**：各シーンで少なくとも2種以上の感覚を動員
- [ ] **環境インタラクション**：環境描写にキャラのインタラクションがあり、空ショットではない
- [ ] **カメラ感**：各段落に明確な撮影対象があり、遠景/中景/近景/特写が交替
- [ ] **水分チェック**：任意の段落を削除した後、読者は困惑するか——困惑しない＝その段落は冗長
- [ ] **視点の一貫性**：全知叙述/神の視点/心理分析が混入していない
- [ ] **リズムの交替**：長短文が交替、連続3短文の後に長文、速い/遅いシーンの交替
- [ ] **没入感**：主人公の目標が明確、行動が理解可能、叙述の立場が主人公側
