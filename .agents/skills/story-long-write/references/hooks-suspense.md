# サスペンス設計

長編サスペンスと読者の期待管理システムの設計。

---

## 期待値管理

読者が読み続けるのは、先の展開が気になるから。その「気になる」という気持ちが期待値。期待値を段階的に解放し、再構築するのが期待値管理の核心。

### 期待値の3要素

```
期待値 = 問題の重要性 × 解答への渇望度 × 解答の遅延
```

**問題の重要性**：
- 命に関わるか？感情に関わるか？利益に関わるか？
- 重要性が高いほど期待値が高まる

**解答への渇望度**：
- 読者はこの問題の答えをどれだけ知りたいか？
- 読者自身が問題に没頭している必要がある

**解答の遅延**：
- 答えを保留すればするほど期待値が高まる
- 保留しすぎるとイライラに変わる

### 期待値コントロール

**期待値を高める方法**：
1. 問題の重要性を高める
2. 読者の問題への没入を深める
3. 解答の開示を適切に遅らせる

**期待値を解放するタイミング**：
1. 新たな対立が始まる前
2. 読者の忍耐が限界に達する前
3. 爽点爆発のピーク時

## サスペンスの3層構造

| 層 | 持続時間 | 機能 |
|------|----------|---------|
| 単章サスペンス | 1章 | 読ませる、この章を読み切らせる |
| 複章サスペンス | 3-5章 | 引き込む、次を読ませる |
| 長編サスペンス | 全書/巻 | 引っ張る、離脱させない |

### 長編サスペンス設計

全書を貫くサスペンスは多層的であるべき：
1. **表層サスペンス**：数章ごとに解決され更新される
2. **中層サスペンス**：巻ごとに部分的に解決される
3. **深層サスペンス**：大枠の謎で、完結まで解決されない

**テンプレート**：
```
表層：今回の敵をどう倒すか？（数章で解決）
中層：誰が黒幕なのか？（巻ごとに一部開示）
深層：この世界の真実とは？（完結時に回収）
```

## 伏線と回収

### 伏線の敷き方

| タイプ | 方法 | 効果 | コード |
|-------|------|------|------|
| 会話伏線 | キャラの口から出る、自然で無理がない | 効果的だが発見されやすい | D |
| 動作伏線 | キャラの動作に埋め込む、気づかれにくい | 非常に効果的、見つかりにくい | C |
| 出来事伏線 | 一見無関係な出来事に埋め込む | 最も効果的、長期間使用可能 | A |
| 設定伏線 | 世界観設定に埋め込む | 長期間効果を発揮 | B |

**3つの伏線配置のポイント**：
1. **タイミング**：伏線は回収章のかなり前に敷く（長編サスペンスは数十章前でも可）
2. **密度**：伏線は密に敷きすぎない。1つの伏線が回収されない限り不自然に見える
3. **自然さ**：伏線は必ずストーリーの一部として自然に機能する

### 回収の技術

| 回収タイプ | 方法 | 効果 |
|----------|------|------|
| 直接回収 | 伏線の答えを直接開示 | シンプルで明確 |
| 反転回収 | 伏線の答えが読者の予想を覆す | 強い衝撃 |
| 拡大回収 | 伏線の答えがより大きな謎の一部 | 長編シリーズに好適 |
| 誤導回収 | 読者が誤った結論を導くように誘導し、真実は異なる | 強い意外性 |

### 伏線のグレーディング管理

| レベル | 重要度 | ヒット率（読者が気づく割合） | 管理方法 |
|-------|--------|--------------------------|---------|
| Lv1 | 高 | 90% 気づく | 複数回強調、回収を外さない |
| Lv2 | 中 | 50% 気づく | 1-2回の強調、自然に回収 |
| Lv3 | 低 | 10% 気づく | 一度だけ触れる、見つからなくても問題なし |
| 煙幕 | 偽装 | — | 読者をミスリードするために使い、真の伏線を隠す |

- Lv1 伏線の総数に制限を設ける。Lv1 が多すぎると読者が疲れる
- Lv3 伏線は「見つかったら嬉しい宝探し」、見つからなくても大丈夫
- 煙幕伏線は重要（本当の答えを隠すため）
