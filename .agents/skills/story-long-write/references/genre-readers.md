# 題材読者分析

各題材の読者心理と期待。

> 本資料は `genre-catalog.md` と合わせて参照。題材選定の際は、まず読者の期待を理解してから、題材カタログの爽点テクニックを適用する。

---

## 玄幻

**なぜ読むのか**：
- 爽快な戦闘描写、逆境からの逆襲、想像力豊かな世界観

**何を期待しているか**：
- 「絶望の中から希望を見つける爽快感」
- 「敵を倒す爽快感」
- 「成長への期待感」

**何を嫌うか**：
- グダグダした話の展開
- いつまでも強くならない主人公
- つまらない設定説明

**読者の読み方**：
- 速読中心、爽点に焦点
- 設定は理解できればそれでいい
- 感情はダイレクトに

## 都市

**なぜ読むのか**：
- 現実世界のファンタジー、人生の再起、権力への欲求を満たす

**何を期待しているか**：
- 「現実世界のリアルな逆襲」
- 「ビジネス/人間関係の中での爽快な反撃」
- 「隙のないストーリー」

**何を嫌うか**：
- キャラの行動の動機が不明確
- 女性キャラの扱いが雑
- 現実離れしたビジネス描写

**読者の読み方**：
- やや速読、爽点に焦点
- 設定のリアリティを重視
- 感情の変化を重視

## 歴史

**なぜ読むのか**：
- 歴史の文脈に巧みに適合する爽快感、制度の革新の醍醐味、知識の優位性

**何を期待しているか**：
- 「歴史の常識に基づく爽快な戦略」
- 「知識の差で逆転する爽快感」
- 「納得感のある制度設計」

**何を嫌うか**：
- あまりにも乱暴な歴史改変
- 現代知識のコピー＆ペースト
- サブキャラの知能が低すぎる

**読者の読み方**：
- やや慎重な読み方、設定を重視
- 論理的一貫性を重視
- 戦略の詳細に注目

## 科幻（SF）

**なぜ読むのか**：
- 未来的な技術体系への好奇心、宇宙の謎を探求する楽しさ

**何を期待しているか**：
- 「論理的な世界観設定」
- 「技術革新の過程」
- 「異種族間の衝突と交流」

**何を嫌うか**：
- 技術設定が不完全
- 論理的な穴
- 人性描写の不足

**読者の読み方**：
- 慎重な読み方、論理を重視
- 設定の整合性に注目
- 戦術の詳細を重視

## 競技

**なぜ読むのか**：
- 熱い試合、成長の過程、チームの結束

**何を期待しているか**：
- 「リアルな試合描写」
- 「キャラクターの成長」
- 「チームワークの爽快感」

**何を嫌うか**：
- 試合の描写が単調
- 勝敗の理由が不十分
- キャラの成長に根拠がない

**読者の読み方**：
- 両方、試合シーンは詳しく、日常シーンは速読
- 試合の戦術を重視
- キャラの変化に注目

## 全題材共通

### 読者の読書時間

| 時間帯 | 読者層 | 読書シナリオ |
|-------|--------|-------------|
| 通勤・通学 | 学生・会社員 | ちょこちょこ読む、1章に3分 |
| 昼休み | 会社員 | 集中して読む、2-3章 |
| 夜寝る前 | 全読者 | リラックスして読む、3-5章 |
| 週末 | 学生・社会人 | まとめ読み、10章以上 |

### 読者の感情状態

**読書前**：
- 退屈している（暇つぶしを求めている）
- ストレスが溜まっている（爽快感を求めている）
- 習慣で読む（目新しいものを求めている）

**読書中**：
- 爽点で興奮する
- フックで引き続ける
- 感情の起伏を楽しむ

**読書後**：
- 満足して眠りにつく（夜）
- 次を楽しみにして通勤（朝）
- 同僚に勧める（昼）

### 読者の読書習慣

- 各題材の読者は好む爽点タイプが異なり、リズムへの要求も異なる
- 同じ題材の読者は類似した読書習慣を持つが、個人差も無視できない
- 読者の「離脱ポイント」は作品序盤に集中（最初の3章が決め手）
- 長編を読む読者は「習慣」で読み続ける（生活の一部になる）
