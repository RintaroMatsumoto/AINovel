# クロス巻想起メソッド

> 長編三部作の後続巻が前巻の情報を呼び起こすための規範と技術。キャラの再登場、設定の深化、伏線の呼応を含み、後続巻で前巻の情感を活用しつつ、シリーズの独立性を維持する。

---

## 機能階層

| 次元 | 方法 | 作用 | 注意 |
|------|------|------|------|
| 情報補完 | 前巻の核心的な成果を示し、現在の用途を提示 | 情報の継続性を維持 | 新読者へのネタバレ防止、情報は後続巻で明確に説明可能な範囲に限定 |
| 情感共鳴 | 前巻の設定やキャラを異なる角度から新たに解釈 | 前巻読者に再発見の驚きを提供 | 感情を引き継ぎすぎない。継承巻は自立し、読者が前巻を読まなくても入り込める |
| 伏線回収 | 前巻に敷かれた伏線を後続巻で回収 | シリーズ全体に統一感を持たせる | 無理に回収しない。回収できない伏線は合理的な説明をつけるか、続編がないことを前提とする |
| 視点転換 | 同じ出来事を別のキャラの視点で再現 | 新たな角度、深みを提供 | シーンは全く同じであってはならず、新しい情報や感情を含める |

## 操作規範

### 核心原則

1. **継承巻は自立している**：読者が前巻を読んでいなくても入り込める。前巻の情報はあくまでボーナスであり、理解の必須条件ではない。
2. **情感は引き継ぎすぎない**：前巻の感情の爆発ポイントを直接使ってはいけない。読者はキャラと一緒に時間を積み重ねてきたわけではないので、情感が伝わらず、かえって「押し付けがましい」印象を与える。
3. **新読者ファースト**：前巻を知っている読者はボーナスを得られる。前巻を知らない読者は「知らない」ことに起因する読書の壁を感じない。
4. **設定の継続性を保つ**：後続巻の新設定は前巻の設定と矛盾せず、整合性を保つ。

### 想起操作

| 想起タイプ | 必要な文量 | 操作 |
|----------|-----------|------|
| 設定呼応 | 1-2文で目的を提示 | 同じ設定情報を継承するが、現在の視点から再解釈 |
| キャラ想起 | 半文〜1文 | キャラの名前と前巻での核心属性 + 現在の関係 |
| 感情呼応 | 伏線として存在、無理に触れない | 設定の重なりを通じて想起させる。直接「あの時」と書かない |
| 反転呼応 | 1段落以内 | 伏線として敷き、開示されれば「そうだったのか」と感じさせ、開示されなければそのまま進行 |

### 想起すべきでない内容

- 前巻の感情爆発ポイント：これらは前巻の専有財産であり、継承巻では劣化コピーになる
- 前巻の感情ピーク爆発パターン：同じ感情ピークパターンを使ってはいけない
- 前巻のダイナミックな戦闘シーン：雰囲気が似すぎてはいけない

### 実戦テクニック

1. 読者がちょうど覚えているであろう核心と、忘れているであろう細部を区別する。核心は自然に呼び起こす。細部は再説明しない。新設定内で自然に発展させる。
2. キャラの過去の経験が今の行動にどう影響しているかを示すことで、情報の継続性を維持しつつ新読者にも説明する。
3. 前巻の設定の一側面を新しい文脈で再解釈する——例えば、前巻で「味方の庇護」と見えたものが、実は「個人的な欲望」だったと明かす。
4. 物語内の作品（手紙、碑文、伝説）を通じて前巻の情報を間接的に語る。原作者の口から直接説明するより自然。
5. 同じ時空の異なる場所での同時展開を活用する。前巻の出来事と後続巻の出来事を時間線でつなぎ、自然な並行感を生む。
