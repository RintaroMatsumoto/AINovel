## 一、共通チェック

### 章構成
- [ ] 冒頭にフックがある（天気/風景/日常で始まらない）
- [ ] 中盤に推進がある（イベントが発生する）
- [ ] 局面に変化がある（この章を読んだ後、世界が以前と違っている）
- [ ] 結末が変化の上にある（総括ではない）

### 冒頭チェック（最初の300-500字）
- [ ] フックがあり、注意を引きつけられる
- [ ] 天気/風景/日常から始まらない
- [ ] 主人公が速やかに登場する
- [ ] セールスポイントまたは危機が見える

### 章の推進
- [ ] 核心イベントがある
- [ ] 局面に変化がある
- [ ] 水増しではない（この章を削除しても理解に影響しない？しない＝水増し）
- [ ] 主線/関係/設定のうち少なくとも1つを推進している

### 情報伝達
- [ ] 長大な設定説明文がない
- [ ] 情報は対立に沿って流れる（イベントを通じて設定を伝える）
- [ ] 設定量は制御可能（1章につき新概念は3つ以内）

### シーンチェック
- [ ] シーンに目標がある（キャラが何を欲しているか）
- [ ] シーンに障害がある（何が妨げているか）
- [ ] シーンに変化がある（終了後、以前と異なる）
- [ ] キャラは何かをしているのであり、感じているのではない
- [ ] 削除可能な段落がない

### 章末
- [ ] 結末が変化の上にある
- [ ] 危機/決断/発見/反転のうち少なくとも1つがある
- [ ] 総括的な結末ではない
- [ ] 読者に次のページをめくらせる

### 言語
- [ ] 空虚な抒情段落がない
- [ ] 同じ感情が連続する複数段落にわたっていない
- [ ] 会話がキャラの身分に合っている（人によって話し方が異なる）
- [ ] 感情が動作で表現されている（直接「彼はとても悲しい」とは書かない）
- [ ] タイトル行以外に章/執筆のメタ情報がない：`第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏線|細綱|读者` といった語句が出現しない；前文を引き継ぐ必要がある場合は、キャラが知覚可能なイベントアンカーまたは相対時間に変更する；物語内で実際に「第X章」を読み/議論する文脈、または実際の読者としての身分に関する文脈は除く

### 連載の連続性
- [ ] 以前の約束/伏線を忘れていない
- [ ] 突然大量の新設定を詰め込んでいない
- [ ] 伏線に推進がある
- [ ] 物語のエンジンがまだ動いている

### 水増し（filler）検出
以下のシグナルが出現＝水増しの可能性：
- 全章の会話に新しい情報がない
- 同じ感情が3段落以上続いている
- シーン描写が500字超だがプロットを推進しない
- キャラが以前の出来事を回想しているが、新しい視点がない
- 2章以上連続で対立がない

## 二、長編专项

### 黄金の三章チェック
- [ ] 第一章の最初の500字にフックがあるか？
- [ ] 主人公が第一章で登場するか？
- [ ] 第一章にイベントがあるか（純粋な前置きではない）
- [ ] 第二章に昇級があるか（矛盾が深化）
- [ ] 第三章に読み続ける理由があるか（続ける動機を与える）
- [ ] 最初の三章に少なくとも2つの感情ピークがあるか？
- [ ] 世界観に長大な説明文がないか？
- [ ] 各章の結末にサスペンスがあるか？

### リズムチェック
- [ ] 直近5章に明確な進展があるか？
- [ ] 感情ピークの間隔が5000字を超えていないか？
- [ ] 2章以上連続で対立がない状況はないか？

### 人物チェック
- [ ] 主人公の行動が人設に合っているか？
- [ ] 脇役に存在感があるか？
- [ ] 敵役の格が現在の段階にマッチしているか？

### 五維評価基準

各次元0-100点、評価結果に基づいて精修戦略を選択する。

### 次元1：核心一致度
チェック：重要な対立、重要な行動、キャラの動機が前後で一致しているか。

| 問題 | 深刻度 | 修正 |
|------|--------|------|
| キャラの動機が突然変化し、布石がない | critical | 動機変化のトリガーイベントを補充 |
| 核心対立が前後で一致しない | high | 遡って対立設定を修正 |
| 重要な行動がキャラ性格と矛盾 | high | 行動を調整するか説明を補充 |
| 次要な対立を忘れている | medium | 回収または弱体化 |

### 次元2：表層リライト度
チェック：句式と措辞が十分に独創的か、テンプレート化された表現を避けているか。

| 問題 | 深刻度 | 修正 |
|------|--------|------|
| 原句をそのまま使い、口調が不自然 | medium | AI臭がある場合のみ書き換え、自然な原句は保持可 |
| AI標誌語を大量に使用 | high | 具体的な描写に置換 |
| 同じ句式が繰り返し出現 | medium | 表現方法を変更 |
| 描写が文学的にすぎる | medium | 口語的/動作的に変更 |

### 次元3：フォーマット一致度
チェック：段落がドラマユニット/ショットごとに自然に区切られているか、主語/キャラ名のリズムが自然か、冒頭と結末のフォーマットが統一されているか。

| 問題 | 深刻度 | 修正 |
|------|--------|------|
| 機械的に字数で段落を区切っている、または主語が密集 | medium | ドラマユニットごとに段落を再構成、段落頭で点名、段落中は代名詞/省略、重要な転換で再点名 |
| 章の字数が目標から逸脱 | **high** | 執筆/大綱修復時はまず細綱に戻って計画内の情節点を補充してから展開；AI臭除去時は既存本文に新たなプロットを追加しない |
| フォーマットが混乱（会話/描写が統一されていない） | low | フォーマットを統一 |

### 次元4：可読性
チェック：冗長、AI腔、空虚な総括、テンプレート修辞がないか。

| AI腔の特徴 | 識別方法 | 修正方法 |
|-----------|----------|----------|
| 空虚な総括 | 「彼はついに理解した」「一切は不言の中に」 | 削除し、動作で代替 |
| テンプレート修辞 | 「運命が彼と冗談を言っているかのようだ」 | 削除するか具体的な描写に変更 |
| 感情ラベル | 「彼は悲しみを感じた」 | 行動表現に変更 |
| 長大な心理描写 | 連続3文以上の内心独白 | 1文に圧縮するか会話に転換 |

### 次元5：論理的一貫性
チェック：文間/段落間が通順か、設定の衝突がないか。

| 問題 | 深刻度 | 修正 |
|------|--------|------|
| 設定が前後で矛盾 | critical | 設定を検索し統一 |
| 時間線の誤り | high | 時間線をマークし修正 |
| キャラの情報が一致しない | high | キャラクター档案を作成し照合 |
| 因果チェーンが断裂 | medium | 経過を補充 |

### 精修戦略

五維評価結果に基づき、精修戦略を選択：

| 主要な問題 | 戦略 | 説明 |
|----------|------|------|
| 核心一致度が低い | rewrite | 核心対立を中心に関連段落を書き直し |
| 字数超過 | compress | プロットを推進しない内容を削減 |
| AI腔が強い | de_ai | 禁止語句を置換、句式を書き換え |
| 小さな問題が多い | polish | 言語の細部を磨く |

## 三、短編专项

### 虐爽リズムチェック

短編特有のチェック項目——虐めポイントと爽ポイントの分布が合理的か：

```
理想分布：虐1 → 虐2 → 虐3 → 爽1(小) → 虐4 → 爽2(大)
禁忌分布：虐1 → 虐2 → 虐3 → 虐4 → 虐5（感情ピークなし、読者離脱）
禁忌分布：爽1 → 爽2 → 爽3 → 爽4（前置きなし、爽感疲れ）
```

チェックルール：
- 300字ごとに少なくとも1つの小衝突
- 虐ポイントの間隔は全文の30%以内
- 最大感情ピークは全文の70-85%の位置に出現
- 結末に感情の着地点が必要

### 会話密度チェック

| 指標 | 合格基準 | 警戒線 |
|------|----------|--------|
| 会話が全文に占める割合 | 45-65% | <30%（乾燥）または>75%（水っぽい） |
| 各章の会話数 | 12-18件/千字 | <8件（相互作用不足）または>25件（断片化） |
| 傷人性会話の割合 | 35-45%（悲劇）/ 20-30%（再生） | 悲劇<20%（痛くなさすぎ）/ 再生>40%（抑圧的すぎ） |

### 主人公冷静度チェック（打顔/復讐文専用）

| チェック項目 | 基準 |
|--------|------|
| 主人公に象徴的な冷静な動作があるか？ | 必須（コップを持つ、スーツを整える、ペンを回す等） |
| 主人公に感情が制御不能になる場面があるか？ | 復讐文は最大1回、かつ前30%以内に限る |
| 敵役は主人公よりヒステリックか？ | 必須——コントラストが爽感の源泉 |
| 主人公の台詞は敵役より短いか？ | 平均30-50%短い——短いほど力強い |
| 「審判式会話」があるか？ | 少なくとも2箇所（主人公の質問→相手が自爆） |

### 証拠チェーン完全性チェック（復讐/打顔文専用）

| チェック項目 | 基準 |
|--------|------|
| 証拠は章ごとに解放されているか？ | 少なくとも3回に分けて暴露、一度に全部与えない |
| 各証拠に布石があるか？ | 前文に必ず手がかりが埋められている |
| 敵役は毎回先に得意になってから打顔されるか？ | 必須——先に持ち上げてから落とす |
| 最終証拠が最も致命的か？ | 最後の証拠は全局の認識を変える |
| 「時限爆弾」証拠があるか？ | 少なくとも1つ、主人公が事前に配置した証拠 |

### 毒点/没入感/衝撃/冒頭/結末/感情/期待感クイックチェック

> 詳細な毒点分類、識別方法、修正案は `anti-ai-writing.md` 参照。

| チェック項目 | 基準 |
|--------|------|
| 感情ピークが不足している | 各章に少なくとも1つの感情転換点が必要 |
| 抑圧に目的がない | 各抑圧は後続の爆発に奉仕しなければならない |
| 敵役の結末が主人公と無関係 | 敵役の死は主人公の行動によって引き起こされなければならない |
| 経済/戦闘力の崩壊 | 設定は前後一致、一般人をアンカーとする |
| 女主人公/女脇役の知能低下 | 人設は正常に書ける、旧テンプレートは書くな |
| 読者の期待が長時間満たされない | 適時満たすか新たな期待を導入 |
| 主人公の行動が理解不能 | 理解可能で共感できなければならない |
| 雰囲気が唐突なネタで破壊される | 雰囲気 > 唐突なネタ（面白い文は除く） |
| フックが回収されない | フックの不回収＝駄作 |
| 衝撃の階層化 | 点→網→深度、点だけの衝撃ではダメ |
| 衝撃が階段状に進む | 階段状に上昇、直線的ではない |
| 衝撃に広がりがある | 関係網全体に反応が必要 |
| 最初の50字に対立/異常がある | 背景布石ではいけない |
| 最初の100字で核心矛盾がわかる | わからなければならない |
| 冒頭の感情強度 | ≧7（1-10） |
| 結末が具体的 | 動作/会話/画面、総括/反省は禁止 |
| 結末に余韻がある | 読者がまだ続きを読みたいと思う |
| 結末の感情強度 | 虐≧8、爽≧7、癒し≧6 |
| 感情の対等な解放 | 虐めた分だけ返す、敵役の結末は主人公に関連 |
| 期待管理 | 二長一短を絶やさず、核心セールスポイントを貫く |
