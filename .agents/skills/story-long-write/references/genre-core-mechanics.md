# 題材コアメカニクス

**各題材を支えるコアな仕組みとリスク。題材選定・爽点設計・差別化戦略の基礎。**

---

## 玄幻

### コアな仕組み

```
境界昇級 + 血脈進化
```

**機能**：
- 境界による制限と解放（各境界の機能が異なる）
- 血脈による特殊能力と制約（血脈がタイトなのに加え、謎の連鎖を生む）
- 遺跡秘境による資源争奪（地図+奪宝+反転の多段階爽点）

**リスク**：
- 設定が複雑すぎて読者が理解困難になる
- 戦力バランスの崩壊（戦力の上限と下限を定義する必要がある）
- 境界昇級が陳腐化する（ブレイクスルーに新しさが必要）

### 境界システム設計原則

| 設計要件 | 説明 | 例 |
|-----------|-------------|------|
| 明確な階層 | 境界は簡潔で理解しやすい | 煉気→築基→金丹→元嬰 |
| 各層の機能 | 各層に異なる能力が追加 | 築基＝体内空間、金丹＝領域 |
| 突破条件 | 昇級の難易度と方法 | 資源＋悟り＋試練 |

### 血脈システム設計ポイント

- **血脈のタイトさ**：血脈が完全にタイトであれば、血脈の謎が物語全体のサスペンスに
- **血脈の多様性**：各種血脈に強みと弱みが必要
- **血脈進化**：血脈は固定ではなく進化できることを示す
- **血脈制限**：血脈に使用制限を設け（反動や副作用）、主人公の成長の余地を残す

### 遺跡秘境の設計

```
秘境の発見 → 秘境への進入制限 → 奪宝過程（協力・競争・裏切り） → 秘境の開放（新たな局面） → 秘境の閉鎖（新たな対立）
```

キーポイント：
- 秘境は強者の進入を制限する仕組みを設け、同等の競争を生む
- 秘境の宝物は単なる資源でなく、プロットの転換点となる
- 秘境の開放 = 新たな対立の始まり

## 都市

### コアな仕組み

```
逆襲 + 情報差
```

**機能**：
- 現代社会の階層対立による抑圧爽点（底辺→逆襲）
- 特殊能力による垂直展開（鑑定・医術・格闘）
- ビジネス戦略による情報差爽点（先読み・伏線・配置）

**リスク**：
- キャラの行動が現実離れする
- 爽点のパターンが単調になる（逆襲ばかり繰り返す）
- 情報差が無理に見える

### 抑圧設定のポイント

| タイプ | 典型的な設定 | 注意点 |
|-------|-------------|------|
| 家族抑圧 | 私生児・継子への差別 | 差別の度合いはリアルで地に足がついていること |
| 職場抑圧 | 上司のパワハラ・同僚のいじめ | 虐待を単なる粗暴にしない |
| 感情抑圧 | 元カノ/前夫の軽視 | 理由づけは十分に行う |
| 社会抑圧 | 貧富の差・身分差別 | 社会問題を単なる爽点の道具にしない |

### 逆襲爽点の節奏

```
抑圧（期待値をためる）→ 突破口（能力獲得/チャンス）→ 逆襲の開始（小爽点）→ 逆襲の深化（中爽点）→ 爽点爆発（大爽点）→ 新たな抑圧
```

各段階で読者に感じさせること：
- 抑圧段階：「はやく逆襲しろよ」と期待させる
- 突破口：「ついに来た！」と爽快感
- 逆襲の開始：「まだまだだ」とまだ物足りなさを残す
- 深化：「これで終わりじゃない」と期待させる
- 爆発：「最高！」と満足させる

## 歴史

### コアな仕組み

```
現代知識 + 歴史の文脈に埋め込む
```

**機能**：
- 現代の知識差を用いた爽点（科学・戦略・制度）
- 歴史的必然と個人の努力の衝突（サスペンス）
- 制度革新による発展爽点（文明・経済・軍事）

**リスク**：
- 知識差が無理に見える（読者が「当時の技術では無理」と感じる）
- 改変の連鎖反応が無視される（一つの改変が時代全体を変える）
- 爽点パターンが単調になる（技術のコピーばかり）

### 知識差の適用のポイント

| 知識カテゴリ | 効果 | 必要なリアリティの度合い |
|-------------|--------|----------------------|
| 農業/手工業 | 最も安定、長期の効果 | 中（基本原理が正しければ良し） |
| 軍事/戦略 | 短期の爽点が強い | 高（具体的な戦術が必要） |
| 制度/管理 | 爽点が持続する | 高（制度の適応性を考慮） |
| 文化/思想 | 爽点は穏やか、長く効く | 中（現代の価値観を投影しすぎない） |

## 科幻（SF）

### コアな仕組み

```
技術革新 + 宇宙の謎
```

**機能**：
- 技術革新による力の獲得爽点
- 宇宙文明間の衝突と交流
- 技術のパラドックス（倫理・制限・反動）

**リスク**：
- 設定が難しすぎる（読者が理解できない）
- 人性描写の不足（テクノロジーだけが目立ち、人の部分が弱い）
- 戦力バランスの崩壊（強すぎる技術＝読めない結末）

---

## 競技

### コアな仕組み

```
成長 + 対決 + 勝利
```

**機能**：
- 試合の爽点是中核（対決の描写が命）
- 成長過程の開示（練習＋努力＋限界突破）
- チームワーク（役割分担＋相互作用）

**リスク**：
- 試合の描写が単調になる
- 成長過程が急ぎすぎる
- 対戦相手が弱すぎて爽点が弱くなる
