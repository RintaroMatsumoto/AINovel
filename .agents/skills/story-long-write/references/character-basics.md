# 人物デザインの基礎

人物の社会的属性、機能的属性、人物アーク、動機システムを提供。プロットと設定構築の基礎。

---

## 社会的属性

### 身分階級設定

| 階層 | 典型的行動ロジック | 核心的弱み | 感情ピークタイプ |
|------|-----------------|----------|---------|
| 底辺（草根） | 生存優先、チャンスがあれば掴む | リソース不足、視野が狭い | 逆襲、底辺からの這い上がり |
| 中間層 | 安定志向、実力で語る | 上からの締め付け、下からの追突 | 昇級、財を成す、権力獲得 |
| 上層 | 利益の最大化、盤面を制御 | 傲慢、判断ミス | その座を打ち破る |
| トップ | ルールの定義者 | 孤独、後継者問題 | 打倒、乗り越え |

**実戦応用**：
- 底辺主人公は「這い上がれる、でも今這い上がる段階じゃない」と感じさせるバランスが重要
- 元上層が落ちぶれる設定は底辺からの逆襲より強い動機を生む（落差感）

### 性別とロール

| 次元 | 男性主人公 | 女性主人公 |
|------|-----------|-----------|
| 成長目的 | 力を得る、財を成す、認められる | 感情の自立、選択の自由 |
| 代表的な感情ピーク | 力を得たら見返す、財を成したら告白 | 離婚したら彼は後悔、自立したら彼が追いかけてくる |
| 核心的対立 | 資源の不足、強者の抑圧 | 感情の束縛、世間の目 |

## 人物アーク

### 基本構造

```
初期状態（弱点/欠乏）→ 葛藤 → 変化初期 → 重大な選択 → 完成状態
```

各段階で、**描写**よりも**行動と選択**で変化を示す。

### 6種の原型アーク

| タイプ | 物語機能 | 段階 |
|------|---------|------|
| 平凡から英雄へ | 最も一般的な成長物語 | 平凡→覚醒→成長→大成 |
| 墜落から贖罪へ | 強い感情の衝突 | 高み→墜落→贖罪→新生 |
| 迷いから覚醒へ | 知性派主人公 | 迷い→探求→発見→覚醒 |
| 利用から信頼へ | チーム成長物語 | 利用→衝突→理解→信頼 |
| 束縛から自由へ | 女性主人公に多い | 束縛→反抗→闘争→自由 |
| 追跡者から守護者へ | 多キャラ成長 | 追跡→直面→転換→守護 |

### 人物アーク設計原則

1. 変化の段階は少なくとも3つの重大な選択を含む
2. 各選択で代価を払うか代償を負う
3. 最終状態は初期状態の論理的延長である
4. 変化は外部イベントに推進されても、内部の衝動に根ざす

**実戦テクニック**：
- キャラの弱点と強みを対応させる（例：傲慢←→カリスマ）
- 各キャラに少なくとも一つの「手柄」を持たせる（読者が思い出せる場面）
- キャラ関係の変化は、人物アークを推進する重要な手段

## 動機システム

### 動機の階層

| 階層 | タイプ | 例 | 持続性 |
|------|------|------|---------|
| 第1層 | 生存動機 | 金を稼いで借金を返す | 短いが強烈 |
| 第2層 | 感情動機 | 親の仇を討つ、愛する人を守る | 中程度 |
| 第3層 | 実現動機 | 強者になり、認められる | 長く安定的 |
| 第4層 | 超越動機 | 世界のルールを変える、生命の本質を探る | 全書を貫く |

### 動機チェーン設計

```
表面的目標 → 本当の欲求 → 根本的な欠乏
```

例：金を稼ぎたい → 認められたい → 幼少期に軽蔑されていた

### 動機の転換原則

動機は固定的ではない。適切なタイミングでアップグレードまたは転換する必要がある：

- 生存問題が解決されたら、尊重の動機に移行
- 初期動機が達成されたら、より高い目標にアップグレード
- 外部的動機が損なわれたら、内部的動機が取って代わる
- 動機の転換は外部イベントによって引き起こされる

### 多重動機のバランス

主人公に複数の動機を持たせ、状況に応じて切り替える：

| 動機ペア | 衝突設計 |
|----------|---------|
| 復讐 vs 守護 | 復讐は無実の人を傷つける |
| 自由 vs 責任 | 自由には代償が伴う |
| 感情 vs 利益 | 感情が合理的判断を妨げる |
| 正義 vs 生存 | 正義の代償は生き残れないこと |

### 登場の瞬間

| タイプ | 手法 | 機能 |
|------|------|------|
| 高調登場 | 他人の口から語られる→本人登場→行動で確認 | 期待→確認 |
| 低調登場 | 普通の状態で登場→徐々に異常を発見 | 反転 |
| 衝突登場 | 対立状態で直接登場 | 即時印象 |
| 神秘登場 | 能力の一部のみを見せ、身分を隠す | サスペンス |
