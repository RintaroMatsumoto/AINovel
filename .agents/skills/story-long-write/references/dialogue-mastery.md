# 会話テクニック

## 会話の機能

### コア原則

会話の3大機能：
1. **キャラクターの性格と関係を示す**（キャラの口調、言葉の選択、情報の出し方）
2. **プロットを推進する**（情報の伝達、意思決定、約束と脅迫）
3. **読みやすさを高める**（地の文の密度を分散、画面感を生む）

### One Piece の会話テクニック分析

**テクニック1：キャラの口調の差別化**

One Piece では各キャラが識別可能な口調を持つ：
- ルフィ：「〜だな」「すげえ！」「おれは海賊王になる！」
- ゾロ：「くそっ」「〜だな」（簡潔で無駄がない）
- ナミ：「ちょっと！あんたたち！！」（ツッコミが多い）

**実戦応用**：キャラごとに3つの口調タグを設定する：
1. よく使う間投詞（「あ？」「えっ？」「はあ…」）
2. 口癖（「〜だぜ」「〜なんだよ」）
3. 感情表現時の口調（怒ったら早口、驚いたら反復）

**テクニック2：自然な情報提示**

One Piece では情報を自然に提示：
- 非対称な知識：ゾロは知っているがルフィは知らない → 説明 → キャラを示す
- 感情的反応と情報の出し方の組み合わせ：驚きが情報の重みを伝える

**実戦応用**：
- 情報は必ずキャラの認知フィルターを通して出す
- 設定は専門家の会話から出す（素人の質問で引き出す）
- 情報の出し方はキャラの立場を反映する（経営陣は異なるデータを重視）

**テクニック3：会話のリズム**

基本パターン：
```
短文の応酬（対立/緊迫）
  →  やや長い叙述（情報/感情）
  →  短文の応酬（決定/反転）
```

**実戦応用**：
- 対立シーン：短文の連続、互いに遮る、言いかけてやめる
- 情報シーン：やや長い発言、肯定/疑問の確認
- 感情シーン：沈黙、言いよどみ、繰り返し

## 会話設計法

### キャラクターの会話習慣の設計

| 次元 | 内省的 | 衝動的 | 計算高い | 率直 |
|------|----------|----------|----------|------|
| 応答速度 | 遅い、間を取る | 早い、遮る | ちょうど良い、間をコントロール | 早い |
| 情報量 | 少ない、慎重 | 多い、整理不足 | コントロールされている、戦略的 | 最大 |
| 感情表現 | 抑制 | 直接的 | 偽装 | 正直 |
| 話題コントロール | 受け身 | 散発的 | 主導権を握る | 率直 |

### 会話推進力

| 推進タイプ | 方法 | 効能 |
|----------|------|------|
| 対立推進 | 利害の衝突、情報のミスマッチ、キャラの衝突 | 強力 |
| 協力推進 | 共通の目標、相互補完 | 中程度 |
| 誤解推進 | 認知の差、虚偽情報 | 中から強 |
| 感情推進 | 親密度の変化、感情の衝突 | 強いがペースは遅い |

### サブテキスト

| レベル | 発言内容 | 真意 |
|-------|---------|------|
| 表層 | 「大丈夫ですよ」 | とても大丈夫じゃない |
| 中間 | 「お好きにどうぞ」 | 私は反対だが、押し通すつもりはない |
| 深層 | 「ごゆっくり」 | 二度と来るな |

**サブテキスト設計のポイント**：
- 会話が長すぎるとサブテキストは機能しない（長い = ごまかし）
- サブテキストは読者が気づける必要がある（あまりに隠しすぎない）
- サブテキストはキャラの性格と一貫している

## 実戦テクニック

### 会話タグ

| タグタイプ | 用法 | 例 |
|----------|------|------|
| 単一タグ | 話者を明確にする | 「私は行かない」と彼は言った |
| 動作タグ | 話者を示し、動作を加える | 「私は行かない」彼はタバコを消した |
| 反応タグ | 話者を示し、聞き手の反応を加える | 「私は行かない」彼女の顔色が一瞬で青ざめた |
| タグなし | 話者の交替が明確な場合 | 「なぜ？」「行きたくないからだ」 |

### 会話リズムテクニック

1. **三文応酬の法則**：会話が3往復を超えたら、間に動作/描写を入れて中断する
2. **感情の山場は短文**：最も感情が高ぶった瞬間は短文で
3. **情報は濃淡をつける**：重要な情報の前後は必ず空白や動作で区切る
4. **沈黙も会話**：沈黙、言いよどみ、考え込む——それらも会話の一部

### 読者を悩ませる会話類型（避けるべき）

| 類型 | 問題 | 解決策 |
|------|------|--------|
| 説明文の会話化 | すべての設定を会話に押し込む | 設定を分割し、20%を会話に、80%を地の文とプロットに |
| 質問漬け | 「〜は何？」「なぜ？」の連続 | 情報の出所を変え、直接尋ねない |
| 無意味な応酬 | 「うん」「ああ」「そうだね」 | 直接削除 |
| 考え込みすぎ | 「うーん…そうだな…つまり…」 | 間は少なくとも、動作で代用 |
