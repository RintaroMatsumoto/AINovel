## 1. 身体詳細で感情語を代替

### ルール

感情語を直接書くことを禁止。身体状態、物理的損傷、日常動作で代替する。

### 置換操作

正文中の感情語をスキャンし、逐一置換：

| 禁止 | 代替 |
|------|--------|
| 心痛/心碎 | 指が肉に食い込んでいるのに自分では気づかない / 彼女は茶碗を置き、浮き沫を吹き、飲まなかった |
| 悲しみ/难过 | 彼は上着を三つ折りにし、クローゼットの一番奥にしまった |
| 怒り/气得发抖 | 彼女の手の甲の青筋が一本一本浮き上がった |
| 怖い/恐惧 | 彼の指がドアノブに触れては引っ込み、三度触れてようやく握った |
| 悔しい/委屈 | 彼女は下唇を噛み、白い跡がつき、離すとすぐに赤くなった |
| 絶望 | 彼はそこに座り、灰がズボンにいっぱい落ちてもはたかなかった |
| 心如死灰 | 彼女はスマホを裏返して机の上に置き、二度と手に取らなかった |

### 身体部位クイック参照

書き方：具体的な部位 + 具体的な動作/状態を使い、抽象的な感覚は書かない。

| 部位 | 句式テンプレート |
|------|----------|
| 手/手指 | 「彼女の手は膝の上に置かれ、指先がスカートのプリーツをぎゅっとつまんでいた」 |
| 目/瞳孔 | 「彼の瞳孔が縮み、すぐに平静を取り戻した」 |
| 唇 | 「唇を一文字に結び、しばらく離さなかった」 |
| 呼吸 | 「彼女は息を吸い、何かを言いかけて、ゆっくりと吐き出した」 |
| 背中/肩 | 「彼の背筋はドアを出るまでピンと伸びていたが、ドアを出たとたんに落ちた」 |
| 傷跡/あざ | 「袖口が少し上がり、手首に古い傷跡の輪が見えた」 |

## 2. 貫通道具システム（三回出現ルール）

### ルール

各叙述ユニット（短編/長編巻）に 1-2 個の貫通道具を設計する。各物品は必ず 3 回出現し、毎回異なる意味を持つ。

### 三回出现編成

| 出現タイミング | 機能 | 例 |
|----------|------|------|
| 第1回出現（前1/4） | 初期意味を構築 | 金の錠前 = 姉から贈られた誕生日プレゼント（温かみ） |
| 第2回出現（中盤の転換） | 意味が覆される | 金の錠前 = 金張りの銅の偽物（偽善） |
| 第3回出現（結末） | 感情の一撃 | 金の錠前がゴミ箱に捨てられる（完全な決裂） |

### 物品設計テンプレート

以下のテンプレートを記入し、設定.md に書き込む：

```
物品：{名称}
第1回出現：第{N}節 | {シーン} | 意味：{初期意味}
第2回出現：第{N}節 | {シーン} | 意味：{転換意味}
第3回出現：第{N}節 | {シーン} | 意味：{結末意味}
```

### 物品タイプクイック参照

| タイプ | 特徴 | 代表 |
|------|------|------|
| 信物型 | 関係の象徴を担う物品 | 金の錠前（義兄が道を案内）、木の小馬（皇弟） |
| 道具型 | 日常使用する機能的な物品 | 採点ノート（准嫁）、帳簿（二十年遅れ） |
| 痕跡型 | 残された身体/環境の痕跡 | 手首の旧傷、壁の身長の刻み目 |
| 数字型 | 関係を担う具体的金額/年数 | 八万の請求書、二十年、800 元 |

## 4. 数字/金額を叙述ツールとして

### ルール

具体的な数字で曖昧な説明を代替。数字が感情の重みを担い、数字の変化がプロットを推進する。

### 操作指令

| シーン | 操作 | 例 |
|------|------|------|
| 重みの構築 | 具体的な金額/年数で「とても」「たくさん」を代替 | 「交際八年」であり「一緒にいてとても長い」ではない |
| ダメージの増加 | 数字が徐々に大きくなる | 800 → 1000 → 8 万 → 120 万 |
| コントラストの一撃 | 極端な拡大の後に突然最小値に | 「姉が私を学校に行かせるために八万の借金をした。義兄が私に1元振り込んできた。」 |
| 時間の重み | 年数で感情を担う | 「二十年ぶりに、彼女が初めて私のことをお母さんと呼んだ」 |

### 数字叙述テンプレート

```
数字線：
第{N}節 | {数字1} | 意味：{初期}
第{N}節 | {数字2} | 意味：{昇格}
第{N}節 | {数字3} | 意味：{一撃/反転}
```

## 5. 一動一静リズム

### ルール

各小節内部で動作と静けさを交互に配置する。動の後には必ず静、静の後には動が可能。

### 動と静の分類

| タイプ | 内容 | 例 |
|------|------|------|
| 動 | 物理的衝撃、暴力、対立の爆発 | 人を斬る、物を投げる、平手打ち、吐血、テーブルをひっくり返す |
| 静 | 日常の細部、微小な動作、静かな観察 | 埃を拭く、粥を食べさせる、服を畳む、浮き沫を吹く、襟を整える |

### 操作指令

- 各小節は ≧1 の「動」+ ≧1 の「静」を含まなければならない
- 連続2節すべて「動」は禁止（暴力疲労）
- 連続2節すべて「静」は禁止（リズムの引きずり）
- 感情の最高点（打顔/反転/暴露）は「動」で
- 感情の最低点（心死/余韻/諦め）は「静」で

### リズム編成例

```
節5（動）：蕭衍が一声命じ、蕭琅に二十棍を打たせた
節6（静）：蕭衍がしゃがみ込み、息子の埃を一滴一滴拭い、襟を整えた
節7（動）：王氏が飛びかかり、地面にひざまずいて頭を下げた
節8（静）：蕭衍は彼女を見ず、息子を抱き上げて去った
```

## 6. 冒頭イベント密度

### ルール

最初の100字に ≧3 のイベントを含めなければならない。背景铺垫はせず、直接イベントチェーンに入る。

### 操作指令

- すべての冒頭背景紹介を削除（「古代XX年間に」「彼女はXXな女の子だった」）
- 第1文はイベントであり、説明ではない
- イベント密度チェック：最初の100字にいくつの独立した「起こったこと」があるか数える

### イベント密度例

```
❌ 低密度（1事象/100字）：
「沈栀は沈家の嫡女で、幼い頃から聡明で父に深く愛されていた。ある日、彼女は聖旨を受け取った。」

✅ 高密度（4事象/50字）：
「蕭衍が帰ってきた。皇后が死んだ。息子が彼の皇弟に殴られて痴ほう症になった。彼は刀を持って宮中に入った。」
（帰朝 → 母の死 → 子が虐待される → 人を殴る、4事象）
```

### 密度チェックテンプレート

冒頭を書き終えた後、最初の100字のイベントリストを列挙：

```
イベント1：{イベント}
イベント2：{イベント}
イベント3：{イベント}
（3つ未満の場合、冒頭を書き直す）
```

## 7. 小節密度診断

### ルール

小節を書き終えて短いと感じた場合、以下の診断リストでチェックする。字数合わせのために描写を追加しない。

### 診断リスト

小節書き終えて短い？順番にチェック：

| チェック項目 | 短い理由 | 補完 |
|--------|----------|------|
| 子イベントの三層を織り込んだか？ | 動作のみで感覚アンカーと身体反応がない | 感覚詳細と身体動作を織り込む（第8節参照） |
| 会話が1-2往復だけ？ | 会話の攻防が不足 | 権力駆け引き会話を1往復追加（第3節参照） |
| 感情語（心痛/悲しみ/怒り）がある？ | 抽象的感情語を使っている | 身体詳細に置換（第1節参照）、自動的に30-50字増加 |
| 三層織り込み後も短い？ | 会話または回想が不足 | 会話（第3節）または短い回想（第7節拡張ルール）を追加 |

### 子イベントが足りない場合の拡大方法

outline を書くときに子イベントが足りない？以下の順序で選択：

```
IF 主イベントが衝突/対抗 → 「妨害」を追加：主人公が途中で中断または阻止される
IF 主イベントに脇役が関与 → 「反応」を追加：脇役の予想外の反応
IF 主イベントに空間移動がある → 「発見」を追加：移動途中に新たな手がかりを発見
IF 主イベントが回想を誘発 → 「倒叙」を追加：2-3文の短い回想を挿入
IF 主イベントが一連の動作 → 「連鎖」を追加：動作が引き起こす連鎖反応
```

### 逆注水ルール

以下の行為を禁止：
- 字数合わせのために環境描写を追加（「窗外阳光明媚」）
- 字数合わせのために既に表現した感情を繰り返す
- 字数合わせのためにキャラの内心独白総括を追加
- 字数合わせのためにキャラに無意味な動作をさせる
- 字数合わせに感情語で身体詳細を代替（逆が正しい）

## 8. シーン写法（三層織り込み）

### 視点姿勢：深度限知（接地没入）

三層織り込みの前に、まず叙述姿勢を定める。デフォルトで主視点キャラの「その時点の知覚」にロックする——彼/彼女がその時に見、聞き、嗅ぎ、身体に感じ、頭の中をよぎったものだけを書く。この一文で最も厄介な二つの AI 臭を同時に解決する：没入感不足、そして「作者がいる」説教/神の腔。

- **カメラを引かない、俯瞰しない、他人の内心に切り替えない**：「ホール全体が死の静寂に包まれた」というカメラ視点は書くな。「彼女は自分の心臓の鼓動を聞き、隣の呼吸音が一瞬で消えた」と書け。
- **読者とキャラが同時に知る**：キャラが知らないことは書くな；事前ネタバレをせず、背景を補完するな。サスペンスは「彼女も知らない」であり、「彼女が知らなかったのは」ではない。
- **思考は動作の一部**：心理は「閃き + 身体」で表現する——半文の、中断された、感情バイアスのかかった主観的判断。完全で理性的な内心独白は書かない。
- **主観的偏差で客観的叙述を代替**：シーンはキャラの感情で色づけされる。彼女が憎む者は憎らしく書かれ、彼女が慌てれば光は揺れる。誰が見ても同じ中立的な記述は書かない。ただし、彼女のその時点での偏見を含んだ一瞬の感覚でなければならず、「決まりきったことを宣告するかのような」客観的な蓋棺断言にしてはならない（それは作者が出てきて定性することであり、anti-ai-writing.md パターン8参照）。

深度限知は「自然な脱AI」の根幹である：カメラをキャラの身体に釘付けにすれば、作者が飛び出して説明、総括、配置する余地はない（anti-ai-writing.md パターン8との連携）。

### ルール

各子イベントは一言で終わらせず、三つの次元を含める：何が起こったか、主人公が何に気づいたか、身体がどう応答したか。三つの次元を同時に同じ段落の連続本文に織り込み、次元ごとに段落を分けて書かない。

### 三層織り込みルール

詳細に書く子イベント ≧100-150字：三つの次元が異なる情報を担い（発生、知覚、反応）、同じ段落に織り込み、別々に書かない。ただし、すべての子イベントを毎回書き込む必要はない——経過、移動、情報伝達系の子イベントは1-2文で軽く流す（「疎密配分」参照）、字数予算を感情ノードに回す。

| 次元 | 内容 | 要点 |
|---|---|---|
| 発生 | 事が起こった | 1-2文、一つの具体的詳細を含む |
| 知覚 | 主人公が何に気づいたか | 少なくとも一つの感覚詳細（視覚+触覚/聴覚/嗅覚）、一つの物品または一つの身体部位に集中 |
| 反応 | 身体がどう応答したか | 具体的な身体動作（手/目/呼吸/姿勢）、一句の極短い心理停止を含む可 |

### 反パターン：積み上げ式描写（絶対禁止）

三つの次元を三段に分けて順に書き終えるのは、AI が最も多用する写作痕跡である。読者が目にするのは、同じ動作が三回に分けて書かれたもの：

> ❌ **積み上げ式（誤り）**：
> 林父はうつむき、左手で書類を押さえ、右手に筆を取り、紙に落とした。
>
> 手が震えていた。
>
> 小さな震えではなく、肘から手首にかけての震えで、筆先が紙の上で止まり、一横を書き、また止まった。その「林」の字のはらいが曲がっていた。彼は間を置き、筆を押し下げ、書き直したが、書き終えても筆はまだ手の中で安定しなかった。

→ 一つのことを発生→知覚→反応の三段に書き、同じ動作を三回に分けている

### 正しい書き方：織り込み式

三つの次元を同じ段落の連続本文に融け込ませ、読者は一つの完結した瞬間を読む：

> ✅ **織り込み式（正しい）**：
> 林父は左手で書類を押さえ、右手に筆を取り紙に落とすと、筆先が紙に触れた途端にそれ、肘から手首にかけて止めどなく震え、その一横は斜めに伸びていった。彼は間を置き、筆を押し下げ、書き直した。書き終えた「林」の字のはらいは曲がっており、筆は手の中でまだ安定していなかった。

→ 発生、知覚、反応が一段で同時に提示され、読者は一つの連続した画面を見る

### 自己チェック方法

一段書き終えた後、「三指隠し法」でチェックする：発生情報、知覚情報、反応情報をそれぞれ隠し、各次元に内容があるか確認する。ある次元が欠けている場合、対応詳細を同じカメラ画面に織り戻し、後で別の段落を起こして補足しない。

### 画面分割（一段で終わらせない防止）

三層織り込みは一つの子イベントを一つの長い段落に詰め込むことではない。織り込みは「同じ瞬間が発生/知覚/反応の三段に分割される」問題を解決する；段落分割は「スマホ読書で一段が過密になる」問題を解決する。

段落分割はカメラ/情報の変化に従い、次元の変化には従わない：

| トリガーポイント | 段落分割方法 |
|---|---|
| 新しい動作の開始 | 別の段落を起こし、読者に次の拍を見せる |
| 新しい物品/手がかりの出現 | 別の段落を起こし、この情報を独立して担わせる |
| キャラの視線移動 | 別の段落を起こし、カメラ切り替えを形成 |
| 直接引用の出現 | 会話を独立した段落に |
| 心理停止/判断の着地 | 単文で段落にでき、停止を生む |

判定ルール：

- 一段は一つのカメラ拍点/一つの動作単元、または未完了の連続した推理、雰囲気、感情チェーンのみを担う。
- 常规叙述は短段落を基調とする；細密な描写、推理判断、雰囲気の圧迫、感情の沈殿はやや長くできるが、前提として同じ事を語っていること。
- 長さは診断であり、強制的な閾値ではない：読み込んでいて窮屈、複数の動作/情報/視線の切り替えを含む場合にのみ分割；完全なドラマユニットが終了していない場合、短くするために無理に分割しない。
- 常规正文は短段落、やや長い段落、会話、動作段落を交替させる；高圧の衝突、打顔、反転段落はより細かく短くできる。
- 連続して複数の段落が同一の長さにならないようにし、完全な推理チェーンを機械的な断片に分割しない。

出力前に必ず自然なリズム再編成を行う：

1. 各自然段落をスキャン；まず「この段落は一事/一つのカメラ/一条の推理または感情チェーンのみを完了しているか」と問う。そうであれば保持し、字数だけで分割しない。
2. 同一段落内に新しい動作、新しい物品、新しい情報、新しい会話、視線移動、シーンの終了があれば、それらの位置で段落を分割する。
3. 連続する複数の極短段落が同一カメラ/同一事に属する場合、隣接する文を統合し、大綱や詩行のように細分化しない。
4. 一つの長文が朗読で引っかかるか情報過多の場合、まず修飾を削除するか文を分割する；分割後も同じ段落のドラマユニットの完全性を保持する。

### 主語と名前のリズム（「主語過密」防止）

主人公名/キャラ名は「主語リセット」と「強調」機能を担い、各文にラベルを貼る機能は担わない：

- 段落頭、シーン切り替え、複数人同場、視点リセット時に、主人公名で主語を確立する。
- 同一動作チェーン/同一段落内では、優先的に「彼/彼女」、動作の継承、または主語の省略で文を自然に流す。
- 重要な転換、感情の爆発点、身分のコントラスト、読者が主人公を再認識する必要がある時に、再点名で強化する。
- 逆シグナル：連続する複数文または複数段落が同一の主人公名で始まるが、その間に主語の混乱、シーン切り替え、強調の必要がない。
- 全章の名前出現回数で機械的に裁定しない；最終基準は読んで「毎文が名前を言っている」という引っ掛かり感があるかどうか。

誤った修正法：短くするために、一条の完全な推理/雰囲気チェーンを複数段落に分割する；主語を節約するために、複数人同場で指示が不明瞭になる。

正しい修正法：同一事の連続性を保持し、新しい動作、新しい物品、新しい情報、新しい会話で分割する；段落頭で指名して主語を確立し、段落内では代名詞/省略で流し、重要な転換で再び指名する。

### 疎密配分（詳略不均）

各ビートを同じ長さ、同じ細かさにしてはいけない——平均的な筆の入れ方は AI 腔の根源であり、読んで「どこも満遍なく書かれているが、どこも目立たない」原因でもある。プロットの重みに応じて筆を配分する：

| ビートタイプ | 筆 | 書き方 |
|---|---|---|
| 爽点/打顔/反転/感情の山場 | 密（詳写） | 知覚、動作、会話の攻防を盛り込み、スローモーションで一拍ずつ展開 |
| 経過/移動/情報伝達/時間跳躍 | 疎（略写） | 1-2文で軽く流し、一句で概括し、三層は展開しない |
| 铺垫/日常/関係の上昇 | 中 | 没入感のある詳細を1-2つ選んで具体的に書き、他は略す |

原則：一章で詳しく書くビートは感情ノードに集中させ、経過は徹底的に圧縮する。読者が覚えているのは密所の画面であり、疎所はただ彼らを次の爽点に素早く送り届けるだけ。密度に起伏があってこそ、リズムに呼吸が生まれる。

### 子イベントの接続

子イベント間は身体動作で接続し、叙述の経過は使わない。接続動作 ~20字：

- ❌ 「そして次のページをめくった。」
- ✅ 「帳簿を膝の上に置き、手のひらにうっすら汗をかいた。」

### 知覚素材庫

| シーンタイプ | 使用可能な知覚詳細 |
|---|---|
| 読書/閲覧 | 字の濃淡、紙の触感、墨の滲み、ページの端の折れ曲がり |
| 会話シーン | 相手の表情変化、口調の間、空気の中の沈黙 |
| 回想シーン | 画面の中のある詳細が突然鮮明になる（匂い/音/触感） |
| 室内シーン | 光の変化、物品の位置、温度 |
| 移動シーン | 足音、地面の触感、風の方向 |

### 三層の境界

- ✓ 知覚は主人公が能動的に気づいた詳細（注意力の焦点がある）
- ✓ 反応は具体的な身体動作（手、目、呼吸、姿勢）
- ✗ 知覚は装飾的なシーン描写ではいけない（「陽光が窓辺に降り注ぐ」）
- ✗ 反応は感情語ではいけない（「心如刀割」）
- ✗ 三つの次元は同じ情報を重複表現してはいけない

## 9. 口調句読点系列（句読点は口調に従う）

### ルール

句読点は飾りではなく、口調、権力関係、感情の拍節の可視形態である。正文を書く時にまず「この文はシーンで何をしているか」を判断し、それから句号、読点、問号、感嘆符、コロン、または改行/動作ビートを決定する；省略記号と破線で停止を生むのをもう使わない。

### 句読点系列

| 口調 / 機能 | 使用可能句読点 | 操作指令 | 禁忌 |
|---|---|---|---|
| 圧迫 / 冷静 / 抑制 | 句号、読点、コロン、短文 | 短文で圧迫し、コロンで判断を落とす；説明を減らす | 「変化」のために乱暴に `！` を入れない |
| 問い詰め / 探り / 反問 | 問号、短文+動作停止 | 重要な質問は `？`、追及は短文を独立した行に | 連続5文すべて `？` にしない |
| 驚き / 爆発 / 打顔 | 少量の感嘆符、単文で段落 | 感情のピーク時のみ1個の `！`、爆発の前後は短文で継承 | `!!!` と段落全体の叫びを禁止 |
| 躊躇 / 言いかけてやめる / 心虚 | 読点、句号、短文、飲み込み/手を止めるなどの動作 | 動作や文長の変化で停止；必要に応じて別の短文を起こす | `……` で停止を代替しない |
| 中断される / 引き延ばし | 動作で中断、改行、短文、未完了の動作 | 「彼は手を挙げて彼女の言葉を遮った。」のような動作で切断 | 正文と会話の両方で `——`/`—`/`--` を使わない |
| 情報開示 / 判断の着地点 | コロン、セミコロン、短文 | 「証拠は一つだけ：ドアの鍵が内側からかかっていた。」コロンで着地点を作れる | 論文式の長いセミコロンチェーンを書かない |

### 実行手順

1. 本シーンの目標感情とキャラの声線を読み、各重要な会話ビートに口調をマークする（圧迫/探り/爆発/躊躇/中断）。
2. 精修時に文末を一通りスキャンする：段落全体に句号しか残っていない場合、問い詰め、躊躇、爆発のポイントが平坦化されていないかチェック；画面中に `？`/`！` が溢れている場合、機能のある位置だけを残す。
3. 正文（会話含む）の `……`、`——`、`—`、`--` はすべて句号、読点、短文、改行、または動作での文の区切りに変更する。知乎塩言の `「」` は引用符スタイルに過ぎず、問号や感嘆符の合法的な使用には影響しない。
