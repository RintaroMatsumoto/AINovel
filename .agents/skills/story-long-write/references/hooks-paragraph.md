# 段落フック技術

段落内の引き、段落末の引き。

---

## 段落末フック

### 機能

| 機能 | 説明 |
|---------|-------------|
| 先を読ませる | 未解決の問題や新たな対立で、読者に次を強く読ませる |
| リズムのコントロール | フックで読書のテンポを調整し、自然にインタラクションを誘発 |
| 期待値の蓄積 | 爽点の手前で溜めを作り、解放後の爽快感を最大化 |
| シーンの切り替え | 自然な段落末のフックでシーンを切り替え、突然感を避ける |

### 段落末フックのタイプ

| タイプ | 原理 | 代表的な形式 |
|-------|------|-------------|
| 情報フック | 新情報を提示するが、完全には開示しない | 「しかし彼が知らなかったのは…」 |
| アクションフック | 動作は開始したが、結果は未確定 | 「彼の拳が既に相手の顔面に向かって…」 |
| 対話フック | 会話に含みを持たせ、伏線を示す | 「実は…あなたのお父さんは…」 |
| 反転フック | 常識を覆す状況や情報を提示 | 「彼が殺したのは、実は…」 |
| 決定フック | キャラクターが決断を下すが、結果は未確定 | 「彼は決めた。今夜、あの場所へ行こう」 |
| 心理フック | キャラクターの心理状態に変化が生じる | 「彼の心の中で、一つの計画がゆっくりと形になり始めていた」 |

## 章末フック（引き）

### 章末フックのタイプ

**1. アクション中断型**
最も直接的なフック。動作の最中に章が終わる：
- 剣が振り下ろされたその瞬間に…
- 彼がドアを開けた瞬間、目に飛び込んできたのは…

**2. 情報のミスマッチ型**
主人公が知らない情報を示す（だが、書き手の神の視点にはならない）：
- 暗がりの中で、誰かが彼の方を見ていたことに彼は気づかなかった

**3. 反転予告型**
これから反転が起きることを示す：
- 「お前を助けに来たんだ」
- 「実は俺が、…なんだ」

**4. 決断保留型**
主人公が決断を下したが、結果は次章へ：
- 彼は引き金を引いた
- 「明日、あいつに決闘を申し込む」

**5. 心理転換型**
キャラクターの心境が重要な変化を遂げる：
- その瞬間、彼はついに理解した。本当の敵は…
- 彼の目に、初めて恐れの色が浮かんだ

### 章末フックの設計原則

1. **未解決の問題を残す**：10の問題を出して9を解決し、1を残す
2. **期待値を高める**：次章で何が起こるかを予感させるが、詳細は明かさない
3. **読者の想像力を刺激する**：「次はどうなる？」と思わせる
4. **感情的な高まりで締める**：爽点のピークや感情の爆発点で引く
5. **自然な中断**：読者に人工的な引きの匂いを感じさせない
