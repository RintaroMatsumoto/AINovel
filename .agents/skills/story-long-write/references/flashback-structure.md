# 回想の挿入技法

> DayTrade 用。GoldenCross 巻。村上春樹『ノルウェイの森』『国境の南、太陽の西』『多崎つくる』の技法に基づく、境界マークなしの自然な回想。

## 核心原理

村上の回想技法の最大の特徴は**境界マークを使わない**こと。
「彼は思い出した」「ふと記憶が蘇った」等の明示的標識を避け、時間と場所を示す語彙の変化だけで現在から過去へ滑り込む。
読者は「いつのまにか過去にいる」——これが自然な回想の溶け込み。

参照：1Q84調査より。天吾が「電車に乗る→父との日曜集金を思い出す」構造。

## トリガー

現在の動作・感覚が過去への入り口になる：

| トリガー | 方法 | 本作での使用例 |
|---------|------|-------------|
| **封筒を開ける** | 封筒の手触り、写真の質感 | 「封筒を開けた。中には一枚の写真。——あの日、百合子はまだ笑っていた」 |
| **音楽** | 特定の曲が記憶を呼び覚ます | 祖父のレコード、百合子と出会った頃の曲。村上の最も得意とするトリガー |
| **数字・チャート** | 含み損の数字が過去の喪失を想起させる | 「含み損が300万。——300万。大学を卒業した年、祖父の金貨を換金した額とほぼ同じだ」 |
| **妻の仕草** | 百合子の動作が過去の彼女を思い出させる | 「百合子が茶碗を置く音。入社したばかりの頃、給湯室で聞いたのと同じ音だった」 |
| **娘・息子の顔** | 栞や翼の顔に百合子の面影を見る | 「栞が笑った。その口元が、若い頃の百合子にそっくりだった」 |

## 回想の溶け込み方

### 基本パターン

```
現在の描写（「封筒を開けた。中には写真が一枚」）
    ↓ 境界なし、自然に
過去の描写（「あの日、百合子はまだ笑っていた。18歳。入社したばかりで——」）
    ↓ そのまま数段落の過去
現在に戻る（「封筒を机に置いた。写真の百合子は、今も笑っていた」）
```

### 短い断片的回想（200〜500字）

現在の文脈に一瞬だけ過去が挿入される。トリガーは感覚的・瞬間的。

例：
```
写真の縁が少し黄ばんでいた。十年以上前のものだ。
あの日——百合子がまだスーツに慣れていなかった頃。給湯室で茶碗を落としそうになって、俺が手を貸した。初めて話したのはあの時だった。
封筒を机に置いた。写真の百合子は今も笑っている。
```

### 長い構造的回想（2,000〜3,000字）

章の大部分を回想が占める。トリガーは封筒の内容など、より大きな衝撃。

封筒L3（全裸＋血痕）を開けた後の誠の内省が、そのまま百合子との出会いから結婚までの数年間を回想する——のような構造。『多崎つくる』の旧友巡礼の一章一章がこのパターン。

## 配置リズム

- 回想は**封筒の直後**に配置する。封筒の衝撃がトリガーとなり、誠の内省の中で自然に過去が蘇る
- 回想と回想の間には**日常の章**を挟む。連続して回想を入れない
- 回想の長さは封筒の衝撃度に**反比例**——L1〜L2は軽い回想、L3〜L5は構造的回想、L6〜L8は回想が短くなる（誠の精神が過去を維持できなくなる）
- 祖父回想は退社直後（L1前）に配置。封筒とは別系統。幸福の頂点で過去を振り返る

## 注意点

- **境界マークは使わない**。「***」や「——」での区切りは禁止。自然な語彙変化で
- **「彼は思い出した」と書かない**。思い出したことを直接書く
- **現在の枠組みを維持する**。長い回想でも、封筒を開けている誠の「今」を見失わせない。1Q84の天吾が電車に乗っていることを忘れさせないのと同じ
- **回想の終了も自然に**。「封筒を机に置いた」「窓の外はもう暗かった」等、現在の動作や時間経過で戻る
