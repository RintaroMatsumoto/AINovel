# 回想の挿入技法

> Golden Cross 用。封筒の合間に回想を配置するためのリズム設計。

## 3つの入り口

参考：zawalife「小説の回想シーンの書き方」より。

| 入口タイプ | 方法 | 本作での使用例 |
|-----------|------|-------------|
| 感覚のトリガー | 匂い・音・光など現在の感覚から過去へ | 誠が見た写真の中の部屋の風景→百合子の記憶へ |
| 感情の揺れ | 怒り・後悔・恋しさなど心の波から | 誠の冷たい態度→百合子の回想へ（「あの頃もそうだった」） |
| 対話と連動 | 誰かの言葉が過去を引き出す | 誠が「昔はよかった」と呟く→百合子の過去へ |

## 封筒と回想の交互配置の原則

### リズム

```
封筒（現在）→ 衝撃
    ↓
百合子回想（過去）→ 真実の開示。読者が呼吸する時間
    ↓
日常生活（現在）→ 誠の変化。封筒の影響を可視化
    ↓
封筒（現在）→ より強い衝撃
```

### 配置ルール

1. 封筒の直後に回想は入れない。封筒の衝撃を読者に味わわせてから
2. 回想の後にすぐ封筒を入れない。回想の情報を消化する日常シーンを挟む
3. 回想の長さは封筒の衝撃度に比例させる。L3（処女喪失）の後は長めの回想、L5以降は短めに
4. 祖父回想はピーク（退社前後）に配置。封筒とは別系統の回想として扱う

## 注意点

- 回想は「説明」にならないように。現在の感情と過去をつなぐ「入口」を必ず設計する
- 入れすぎると全体のテンポが死ぬ。封筒の8ヶ月に対して3回が上限の目安
- 読者が混乱しないよう、回想の始まりと終わりは明確にマークする
