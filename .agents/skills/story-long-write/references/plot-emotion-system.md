# 感情システム設計

章ごとの感情の目標を設定し、感情の流れを設計する。

---

## 感情基調

章の感情基調は以下のいずれか：

| 基調 | 読者への感情訴求 | 使用場面 |
|-------|----------------|----------|
| 緊張 | やきもきさせる、先が気になる | 対立、危機、戦闘前 |
| 爽快 | スッキリする、胸がすく | 逆襲成功、爽点爆発 |
| 温かみ | ほっこりする、感動する | チームの絆、感情の進展 |
| 悲しみ | 切なくなる、感情移入する | 別れ、犠牲、挫折 |
| 驚き | 度肝を抜かれる | 反転、伏線回収 |
| 期待 | ワクワクする | 伏線を敷く、目標を設定する |
| リラックス | ほっとする | 日常、息抜き |

### 章と章の感情接続

| 前章 | 本章 | 接続方法 |
|------|------|------|
| 緊張 | 爽快 | 期待値を解放する爽点爆発 |
| 爽快 | 期待 | 爽点爆発後、新たな問題を提示 |
| 悲しみ | 温かみ | 悲しみの中に希望の光を差し込む |
| 緊張 | 驚き | 伏線回収時の反転 |
| リラックス | 緊張 | 平和な日常が突然壊れる |

## 感情カタルシスと調整

### 感情カタルシスの設計原則

1. **合目的的**——その章で読者に感じさせたい感情を明確にする
2. **段階的**——感情の蓄積から解放までに十分な過程を設ける
3. **メリハリ**——感情基調は章ごとに変え、単調さを避ける

### 感情強度チェック

| 強度 | 説明 | 連続使用可能時間 |
|--------|---------|------------------|
| 1-3 | 弱い感情（日常、移行） | 無制限 |
| 4-6 | 中程度の感情（通常の爽点、小さな感情の変動） | 3-5章 |
| 7-8 | 強い感情（大きな爽点、主要な反転） | 1-2章 |
| 9-10 | 極めて強い感情（主要なキャラの死、感情爆発） | 1章以内、その後は緩衝が必要 |

### 感情調整戦略

| 読者の状態 | 調整方法 |
|-----------|---------|
| 感情が高ぶりすぎ | リラックス基調の章で緩衝 |
| 感情が沈みすぎ | 爽快基調の章で持ち上げる |
| ややマンネリ | 驚き基調の章で刺激を与える |
| 興味が薄れてきた | 期待基調の章で引き続ける |
