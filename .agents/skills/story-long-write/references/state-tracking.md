# 状態追跡プロトコル

> 本ファイルは「本節速記」の抽出ロジックと「キャラ状態スナップショット」のフォーマットを定義する。ライティングスキルは執筆前準備の状態選別ステップで本ファイルを読み込む。

---

## 本節速記

各章/各節を書く前に、すべてのロード済みコンテキストから本節に関連する情報のみを選別する。目的は全量ロードによる LLM コンテキストの希釈を避けること。

### 選別ロジック

コンテキストから三種類の情報を抽出：

1. **現在の状態**：本章に関わるキャラの最新の能力、関係変化、公衆イメージ
2. **歴史的因果**：本章のイベントに直接関連する伏線の成因、前史イベント
3. **世界の制約**：本章に関わる世界観ルール（戦力体系、社会ルール、地理的制限）

### 選別基準

**「これを知らなければ本章を書き間違える」情報のみを保持する。**

具体的な判断方法：
- 本章の細綱で特定のキャラに言及している → そのキャラの現在の状態を保持
- 本章で伏線を回収する → 伏線の設置詳細と前文の铺垫を保持
- 本章が特定の場所/能力/ルールに関わる → 関連する世界観の制約を保持
- 純粋な背景知識（本章イベントと因果関係がない） → 破棄

### 出力フォーマット

選別後、簡潔な「本節速記」を出力：

```
## 本節速記（第{N}章）

### キャラ状態
{キャラA}：{一言の現在の状態、直近の変化を含む}
{キャラB}：{一言の現在の状態}

### 関連伏線/前史
{伏線1}：{設置詳細、{設置章}}、本章で{回収/推進}が必要

### 世界の制約
{制約1}：{本章に関連するルール/設定}
```

**例（都市文芸第12章）：**
```
## 本節速記（第12章）

### キャラ状態
邵阳：転生者、前世は二線歌手、宋佳倫のコンサートで一曲披露し衝撃を与えた、現在「仮彼女」の薛嘉嘉がそばにいる
薛嘉嘉：ヒロイン、敏腕プロデューサーの正体を隠す、表向きは邵阳の仮彼女、実際は既に彼に好意を抱いている
宋麗：元彼女、邵阳の突然の大ブレイクを見て複雑な心境、新しい恋人との関係に亀裂

### 関連伏線/前史
薛嘉嘉の隠された身分：第3章で邵阳が彼女を助けたときに暗示、本章では公の場で身分が露見する前兆が必要
五万元の結納金：宋麗が練習生の名目で持ち去った金、第2章で設置、本章で邵阳が返還を決意

### 世界の制約
藍星パラレルワールド：地球の文芸作品は存在せず、邵阳の前世の記憶は差別化戦力
```

## キャラ状態スナップショット形式

> **本節は長編執筆にのみ適用。** 短編では通常、独立したキャラ状態追跡ファイルは不要。

`追踪/角色状态.md` は主要キャラの状態変化を追跡する。Phase 3 大纲完了時に初期状態を作成し、Phase 4 各章執筆後に更新する。

### 形式

```markdown
# キャラ状態追跡

> 用途：本節速記のデータソース。各章執筆前に本ファイルから本章に関連するキャラ状態を選別。
> 更新タイミング：Phase 3 大纲完了時に初期状態を作成；Phase 4 各章執筆後に変化を更新。

## {キャラ名}
- **現在の身分**：{最新の身分/職業}
- **現在の能力**：{最新の能力レベル}
- **重要関係**：
  - {キャラB}との関係：{現在の関係状態}（第{N}章で変化）
  - {キャラC}との関係：{現在の関係状態}
- **公衆イメージ**：{外部からそのキャラはどう見られているか}
- **未回収伏線**：{そのキャラに関連する未回収の伏線}
- **状態変更記録**：
  - 第{N}章：{変化の説明}
```

### 更新ルール

1. 各章執筆後、本章がキャラの状態変化（身分、能力、関係、公衆イメージ）を引き起こしたか確認
2. 変化がある場合：対応キャラのフィールドを更新し、「状態変更記録」に行を追加
3. 変化がない場合：スキップ
4. 主要キャラのみ追跡（登場 ≧3回 または独立したプロット線を持つキャラ）、端役は追跡しない
5. 変更記録のメンテナンス：各キャラの直近10件の詳細変更記録を保持。10件を超えた場合、最も古い記録を対応フィールドに要約（例：「現在の身分：第1-20章で学生から歌手へ」）、統合済みの旧記録行を削除

### 本節速記との関係

各章執筆前の「状態選別」ステップでは `追踪/角色状态.md` から本章に関わるキャラの現在の状態を抽出し、本節速記の「キャラ状態」部分とする。全量読み取りではなく、本章の細綱に記載されたキャラのみを選別する。
