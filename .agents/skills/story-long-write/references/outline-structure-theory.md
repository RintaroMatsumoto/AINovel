# 物語構造理論

ネット小説の物語構造モデルと配置理論。伝統的な物語の授業の代替ではなく、ネット文の実戦のための構造フレームワーク。

---

## ホラーの見えない構造

### ホラー構造の核心

ホラー作品の核心構造は「見えない恐怖」。読者は何が怖いのかを明確に見てはいけないが、恐怖の存在を感じなければならない。

**恐怖の源泉**：
1. **未知**——読者がルールを知らない
2. **無力感**——読者が対抗手段を持っていない
3. **孤立**——読者が助けを求められない
4. **異常**——日常的なものが非日常的に変わる

### 見えない構造の応用

ネット小説では、見えない構造は「サスペンスの蓄積」に活用できる：

1. **読者が「何かおかしい」と感じるが、はっきり特定できない**
2. **情報のミスマッチ**：読者は主人公より多くの情報を持っている／持っていない
3. **日常の異常化**：一見普通の状況に違和感が潜んでいる
4. **因果関係の欠如**：原因が結果と結びつかない

**実戦例**：
```
「彼は毎朝6時半に目を覚ます。これはここ三ヶ月変わっていない。
　ただ、ここ三日間、目を覚ますたびに時計が6時15分を指している。
　彼は時計を修理に出した。店員は直ったと言っている。
　今朝も6時15分だった。」
```

## 犯罪/推理の構造

### 推論の階層

```
提示（事件）→ 推理（手がかりの収集と分析）→ 反転（推理の覆る）→ 解決（真実の開示）
```

各段階で開示する情報量：
1. **提示段階**：80%の情報を開示（20%は隠す）
2. **推理段階**：開示情報とキャラの推理を同時進行
3. **反転段階**：新情報を投入、既存の推理を覆す
4. **解決段階**：全情報を開示

### ネット文での推理要素の簡略化

ネット小説は推理小説ではない。推理要素は以下のように簡略化する：

1. **手がかりは直感的**：抽象的な推理は不要
2. **犯人特定は早めに**：捜査過程を長く引き延ばさない
3. **反転は爽点として**：反転をスリルとして捉え、爽点爆発の一形態とする
4. **推理は主人公の能力を示す**：推理過程で主人公の知能/知識をアピール
