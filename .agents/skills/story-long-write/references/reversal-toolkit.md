# 反転設計ツールボックス
> 操作マニュアル：反転タイプ、ネスト反転、ミスリード技法、打顔リズム。判断ルーティングに従いモジュールを選択し、設置/開示手順に沿って実行、セルフチェックリストで検収。
> 反転タイプの列挙は拆文 `_meta.json.reversal_type` フィールドと一致：視点/身分/動機/時間線/情報/認知/無反転。

## 判断ルーティング

| 何を設計するか | どの反転を使うか | キー操作 |
|-------------|-----------|---------|
| キャラが読者と思っていた人物と違う | 身分反転 | 行動詳細で3箇所に暗示を埋める |
| 別の角度から見ると真実がまったく異なる | 視点反転 | 別のキャラの視点を導入し認識を打破 |
| キャラがあることをする理由が読者の想定と違う | 動機反転 | 高圧的状況で二者択一を迫り真の動機を暴露 |
| 時間順序が読者の理解と異なる | 時間線反転 | 嘘はつかず叙述順序を調整するのみ |
| 読者が誤った情報を握っている | 情報反転 | 新証拠が旧「事実」を直接否定 |
| 読者のキャラ/関係に対する理解全体が覆る | 認知反転 | 全体を通じて感情色を敷き、結末で色を反転 |
| 甜寵/コメディ/報応型で、そもそも反転がない | 無反転 | 報応の実行または甘さの段階的向上を行い、無理に反転を入れない |
| 複数層の反転を重ねたい | ネスト反転 | 主従を明確にし、間隔を徐々に縮める |

## 反転タイプ

### 1. 身分反転

**トリガー条件**：キャラの本当の身分が読者の認識と異なる。

**設置手順**：
1. 表面的な身分と隠された身分を確定
2. 行動の詳細を通じて漏らす（語り手による直接説明は禁止）
3. 少なくとも3箇所に暗示を埋めたことを確認

**開示手順**：
1. シーンで身分と動機を同時に開示
2. キャラに「実は私はXXだ」と自己申告させることを禁止
3. 読者が最も開示を予期しないタイミングを選ぶ

| 表向きの身分 | 隠された身分 | 铺垫となる手がかり |
|----------|----------|----------|
| おとなしい継娘 | 舞台裏の操縦者 | 決定的な瞬間にいつも「たまたま」不在 |
| 熱心な隣人 | 主人公を傷つける者 | 主人公の家の間取りをよく知りすぎている |
| 死んだ恋人 | まだ生きている | 「遺品」の中に存在するはずのないものがある |
| 見知らぬ人 | 主人公が記憶喪失になる前の肉親 | 主人公の肉親しか知らない呼び名を口にした |

示例鋪排：
```
铺垫1（5%）：隣人が水道管を修理し、配管の経路を異常に詳しく知っている
铺垫2（25%）：隣人が「何気なく」主人公の家の電気が毎日何時に消えるか言う
铺垫3（50%）：誰かがベッドの前に立つ夢をみる、目覚めるとタバコの匂い——隣人はタバコを吸う
開示（75%）：監視カメラに、毎晩ベッドの前に立つ人物が隣人のあの灰色のコートを着ている
```

### 2. 視点反転

**トリガー条件**：語り手の視点は一面的であり、別の角度から見ると真実がまったく異なる。

**設置手順**：
1. すべての叙述が事実であることを確保するが、すべての事実ではない
2. 語り手の解釈が読者を誤った方向に導く
3. キー情報が「合理的に」スキップまたは軽視される
4. 語り手自身もこの語りを誠実に信じている——読者を騙しているのではなく、自分自身も騙されている

**開示手順**：
1. 別のキャラの視点/証言を導入
2. 主人公が「見ていない」シーンを見せる
3. 証拠で認識を打破

| 主人公の視点 | 本当の視点 | 重要な差異 |
|----------|----------|----------|
| 夫が浮気している、私を裏切った | 私こそが騙されていた第三者だった | 時間線の空白 |
| 同僚が私を排除している | 私の「親切」がずっと誰かを傷つけていた | 他人の視点から見た私の行動 |
| 私はこの関係を救っている | 私は相手をコントロールしている | 相手の反応は実は自己防衛 |
| 私は被害者だ | 私は加害者だ | 記憶が語り手によって改ざんされた |

**鉄則**：語り手は自分の視点を誠実に信じていなければならず、語り手が真実を知りながら意図的に読者を誤導することを禁止する。

### 3. 動機反転

**トリガー条件**：キャラがあることをする本当の理由が読者の想定と異なる。

**設置手順**：
1. キャラに読者が合理的だと思う「表面的動機」を与える
2. 本当の動機は表面の下に隠す
3. 行動の細部と表面的動機の間の微細な矛盾を埋める（矛盾は大きすぎない）

**開示手順**：
1. 高圧的状況を作り、キャラに二者択一を迫る
2. 表面的動機はAを選ぶ方向だが、キャラはBを選ぶ
3. 選択行動が直接本当の動機を暴露

| 表面的動機 | 本当の動機 | 行動の矛盾する手がかり |
|----------|----------|-------------|
| 元夫と復縁したい | 婚家の家に隠した物を取り戻したい | 彼の生活には興味がなく、あの家にだけ関心がある |
| 妹を守る | 妹を妬み、コントロールしたい | 「守る」たびに妹がより孤立する |
| 公平な正義を追求 | 個人的な復讐 | 標的がたまたまあの年の事件に関係している |
| 友達を失うのが怖い | 友達が自分の裏切りに気づくのが怖い | 友達が真実に近づくたびに新たな危機を仕掛ける |

### 4. 時間線反転

**トリガー条件**：物語の実際の時間順序が読者の理解する順序と異なる。

**設置手順**：
1. 本当の時間順序と読者の理解する順序を確定
2. 叙述技法を使って読者にAがBの前にあると思わせるが、実際はBがAの前
3. 嘘はつかず、叙述順序を調整するのみ
4. 時制、季節、物品の新旧を自然な時間の手がかりとして使用

**開示手順**：
1. ありえない時間矛盾を見つける
2. またはキャラに「まだ起こっていない」ことに言及させる
3. または物品の状態が時間線と合わないことを示す

| 読者が思う時間線 | 本当の時間線 | 開示方法 |
|------------------|-----------|----------|
| 夫は妻の死後に変わった | 妻は「死後」まだ生きている | 時間スタンプが合わないメッセージ |
| 姉は弟の事故後に崩壊した | 弟の事故は姉が先にあることをしたから | 病院記録の時間 |
| 二人は恋愛中 | これは回想で、すでに別れている | 「あれが最後だと、あの時は知らなかった」 |
| 転生後二日目 | 転生前の最終日のループ | 鏡の中の映りが前と違う |

**鉄則**：書き終わったら必ず時間線図を描いて自己チェックする。

### 5. 情報反転

**トリガー条件**：読者（と主人公）が誤ったキー情報を握っている。

**設置手順**：
1. 読者に信頼できるソースからの「事実」を与える
2. すべての人物がこの「事実」に基づいて行動する
3. 結果の中に矛盾する証拠を埋める

**開示手順**：
1. 新証拠が旧「事実」を直接否定
2. 読者と主人公が同時に騙されていたことに気づく
3. これまでのすべてのプロットが新たな解釈を得る

| 誤った情報 | 本当の情報 | 開示の連鎖反応 |
|----------|----------|---------------|
| 遺言で遺産は長男へ | 遺言がすり替えられており、本来は次男へ | 長男のすべての「親孝行」は演技 |
| 医者が子は実子と言った | DNA報告が改ざんされた | 配偶者が被害者から加害者に |
| 友人が彼の浮気を見たと言った | 友人が嘘をついている | 友人の「慰め」は実は操作 |
| 上司が昇進させると言った | そのポストはすでに廃止 | 上司の絵は仕事を増やすため |

**核心の違い**：情報反転は認知レベルのもの——読者は世界がAだと思っていたが、実はB。核心は「一条の偽情報」。

### 6. 認知反転

**トリガー条件**：読者のあるキャラ/関係に対する全体的な理解が覆る。ある一つの情報が間違っているのではなく、感情の色全体が反転する。

**情報反転との違い**：情報反転は一つの事実を覆す（遺産が誰に行くか、子が実子かどうか）。認知反転は読者のキャラ/関係全体に対する感情判断を覆す（ずっと憎んでいた母が実はずっと守っていた）。情報反転は「何が」を変え、認知反転は「彼に対する私の感覚」を変える。

**設置手順**：
1. 全体を通じて読者に一つの感情色を蓄積させる（この母は冷酷/この夫は薄情/この敵は純粋な悪）
2. 各ネガティブシーンに無視される逆方向の詳細を埋める（酷い言葉の後でさらに多く金を入れる、振り返って涙を拭う）
3. 詳細は読者がその時は気にしないくらい小さく、振り返ってみれば至る所にあること

**開示手順**：
1. 一つのシーンまたは遺品で、すべてのネガティブな行動が同時に逆方向の解釈を得る
2. 説明せず、読者自身に全体を再検討させる
3. 開示後の感情が「恨み/怨み」から「負い目/切なさ」に反転

| 全体の認知 | 反転後の認知 | 逆方向の詳細铺垫 |
|----------|-----------|-------------|
| 継母は意地悪で追い出した | 追い出したのは自分の敵が私に累を及ぼすのを恐れたから | 罵るたびに私の鞄に金を入れた |
| 夫は冷淡で家庭を顧みない | 外で私の代わりにすべての借金を背負っていた | 深夜の「接待」電話はすべて借金の取立て |
| 師匠はえこひいきで私を押さえつける | 押さえつけたのは私が狙われることを知っていたから | 罰するたびに他人の見える場所で行った |

**追妻/世情主力反転**：これは追妻火葬場、世情で最もよく使われる反転——男主/姑/親族が全体を通して恨まれ、結末で「実はずっと愛していた/守っていた」と反転し、切なさが最大化する。

### 7. 無反転

**トリガー条件**：甜寵、コメディ、コントラスト萌え、報応型復讐/転生——这类故事本就没有传统反转，强行塞入反而破坏节奏。

**爽感の源泉（反転の代替）**：
- **報応実行型**（復讐/転生爽文）：爽点は「真実の反転」ではなく、敵役が一歩一歩破滅に向かい、各悪行に精密に対応する報応が訪れる点（以彼之道還施彼身）。報応設計表：悪行→報応→爽感源泉。
- **甘さ段階的上昇型**（甜寵/青春）：爽点は関係が一歩一歩温まる点、コントラスト萌えが繰り返し「装いに失敗する」。全体を通じてポジティブな感情が階段状に上昇し、反転によるネガティブな下降を経験しない。

**書き方の要点**：
1. 「設計感があるように見せる」ために無理に反転を入れない
2. 報応型：各報応は読者に待たせ、铺垫を経てから実行されるときに溜飲が下がる
3. 甜寵型：上昇の拍子が密集し、各節に甘いポイント/反転ポイントを与える

> 拆文時にこのタイプに遭遇した場合、`reversal_type` は「無反転」とし、`setup_clues`（反転铺垫）は閾値をスキップする（analyze output-contract Phase 7.2 参照）。

## ネスト反転

一編の短編で2-3層の反転を重ねられるが、必ず主従を明確にしなければならない。

### 二層ネスト

```
読者が思う：A（铺垫段階）
第一層反転：実はB！（70%の位置）
第二層反転：Bも偽物で、実はC！（90%の位置）
```

**実行要件**：
- 第一層反転は十分に説得力があり、読者にBが真実だと受け入れさせなければならない
- 第一層の後に1-2段落の「消化時間」を与える
- 第二層はAとBの両方を同時に説明でき、第一層より衝撃的でなければならない

示例：
```
铺垫：夫が浮気している、妻は証拠を集めて離婚の準備をしている
第一層（70%）：夫は浮気していなかった、あの女は彼の協力者だった——彼は妻の会社を調査していた
第二層（90%）：妻の会社には確かに問題があったが、告発者は夫ではなく、妻自身だった
——彼女は意図的に夫に気づかせた、夫が「何気なく」彼女を暴露する方法で保険金を受け取るために
```

### 三層ネスト（慎重に）

**使用条件**：15000字以上でなければ三層は収まらない。

**実行要件**：
- 間隔を短縮：第一層50-60%、第二層75-80%、第三層90-95%
- 第三層は最も短く最も鋭く——一言で十分
- 最後の層はすべての疑問に答えなければならない
- 各層に感情的な衝撃が必要であり、情報的な衝撃だけでは不十分
- 題材制限：高知能サスペンス、精巧に設計された復讐にのみ適する

## 反転のタイミング

### 最適な開示位置

| 反転タイプ | 最適位置 | 理由 |
|----------|----------|------|
| 身分反転 | 65-75% | 身分変化後の新たな対立を示す時間を残す |
| 視点反転 | 70-80% | 誤った認識を構築するのに十分な篇幅が必要 |
| 動機反転 | 75-85% | 動機はキャラが重要な選択をする前に開示する必要がある |
| 時間線反転 | 80-90% | 時間線は最も長い铺垫を必要とする |
| 情報反転 | 70-80% | 開示後に連鎖反応を示す必要がある |
| 認知反転 | 75-90% | 感情色を全体を通じて十分に蓄積してからでないと反転できない |

### タイミングの鉄則

- 50%以前の開示を禁止——铺垫が足りず、反転に力が出ない
- 95%以降の開示を禁止——開示後に展開する余地がない
- 最適区間：70-85%
- 二重反転：一つ目を55-65%、二つ目を80-90%

## ミスリード技法

ミスリードは読者を騙すことではなく、読者自身に誤った結論へ向かわせることである。

### 二大基本経路

- **加法経路（階層法）**：真實情報の上に偽情報を重ねる。手がかりは論理線AでもA'と解釈でき、BでもB'と解釈できる。A'はミスリード方向（よくあるストーリー）、B'は真実（あまりないストーリー）。読者にA'だと思わせる一方で、B'に関連する手がかりも同時に隠して埋めなければならない。
- **減法経路（情報欠損法）**：偽情報を追加せず、キー情報の一部を隠す。成功した部分だけを主人公に知らせる。下降をもたらすのは、主人公が能動的に行動して得たものであるべきではない——脇役がその半分の情報を得た後、主人公に渡すときに事故が発生する、といった方法が考えられる。

### 五種技法クイック参照

| 技法 | 操作方法 | 例 |
|------|---------|------|
| 選択的叙述 | 主人公が特定の情報だけに注目し、読者もそれに従う | 主人公は夫と女性同僚の親密さを気にするが、「顧客」からの変な電話は無視する |
| 感情誘導 | 感情的なシーンで判断を誘導する | 温かい父娘のシーン→実は罪悪感で、彼は娘に申し訳ないことをした |
| 偽の手がかり（赤ニシン） | 怪しいキャラ/イベントで注意を引く | 不気味な隣人は主線と無関係で、本当の脅威はずっと普通だった人 |
| ステレオタイプの利用 | 社会的認知バイアスを利用する | 強気な姑は実は嫁を守っている、嫁の知らない何かを彼女は知っている |
| 情報の階層化 | 真実と偽情報を混在させる | 夫が確かに秘密裏に連絡している（真）→元彼女（偽）→実の妹（真） |

**赤ニシンの鉄則**：赤ニシンはストーリー内に自身の機能（プロットの推進/面白さの追加）を持たなければならず、単に反転の答えでないというだけである。

## 反転セルフチェックリスト

### 合理性
- [ ] 振り返って铺垫を見ると、少なくとも3箇所の暗示が反転を指している
- [ ] 反転が偶然に依存していない——キャラの選択が反転を推進した
- [ ] 前にまったく触れられていない新情報を導入していない

### 衝撃力
- [ ] 反転後の感情強度が反転前より高い
- [ ] 反転が読者のこれまでのすべてのプロットに対する理解を変えた
- [ ] 反転によって読者が冒頭に戻って読み直したくなる

### 公平性
- [ ] 読者が反転前に推測できる可能性がある（必須ではないが、可能性はある）
- [ ] 読者に対して嘘をついていない——ただすべての真実を話していないだけ
- [ ] 開示方法が自然で、キャラの長大な独白による説明に依存していない

### リズム
- [ ] 反転の開示が300字以内（速く、簡潔に）
- [ ] 開示後に反転の影響を示す十分な篇幅がある
- [ ] 反転後の結末が反転によって生じた感情の上で収束する

## よくある反転の誤り

| 誤り | 問題 | 修正 |
|------|------|------|
| 天降反転 | 前にまったく铺垫がない | 少なくとも3つの手がかりを埋める |
| 説明過多 | 長大な文字で反転を説明 | 行動/シーンで読者自身に理解させる |
| 反転が弱すぎる | 読者がとっくに推測していた | ミスリードを追加するか反転タイプを変更 |
| 反転が多すぎる | 3つ以上の反転が積み重なっている | 1-2個に減らし極限まで追求する |
| 反転が無感覚 | 情報が変わっただけで感情が変わらない | 反転は同時に読者の感情判断を変えなければならない |
| 反転がズル | 前に存在しない情報を導入する | すべての反転要素は前文に出現していなければならない |

## 特殊反転技法

### 虚仮威し反転法

まず「起こるはずがない」という期待を読者に与えてリラックスさせ、その後意外な形で反転が発生する。ホラー映画でドアを開けても何もいない→ほっとする→振り向いて幽霊がいるのに似ている。

### 超過収穫反転

反転後の収穫が予想を超え、二重の驚きを生む：
- 短編：主人公は一つの問題だけを解決すると思っていたが、結果的に隠れたより大きな問題も一緒に解決した
- 网游文模式：Bossが三つドロップする——すぐに使える / 贈って関係を築く / 今は使えないが後で役立つ

### 感情引張り反転標準フロー

1. 物品/能力の強さを示し、読者の期待+1
2. 脇役が情報差で役立たずと思い、読者の打顔期待+1
3. 敵役の特性がちょうどカウンターであることを示し、読者の期待+1
4. 脇役がより強い装備で敵役に失敗し、期待+1
5. 皆が主人公を低く見て、期待さらに+1
6. 主人公が秒殺し、期待が満たされる
7. 皆が衝撃を受け、脇役が後講釈を分析し、期待が満たされる
8. 新たな収穫ラウンド、満足＋新たな期待の発生

## 打顔の深層リズム

### 三種の打顔方式

| 方式 | 特徴 | 適用シーン |
|------|------|----------|
| 能動的挑発→打顔 | 単純明快 | 初中級者文で最も一般的 |
| 相手の挑発→打顔 | 主人公を抑えつつ、読者に安心感と反撃の暗示を | 恨みを蓄積する必要がある時 |
| 他人の手を借りて打顔 | 支持者が代わりに反撃し、主人公のイメージを損なわない | 主人公の高格を保つ時 |

### 打顔リズムの鉄則

- 抑圧は長すぎない——連続8敗を3万字書くのはダメ、連続4敗＋略記に変更
- 抑圧と同時に読者に自信の暗示を与える（主人公が自信過剰になるくらい：「我々はまだリーグ4位だ！」）
- 主人公が虐げられることより、読者が嫌うのは主人公の自暴自棄
- クライマックス部分は引き延ばし、最大化する（ファンの反応、解説者、試合後のフォロー）
- 大クライマックスで薄氷の勝利をしない——十分な铺垫の後は思う存分圧勝し、潔く決定的な勝利を

### クライマックス間の経過

昇級修行も爽点だが大きな爽点ではない。読者が期待するのは昇級後の打顔であり、昇級そのものではない。
