# 標準フォーマット

執筆時のフォーマット規範。公開時はプラットフォームの要件に従う。

---

## 章タイトル

```
第N章 章タイトル
```

- 章タイトルは省略可能。読者がパッと見て内容を把握できることが条件
- タイトルは10字以内、ネタバレしない

## 段落レイアウト

### 範囲：章内の会話段落範囲

**ルール**：ネット小説の会話段落範囲には国語規範の「一人一段」を**厳守**する。つまり、話者が変わるたびに必ず改行する。同じ話者の複数段落の会話では、各段落の末尾に `"` をつけ、段落の先頭にも `"` をつける：

```
「まずは昼メシだな。ここで食べていくのはどうだ？」
　劉豪は二階から屋根の上に飛び移った。夜明けまであと一時間もなかった。
「俺の小型ナイフはな…肉切り包丁なんだぜ」
「見ればわかる」
```

同じ話者でも、発言の間に動作や叙述が入る場合：

```
「あんたはどういうつもりだ」
　シャオマオは刀を収めた。
「説教に来たのか？」
```

話者が変わるたびに段落を区切り、同じ段落で複数のキャラの会話を**絶対に混在させない**。

### 改行のリズム

- **自然な息継ぎ**：各段落は1つの独立した動作またはシーンチェンジ
- **会話段落**：話者が変わるたびに改行
- **段落間の間**：シーンチェンジも段落間空行は禁止（`\n` のみ）。動作や時間マークで境界を明確にする
- **思考の流れ**：心理活動も段落で区切り、説明の塊にならないようにする

### 標準段落構造

スマホ画面では1段落3-5行が最適：

- 動作：1段落で1つの動作が完了、または密接に関連する一連の動作の完成
- 会話：話者が変わるたびに改行。同じ段落に複数の会話を含めない
- 心理：1段落で1つの感情の流れが完了
- 説明：説明はできるだけ自然に分散させる

## 句読点の使用

### 句読点の効果

| 句読点 | 効果 | 使用場面 |
|-------|------|---------|
| , | 区切り、短い間 | 同一動作内の複数の動作 |
| 。 | 文末 | 独立した意味の単位 |
| ? | 疑問、挑発 | 疑問文、修辞疑問 |
| ! | 強い感情 | 驚き、怒り、命令 |
| … | 沈黙、余韻 | 会話内の間合い（ダッシュ禁止に伴う移行） |

**句読点の使用規範：**
- 句号「。」は読点よりも優先する。句号は短文のリズムを作り、読書のスピード感をコントロールできる
- 複数の文が一つの句読点でつながれてはならない。「,」で区切る文は独立した意味を必要とする
- 感嘆符「!」は強調にのみ使い、乱用しない

### 特殊句読点

英字の使用：
- 英語の固有名詞や引用では半角英字を使用し、スペースで区切る：`Inception`
- 全角英字は使用しない：`Ｉｎｃｅｐｔｉｏｎ`

### ダッシュの禁止

本文（地の文および会話を含む）ではダッシュ `——` / `—` および二重ハイフン `--` の使用を禁止する。

ダッシュの機能は句号、読点または行末で代替する：

- 会話の中断や言いよどみ：ダッシュ `——` の代わりに句号または省略記号「…」で区切る
- 補足説明：ダッシュでなく句号または読点で区切る。例：`答えは一つしかない——死だ` → `答えは一つしかない。死だ。`
- 強調や転換：短文の独立した段落に分割する

**例外**：直接的な引用、タイトル、引用符内の元の句読点は保持可。

## 特殊状況

### 回想

- 回想は段落をまたいでよい。冒頭に時間マークを付ける：「三年前…」
- 現在に戻る時も時間マーク：「現在に戻って…」
- 回想の長さは内容に応じて柔軟に。自然な流れで現在と過去を往還する

### 視点切り替え

- 視点の切り替えはシーンの区切りで行う（改行1つのみ。時間マークで境界を明確に）
- 1章で視点を切り替えるのはせいぜい2-3回
- 視点の切り替えにマークを使わない（読者が自然に感じ取れるように）
