# 人物関係設計

## 関係タイプ

### 機能タイプ

| タイプ | 典型的な関係 | 回路の使用例 | 代表的な小説のペア |
|------|-------------|------------|-------------|
| 師弟型 | 師弟、親子、先輩後輩 | 教える側は隠された秘密を持ち、教わる側は成長しつつ古い教えを破る | 石昊・柳神 |
| パートナー型 | 兄弟、戦友、主従 | 目標の違いによる衝突、逆行を生き抜く誓い | 范閑・五竹 |
| 恋愛型 | 恋人、夫婦、片思い | 身分差、誤解、救済、裏切り | 徐鳳年・姜泥 |
| 敵対型 | 宿敵、競争相手 | 対立する理念、殺親の仇、生存競争 | 孟浩・王騰飛 |
| 共生型 | 契約、同居、体内の老怪 | 利益共存、徐々に絆を深める | 韓立・掌天瓶 |

### 感情尺度

敵対から共生へのマッピングは単純な善悪ではない。関係の距離 + 利益の方向性で判断：

| 利益\感情 | 近距離 | 疎遠 |
|----------|--------|------|
| 一致 | 親友/恋人 | 協力者 |
| 矛盾 | 愛憎 | 敵対 |

### 関係変化の三段階

| 段階 | 距離 | 利益 | 代表的な出来事 |
|------|------|------|------------|
| 1 | 疎遠→近距離 | 対立 | 初対面の衝突、身分差での誤解 |
| 2 | 近距離 | 一致→矛盾 | 物語の転換、情報開示 |
| 3 | 新バランス | 再調整 | 和解/訣別/裏切り |

## 関係変化の類型と設計方法

### 六種の関係変化

| タイプ | 原理 | 物語機能 | 代表例 |
|------|------|---------|------|
| 自己強化型 | 内的信念が外的関係に及ぼす影響 | 人物アークの外部表現 | 正義感の強いキャラが徐々に権力に染まる |
| 衝突駆動型 | 利益衝突が関係を再形成 | プロット推進の核心エンジン | 奪宝→一時協力→再対決 |
| 感情浸透型 | 日常の蓄積が距離を変える | 雰囲気調整、リアリティ向上 | チームが日々の交流で絆を深める |
| 危機凝集型 | 生死の試練が関係を強化・瓦解 | 物語の山場 | 命を救う/裏切る |
| 情報非対称型 | 認知の差異が関係をねじ曲げる | サスペンスと誤解の源泉 | 身分の隠蔽/誤認 |
| 外的力強制型 | 環境強制による関係変化 | プロット転換、逆転 | 師門の命令での結婚 |

### 問題の解決法

| 問題 | 解決策 |
|------|--------|
| キャラ関係が陳腐 | 感情尺度を使ってポジションを再調整：敵に利益が一致する余地を、味方に利益の矛盾を |
| キャラ関係が混乱 | 機能タイプで整理：各関係に主要な機能を割り当てる |
| 関係変化が不自然 | 六種の変化類型を確認：原理に合っているか、推進力が合理的か |
| チーム感覚が薄い | パートナー型関係を支援。チーム内の関係がいずれ「三種を超える」タイプになる必要がある |
| 恋愛線が唐突 | パートナー型を基礎に、感情浸透型で徐々に育てる。同じ釜の飯を食べ、同じ敵と戦い、同じ困難を乗り越える中で自然に生まれる |

## 実戦テクニック

### チーム配置

| サイズ | 推奨構成 | 管理のポイント |
|--------|---------|------------|
| 2-3人 | 主C + サブC + サポート | 個人の成長弧線を明確に |
| 4-6人 | フルポジション + 感情線 | 役割の重複を避ける |
| 7人以上 | コアチーム + 周辺チーム | 人員をグループ化して管理 |

### 配置原則

1. 各キャラ間に関係線を引く（単なる集まりにしない）
2. チーム内の少なくとも1組は感情衝突の可能性を持つ
3. 各キャラに独立した人間関係圏を持たせる（チームだけに限定しない）
4. 核心キャラとそれ以外のキャラの関係に少なくとも1つの伏線を敷く

## 関係図の作成

### 3層法

| 層 | 範囲 | 表示内容 | 更新頻度 |
|-----|-------|----------|---------|
| 第1層 | 世界観レベル | 全勢力、全キャラの関係概要 | 巻単位 |
| 第2層 | 巻レベル | 本巻に関わるキャラの相対位置 | 章単位 |
| 第3層 | 章レベル | 本章に登場するキャラの相互作用 | 執筆時 |

### Markdown での関係図

```
# 勢力関係（第1層）

## 正派陣営
- {陣営名}：{所属キャラ}
  - 核心キャラ関係：{簡述}
  - 内部対立：{簡述}

## 敵対陣営
- {陣営名}：{所属キャラ}
  - 核心キャラ関係：
  - 内部対立：
```

```
# キャラ関係（第2層）

{キャラA} ↔ {キャラB}
- タイプ：{師弟/パートナー/恋愛/敵対/共生}
- 現在の状態：{距離 + 利益バランス}
- 変化節点：{章節/イベント}

{キャラA} ↔ {キャラC}
...
```
