# 感情表現技術

> 感情は形容詞ではなく動作で表現する。感情は説明するものではなく、感じさせるもの。本稿では感情を表現するための具体的な身体反応と動作テクニックを提供する。

---

## 核心原則：外界/身体 → 内面

ネット小説の感情描写核心：「感情は外から内へ」

```
外部刺激 → 身体反応 → 内面感情
```

- 鳥が鳴く = 外部刺激
- 鳥の鳴き声を聞く = 身体反応
- 彼は目を覚ました = 内面感情

**身体反応が感情を表現する**：

```
涙を流す → 悲しみ
拳を握る → 怒り
足が震える → 緊張
飛び上がる → 喜び
```

### 描写的感情表現（避けるべきパターン）

1. 定義的な感情語：「彼はとても悲しい」「彼女は怒っている」「彼は緊張している」
2. ナレーションタイプの感情語：「悲しみが押し寄せる」「怒りが心の中で燃える」「緊張が彼を包む」
3. 修飾された感情語：「強い悲しみ」「言い表せない怒り」「底知れない恐怖」
4. 弱化副詞：「少し緊張している」「少し悲しい」「少し寂しい」

**感情は必ず外在化させる。直接説明してはいけない。**

## 基本感情の外在化

### 喜び

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：満足 | 口元が緩む、動作が軽い | 彼女はファイルを閉じ、椅子の背に寄りかかり、ゆっくりと目を閉じた |
| 中：嬉しい | 笑う、鼻歌 | 彼はチケットを振りながら家に入ると、「今日の晩飯は俺の奢りだ」 |
| 強：狂喜 | 大声、跳ねる、抱き合う | 彼は机を叩いて立ち上がり、椅子が倒れた |
| 極：有頂天 | 涙、震え、言葉が出ない | 彼は何度も口を開け閉めしたが、声が出なかった。ただ手を握り拳にして、必死に肩を震わせているだけだった |

### 怒り

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：不機嫌 | 眉をひそめる、口をへの字にする、動作がぶっきらぼうになる | 彼はドアを押すと、ドアが壁にぶつかって大きな音を立てた |
| 中：怒り | 声が大きくなる/低くなる、呼吸が荒くなる、指をさす | 「もう一度言ってみろ」彼の声はかすれていた |
| 強：激怒 | ものを壊す、人を殴る、血管が浮き出る | 彼は茶碗を掴むと、真っ直ぐ壁に投げつけた |
| 極：冷静な怒り | 過度の冷静、逆に笑う、一言一言が重い | 彼はハンカチで手を拭き、「で、始末はつけたのか？」 |

### 悲しみ

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：物悲しい | 溜め息、放心、動作が遅い | 彼は煙草に火をつけ、煙が彼の顔を覆った |
| 中：悲しい | 涙が目に溜まる、声が詰まる、うつむく | 彼女はうつむいてコーヒーをかき混ぜ、長い間混ぜ続けた |
| 強：号泣 | 嗚咽、肩が震える、呼吸が乱れる | 彼女はドアのところにしゃがみ込み、額を壁につけた |
| 極：絶望 | 涙も出ない、動かない、周りが見えない | 彼はベッドに仰向けに倒れ、天井の染みを見つめて、一瞬も瞬きをしなかった |

### 緊張

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：落ち着かない | 貧乏ゆすり、指先で叩く、姿勢を頻繁に変える | 彼は煙草に火をつけては消し、また火をつけた |
| 中：緊張 | 手のひらに汗、口が乾く、視線が泳ぐ | 彼は手のひらをスーツのズボンで拭いた |
| 強：極度の緊張 | 吐き気、震え、冷や汗 | 彼はトイレに駆け込み、胃の中のものを全部吐き出した |
| 極：恐慌 | 呼吸困難、めまい、思考停止 | 彼の耳元で自分の心臓の鼓動だけが聞こえ、相手の口が動いているのが見えたが、何と言っているかは聞こえなかった |

### 恐怖

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：不安 | 周りを気にする、警戒する | 彼は後ろを振り返った。誰もいなかった |
| 中：怖い | 後退する、壁に貼りつく、声が震える | 彼女は二歩後退し、背中が壁にぶつかった |
| 強：戦慄 | 全身の筋肉が硬直、息を止める | 彼は息を止め、動かず、心臓がドアを破って飛び出しそうだった |
| 極：恐慌 | 叫ぶ、逃げ出す、失禁 | 彼女は口を押さえ、吐き気をこらえた |

### 驚き

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：意外 | 眉をひそめる、動作が一瞬止まる | 彼の箸が止まった |
| 中：驚く | 目を見開く、口が開く、手に持ったものを落とす | 彼女の手に持ったペンが机の上に落ちた |
| 強：衝撃 | よろめく、座り込む、信じられない | 彼は書類を三度見直した |
| 極：度肝を抜く | 卒倒、一過性の失声 | 彼女は立ったまま動けず、聞こえたことが信じられなかった |

### 羞恥/気まずさ

| 強度 | 身体反応 | 例 |
|------|---------|------|
| 弱：気まずい | 視線をそらす、頭をかく | 彼は咳払いを一つして、話題を変えた |
| 中：恥ずかしい | 顔が赤くなる、うつむく、無意味な動作 | 彼女は髪を耳の後ろにかけ、目はどこを見ていいかわからなかった |
| 強：辱め | 耳まで真っ赤、涙がにじむ、逃げ出したい | 彼は頭を上げられず、地面に穴があったら入りたい気持ちだった |

### 焦り/不安

キーポイント：焦りは複合感情（怒り＋緊張＋不満）

| タイプ | 行動 | 例 |
|------|------|------|
| 待つ焦り | 時間を気にする、歩き回る | 彼は腕時計を三度も確認した |
| 決断に迷う焦り | 姿勢を変える、タバコを吸う | 彼は起き上がったり座ったりを繰り返し、やがて煙草に火をつけた |
| 説明を求める焦り | 相手の話を遮る、詰め寄る | 「それで？」彼はテーブルに身を乗り出した |

### 沈黙による感情表現

| 感情 | 沈黙のタイプ | 動作の組み合わせ |
|-------|--------------|------------------|
| 承諾 | 短い沈黙＋肯定の動作 | うなずく、手を離す |
| 拒絶 | 硬い沈黙 | 動かない、表情が消える |
| 驚き | 静止した沈黙 | 口が半開き、瞬きしない |
| 計略中 | 沈黙＋無意味な動作 | 煙草を弄ぶ、グラスを回す |
| 感情的距離 | 長い沈黙＋視線を合わせない | スマホをいじる、窓の外を見る |

## 感情表現障害チェック

- 「彼は感じた/思った/気づいた」で直接感情を説明していないか
- 「悲しみ/喜び/怒り」などの感情語を直接使っていないか
- 感情はすべて動作や身体反応で表現されているか
- 感情強度ごとに異なるレベルの反応が用意されているか
- 複合感情（嬉しいけど心配など）が単一の動作で表現されているか
- キャラごとに異なる感情反応パターンがあるか
