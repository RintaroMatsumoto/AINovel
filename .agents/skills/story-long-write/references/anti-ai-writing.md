## AI 執筆の指紋（必ず回避すること）

### AI 高頻度語

> 完全な禁用語一覧は [banned-words.md](banned-words.md) を参照。

**補助カテゴリ**（`banned-words.md` 未カバーの高度置換）：

| カテゴリ | 代替原則 |
|------|---------|
| 抽象的昇華語（運命、宿命、注定） | 具体的な出来事で抽象概念を代替 |
| 万能比喩（波のように、雷のように、春風のように） | 日常的・身体的な具体的比喩に置換 |

### 章末総括体

**禁止**：章の終わりを以下の方法で締めること：
- 総括的悟り（「彼はついに理解した…」）
- 昇華的感嘆（「この夜、誰も眠れないのは必定だった」）
- 哲学的な締め（「人生とはそういうものだ…」）
- 伏線的予告（「彼が知らなかったのは、さらに大きな嵐が迫っていることだった」）

**正しい方法**：章末は動作、会話、またはサスペンスで締め、プロット自体が余韻を生み出すようにする。

### 重畳的描写（同一動作を 3 回に分解）

**検出パターン**：動作/感情の発生 → 知覚の詳細 → 身体反応、を 3 段落に分けて順に書く。読者には同一動作を 3 回に分解して書いているように見える。

**典型的特徴**：
- 最初に総括動作、次に同一動作の詳細、次に身体反応：3 段落で同じことを言っている
- 「発生層→知覚層→反応層」が順番に段落分割されている
- 各次元が独立した段落になり、同一段落に織り込まれていない

**誤例**：
> 林父はうつむき、左手で証書を押さえ、右手に筆を持って紙に落とした。
>
> 手が震えている。小さな震えではない。肘から手首にかけての震えだ。
>
> 筆先が紙の上で止まり、一横を書き、また止まった。その「林」の字の払いが歪んだ。

→ 同一動作（手の震え/字を書く）を 3 段落に分割し、各段落が同一瞬間の異なる次元を描写している。

**正しい方法**：発生、知覚、反応の 3 次元を同一段落に織り込み、読者が一つの完全な瞬間として読めるようにする：

> 林父は左手で証書を押さえ、右手に筆を持って紙に落とした。筆先が紙に触れた途端にそれた。肘から手首への震えが止まらず、その一横は斜めに伸びていった。

→ 発生、知覚、反応が一段落で同時に提示されている。

**処理原則**：感情の詳細を削除するのではなく、同一瞬間の重複描写を統合する。統合後に明らかに薄くなった場合、原文にあった機能的情報を優先的に復元するか、既存の情報をより自然な動作/会話表現に変更する。原文にないプロット、設定、関係、時間線を新たに追加しないこと。

## コアルール

### ルール 1：段落密度診断

段落は細かければ良いわけでも、長ければ質が高いわけでもない。チェックの重点は音読とスマホ読書で引っかからないか：

- 一段落は通常、一つの動作、一つの情報変化、または密接に関連する反応群をのみを担う。
- 読点の連なりが長すぎる、複数の完全な動作が一段落に詰め込まれている場合、動作や情報変化に従って分割する。
- 短文が連続して箇条書きのようになっている場合、同一の画面内の隣接する文を統合し、画面の連続性を保つ。

```
過密：彼は窓の外の雨を見つめ、胸に言葉にできない感覚が湧き上がり、これまで歩んできた道と、もう忘れてしまった多くのことが、この瞬間に心に浮かんだ。

より自然：彼は窓の外を見つめた。雨が長く降り続いていた。
「まだ彼女のことを考えているのか？」と老劉が尋ねた。
彼は答えなかった。
```

### ルール 2：内省＋動作＋会話

三要素を循環させて推進。内省も主要な武器として許容する（村上文体）：

```
内省 -> 動作 -> 会話 -> 内省 -> 動作 -> ……
```

感情表現は「彼は感じた/彼は思った」の単発使用を許容。ただし空虚な一語要約は避け、内省の過程を具体的に書く：
- ✅ 「なぜ今なんだろう、と誠は思った」—— 疑問が内省を始める
- ✅ 「彼はとても緊張していた。手のひらは汗まみれで、箸を落としそうになった」—— 内面と外面の二層
- ❌ 「彼は悲しかった」—— 一語要約で終わっている。なぜ悲しいのか、何を考えたのかを書く
- 2段落以上の内心独白も内容に必然性があれば許容。空虚な反復は避ける

### ルール 3：シーンに応じた文長

村上文体では短さよりも自然なリズムを優先する。一律の文長制限は設けない：

| シーン | 文長の目安 | 注意 |
|------|------|------|
| 格闘/緊張 | 短め（自然に） | 翼の格闘シーンは身体感覚が優先。短さより正確さ |
| 会話 | 口語的 | 「正気か？」「かもしれないな」。沈黙も会話 |
| 日常/内省 | 長めを許容 | 誠の内省は自然な思考の流れで。一文一情報に縛られない |
| 描写 | 丁寧に | 情景・感覚を書くべき時は書く。飾りではない描写を

### ルール 4：口語化表現

- 俗語、汚い言葉の使用を許可（キャラクターの身分に合致すること）
- 会話で書面語を使わない（「私は本件は妥当でないと考えます」→「ありえないでしょ」）
- 地の文もかしこまらない（「彼の目は灯火のごとく」→「彼の目はじっと動かなかった」）
- 成語よりフレーズ優先（「やむを得ない」→「しょうがない」）

## Show Don't Tell の原則

| Tell（伝える） | Show（示す） |
|-------------|-------------|
| 彼は小心者だ | 彼は検査報告書を手に何度も裏返して見て、それでも開けられなかった |
| このバーはとてもうるさい | バーテンが彼の耳元で叫んで2回目でやっと聞こえた |
| 彼女はとても裕福だ | 彼女はクレジットカードをテーブルに無造作に置いた。カードの数字はこの食事の10倍の値段だった |
| 二人の関係は非常に悪い | 彼は彼女が淹れたばかりの茶碗にタバコを押し消した。彼女は無表情で茶碗を脇に押しやった |
| 彼はとても賢い | 3秒。3秒見ただけで彼はファイルを閉じた。「3ページ目、2行目です」 |

**コア方法**：
1. 形容詞の代わりに行動を使う
2. 総括の代わりに詳細を使う
3. ナレーション説明の代わりに会話を使う
4. 感情語の代わりに反応を使う

## 品質次元チェック

### 1. コア一貫性（最重み）
- プロットが大綱/前文と一致しているか
- キャラの行動が人物設定に合致しているか
- 設定に前後矛盾がないか

### 2. 表面書き換え（AI 指紋対策）
- AI 高頻度語が含まれていないか（上表参照）
- 章末に総括/昇華がないか
- 大量の純粋な心理描写がないか
- 段落が劇的単位/カメラに従って自然に区切られ、機械的な一文一段や箇条書きになっていないか

### 3. フォーマット一貫性
- 会話フォーマット統一：プロジェクト/プラットフォームの約定に従い同一引用符スタイルを維持。知乎塩言短編は「」使用可
- 句読点のリズムが語気に合致：終始句読点のみにならないよう注意。機能的な疑問符と少数の感嘆符を保持。躊躇や中断は省略記号やダッシュで無理に作らず、動作や短文で表現
- シーン切替に明確なマークがある
- 時間線が追跡可能

### 4. 可読性
- 連続する複数の長文が読書リズムを圧迫し、動作、会話、短文の息継ぎがないか
- 会話が口語化されているか
- 未説明の難解語/設定用語がないか
- リズムに緩急があるか（単一リズムのみは不可）

### 5. 論理的一貫性
- キャラの動機が合理的か
- 出来事の因果連鎖が明確か
- 時間線が合致しているか
- キャラの知識範囲が合理的か（神の視点になっていないか）

## クイックセルフチェック暗記

```
一事一段、カメラ自然に切る。
会話は人間の話し言葉らしく。
気持ちは心の声で書くな。
終わりに大昇華をするな。
戦闘は流れ作業にするな。
日常には伏線の種を仕込め。
```

> 網文段落ルール：劇的単位/カメラ/一事の終了で自然に段落を区切る。短文は速読、長文は完全な推理、雰囲気、感情連鎖を担う。機械的な一文一段や全編同一長文を避ける。

## 8 種類の AI 執筆パターン検出

### パターン 1：AI 高頻度語

| 禁用 | 置換 |
|------|--------|
| 不禁 | 削除 |
| 仿佛/宛如 | 削除または具体的な描写に |
| 映入眼帘 | 削除 |
| 心中暗道 | 動作で思考を示す |
| 沉声道/淡淡地说 | 動作タグに置き換え |
| 脸色一变 | 具体的な表情/動作で表現 |
| 嘴角微扬 | 彼は笑った/彼は口を歪めた |
| 不由自主 | 削除 |
| 只见/此时此刻 | 削除 |
| 目光如炬 | 削除または具体化 |

### パターン 2：弱化副詞の氾濫
閾値：1000 字あたり 3 個超過 = AI 署名。重点監視：微微、淡淡、缓缓、轻轻。

### パターン 3：意味の拡大
- "意義深遠" → 具体的な結果を書く
- "前代未聞" → 比較参照を示す
- "いわば" → 削除

### パターン 4：万能的結論
- "未来は期待できる" → 未解決の緊張感で終わらせる
- "前途は限りない" → 削除
- "希望に満ちている" → 具体的な次の動作を書く

### パターン 5：論文体的段落構造
小説に以下の書き出し文が出現 = AI 侵入：
- "見てわかるように""これにより""事実上""以上をまとめると"

### パターン 6：書面語接続詞の氾濫
叙事散文中に頻繁に出現："そこで""と同時に""それによって""したがって""確かに" → 口語化して置き換えるか直接削除。

### パターン 7：三連排比癖
AI は物事を 3 つ揃えて「完全」に見せたがる。→ 最も力強い 1 つだけ残して削除。

### パターン 8：説明口調/神の視点/作為感
最も気づきにくく、最も「AI らしい」タイプ。語り手がキャラクターの現在から飛び出して、説明、ネタバレ、総括、断定、格上げを行う。読者は「作者がいる」「プロットが作られている」匂いを感じ取る。

| 症状 | 例（削除/修正） |
|---|---|
| 因果の説明 | 「なぜなら…だからだ」「つまり」「これは意味する」「正にそのため」→ 削除。因果はキャラの動作、会話、反応からのみ読者自身に組み立てさせる |
| 神の視点ネタバレ | 「彼女が知らなかったのは」「殊不知」「多年後」「冥冥之中」「あたかも予示するかのように」→ 削除。キャラが今知っていることだけを書き、サスペンスは読者に預ける |
| 読者の代わりに結論/断定 | 「本当に上手く演じた」「この芝居は彼女が一度見た」「彼はそういう薄情な人間だ」→ 削除。証拠（表情、動作、セリフ）を並べ、断定は読者に委ねる |
| キャラの代わりに心理を総括 | 「彼女は理解した、これが全て運命だと」→ 偏見のこもった一瞬の思いか、身体反応に置き換える |
| 作為感/無理な伏線 | 後続プロットのために強引に背景説明、段落全体の回想・倒叙 → 背景はキャラが今本当に必要としている分だけ、一瞬の思い、半端なセリフ、物の断片で散りばめ、集中説明しない |
| 昇華式の締め | 結末で対比による格上げ、金言で主題を指す → 動作か余白を残したセリフで締め、「意味」を画面に押し込む |

**より隠れた層（最も自己チェック困難、指標語なし）**——同じく作為感/神の視点：
- 評価的副詞/補語：「心配りが程よい」「笑い方が恰幅良い」「多からず少なからず」→ 作者が読者に代わって「これは演技だ」と認定している。動作だけ書く（「彼女は手巾を押し当て、目は動かなかった」）、演技かどうかは読者に判断させる。
- ネタバレ的潜在意識の露呈：「その笑いを彼女ははっきり見た」「誰の目にも彼が嘘をついているのは明らかだった」→ 隠されているものを明かしてしまっている。そのまま残して明かさない。
- 断定的比喩/断定の決め文句：「あらかじめ決められたことを宣告するかのように」「死物を見るかのように」→ 比喩がキャラの代わりに断定している。キャラの強烈な主観的感觉でなければ削除。残す場合も、彼女の偏った瞬間の感覚であって、客観的断言ではない。

自己チェック：文ごとに問いかける——これは「キャラが経験している」のか、「作者が解説/配置している」のか。作者が飛び出してきたら削除、またはキャラの視点内の表現に変更する。根本的な治療法は深度制限視点（writing-craft.md「視点の姿勢：深度制限視点」参照）に固定し、カメラをキャラの身体に釘付けにすること。作者が飛び出す場所はなくなる。

## 体系的な AI 臭除去 3 パス法

### Pass 1：汎化除去（Strip Generic）
- 抽象的総括文 → 削除または具体的行動に置換
- 偽の深み文 → 削除
- 意味の拡大 → 具体的影響に縮小
- 空虚な結論 → 削除
- 整然とした対比句式 → 分解して書き直し
- 装飾的形容詞の積み重ね → 白描
- "于是""然而""此刻"の過度使用 → 半分に削減
- 全キャラが同じように「高度」な話し方 → 口調を区別

**原則**：削除できるものは削除、できないものは具体的詳細で置換。このパスで AI 臭の 80% が除去される。

### Pass 2：脱書面化（Cut Professional Diction）
- 分析的用語（「メカニズム」「構造」「ロジック」「システム」が小説に出現）→ 日常表現に変更
- 抽象名詞の濫用 → 直接的に述べる
- 体制内用語（「さらに」「深く」「推進」「実行」など）→ 削除
- 専門用語の積み重ね → 必要なもののみ残し、わかりやすい言葉で説明

**例外**：専門性を保持すべきシーン（歴史題材の正式用語、文学的な密度表現、喜劇的な誇張修辞）。

### Pass 3：自然感の回復（Restore Natural Presence）
- 具体的な感覚の詳細（匂い、温度、触感）
- キャラの話し方の区別（人による口調の違い）
- リズムの変化（短文と長文の交錯）：感情のビート、動作の推進、劇的単位に従って文の長さを自然に調整。連続する段落が同一長さにならないよう注意。また短文にしすぎて箇条書きのようにならないよう注意。長短はランダムではなく、沈殿するところは緩やかに、衝突/反転のところは突然短く、完全な推理と感情連鎖は一貫性を優先
- 社会的立場による会話の違い（上司と部下の話し方の違い）
- シーン特有の記憶ポイント
- プロジェクト特有の言語習慣（キャラの口癖）

**原則**：少なければ少ないほど良い。段落ごとに 1〜2 個の具体的な詳細を追加すれば十分。

### アップグレード戦略

| AI 臭の程度 | 戦略 |
|----------|------|
| 軽度 | Pass 1 のみ |
| 中度 | Pass 1 + Pass 2 |
| 重度 | 完全 3 パス + 重点段落の書き直し |

### セルフチェックリスト
- 会話の自然度チェック：会話が口語表現を使っているか、書面語/正式な口調を避けているか
- 任意の 1 文を削除した場合、理解に影響するか？しない = 冗長の可能性
- 異なるキャラを会話で区別できるか？
- このシーン特有の詳細は 1 つでもあるか？

## AI 臭除去補足技法

### Show vs Tell

| 告知タイプ | AI 的書き方 | 自然な書き方 |
|----------|--------|----------|
| 期待感を伝える | "彼はとても期待していた" | 期待→感情→満足の連鎖を示す |
| キャラの目的を伝える | "彼女は離婚したかった" | 行動で目的を示す |
| キャラの態度を伝える | "彼女はとても冷静だった" | 会話と反応で表現する |
| プロットの方向性を伝える | "次に大きな出来事が起きる" | 布石→反転→継続で示す |

### 心理描写の自然な溶け込み

- 括弧書きで内心の活動を注記 = 没入感を破壊
- 大量の内心独白で動機を説明 = AI 署名
- 直接「彼女は感じた」「彼女は気づいた」と書く = 感情の告知

**自然な書き方**：心理活動を自然に物語に溶け込ませ、行動で心理を暗示し、沈黙/動作/異常な行動で内心を表現する。

### 没入感チェック
- 主人公の行動を読者は理解、共感、受け入れられるか？
- 敵役は十分に強いか？（弱い敵役 = 読者は主人公の勝利に意義を感じない）
- 人物設定に沿った行動か？（行動/言語/思考が人格に沿っているか）
- 読者の既知情報が効果的に操作されているか？（情報格差が感情の起伏を生む）

## 書き換え例集

### 感情の外化例

**緊張**
- 「彼は緊張を感じ、心臓が思わず速くなった」
- 彼は手に持った紙コップを握りしめ、水が少しこぼれた

**怒り**
- 「怒りが彼の胸で燃え上がり、彼は思わず拳を握りしめた」
- 彼は箸をテーブルに叩きつけ、茶碗のスープが飛び散った

**悲しみ**
- 「悲しみが胸に込み上げ、彼女の目に涙が光った」
- 彼女はうつむいてコーヒーをかき混ぜていた。長い間、混ぜ続けた

**恐怖**
- 「恐怖が瞬時に彼を包み込み、彼は身震いした」
- 彼の背中が壁に貼りつき、動けなかった

**失望**
- 「彼女は少し落胆を感じ、心が何かに掴まれたようだった」
- 「ああ」彼女は携帯のロックを解除した

**驚き**
- 「彼の瞳孔が微かに収縮し、まさかこんな言葉を聞くとは思っていなかったようだ」
- 彼は口を開けたが、何も言えなかった

### シーン描写例

**AI 風のシーン**
- 「陽光がカーテンの隙間から差し込み、床に斑模様を落とした。空気には微かな花の香りが漂い、全世界が静かで平和な雰囲気に包まれているかのようだ」
- 午後3時、リビングには時計の音だけが響いていた

**AI 風の天気**
- 「空はどんよりと曇り、黒雲が立ち込め、いつ大雨が降り出してもおかしくなかった。凛とした寒風が吹きすさび、肌を刺すような寒さを伴っていた」
- 雨が降りそうだ。風が外に干してある服を激しく揺らしている

**AI 風の格闘**
- 「彼の拳は疾風のごとく激しく、一撃ごとに疑いを許さない力が込められていた。相手の瞳孔が微かに収縮し、まさかこれほど激しい攻撃が来るとは思っていなかったようだ」
- 彼が一発殴りつけると、相手は避けきれず、口元が切れた

### 結末の書き換え例

**昇華式結末** → 「彼は窓辺に立ち、遠くの地平線を見つめ、ついに人生の真髄を悟った。時には手放すことが最良の選択なのだ」 → 彼はタバコを消し、部屋に戻って寝た。

**総括式結末** → 「この瞬間、全てが変わった。彼女は知っていた、これから彼女の人生は新たな一ページを開くのだと」 → 彼女はその扉を閉めた。振り返らなかった。

**感慨式結末** → 「歳月は水の流れのように静かに過ぎていく…」 → この種の段落は直接削除。

### リズム調整例

**排比文**
- 「彼は彼女の目を見つめ、彼女の唇を見つめ、彼女の微かに震える睫毛を見つめ、胸に名状しがたい感情が湧き上がった」
- 彼は彼女を見つめた。彼女は何も言わなかった。

**長文の分割**
- 「彼がついにあの重い木の扉を押し開けた時、目に飛び込んできたのは薄暗い部屋で、空気には古びた匂いが満ち、隅には埃をかぶった箱が積まれていた」
- 扉が開いた。部屋は暗く、隅にいくつか箱が積まれ、上は埃だらけだった。

**整然とした段落の破壊**
- 「彼女は春の花が好きで、夏の日差しが好きで、秋の落ち葉が好きで、冬の白雪が好きだ。どの季節にも独特の美しさがある」
- 彼女は春が好きだ。他の季節もまあまあだ。

## 衝突会話書き換え例

### AI 的な穏やかな会話
- 「あなたのやり方は適切ではないと思います。私の気持ちも考えてもらえませんか？」→ 「あなたの目に私は映ってるの？」

### AI 的な完璧な説明
- 「実は私には理由があって、当時の状況が非常に複雑だったため…」→ 「何か文句でも？」彼女は茶碗を重々しく置いた。

### 会話感情の 5 段階進行例

同一衝突シーン、弱から強へ：

1. **客観的陳述**：「俺の物を捨てたな」
2. **陳述+提案**：「俺の物を捨てたな。次からは一声かけてくれ」
3. **主観的非難**：「てめぇ、何で俺の物に触るんだ」
4. **非難+命令**：「お前ごときが、俺の物に触る資格があるのか？出ていけ」
5. **非難+支配**：「俺がお前に飯を食わせ、着せてやってるのに、お前は物一つまともに置けないのか。お前の人生は所詮その程度だ。俺がいなけりゃお前は何もならない」

### 驚きの階層的書き換え例

**AI 的な一気呵成**：全員が驚愕し、自分の耳を信じられなかった。

**自然な階層的驚き**：
1. 向かいの男の手が震え、茶碗の湯がこぼれた
2. 隣の者たちが互いに顔を見合わせた。後退する者がいた。隅で携帯を取り出し始める者がいた
3. 先ほどまで威張っていた女の顔の笑みが凍りついた。彼女は口を開けたが、一言も発せられなかった
