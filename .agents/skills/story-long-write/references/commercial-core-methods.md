# 商業コアメソッド

> ネット小説創作の中核となる爽点設計と商業モデルを分析。14種の爽点タイプ、6種のリサイクルモデル、それぞれに対応する実戦技能。

---

## 爽点の核心——読者が求めているもの

**読者が本当に求めているもの：**
- 感情価値（嬉しい、すっきりする、感動する）
- リズム感（先が気になる、やめられない）
- 安定感（順調に更新されてほしい、終わりまで見たい）

**読者が求めている爽点：**
- 仮想的な没入による満足感
- 感情のカタルシス
- 知力の優位性
- 成長による認められ方
- 不当な扱いからの解放
- 理想の実現への代償

## 14種の爽点タイプ

### 類型論の核心

| 次元 | 説明 |
|------|-------------|
| 抑圧からのカタルシス爽点 | 我慢したのちに解放、最も基本的で強い爽点 |
| 成長満足爽点 | 努力が報われる、昇級の達成感 |
| 知力優位爽点 | 先読み、裏をかく、トラップを仕掛ける |
| 身分逆転爽点 | 見下した相手に一発逆転 |
| 感情充実爽点 | 愛情、兄弟愛、家族愛の満たし合い |
| 財力爆発爽点 | 富の象徴、使い放題 |
| 権力掌握爽点 | 人に命令する、場を掌握する |
| 運命抗戦爽点 | 逆境での不屈、格好良さ |
| 技術炫耀爽点 | 専門スキルで周囲をあっと言わせる |
| サプライズ反転爽点 | 覆る、思いもよらない変身 |
| 共闘一致爽点 | 集団での共闘、チームワーク |
| 理屈勝ち爽点 | 議論や口論で相手を言い負かす |
| 庇護爽点 | 強い者が弱い者を守る |
| 運ゲー爽点 | 偶然の幸運、掘り出し物 |

### 爽点満足度方程式

```
爽点満足度 = 期待値 × 反転角度 × 共感度
```

反転角度は事前に敷かれた伏線に依存する。伏線が2段ある場合、通常10%の読者しか気づかない。表面の伏線は多くの読者が気づける。反転のショック値は表面の伏線数に影響され、深層の伏線数に影響されない。

**各次元の最大化原則：**
- 期待値は、爽点の前にどのくらい我慢させたか（抑圧の度合い）、どれだけの伏線を敷いたか（情報の非対称性）
- 反転角度は、事前の伏線の数を最大化することではなく、重要な伏線を覆すことが爽点を最大化する
- 共感度は流動的であり、フェーズごとに同じ手法で満足度を最大化することはできない

## 爽点の技術的カテゴリ

### タイプA：蓄積解放型

- 原理：抑圧の度合い × 解放の強度
- 実戦法則：「爽点 = 共感度 × 期待値」。抑圧段階では期待値を十分に醸成し、共感度を高める。
- 上限解放：複数回の期待値の蓄積 → 各期待値の単独解放ではなく、同時に解放することで満足度を爆発させる。

| 要素 | 説明 | 操作のポイント |
|---------|------|-------------|
| 目標設定 | 明確で階層的な目標チェーン | 短期目標（食うため）/中期目標（強くなるため）/長期目標（世界を救うため） |
| 成長提示 | 数値化/比較/資格の獲得 | 昇級、競技でのランクイン、入門試験合格 |
| 難関突破 | 山場を設定し、代価と共に | 戦闘・試験・攻略・覚醒 |
| 身分確認 | 称号/役割/位置づけの確認 | 序列変更、実力認定、正式資格 |

### タイプB：感情共鳴型

- 原理：価値観の一致 × 感情の流れ
- 実戦法則：「爽点 = 期待値 × 反転角度」。適切な反転は期待値を爆発的に高める。
- 汎用テンプレート：チームメイトが命を落とす → かつて助けた獣が味方になる → どんでん返し

### タイプC：知力爽点型

- 原理：情報非対称性 × 判断の正確さ × 利益の最大化
- 実戦法則：読者が主人公の正しさに気づき、主人公の次の動きに期待する段階で十分に溜める→主人公の連続的な正確な判断で爽点を爆発させる
- 操作のポイント
  - 情報差を埋める：作者と読者の間の情報差で読者をやきもきさせる
  - 認知逆転：読者が間違っていると思い込んでいたものが、実は正しかった
  - 利益最大化：リスクを最小限に抑え、複数の利益を同時に得る
  - 代償の割引：主人公は代償を払って勝つ読者の予想を覆す

### タイプD：身分爽点型

- 原理：落差感 × 周囲の反応 × 身分の確認タイミング
- 操作のポイント：
  - 先に抑える：主人公が低い身分で虐げられる。抑えれば抑えるほど、後に跳ね返る
  - 適切なタイミング：確認のタイミングは必ず最も必要な時
  - 段落感を出す：周囲の反応は1回の確認で使い切ってはいけない。情報を開示する相手を変える
  - 確認の深化：低い身分を確認して周囲の反応を得た後に、より高い身分を確認し、反応を再び高める

## 6種の爽点リサイクルモデル

### Model 1：三段式爽点サイクル
- 爽点の提示 → 読者の期待 → 爽点の達成
- 短いサイクル：毎章1-2個の爽点の提示と達成
- 中程度のサイクル：数章で1セットの爽点の積み重ねと解放
- 長いサイクル：巻単位での爽点の蓄積と爆発

### Model 2：抑圧解放モデル（蓄積→爆発→休止→再蓄積）
```
抑圧 → 蓄積 → 爆発 → 休止（新たな対立）
```
「3章の蓄積+1章の爆発」リズムで短サイクル爽点を繰り返す。ステータスを戦闘力やクールダウン時間に例えられる場合、爽点爆発後は設定を利用して主人公に新たなボトルネックを発生させる（例：霊力枯渇、丹薬副作用）。

### Model 3：情報差モデル（伏線→開示→反転）
```
伏線の敷設 → 情報差 → 開示 → 反転（読者の予想を裏切る）
```
主要反転と伏線回収で使用。

### Model 4：成長達成モデル（目標→努力→結果→新目標）
```
目標設定 → 努力の過程 → 結果の確認 → 新目標
```
二次元、ゲーム類の成長線で使用。

### Model 5：意外性サプライズモデル（通常状態→予想外の展開→驚き）
```
日常状態 → 予想外のイベント → 強い驚き（意外な結果）
```
反転爽点、隠された身分開示等で使用。

### Model 6：共感共鳴モデル（類似経験→価値観の一致→感情のカタルシス）
```
類似経験の提示 → 価値観の一致 → 感情のカタルシス
```
感動シーン、熱血シーンで使用。

## 爽点密度コントロール

### 密度基準（字数ベース）

| タイプ | 最小爽点密度 | 典型的な周期 | 説明 |
|------|---------------|-------------|------|
| ストーリー主導 | 1000字に1回 | 500-1500字 | 爽点サイクルが速く、成長線爽点＋反転爽点＋共感爽点が交代する |
| 感情主導 | 1500字に1回 | 800-2000字 | 感情爽点の密度はやや低下するが、感情的な盛り上がりシーンでは逆に上昇 |
| 設定主導 | 2000字に1回 | 1500-3000字 | 設定説明の章は爽点密度が低下する可能性があるが、設定披露で補う |

### 爽点の連続回収

爽点は同時に複数の爽点モデルをトリガーできる：

| モデル | レスポンス | 説明 |
|-------|----------|-------------|
| 抑圧解放 + 成長達成 | 最も強力な爽点、読者を夢中にさせる | 困難な訓練を経て大成した瞬間、爽点 × 達成感が同時にヒット |
| 情報差 + 共感共鳴 | 伏線回収に適し、読者の没入感を深める | ポジティブで予想外の展開が心の奥深くに響く |
| 情報差 + 抑圧解放 | 冷静さと熱血の両方を備えた爽点 | 事前に敷かれた伏線によって権謀術数の爽点が爆発 |
| 成長達成 × N | 最も中毒性のある爽点、やめられない | 同種の爽点モデルを短時間内に高頻度で連続ヒットさせる |
| 抑圧解放 + 意外性 | 反転タイプの爽点に適する | "見下した相手→あっと言わせる→大物が現れる→あっと言わせる" の3連爽点 |

### 爽点の連鎖爆発リズム

```
爽点A → [読者期待] → 爽点B（Aの強化版） → [読者期待] → 爽点C（A+B以上の総和）
```

典型テンプレート：
1. 底辺からの逆襲（A爽点）：虐げられた主人公が初めて反撃
2. 身分開示（B爽点）：もっと強い背景が明らかに
3. 爽点爆発（C爽点）：虐げた相手が土下座

### 爽点の配置位置

| 位置 | 機能 | 字数割合 |
|------|---------|---------|
| 冒頭（1-3章） | 読者を掴む爽点、フック | 5-10% |
| 序盤（3-10章） | 爽点が特徴を示す | 15-20% |
| 中盤（10-50章） | 爽点パターンが安定 | 50-60% |
| 終盤（50-100章） | 爽点が集中的に爆発 | 20-30% |

## リズム設計——爽点の安定出力と引き際

- 爽点は連続して出力する必要はなく、読者が息継ぎできる「空白」が必要
- 爽点解放後の休止期間も重要な爽点の構成要素であり、次の爽点爆発への期待値を高める
- 引き際は爽点爆発のピーク時である。ピークが過ぎてから引いてはいけない
- **爽点の前に十分な危機と期待を敷く**——爽点が唐突に見えるのを避けるため

**実戦のポイント：**
- 爽点は配置するだけではなく、敷く必要がある。「3章の抑圧 + 1章の爆発」は常に有効
- 爽点の解放は一度に全部ではなく、徐々に行い、ピークを過ぎては引く
- 読者の爽点疲労に注意する：同じ爽点モデルは連続使用回数に制限を設け、種類を変える
