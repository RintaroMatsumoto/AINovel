# 成果物作成テンプレート

各成果物の標準テンプレートと作成ガイド。agent は Phase 2-3 移行時に必要に応じて本ファイルを読み込む。

**テンプレート一覧：**
- 設定/関係.md
- 設定/題材定位.md
- 大綱/巻綱_第X卷.md（感情弧線＋反転計画含む）
- 追跡/伏線.md
- 追跡/時間線.md
- 追跡/キャラ状態.md
- 参照/{参照書名}/分析報告.md
- 参照/{参照書名}/原文/第XXX章_{章名}.md

**階層関係：**
- 大綱.md = 全書鳥瞰（各巻1〜2文で定位）
- 巻綱_第X卷.md = 単巻計画（感情ピークリズム＋感情＋人物＋伏線＋反転）
- 細綱_第XXX章.md = 単章設計図（内容概括＋複線プロット＋人物関係/登場順＋プロット詳細＋結末設定/フック；旧フィールドの核心事件/目標感情/章首フック/感情ピーク/章尾フック/字数目標は維持）

## 参照/{参照書名}/分析報告.md

> **分析库/参照関係**：`分析库/` = analyze skill の生出力（データソース）。`参照/` = 写作プロジェクトの参照ビュー。初回参照時に `分析库/` から `参照/` にコピー。

本ファイルは `story-long-analyze` 分解パイプラインの出力（クイックプレビュー報告または完全分解報告）。write skill の責務は**読み取り**であり、作成ではない。

手動で簡易版参照サマリーを作成する場合（analyze skill 未使用時）：

```markdown
# {参照書名} 参照サマリー

## 基本情報
- 書名：{}
- 作者：{}
- 題材/タイプ：{}
- 対象プラットフォーム：{}
- 成績：{平均購読/同時接続/人気度}

## 核心的発見
- 冒頭フック：{タイプ＋手法}
- 感情ピーク密度：{約 N 字/回}
- リズムパターン：{説明}
- 参考可能な定型パターン：
  1. {}
  2. {}
  3. {}

## そのまま流用禁止
- {}（構造のみ学び、場面をコピーしない）
```

作成参照：`plot-special-topics.md`（参照書選択法則）

## 大綱/巻綱_第X卷.md

巻綱は大綱の展開——大綱が方向を決め、巻綱がリズムを決める。本巻の全創作計画を含む。

```markdown
# {巻名} 巻綱

## 核心情報
- 章範囲：第{X}-{Y}章
- 字数目標：{W}万字
- 本巻定位：{伏線/展開/山場/転換/収束}

## 核心的対立
{一言：本巻で解決すべき問題または達成すべき目標}

## 感情弧線
- テンプレート：{V形/逆V形/W形/段階形/遅延滿足形/急転換形}
- 選択理由：{題材と本巻定位に基づく}

| 章 | 感情基調{緊張/リラックス/悲しみ/熱血/温かみ/衝撃} | 強度{1-10} | トリガーイベント |
|------|-----------------------------------------|-----------|---------|
| 第{N}章 | {基調} | {N} | {イベント} |

## 感情ピークリズム
| 周期 | 章範囲 | 伏線(起) | 放出(承) | 反応層 | 接続(転) |
|------|---------|---------|---------|-------|---------|
| 第1個 | {章X-Y} | {簡述} | {簡述} | {N層} | {方式} |

## 人物弧線
| キャラ | 本巻起点 | 本巻終点 | キー転換 |
|------|---------|---------|---------|
| {名} | {状態} | {状態} | {イベント} |

## 本巻の反転（ある場合）
| タイプ{身分/動機/陣営/情報/運命} | 関連キャラ | 誤誘導経路 | 開示章 | 影響範囲 |
|------|---------|---------|---------|---------|
| {タイプ} | {名} | {読者をどう誤誘導するか} | 第{N}章 | {どの線に影響するか} |

|------|---------|---------|---------------------|
```

## 大綱/細綱_第XXX章.md

細綱は本文執筆の章別設計図であり、イベントとフックだけを列挙したリストではない。新版テンプレートは旧フィールドと互換：旧プロジェクトに `核心イベント / プロットポイント列 / 目標感情 / 章首フック / 感情ピーク / 章尾フック / 字数目標` がある場合は日更可能；新規作成、補完、再入力時は以下の構造を使用。不明なフィールドは `[未確定]` と書き、埋めるために副線や人物関係を捏造しない。

```markdown
## 細綱（第 N 章）

### 第 N 章：{章名}
- 核心イベント：{一言}
- 字数目標：{X} 字
- 目標感情：{本章が提供する感情}
- 章首フック：{タイプ} — {具体内容}
- 感情ピーク：{本章の感情ピーク / 顕在的な感情ピークはないが担う機能}

#### 内容概括（五段式）
- 起因：{なぜイベントが起こるか}
- 展開：{対立がどう進むか}
- 転機：{情報/関係/情勢の変化}
- 山場：{感情または動作のピーク}
- 結末：{収束状態}

#### プロット構成（マルチライン）
- 主線進行：{主目標の推進}
- 副線進行：{「なし」または `[未確定]` と記入可能}
- イベント線 / 任務線：{外部イベントチェーン}
- 感情線 / 関係線：{関係変化；顕在的でなければ「顕在的でない」と明記}
- 論理線：原因 → 行動 → 結果 → 結果/新たな問題

#### 人物関係と登場順
- 登場順：{キャラ/勢力/キーアイテムを実際の登場順に}
- 人物関係変化：{本章前 → 本章後}
- 視点/情報差：{誰が何を知っているか；読者は何を知っているか；主人公の誤判断}

#### プロット詳細化
- プロットポイント列：{字数目標から逆算；各点に「誰が何をした＋機能ラベル」}
- 代価の支払い / 収益の獲得：{誰が代価を払うか；誰が収益を得るか；後続への影響}

#### 結末設定とフック
- 結末設定：{未解決の問題；次章への推進力}
- 章尾フック：{タイプ} — {具体内容；期待度；次章との接続}
```

## 追跡/伏線.md

**状態の意味**：`未埋` = 計画済みだが未設置；`已埋` = 設置済みでまだ開放中、長編の正常状態；`已回収` = クローズ済み；`已过期` = 想定回収期間を過ぎた。SessionStart hook は `未埋`、`已埋`、`已回収` のみで警告しない。日更フローでは今回新規追加/推進/回収の伏線のみを処理。全量伏線監査は `/story-review` またはユーザーの明示的要求でのみトリガー。

```markdown
# 伏線追跡

## 伏線状態表

| ID | 伏線内容 | 設置章 | 想定回収章 | 状態{未埋/已埋/已回収/已过期} | 重要度{高/中/低} |
|----|---------|---------|-------------|-----------------------------|----------------|
| F001 | {内容} | 第{N}章 | 第{N}章 | {状態} | {レベル} |

## 回収ログ
| 章 | 回収した伏線ID | 回収方式{開示/反転/呼応} | 効果 |
|------|-------------|-------------------------|------|

## 期限切れ伏線
| ID | 原因 | 処理{補回収/放棄/長期化} |
|----|------|--------------------------|
```

作成参照：`plot-core-methods.md`（連続性追跡とリズム管理）

## 追跡/キャラ状態.md

キャラ状態のスナップショット。Phase 3 大綱完了時に初期状態を作成し、Phase 4 各章執筆後に必要に応じて更新。

テンプレートフィールド、スナップショット形式、更新ルールは統一して `state-tracking.md`「キャラ状態スナップショット形式」を参照。本ファイルではインラインで重複して記載しない。
