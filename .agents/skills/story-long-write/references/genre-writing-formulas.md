# 題材創作公式

各題材の爽点公式と創作フレームワーク。公式は固定ではなく、題材に応じて調整可能。

---

## 公式の核心──題材の組み合わせ

現代のネット小説は単一題材の黄金期を過ぎ、複合題材が主流。以下の公式テンプレートは多くが中核題材 + 爽点システムの組み合わせ。

**題材組み合わせ原則：**
- 中核題材一つ、補助題材一つ、最大三つまで
- 補助題材は中核の爽点を阻害しない
- 各題材は読者層を広げるか、爽点密度を高める

---

## 主な題材創作公式

### 玄幻 + システム

```
玄幻の世界観 × システムの成長保証 × 爽点の定時解放
```

**公式の要点**：
- システムは成長ロードマップを提供（爽点の確実な解放）
- 玄幻世界観は自由な戦闘枠組みを提供
- システムは枠組み（ルールと報酬）を定義し、詳細は世界観が埋める

**中核爽点配置**：

| 爽点 | 玄幻側 | システム側 |
|------|--------|------------|
| 昇級 | 境界突破 | レベルのアップグレード |
| 戦闘 | 神通の応用 | システム装備/スキルの相乗効果 |
| 宝物 | 天地の霊宝 | システム商店 |
| 身分 | 勢力の後ろ盾 | システムの称号 |

**代表作品**：該当なし（複合題材フレームワークのみを説明）

### 都市 + 鑑定/医術

```
都市の戦闘力枠組み ＋ 鑑定/医術の情報差
```

**公式の要点**：
- 都市の戦闘力ピラミッドを保有（抑圧爽点の源泉）
- 鑑定/医術の情報差で現実世界のルールを超越
- 鑑定/医術は機能を簡潔に（一覧、鑑定、取引、治療、解毒）

**中核爽点配置**：

| 爽点 | 発動条件 |
|------|---------|
| 能力発動 | 誰も見抜けないものを見抜く（真贋、人体の病変） |
| 逆襲達成 | 鑑定/医術で局面を逆転する、地位と名声を獲得する |
| 身分開示 | 特殊能力で高みに上り詰め、身分を開示して周囲を驚かせる |

### 架空歴史 + 内政

```
改変の余地 × 制度設計 × 長期発展の爽快感
```

**公式の要点**：
- 歴史は改変の余地を大きく残す（戦国・三国・隋末）
- 内政は発展の明確なロードマップを提供
- 「リアリティ」が命：改変は速すぎず、制度は時代に合っている必要がある

**中核爽点配置**：

| 爽点 | 発動条件 |
|------|---------|
| 現実の成果 | 国が強くなり、民が豊かになる具体的な数字/事例 |
| 戦争勝利 | 戦術で多くを少なくで破る、読者に納得感のある過程が必要 |
| ライバルの反応 | 敵対勢力の驚きと模倣 |
| 内部統一 | 朝廷内の異論派を政治的に処理する爽快感 |

### 終末 + 進化

```
生存圧力 ＋ 進化の自由度 × 資源争奪
```

**公式の要点**：
- 終末は強い生存圧力を提供（爽点の原動力）
- 進化システムは自由な成長ラインを提供
- 資源争奪はプロット推進のエンジン

**中核爽点配置**：

| 爽点 | 発動条件 |
|------|---------|
| 進化突破 | 資源の蓄積＋限界突破＋能力アップグレード |
| 資源争奪戦 | 他者との競争＋反転＋勝利 |
| 基地発展 | 生存基盤の建設＋防御＋拡大 |
| 敵対者打倒 | 敵勢力を殲滅、資源を奪取 |

### 学園 + 超能力

```
青春の日常 ＋ 超能力バトル × チーム成長
```

**公式の要点**：
- 学園は日常の雰囲気を提供（リラックス爽点）
- 超能力バトルは熱いシーンを提供（緊張爽点）
- チーム成長は感情の蓄積を提供（持続爽点）

**中核爽点配置**：

| 爽点 | 発動条件 |
|------|---------|
| 能力覚醒 | 才能の開花、実戦での異常な強さ |
| 試合勝利 | チーム戦術＋個人の能力爆発 |
| 日常の温かさ | キャラ同士の掛け合い、イベントの楽しさ |
| 感情の進展 | 片思い→告白→両思いの過程 |
