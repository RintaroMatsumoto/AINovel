# Story Format Rules

正文ファイルの形式規範。ユーザーが正文ファイルを直接編集する時に自動ロード。

## 絶対禁止

1. **機械的分段または通篇大段落禁止**：段落はドラマ単位/カット/一事終了で自然に区切る。固定字数で強制分割しない。複数の動作、線索、視線切替を1段落に詰め込まない。完全な推理、雰囲気圧迫、情動変化連鎖はやや長めの段落を保持可。
2. **段落間空行禁止**：正文隣接段落間は1つの改行 `\n` のみ。空行または連続改行 `\n\n` を出現させてはならない。
3. **「彼が言った」「彼女が言った」禁止**：対話は動作で対話タグを代替する。
4. **大段落描写積み重ね禁止**：描写は動作または対話を間に挟む。3段落以上の純粋な描写を連続させない。
5. **視点飛出禁止**：確定した視点（一人称/限知三人称）から他のキャラの内心に切替えない。
6. **主語過密禁止**：同一動作連鎖内で同じ主人公名を不要に連続文/段落で繰り返さない。段首または主語リセット時に指名、段中は代名詞/動作承接/合理省略、キー転換時に再指名。

## 形式規範

- 対話は独立行。コロンまたは動作で導出。
- 段落はドラマ単位、カット、情動または動作で区切る。
- 章タイトルは `## 第X章 章名` 形式。タイトル後に1つの Markdown 空行を保持。
- 正文隣接段落間は1つの改行 `\n` のみ。空行または `\n\n` 不可。
- 章間に `---`、水平区切り線、または余分な空白行を使用しない。

## Examples

### Correct — ドラマ単位で自然断段
```
沈栀が手を上げ、霊力が指先から溢れ出た。
目の前の結界に亀裂が入り、砕けた模様が蜘蛛の巣のように広がった。
彼女は歯を食いしばって出力を強め、腕全体が震え始めた。
```
各段落は1つの動作/情報変化のみを担い、ドラマ単位で自然に推進。

### Wrong — 複数の拍点を1段落に圧縮
```
沈栀が手を上げ霊力が指先から溢れ出た目の前の結界に亀裂が入り砕けた模様が蜘蛛の巣のように広がった彼女は歯を食いしばって出力を強め腕全体が震え始め最後に結界が轟音と共に砕け散った。
```
同一段落に複数の動作、線索、結果が混在し、読者がキー変化で息継ぎできない。

### Correct — 対話を動作で導出（「彼が言った」不使用）
```
沈栀が茶碗をテーブルに置いた。
「いったい何が言いたいの？」
陸衍は答えず、ただ窓の外を見つめていた。
```

### Wrong — 対話タグ使用
```
沈栀が茶碗をテーブルに置いた。
彼女が言った：「いったい何が言いたいの？」
陸衍は答えず、彼はそっと溜息をついて言った、ただ窓の外を見つめていた。
```

### Correct — 章タイトル後に余分な空行なし
```
## 第二章 暗流

陸衍がドアを押し開けると、部屋の中にはすでに3人が座っていた。
```
章タイトル `##` と正文の間は1つの空行のみ。正文段落間に空行なし。

### Wrong — 段落間に余分な空行
```
## 第二章 暗流


陸衍がドアを押し開けると、部屋の中にはすでに3人が座っていた。


沈栀は最も奥の隅に座り、手に一枚の紙切れを握っていた。
```
段落間に余分な空行（連続改行 `\n\n`）が出現。コンパクトなリズムを破壊。
