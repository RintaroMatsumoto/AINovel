# Story Narrative Rules

分解、参照分析および設定ファイル中の叙事規則。

## Rules

1. **設定交叉チェック**：新規または修正設定時、必ず既存設定と交叉チェックし矛盾を確認。チェック方法：grep で既存設定ファイル中のキーワードを検索し、矛盾がないことを確認。

2. **言語スタイル一貫**：キャラ対話はキャラ設定中の言語スタイル档案（語気、用語習慣、感嘆符使用頻度など）に合致しなければならない。

3. **世界観規則明確**：力量体系、社会規則など「可能」と「不可能」の事は設定ファイルに明確に記録し、本文で一貫して遵守する。

4. **緊張には文書化された「本当の答え」が必要**：設定された各緊張/謎は、`追跡/` または `設定/` ファイルに明確な本当の答えの記録が必要。曖昧にしてはならない。

5. **キャラ動機と関係の内部自己整合**：キャラの行動は設定された動機に合致しなければならない。キャラ関係の変化には合理的なトリガーとなるイベントが必要。

6. **AI腔禁止**（赤線級制約）：
   - 章末の要約/昇華/哲理收尾禁止
   - 「彼は感じた/思った」で情動を直接叙述禁止。身体反応で代替
   - 2段落以上の純心理活動禁止。動作/対話を間に挟むこと
   - 万能的比喻禁止（「潮のように」「電光の如く」）。使わないか生活化的比喻に
   - 全キャラの話し方を同じにしない。各キャラは言語スタイル档案の7次元に合致

7. **対話三機能テスト**：各対話を削除した後チェック——プロットはまだ推進できるか。期待感はまだあるか。情動はまだ十分か。三つともノー＝水増し。削除。

## Examples

### Correct — 設定交叉チェック
```
新規設定：霊力等級は九層に分かれ、最高は第九層「破境」。
実行：
1. grep で設定/ ディレクトリ全ファイルを検索し、他の霊力体系記述がないか確認
2. grep で追跡/伏線.md の「霊力」キーワードを検索し、矛盾伏線がないか確認
3. 更新 追跡/上下文.md：[2024-05-05] 新規霊力九層体系追加
```

### Wrong — 設定未交差チェック
```
設定/世界规则.md で直接「霊力等級は十層に分かれる」を追加。
結果：既存設定ファイルに「霊力最高は九層」と記載あり、二箇所で矛盾。
且つ追跡/伏線.md に「九層」設定に依存する伏線が1条存在。
```

### Correct — 緊張に文書化された本当の答え
```
本文第15章：密室の古鏡が見知らぬ人の顔を映し出す。
追跡/伏線.md 記録：伏線#12（第15章 古鏡の見知らぬ人）→ 本当の答え：沈栀前世記憶の残留投影。回収章：第38章。
```

### Wrong — 緊張に文書記録なし
```
本文第15章：密室の古鏡が見知らぬ人の顔を映し出す。
追跡/伏線.md に記録なし。
執筆第40章時、後続本文がこの緊張を忘れるか、既存追跡記録と矛盾する説明を与える。
```
