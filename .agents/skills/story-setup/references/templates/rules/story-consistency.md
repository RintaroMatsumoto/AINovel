# Story Consistency Rules

修改設定、大綱、追跡ファイル時必須遵守の一貫性規則。

## Rules

1. **設定変更時は必ず追跡/をチェック**：いかなるキャラ設定や世界規則の変更時も、`追跡/` ディレクトリ下の `伏線.md` と時間線ファイルをチェックし、変更が既存の伏線と矛盾しないことを確認する。

2. **新規キャラ追加時は独立ファイルを作成**：各主要キャラは独立した設定ファイルを持ち、`关系.md` が存在する場合は更新する。

3. **時間線変更時は同期更新**：変更が時間順序（イベントの発生時点）に関わる場合、`時間線.md` を同期更新する。

4. **設定変更は上下文.md に記録**：重要な設定決定は `追跡/上下文.md` の「最近の決定」部分に記録する。

5. **一貫性チェックは grep を使用**：記憶に頼らず、検索で検証する。常用チェックコマンド：
   - キャラ属性：`grep -rn "キャラ名" 設定/ 本文/ | grep "属性キーワード"`
   - 時間線：`grep -rn "第.*天\|.*日後\|過了.*時" 本文/`
   - 力量体系：`grep -rn "体系キーワード" 設定/ 本文/`
   - 伏線状態：`grep -rn "伏線#" 追跡/`

6. **水増し検出信号**（出現時は警告）：全章対話に新情報なし、同質情動が3段落以上継続、シーン描写500字超で推進なし、キャラの昔の回想に新視点なし、2章連続で衝突なし。

## Examples

### Correct
```
沈栀の霊力等級を「第六層」に変更後：
1. 追跡/伏線.md に霊力等級に依存する伏線がないかチェック
2. 追跡/上下文.md 更新：[2024-05-05] 沈栀霊力等級を第六層に変更
3. 時間線ファイルがある場合、第45章対応時点が合理かをチェック
```

### Wrong
```
設定/キャラ/沈栀.md で霊力等級を直接変更し、関連ファイルを一切チェックしない。
結果：第20章の「沈栀の霊力は第三層のみ」の伏線が矛盾する。
```
