# Story Outline Rules

大綱ファイルの規範。

## Rules

1. **巻綱必須記入項目**：各巻綱（`卷纲_*.md`）は以下の部分を含まなければならない：
   - 本巻目標（主人公が本巻終了時に何の状態に達するか）
   - 爽点リズム（何章ごとに大爽点）
   - 情動弧線（本巻全体の情動走向）
   - 人物弧線（主要キャラの本巻での成長/変化）
   - 伏線配置（本巻で敷設する伏線と計画回収時間）
   - キー反転（本巻で最低1つのキー反転）

2. **細綱必須記入項目**：各細綱（`細綱_*.md`）は新版「章ブループリント」を含み、同時に旧フィールドも兼容性のために保持：
   - 旧フィールド：本章核心イベント、字数目標、目標情動、章首フック、本章爽点、章尾フック
   - 内容概括（五段式）：起因 / 展開 / 転換 / 山場 / 结尾
   - 情节配置（多線）：主線推進 / 輔線推進 / 事件線または任務線 / 感情線または関係線 / 論理線
   - 人物関係と出场順序：実際の出現順に役割/勢力/キー物品を列記。人物関係変化を書く
   - 情节细化：情节点系列に「誰が何をした + 機能タグ」と標記。代償履行 / 収益履行を標記
   - 結末設定とフック：収束状態、未解決問題、次章推進力、章尾フック

3. **増分書込**：大綱は増分書込する。先に骨子（キーイベントと爽点）を書き、節ごとに詳細を充填。一度に全詳細を書かない。

4. **本文との同期**：一章の本文を書き終えた後、細綱の「実際の完了状況」部分を振り返って更新。

5. **章首フックは以下の種別から選択**：
   緊張対話開局 | 先走り断片 | カウントダウン開局 | 神秘独白 | 反差シーン | 未完了動作開局 | 意象予示

6. **章尾フックは以下の種別から選択**：
   突然開示 | 緊急危機 | 未完了動作 | 身分反転 | 二者択一 | 神秘物品/線索 | カウントダウン | 約束/脅迫 | 消息不明 | 隠された含意 | 意象フック | エコーフック | 余白フック

7. **各章に情動変化が必要**：細綱は情動起点→終点を標記（例：「平静→驚愕→怒り」）。2章連続で情動変化なし＝調整必要。

8. **旧版細綱兼容**：既存旧版細綱に「内容概括/情节配置/人物関係/情节细化/結末設定」がない場合、欠落フィールドを理由に続筆を妨げない。しかし新規作成、補完、改綱または再記入時は必ず新版ブループリントに従い補完する。

## Examples

### Correct — 完全な巻綱
```
# 卷纲_第一卷.md
## 本巻目標
沈栀が霊力第三層から第五層に突破し、暗衛に加入する。
## 爽点リズム
5章ごとに大爽点（突破/反撃/身分開示）
## 情動弧線
抑圧→低谷→覚醒→爆発→余韻
## 人物弧線
沈栀：忍耐から主体反撃へ
## 伏線配置
- 伏線#3：古鏡破片（第8章埋設、第二巻回収）
- 伏線#7：師匠の本当の身分（第12章埋設、第三巻回収）
## キー反転
第18章：暗衛首領は実は沈栀の生き別れの兄だった
```
全ての必須記入項目が揃い、伏線に明確な回収計画がある。

### Wrong — 必須項目が不足した巻綱
```
# 卷纲_第一卷.md
## 本巻目標
沈栀が暗衛に加入する。
## 爽点リズム
5章ごとに大爽点。
```
情動弧線、人物弧線、伏線配置、キー反転の4つの必須記入項目が欠落。
