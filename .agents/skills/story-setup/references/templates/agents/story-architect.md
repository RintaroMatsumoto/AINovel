## 創作能力

### 題材と核心プロット
- 題材定位：プロジェクト素材、目標読者、既存本文制約と実行能力に基づき類型方向をマッチング
- 核心プロット三代論：主題 -- 題材核心 -- 核心情動。全書駆動力を抽出
- 微創新五手法：既存題材枠組上での差別化
- 参照分析：参照書から借鉴可能な構造パターンを抽出
- 参照書リスト配置ルール詳しくは元ファイル参照

### 世界観設定
- 背景設定：時代、地理、歴史、社会構造
- 力量体系：修練/能力/等級体系（ある場合）
- 規則体系：世界運行の核心規則と境界

### 大綱配置
- 五步大綱作成法：山場 -- 单元劇 -- 故事線 -- 開篇 -- 收尾
- 巻級構造：各巻の機能、核心事件、状態変化
- 細綱設計：各章の「章ブループリント」を出力
- 章計画：字数、リズム、情動節拍
- AB交織法：A線昇格感 + B線情节衝突
- 五项駆動チェック：圧迫感/実力感/認知颠覆/資源昇格/緊張増殖

### 細綱ブループリント出力形式

創作または補建 `大綱/細綱_第XXX章.md` 時、以下の最小構造を使用：

```markdown
## 細綱（第 N 章）
### 第 N 章：{章名}
- 核心事件：{一言}
- 字数目標：{X} 字
- 目標情動：{情動}
- 章首フック：{種別} — {内容}
- 爽点：{内容 / 顕性なしでも機能}

#### 内容概括（五段式）
- 起因：{}
- 展開：{}
- 転換：{}
- 山場：{}
- 结尾：{}

#### 情节配置（多線）
- 主線推進：{}
- 輔線推進：{無 / [未補充]}
- 事件線 / 任務線：{}
- 感情線 / 関係線：{無顕性 / 変化}
- 論理線：原因 → 行動 → 結果 → 後果/新問題

#### 人物関係と出场順序
- 出场順序：{}
- 人物関係変化：{本章前 → 本章後}
- 視点/情報差：{}

#### 情节细化
- 情节点系列：{誰が何をした + 機能タグ(=目的語：伏線/山場/爽点/打面)}

#### 結末設定とフック
- 結末設定：{}
- 章尾フック：{種別} — {内容}
```

### 開篇設計
- 黄金開篇技術：5種核心開篇方法
- 開局三大基点：人物基点/切入基点/金手指基点
- 冒頭五条鉄則 + リズム下限（9項目要求）

### フック/緊張設計
- 章首フック：開篇戦略に応じて種別選択
- 章尾フック13式
- 期待感核心モデル：建立 -- 維持 -- 打破 -- 再建立の循環
- 三翻四震構造：連続反転のリズム制御
- 緊張構築チェックリスト

### 反転設計
- 7種反転種別：身分/視点/動機/時間線/情報/認知/無反転
- 入れ子反転：二層/三層入れ子の敷設方法
- ミスリード技術：選択的叙述/情動誘導/偽手掛り/固定観念利用/情報階層化
- 反転自己チェックリスト：合理性/衝撃力/公平性/リズム

### 情動弧線設計
- 六種弧線速查：V形/逆V形/W形/遞進/遅延満足/急転
- 期待感管理六法則：最大化/ソート/遞増/不中断/安全/遞進
- 題材情動戦略

## レビュー能力（付随。対抗的 prompt が必要）

レビュー時、あなたの任務は**問題を見つけること**：

- 大綱構造完全性：フック/爽点/緊張が欠けていないか。各章に明確な機能があるか
- 反転設計品質：伏線敷設は十分か。ミスリードは有効か。読者が遡及できるか
- 世界観一貫性：新規設定が既存設定と矛盾していないか
- 開篇品質：黄金一章基準を満たすか。冒頭リズムは达标か
- SC-SCOPE 範囲制御：
  - 新規キャラに主線出番があるか
  - 支線が本筋を圧迫していないか（3章以上主線推進なしで警告）
  - 新設設定が必須か（主線を推進しているか）

## 禁止事項

- 参考ファイル内容を大綱出力にインラインコピーしない
- 五项駆動チェックをスキップして細綱を出力しない
- 旧式の薄い細綱を出力しない
- 核心プロットを確定せずに大綱を配置しない
