> 書き出しの設計手法とテンプレート。本書の黄金の3章と各章の書き出し技法。

## 書き出しの作用機序

```
第一印象（3秒以内に読者を掴む）
↓
情報投入（自然に設定と背景を開示する）
↓
期待形成（読者に「この先どうなるんだろう」と思わせる）
↓
読了欲求（書き出しの終わりで読者に読み続けさせたいと思わせる）
```

## 黄金の3章原則

### 第1章の任務

1. **主人公の確立**（誰が、どんな人か）
2. **核心的な葛藤**（今何が問題か）
3. **1つの小さな爽快ポイント**（読者にまず気持ちよくなってもらう）
4. **1つのフック**（次章を読みたくなる）

### 第2章の任務

1. **世界観の拡大**（より多くのキャラや設定を見せる）
2. **葛藤の深化**（問題をより大きく、より切実にする）
3. **能力の予告**（主人公には解決の可能性があることを示す）
4. **新たなフック**

### 第3章の任務

1. **小さな決着**（第1章で提起された問題を解決する）
2. **大きな伏線**（核心的な葛藤への布石）
3. **読者をさらに引き込む**（より多くの情報を提供する）

## 書き出しの型

### 型1：即興型（3秒以内に火がつく）
```
書き出し = 事件 + 反応 + 予告
```

**構造**：
```
事件が発生する（短く、衝撃的に）
主人公の反応（性格を示す）
続く行動（主人公が積極的に動く）
次の予告（何が起ころうとしているか）
```

**コツ**：
- 書き出しの三行以内に事件が発生する
- 設定説明は後回し
- 主人公の最初の行動が性格を決める

### 型2：引きの強い書き出し
```
書き出し = フック + 疑問 + 期待
```

**構造**：
```
強力なフックで始める（何かがおかしい）
読者の疑問を引き出す（なぜ／どうして）
すぐに続きを読ませたくなる（答えがほしい）
```

**注意点**：
- この型はフックそのものの質に依存する
- フックが強すぎると序盤に説明過多になる
- フックが弱すぎると読者が興味を失う

### 型3：日常型（スライス・オブ・ライフ）
```
書き出し = 日常 + 異変 + 展開
```

**構造**：
```
日常的なシーン（読者が共感しやすい）
小さな異変（日常が破られる予兆）
展開（異変が事件を引き起こす）
```

**注意点**：
- 日常が長すぎない（200字以内）
- 異変は自然に発生する
- 異変と事件の関連性が合理的である

## 章の書き出し技法

### 会話の書き出し
```
会話から始める（読者を直接シーンに入れる）
```
**適用**：テンポの速い章、感情的な章
**注意**：会話だけで書きすぎない（地の文とのバランス）

### アクションの書き出し
```
行動から始める（読者に「何が起こっているのか」を考えさせる）
```
**適用**：戦闘シーン、緊張した場面
**注意**：あまりにも唐突だと読者がついていけない

### タイムリープの書き出し
```
時間を超えて始める（過去／未来）
```
**適用**：回想シーン、伏線を張る場面
**注意**：読者が時間の変化に気づくようにする
