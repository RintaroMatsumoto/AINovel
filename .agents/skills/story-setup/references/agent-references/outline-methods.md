## 起承転結の四段階

### 起
新しい章の始まり。前章のフックに接続し、新たな情報や状況を提示する。

- 長さ：全体の15〜20%
- 任務：
  - 前章との接続（情緒／プロット）
  - 本章の前提条件の説明
  - 読者を本章に引き込む

### 承
章の中核部分。葛藤を展開する。

- 長さ：全体の50〜60%
- 任務：
  - 葛藤の提示（何に対立しているか）
  - 葛藤の深化（もつれ合い、誤解、チャンス）
  - 感情の蓄積（読者の情緒的負荷）
  - 伏線の内包（今後の展開への布石）

### 転
物語の転換点。

- 長さ：全体の10〜15%
- 任務：
  - 反転（意外な展開、情報の開示）
  - 爽快（期待に応える、侮辱への反撃）
  - または虐め（期待を裏切る）

### 結
章の終わり。フックと次の章の伏線。

- 長さ：全体の10〜15%
- 任務：
  - 本章のテーマをまとめる
  - 感情の余韻を残す
  - フックをかける（次章で読ませるため）

## マルチラインインタリーブ

複数のストーリーラインを同時に進行させ、章ごとに切り替える。

```
【メインライン】主人公の成長ライン。全編を貫く。
【サブラインA】感情ライン。進行は比較的遅い。
【サブラインB】敵ライン。敵の行動を示す。
【サブラインC】伏線ライン。設定の謎を明かす。
```

### 配置原則
```
章序盤：前章の伏線ラインから入る
章中盤：メインラインを中心に据える
章終盤：サイドラインを絡め、新たな伏線を張る
```

## 三行プロット法

各章を三行で要約：

```
第一行：本章のコアイベント（何が起こるのか）
第二行：本章の感情目標（読者に何を感じさせるか）
第三行：本章のフック（次章をどうつなぐか）
```

### 例
```
第一行：主人公〈翔〉が〈白虎商会〉に到着し、〈試験〉で力量を証明する
第二行：爽快感。圧倒的強さを見せつける
第三行：白虎商会の会長が突然、この試験には別の目的があると明かす
```
