> プロット設計の中核的手法。対立の張り方とサスペンス・爽快ポイントの配置技法。

## 「期待─反転」モデル

期待を利用して読者の感情を操作する：

```
期待を植え付ける（読者に「こうなるはずだ」と思わせる）
↓
期待を育てる（情報や伏線で期待を強化する）
↓
期待を裏切る（反転が出る）
↓
反転を合理的にする（遡って説明する）
```

## 「情報の非対称性」モデル

読者とキャラクターの間の情報量の差を利用する：

```
読者の知っている情報 > キャラクターの知っている情報（もどかしい）
読者の知っている情報 < キャラクターの知っている情報（サスペンス）
```

## 爽快ポイントの配置

### 爽快ポイントの種類

```
侮辱への反撃型：虐められた後の痛快な逆襲
能力披露型：新しい能力を使って敵を驚かせる
真相暴露型：隠された秘密や真実が明らかになる
逆転勝利型：劣勢からの大逆転
報酬入手型：努力が報われて宝物を手に入れる
```

### 爽快ポイントの配置ルール

```
最低でもX章ごとに1つの小爽快ポイント
大爽快ポイントはX〜Y章ごとに1つ
爽快の前に十分な虐めや蓄積が必要
爽快の強度は蓄積に比例する
虐：爽の比率はおよそ2：1を維持
```

## 伏線の配置技法

### 伏線の埋め方

```
自然に埋め込む：普通の記述や会話の中に伏線を織り込む
伏線を前面に出さない：伏線自体は読者の注意を引かないようにする
合理的なカモフラージュ：伏線はこの時点の物語に必要に見えるようにする
```

### 伏線の回収

```
適時に回収する：伏線の効果を最大化するタイミングで回収する
段階的に回収する：大きな伏線は複数回に分けて回収できる
意外な回収：伏線が予想外の形で効力を発揮する
```
