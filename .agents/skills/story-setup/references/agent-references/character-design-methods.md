> キャラクター設計の反転ツールキット。読者の予想を裏切るキャラクターを作るために使う。

## 核心手法：反転チェーン

**定義**：キャラクターの連続する行動の中に、表向きの論理とは矛盾する反転要素を埋め込むことで、深層の動機を暗示する。

**構造**：
```
表向きの行動（皆が見ているもの）→ 反転の手がかり（違和感）→ 深層の動機（本当の理由）
```

**例**：
- 表向き：高校生が毎日真面目に授業に出る
- 反転の手がかり：でも彼女はいつも二階の窓側の席を選ぶ
- 深層の動機：彼女はずっと、向かいのビルのあの少年を見ていた

### 三層反転チェーン

```
第一層：日常行動（誰でも見える）
第二層：異常行動（親しい人が気づく違和感）
第三層：核心秘密（作者だけが知っている）
```

## キャラクターの孤光（成長曲線）

### 成長曲線の型

| 型 | 説明 | 例 |
|----|------|-----|
| 成長型 | 弱い→強い | 初心者がトップに |
| 堕落型 | 強い→弱い | 英雄が悪党に堕ちる |
| 覚醒型 | 迷い→確信 | 目標を見つける |
| 救済型 | 罪→贖い | 悪党が善人に改心 |
| 破滅型 | 良→悪 | 純粋な人が現実に打ちのめされる |

### 変化のきっかけ設計

各キャラクターの転機は以下のいずれかを満たす：
1. 安全領域を打ち砕く（安逸を強いられた脱出）
2. コアバリューを挑戦する（信念を揺さぶる）
3. 決断不能を強制する（究極の二者択一）
4. 予期せぬ結果をもたらす（善行が悪報を招く）

### 罪と代償の設計

全キャラクター（特に敵役、脇役）に明確な罪と代償を設定する：

**罪の類型**：
- 利益の罪：私利のために他者を傷つける
- 信念の罪：理想の名の下に破壊を行う
- 無為の罪：行動すべき時に行動しない
- 傲慢の罪：知りながら改めない

**代償の形式**：
- 肉体的代償：身体の傷害、寿命の消耗
- 精神的代償：良心の呵責、記憶の喪失
- 社会的代償：人間関係の崩壊、名誉の失墜
- 運命的代償：因果応報、連鎖反応

## 敵役の設計

### 敵役の行動論理

敵役にも以下のものが必要：
- 自己正当化の論理（自分は間違っていないと考える理由）
- 共感できる動機（理解はできないが、共感はできる）
- 明確な欲望体系（何が欲しくて、何をしているか）

**敵役の共感度スペクトラム**：
```
純粋な悪 ←───────────────→ 理解できる敵
```

位置づけは物語のタイプに依存。読者が敵役を「理解できる」必要があるかは、物語のタイプに応じて決める。

## 脇役の設計

### 脇役の機能分類

| タイプ | 機能 | 設計の注意点 |
|-------|------|------------|
| ミラー型 | 主人公の別の可能性を映す | 特定の属性で対照を作る、全面的な対比は不要 |
| 道具型 | 特定の情報／機能を提供 | 目的を果たした後の処理を考慮 |
| 感情型 | 読者の感情反応を引き出す | かわいそう、憎たらしい、残念などの感情 |
| テーマ型 | テーマの異なる側面を表現 | 主人公と似ているが異なる選択をする |

## 感情を引き出すコツ

### 「かわいそう」を書く技術
- 被害の直接描写を避ける、転換で表現する
- 善良な人が不本意な選択を強いられる
- 大きな被害を受けても日常を保とうとする
- 他人を傷つけることを選ばない

### 「憎たらしい」を書く技術
- 読者の逆鱗に触れる行為（裏切り、侮辱、恩を仇で返す）
- 行為の対象が読者の好きなキャラクターである
- 行為のタイミングが読者の期待を裏切る
- 行為の理由が完全に利己的または悪意に基づく

### 「悔しい」を書く技術
- 一歩届かない差
- わかっているのに変えられない無力感
- タイミングが合わないすれ違い
- 理解してもらえない誤解
