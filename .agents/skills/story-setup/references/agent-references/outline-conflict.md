> プロット対立の設計手法。対立に強度と段階を持たせる方法を含む。

## 対立の発生メカニズム

### 対立の源泉

```
資源不足（全員が手に入れたいが、限りがある）
目標相反（Aの目標とBの目標が両立しない）
価値観の衝突（善悪の基準が異なる）
誤解と情報不足（知らないことが衝突を生む）
地位と権力（上下関係と支配欲求）
愛と嫉妬（独占欲と不安感）
```

### 対立の深化

```
表面的対立（誰が見てもわかる）
→ 認識の相違（同じ事実に対する解釈の違い）
→ 価値観の衝突（譲れないものの違い）
→ 存在の対立（お互いの存在そのものが挑戦である）
```

## 対立の強度設計

### 強度スペクトラム

```
口論（言葉の衝突）
↓
対抗（行動での牽制）
↓
衝突（物理的な衝突）
↓
抗争（全面戦争）
↓
決裂（和解不能）
```

## 三幕式対立構造

### 第一幕：対立の確立
```
問題の提示（何が問題か）
立場の表明（それぞれの立場）
対立の明確化（どう対立しているか）
観客の興味を引く（どちらを応援するか）
```

### 第二幕：対立の深
```
膠着状態（どちらも決定的な勝利を得られない）
戦術の応酬（駆け引きと策略）
感情の高まり（対立に伴う感情の起伏）
転換点（どちらかが突破口を見つける）
```

### 第三幕：対立の解決
```
最終対決（決着をつける）
結果の受容（結果を受け入れるか拒否するか）
影響の拡散（対立の余波）
新たな始まり（対立の解決が新たな対立を生む）
```

## 多層対立

### 同時対立の層

```
外部対立（主人公 vs 敵）
内部対立（主人公 vs 自分自身）
人間関係対立（主人公 vs 仲間）
社会的対立（主人公 vs 環境）
```

例えばキャラクターが同時に複数の対立を持つ：
- 敵と戦っている（外部対立）
- 自分の恐怖と向き合っている（内部対立）
- 仲間が自分を誤解している（人間関係対立）
- 社会のルールに縛られている（社会的対立）

これらの対立を同時に進行させ、読者を引きつけ続ける。
