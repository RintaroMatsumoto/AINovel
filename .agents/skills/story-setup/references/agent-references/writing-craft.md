> 創作技法集。視点制御、人物造形、会話テクニックなどの具体的な技法を網羅。

## 視点技法

### 視点の選択

**一人称**：
- 「私」が主体で、視野は制限される
- 没入感が強く、感情の伝達に優れる
- 主人公の推理・感情を直接書ける
- 限界：主人公の知らないことは書けない

**三人称限定的視点**：
- 「彼/彼女」が主体だが、視点は常に一人のキャラに限定
- 沒入感は一人称に劣るが、制御はより柔軟
- 「視点キャラ」の知覚・感情範囲の情報のみ書ける（神の視点は使わない）

**神の視点（三人称全知）**：
- 作者は全てを知っている
- 網文では必要な時のみ使用（設定説明、並行するシーンのクロスカット）
- 多用は禁物。読者の没入感を破壊する

### 視点切り替えの原則

```
1. 明確な切れ目（改行、または区切り記号）
2. 切り替え頻度を低く（一章につき1-2回推奨）
3. 視点キャラを明確に（読者が混乱しない）
4. 切り替えはセクションの切れ目で（段落途中での切り替え禁止）
5. 切り替え後の情緒を比較的大きく（視点切り替えにはコストがかかる）
```

## 人物造形技法

### 台詞で性格を示す

台詞の設計三原則：
1. キャラクターは自分の欲しいもののために話す
2. 台詞の内容は思考過程を反映する（論理的／直感的／感情的）
3. 台詞の調子はキャラの身分に合致する（学歴、職業、年齢）

**台詞で性格を示すテクニック**：
- 語彙の選択：簡単な語彙か複雑な語彙か
- 構文の癖：短文で区切るか長文を使うか
- 語気の強さ：断定調か疑問調か
- 沈黙の使い方：すぐに答えるか、ためらうか

### 動作で性格を示す

日常動作の選択が性格を反映する：

```
動作：コーヒーを飲む
几帳面な人：カップの取っ手を回し、少しずつ飲む
大雑把な人：一口飲み干し、カップを置く
神経質な人：カップの縁を指でなぞる
自信家：コーヒーを飲みながら目を合わせる
```

## 対話技法

### 対話の機能

```
情報伝達：プロットを進める
↓
キャラクター造形：性格を示す
↓
人間関係の構築：親疎を表現する
↓
情緒推進：感情を高める
```

良い対話は一度に複数の機能を果たす（例えば、情報を伝えながらキャラの性格も示す）。

### 台詞タグの処理

| タグのタイプ | 例 | 適用シーン |
|------------|-----|----------|
| 動詞タグ | 「やめて」と彼は言った | 単純な会話 |
| 動作タグ | 「やめて」と彼はコーヒーカップを置いた | 会話と動作の同時進行 |
| 無タグ | 「やめて」 | 連続する会話（誰が話しているか明確な場合） |

**動作タグ推奨**。読者は台詞を聞きながら動作も見ることで、より強い画面感を得られる。
