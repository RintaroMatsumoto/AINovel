> 章ごとの感情曲線設計。各章の感情目標と起伏設計。

## 感情曲線の設計原則

### 感情の型

```
高揚型：安堵 -> 喜び -> 興奮 -> 幸福感
下降型：平穏 -> 不安 -> 緊張 -> 絶望
起伏型：希望 -> 絶望 -> 希望 -> 絶望
反転型：喜び -> 悲しみ（または逆）
```

### 各章の感情位置づけ

全章を感情スペクトル上に配置：

```
第1章：導入（感情は中性）
第2章：緊張構築（不安感）
第3章：小決算（小さな安堵）
第4章：反転（感情も反転）
```

## 微視的感情テクニック

### 予告と反転

正しい感情反転のタイミング：
```
読者に期待させる（不合理な期待ではない）
→ 期待を高める（証拠と理由を与える）
→ 期待を破る（反転、しかし筋は通っている）
→ 反転がもたらす感情（驚き、落胆、歓喜）
```

### 感情のコントラスト

```
前一幕：感情の高まり（読者が笑った / 泣いた）
間奏：出来事の進行（情報の更新）
後一幕：感情の反転（笑っていた読者が泣く）
```

**原則**：
1. 前の感情状態をはっきり書く（読者が今の感情を自覚させる）
2. 十分に中間情報を与える
3. 感情の反転がプロットの必然であることを確認する（無理な反転は逆効果）

### リリースと負荷

**リリースポイント**：
- 過度の感情的負荷の後に配置
- リリースの形式：ユーモア、日常的な細部、セリフ
- 1 つのリリースの後、感情は引き続き前進

**負荷の蓄積**：
- 情報の非対称性（読者だけが知っている）
- 時間の圧迫感（制限時間がある）
- 二者択一のジレンマ（合理的な解答がない）
- 連続する挫折（成功と見せかけての挫折）

**負荷とリリースの比**：
```
軽い話：負荷1:リリース1
重い話：負荷3:リリース1
先甜後苦：負荷2:リリース3（突然の反転）
```
