> 感情を「伝える」のではなく「見せる」手法集。身体反応、行動、会話を通じて感情を表現する具体的なテクニック。

## 顔の表情・感情表現

### 表情の描写

| 説明型 | 表現型 |
|-------|--------|
| 彼は怒っていた | 彼の額に青筋が浮き出ていた |
| 彼女は悲しかった | 彼女は唇を噛みしめ、うつむいて何も言わなかった |
| 彼は驚いた | 彼の手が止まり、箸がポトリと落ちた |
| 彼女は緊張した | 彼女は爪を噛みながら、何度もスマホをチェックした |

### 文章量を減らす方法
- 「思う/感じる」を削除：思ったことを直接的・行動的に書く
- 感情説明を削除：読者自身に感じさせる
- 読者の感じることをキャラクターに言わせない：「どうしてそんなことが…」を削除
- キャラに「だって」と言わせない：自分の行動を説明させない
- キャラにストーリーを説明させない：余計な背景説明を避ける
- キャラに設定を説明させない：ありきたりな説明パートを避ける

## 身体反応

### 身体反応の種類

- 呼吸（速い、止まる、震える）
- 筋肉（硬直、震え、脱力）
- 皮膚（冷や汗、鳥肌、紅潮）
- 内臓（胃の締め付け、吐き気、口の渇き）
- 四肢（震え、麻痺、力が入らない）
- 声（震え、声が掠れる、声が裏返る）

### 身体反応の使い分け

**緊張の表現**：
- 手汗で紙が濡れる
- コップを握る手の震え
- 読んだ文章を何度も読み返す
- 無意識に爪や唇を噛む

**驚きの表現**：
- 動作が一瞬止まる
- 手に持っていた物を落とす
- 口が開いたまま閉じない
- 体が硬直する

**怒りの表現**：
- 声はかえって落ち着く
- 動作が荒くなる（物を置く音が大きい）
- 呼吸が荒くなる
- 目が見開かれる、または据わる
- 笑顔の中に冷たさがある

**悲しみの表現**：
- 食欲がなくなる
- 不眠、または過眠
- 何かにぼんやりと見入る
- 反応が遅くなる 聞き返す 会話のテンポが遅くなる
- 笑おうとしても笑えない
- すべてに無関心になる

## ジェスチャー・行動

### ジェスチャー感情

- 指で机を叩く（イライラ）
- 手で顔を覆う（困惑、恥、悲しみ）
- 腕を組む（警戒、防御）
- 手を振る（否定、拒否）
- 肩をすくめる（無関心、無力）
- 頭を振る（否定、諦め）
- うなずく（同意、承認）
- 指を指す（非難、強調）

### 特殊行動暗示

以下の特殊行動は特定のキャラクターのみが行い、性格と習慣を示すために用いる：
- 会話中にタバコを吸う（リラックス、考え中、または回避）
- 緊張で頭を掻く（照れ、または自信のなさ）
