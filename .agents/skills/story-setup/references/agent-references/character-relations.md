> キャラクター間の関係性設計のコア。血縁、利害、感情、対立など、複数の軸にわたる関係モデルを含む。

## 関係設計の基礎

### 関係の次元

```
血縁関係（生まれつきの繋がり）
利害関係（資源の分配と競合）
感情関係（愛憎、親しさ、信頼）
地位関係（権力、身分の上下）
成長関係（師弟、ライバル、導き手）
```

### 関係の表示方法

- 各関係は複数の次元を持ち、単一の関係に単純化しない
- 関係の変化は具体的な事件を通じて表現する
- 関係の非対称性を維持する（AのBに対する感情とBのAに対する感情は異なる）
- 依頼と依存を区別する（依頼は資源が必要、依存は感情が必要）

## 関係のダイナミクス

### 関係強化のきっかけ
```
共通の敵に直面 -> 生死を共にする -> 秘密を共有する -> 利益の相互依存
```

### 関係悪化のきっかけ
```
価値観の衝突 -> 利益の対立 -> 誤解の蓄積 -> 裏切りと背信
```

### 関係逆転の手法

1. **依存の逆転**：弱者が強者を制する鍵を握る
2. **立場の逆転**：保護者が保護される側になる
3. **認識の逆転**：長年敵と思っていたら実は味方だった
4. **価値の逆転**：軽蔑していた人の本当の価値をようやく理解する

## 感情線の設計

### 感情のタイプ

| タイプ | 特徴 | 適用シーン |
|-------|------|-----------|
| 共鳴型 | 価値観と趣味が合い、自然に引き寄せられる | パートナー、親友 |
| 対抗型 | 衝突の中で惹かれ合う | 恋敵、犬猿の仲 |
| 補完型 | 互いに相手にないものを持つ | 師弟、パートナーシップ |
| 救済型 | 一方が他方を闇から救い出す | 恩人、カウンセラー |
| 寄生型 | 一方が他方を利用し搾取する | 加害者と被害者 |

### 感情の推進階梯

```
出会い（第一印象）-> 接触（相互理解）-> 深化（信頼構築）
-> 試練（関係の試練）-> 転換（関係のアップグレードまたは終了）
```

## 群像劇の設計

### 勢力分布図

```
　　　　　　　　　　勢力A（トップ）
　　　　　　　　／　　　｜　　　　＼
　　　　 幹部1　　　幹部2　　　幹部3
　　　　／　　＼　　　｜　　　／　　＼
　　 メンバー メンバー メンバー メンバー メンバー
```

勢力間の境界線と接触点を明確にする。

### 各勢力争いの核

| 勢力 | 核となる利益 | 主要な対立相手 | 内部矛盾 |
|------|-------------|---------------|---------|
| A | 地下取引の支配権 | B、C | 新旧派閥の争い |
| B | エリアの縄張り | A、D | 後継者争い |
| C | 政治資本 | A、行政 | 穏健派と強硬派 |
| D | 情報ルート | B、行政 | 金銭的な仲違い |

### キーパーソン関係マップ

```
　　　　A（元締め）
　　　／  ↓  ＼
　　B──C──D
　　｜＼／｜＼／｜
　　E  F  G  H  I
```

実線は強い関係、点線は弱い関係、矢印は権力の方向。

### 内部関係の細かい調整

派閥内部の動態を含める：
- 新旧派閥の対立（世代間の闘争）
- 利益分配の不満（不平等感）
- 後継者争い（権力の真空）
- 理念の対立（路線闘争）
