> サスペンスとフックの高階設計。単一の章のフックを超え、長期間持続するサスペンスモデルと情報制御技法。

## サスペンスの本質

**サスペンス = 情報の非対称性 + 時間的切迫感**

```
情報の非対称性：読者はキャラクターより多くを知っている／少なく知っている
時間的切迫感：ある時点までに結果が明らかになる必要がある
```

## サスペンスの分類

### タイプ別

| タイプ | 特徴 | 例 |
|-------|------|-----|
| 秘密型 | 核心秘密が隠されている | 誰が裏切ったのか |
| 選択型 | 決断を迫られる | 救うか、殺すか |
| 競争型 | 限られた資源の奪い合い | 宝を探すレース |
| 危険型 | 危険が迫っている | 爆弾が爆発するまであと10分 |
| 推理型 | 謎を解く | 密室殺人事件 |

### 持続時間別

| タイプ | 持続時間 | 適用 |
|-------|---------|------|
| 瞬間型 | 1章以内 | 戦闘の結果、選択への反応 |
| 短期型 | 1〜5章 | 事件の解決、敵との対決 |
| 中期型 | 5〜20章 | 一つの段階の主要な対立 |
| 長期型 | 全巻 | 核心的な謎、最大の陰謀 |

## 情報制御技法

### 情報の段階的開示

```
情報のヒント（伏線）→ 情報の一部開示 → 情報の大部分開示 → 情報の完全開示
```

各段階の間隔を調整し、読者の推理ペースをコントロールする。

### 誤情報の誘導

```
誤った手がかりを提示する（読者に誤った推理をさせる）
→ 後に誤情報を覆す（反転で衝撃を与える）
```

### 効果的な情報制御

```
常に読者に一歩先を行かせる：
情報が多すぎる（読者が先に読めてしまう）→ サスペンスがない
情報が少なすぎる（読者が推理できない）→ サスペンスが退屈
適切な情報量（読者が推理できるが確定できない）→ 最良のサスペンス
```

### 「マジック」：見せることで隠す

最も重要な情報は、最も目立つ場所に隠す：

```
重要な情報を最も平凡な細部として提示する
→ 読者はこの情報に気づく
→ しかしその重要性には気づかない
→ 反転した時に読者は深く印象に残る
```

**適用方法**：
1. その情報を含む文脈が読者の注意を本質からそらすようにする
2. 「最も目立たないように目立たせる」：説明として流すように書く
3. 真の役割が明らかになる時まで、情報がすでに提示されていることに読者が気づかないようにする

## 高階サスペンス構造

### 「時限爆弾」構造

```
特定の時点／出来事による制限
各章で時間が迫る
クライマックスで爆発
爆弾解除／爆発後の処理
```

### 「ロシア人形」構造

```
問題Aが明らかになる（解決したと思わせる）
→ 問題Aの解決が問題Bを明らかにする（より深い陰謀）
→ 問題Bの解決が問題Cを明らかにする
→ ……
```

各層の陰謀はより深く、より強力。

### 「盲人が象を撫でる」構造

```
複数の勢力が同一の秘密を追う
各勢力が秘密の一部を握る
誰も完全な真実を知らない
徐々に情報を統合し、完全な真実を明らかにする
```

## サスペンスの維持技法

### 新たな疑問の投入

一つのサスペンスが解決する前に、次のサスペンスを投入する：

```
サスペンスA（確立）→ サスペンスB（確立）→ サスペンスA（解決）→ サスペンスC（確立）
```

### サスペンスのエスカレーション

```
小問題（この町から出られるか）
→ 中問題（敵の包囲から逃れられるか）
→ 大問題（この世界を救えるか）
```

### 期待と反転

```
期待に応える（読者の期待通りに進む）
→ 期待を覆す（意外な反転）
→ 教訓を残す（反転から教訓を引き出す）
```

## サスペンスの配置

### 情報制御曲線

```
序盤：情報の非対称性を確立（謎を提示）
中盤：情報の段階的開示（手がかりを提供）
終盤：情報の大部分開示（反転）
最終盤：情報の完全開示（謎を解明）
```

### 読者の感情曲線

```
序盤：好奇心（「これはどういうことだ？」）
中盤：推理欲（「真実はこうだに違いない」）
終盤：衝撃（「まさかそうだったとは！」）
最終盤：満足感（「なるほど、つじつまが合った」）
```
