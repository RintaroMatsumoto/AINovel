> 各ジャンルの書き方の型とテンプレート。

## 型を分解する方法

```
型 = プロットモデル + リズムパターン + 感情曲線 + 章の型
```

### プロットモデル
- メインプロットとサブプロット
- 核心対立と段階的反転
- 伏線の設置と回収のタイミング

### リズムパターン
- 章ごとのリズム配分
- 感情曲線の谷と山の間隔
- 爽快ポイントと休息ポイントの配分

### 章の型
- 起承転結の配分
- 引きと伏線の頻度
- 爽と虐の配分比率

## ジャンル別型分析

### 都市爽文 書き方の型

**5章サイクル**：
```
第1章 問題提起（面倒なことが発生）
第2章 能力発揮（問題解決能力を示す）
第3章 対立激化（敵の反撃、または新たな問題）
第4章 爽快解決（見事な解決）
第5章 引き（新たな展開、または次なる敵の予兆）
→ 次のサイクルへ
```

**解決の型**：
```
問題の発生 -> 読み手をイライラさせる -> 解決の伏線を張る -> 爽快に解決
```

### 純愛文 書き方の型

**感情進行テンプレート**：
```
出会い（きっかけ、偶然の出会い）
↓
倦怠期（誤解、すれ違い、第三者）
↓
感情の芽生え（一緒に困難を乗り越える）
↓
告白（感情のピーク）
↓
障害（家族、社会、身分）
↓
両想い（すべてを乗り越える）
```

**虐め → 償いの節**：
```
虐め（一方が他方を傷つける）
↓
決裂（別れ）
↓
償い（虐めた側の反省）
↓
再燃（もう一度）
↓
和解（一緒に終わる）
```

### 玄幻文 書き方の型

**成長テンプレート**：
```
弱い出発点（廃嫡、貧しい家柄）
↓
偶然の出会い（師匠、空間、秘籍）
↓
急速なレベルアップ（基礎を固める）
↓
初めての戦い（同レベルの者に勝利）
↓
侮辱される（強い者に阻まれる）
↓
修練の突破（新たな能力を得る）
↓
侮辱への反撃（痛快に打ち負かす）
```

### サスペンス文 書き方の型

```
謎の配置（事件の発生）
↓
調査（手がかりを集める）
↓
偽りの解決（容疑者を特定するが間違いと判明）
↓
反転（新たな手がかりが真実を示す）
↓
謎の解明（真犯人を暴く、または意図的に伏線を残す）
```
