> 章末の引きの設計手法。章末フックと読者に次章を読ませる方法。

## フックの作用機序

```
情報の非対称性（読者は不完全な情報を保持）
↓
好奇心の活性化（不完全な情報が理解欲求を刺激）
↓
読み続けたい欲求（「何が起きたのか」を確かめるために読み続ける）
```

## フックの分類

### タイプ1：逆転型フック
```
直前の判断が覆される
例：勝利したと思ったら敵の援軍が現れる
```

### タイプ2：秘密型フック
```
新たな秘密が明らかになる（が完全には明かされない）
例：「お前の本当の身分は…」
```

### タイプ3：危機型フック
```
主人公が新たな危機に直面する
例：ドアが開き、銃口が彼の眉間を狙っていた
```

### タイプ4：選択型フック
```
主人公が難しい選択を迫られる
例：「一つの命か一万の命か、お前が選べ」
```

### タイプ5：情報型フック
```
新たな重要な情報が明らかになる
例：「実は真犯人はまだ生きている」
```

## フックの設計ルール

### タイミング
- 毎章の末尾にフックを配置する（緩い章は除く）
- 章途中でもフックを配置可能（読者を引きつけるため）
- 巻の終わりは大フック（続巻を期待させるため）

### 強度
- 通常章：中程度の強度（秘密型、選択型）
- 山場：強い強度（逆転型、危機型）
- 過度章：軽いフック（情報型）
- 緩い章：フックなし（読者の息抜きのため）

### フォーマット
- フックは独立した一行（空白行を空ける）
- フックは感情を高める（説明しない）
- フックの後に地の文を続けない

## よくあるミス

### 説明過多
```
誤：彼は目の前の光景に驚いた。それは…
正：彼は一歩後退した。その光景は——
```

### フックの出し惜しみ
```
誤：彼はドアを開けた。驚くべきことに中から出てきたのは…
正：ドアが開いた——彼は全身を硬直させた。
```

### 前置きが長い
```
誤：彼は心の中で激しく葛藤した末に、ついに重い口を開いた…
正：「本当のことは——お前の父親はまだ生きている。」
```

### フックと解決策の距離
```
近すぎる：フック直後に解決策が出てくる（読者の期待感が不十分）
遠すぎる：フックから数章後に解決策が出てくる（読者が忘れる）
適切：フックから1〜3章以内に解決策（期待感を保ちつつ引っ張らない）
```

## フックの連鎖

```
第1章フック：秘密が明らかになりかける（完全には明かされない）
第2章フック：同じ秘密が関わる新たな手がかり
第3章フック：秘密が少しずつ明らかになる
第4章フック：秘密に関わる危機が発生する
第5章：秘密が明らかになり、新たな秘密の伏線が張られる
```
