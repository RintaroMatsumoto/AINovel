> プロットリズムの設計手法。展開速度と章ごとのリズム配分。

## リズムの次元

### 展開速度

```
遅い ────────────→ 速い
スライス・オブ・ライフ  事件連続発生
```

**速度の調整方法**：
- 遅くする：心理描写、情景描写、会話を増やす
- 速くする：事件の頻度を上げ、心理描写を減らし、時系列を短縮する

### 緊張度

```
弛緩 ────────────→ 緊張
リラックス、日常         切迫、危険
```

**緊張度の調整方法**：
- 上げる：情報の非対称性、時間制限、危険の接近
- 下げる：問題の解決、ユーモア、リラックスした会話

### 情報密度

```
低い ────────────→ 高い
ほとんど新情報なし     大量の設定／伏線
```

**情報密度の調整方法**：
- 上げる：複数の情報を同時に投入、伏線を密集させる
- 下げる：リラックスした会話、日常の細部

## リズム型

### 上昇型

```
事件 -> 推進 -> 激化 -> ピーク -> 反転
```

**用途**：戦闘、対決、感情の高まり

### 下降型

```
平穏 -> 異変 -> 緊張 -> 爆発 -> 沈静
```

**用途**：謎解き、サスペンス、緊張の蓄積

### 波型

```
弛緩 -> 緊張 -> 弛緩 -> 緊張
```

**用途**：群像劇、多線進行

## 章ごとのリズム配分

### 標準章のリズム配分

```
【序盤】前章との接続、状況の設定（遅い）
【中盤】葛藤の提示と深化（徐々にテンポアップ）
【終盤】反転または爽快（テンポ最速）
【フック】次章へ（突然の停止）
```

### 緩い章のリズム配分

```
【序盤】日常の描写（遅い）
【中盤】キャラクター間の交流（緩い）
【終盤】軽いフックまたはなし
```

緩い章は主に次の山場への布石として使う。

### 激しい章のリズム配分

```
【序盤】事件が直ちに発生（速い）
【中盤】連続する葛藤（継続的に速い、強い）
【終盤】決着（急速な低下）
```

## リズム感知技法

### 文字数のコントロール

```
日常／描写：500〜1000字
対話／葛藤：1000〜2000字
戦闘／ピーク：1500〜2500字
```

### 段落の長さコントロール

```
リラックス時：段落長め（ゆったり読ませる）
緊張時：段落短め（一気に読ませる）
激化時：一文段落（テンポを強調する）
```

### 会話密度コントロール

```
リラックス時：会話の割合が低い（動作主体）
緊張時：会話の割合が高い（情報交換）
感情時：会話の割合が非常に高い（感情表現）
```
