> 各ジャンルの核心メカニズムと基本テンプレート。読者の期待に応える最低要件を定義する。

## 男性向けジャンル

### 玄幻の核心メカニズム

**読者の核心欲求**：
```
力の成長（明確なレベルアップと能力の向上）
宝と運（思いがけない収穫と偶然の出会い）
美女と兄弟（地位に応じた女性と忠実な仲間）
侮辱への反撃（辱められた後の痛快な復讐）
```

### 仙侠の核心メカニズム

**読者の核心欲求**：
```
長生への追求（寿元の制限と突破）
資源の争奪（霊薬、鉱石、秘境）
因縁と因果（前世の因縁、因果の報い）
飛翔と昇天（位階の突破と境界の超越）
```

### 都市の核心メカニズム

**読者の核心欲求**：
```
金持ちになる（ビジネスの成功、投資の勝利）
権力の掌握（地位の向上、権力の拡大）
美女を娶る（複数の女性との感情の発展）
侮辱への反撃（軽蔑された後の逆転）
```

### 武侠の核心メカニズム

**読者の核心欲求**：
```
武術の追求（最強の武術を巡る争い）
江湖の義理（恩讐、義侠心、兄弟の絆）
正邪の対立（正義と悪の闘争）
奇遇と偶然（洞穴での秘籍、隠れ里での伝授）
```

## 女性向けジャンル

### 現代言情の核心メカニズム

**読者の核心欲求**：
```
男神が深く愛する（自制心を失うほど夢中になる）
虐めと償い（感情の苦しみと和解）
身分差を超える（身分違いの恋と障害を乗り越える）
守護と献身（無条件の愛情と犠牲）
```

### 古代言情の核心メカニズム

**読者の核心欲求**：
```
宮廷での戦い（寵愛を争い、正妻の座を争う）
政略結婚（力の結びつきと感情の芽生え）
復讐と逆襲（前世の虐めへの反撃）
身分の偽装（男装、身分を隠す）
```

## サスペンス・ミステリー

### サスペンスの核心メカニズム

**読者の核心欲求**：
```
謎の設定（明確な謎と段階的な解明）
推理の過程（読者も一緒に推理できる伏線）
反転（意外だが納得の結末）
恐怖の雰囲気（緊張感と不安感の持続）
```

### ミステリーの核心メカニズム

**読者の核心欲求**：
```
完全なトリック（論理的に欠陥がない）
公正な推理（読者に同じ情報を提供）
意外な犯人（意外性と合理性を兼ね備えた犯人）
収束する伏線（すべての伏線が合理的に回収される）
```
