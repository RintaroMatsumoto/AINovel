> 対戦・格闘シーンのための文体ガイド。フェイス（顔面）を重視した格闘描写の技法を網羅。

## 核心方法：フェイス（面子）読心術

フェイス（面子）に焦点を当てた格闘シーンは、観客に「お互いのフェイス（面子）を読む」ように導く：

```
行動
→ フェイス（表面の動き）
→ 読者の推理（内心の動き）
→ 心理的衝撃
```

読者はキャラクターの表と裏（外見と内心）の差を感じ取る。

## 頭部描写テクニック

### 「目」の技法

目以外の部位も「見る」ことに参加する：

```
頭を上げる / 下げる / 傾ける：身長差、ライトアングルの構え
眉：位置と動きの滑らかさ
頬：緊張 / 脱力、口の端の連動
首：太さと角度
肩：拳と肩甲骨の位置関係
```

### 「顔面描写」技法

```
全体の輪郭と角度：力を入れたり抜いたりする感じ
前頭骨と側頭骨：光的な立体感
汗と埃：試合の激しさを暗示
傷と腫れ：継続的なダメージ
表情：抑制された表情（不気味な静けさ）
```

## リズムとフレーミング

### 「静→動」の対比技法

```
構えの静（スタンス、拳の位置）
攻撃前の静（攻撃のタイミングを見計らう）
攻防交替の静（探り合い）
決着後の静（勝者と敗者の間）
```

### フレーム内の視線誘導

格闘シーンは絵コンテとして設計する：

```
中景：二人の距離感（サークルコントロール）
クローズアップ：手、足、視線（細部）
ワイドショット：フィニッシュブローの選択
主観視点：打たれる側が見るもの
```

### 音効技法

```
無音状態：打撃が耳をつんざく、相手の（聞こえない）叫び声
聴覚的反応：打撃、防御の反響、ステップワーク
環境音：観客の呼吸や一瞬の静寂
```

## 打撃の描写

### パンチの新しい描写方法

打撃の痛覚以外の次元を引き出す：

```
浮遊感：避けたり、打撃を外した時のバランスの崩れ
爆発感：打撃が当たった時の衝撃、力の放出
圧迫感：相手のプレッシャーやプレッシャーの突然の解消
ねじれ感：打撃を当てる前の筋肉のねじれ
```

### フィニッシュブローの蓄積

```
序盤：探り合い、読み合い
中盤：互いにダメージを受け始める（消耗戦）
終盤：相手の崩れを捉える（隙）
ラスト：勝負を決める一撃
```

### 防御描写

```
固い防御：カバー、呼吸の止め方
柔らかい防御：受け流し、体をひねる
防御の崩壊：カバーが崩れ、打たれる前の兆候
カウンター：相手の攻撃を利用する
```
