> キャラクター設定の核心情報。キャラクターを動かす原動力と信念体系、および外見的特徴と話し方の特徴を含む。

## 書き方の順序

```
欲望の核心 -> 価値観と信念 -> 能力と技能 -> 外見的特徴 -> 話し方の特徴
```

## 欲望の核心設計

### 欲望の三層構造

```
最表層：目先の目標（例：今月の家賃を稼ぐ）
中間層：行動の動機（例：自立した生活を証明する）
最深層：価値の欲求（例：尊重されたい、愛されたい）
```

### 欲望の衝突設計

- 欲望A vs 欲望B —— 主人公の内部対立の核心
- キャラの欲望 vs 他人の欲望 —— キャラ間の対立の核心
- キャラの欲望 vs 世界のルール —— 社会・環境との対立の核心

## 価値観と信念体系

### 信念の形成要因
- 記憶に残る幼少期の出来事（一番大きなトラウマ／歓喜）
- 家族の価値観の影響（受容／反発）
- 重要な人生経験（転機となった出来事）
- 環境の制約（時代、身分、経済）

### 信念の表現方法
- 日常会話での口癖や態度（キャラクターがよく言う言葉）
- 重要な決断での選択
- 極限状況での本能的反応
- 他人への価値判断

### 信念の崩壊と再構築

```
信念の確立 -> 挑戦に直面 -> 疑念と動揺 -> 崩壊/転換 -> 再構築
```

## 能力と技能設定

### 能力成長の三段階
```
初級：基礎（基本的な生存技能）
中級：実践（体系的に学んだ専門技能）
上級：創造（独自の技能体系の形成）
```

### 成長の道筋

各主要技能は具体的な成長経路を設定する：
- 初期の出発点（能力の原点）
- 学習の過程（師弟関係、自己研鑽、実戦の蓄積）
- 突破の契機（重要な実戦、師の指導、頓悟）
- 代償と代価（能力向上に伴う肉体的／精神的代償）

## 外見的特徴

- 年齢に合致（幼すぎる／老けすぎるは理由が必要）
- 身分に合致（肉体労働者／オフィスワーカーの外見の差異）
- 職業的特徴（トレーダーは手と目の疲労、格闘家は身体の傷跡など）
- 象徴的習慣（首をかしげる、指で机を叩く、爪を噛むなど。一貫性があり、過度にならない）

### AI生成の顔写真からの脱却

1. 複数の特徴を積み重ねるな、一点を強調しろ
2. 細部の質感を捉えろ（ほこり、傷、しわ、使い込まれた道具の感触）
3. 容赦のない肉眼——全身鏡の前で、完全に客観的に自分を見るようにキャラクターを書け

## 話し方の特徴

### 表現手段
- 口癖（特定の語彙、間投詞、相槌）
- 語気と語速（早い／遅い／重い／軽い／遮りたがる／言いよどむ）
- 常用の修辞（たとえ話が多い／比喩が嫌い／大げさか控えめか）
- 身分に応じた言葉遣いの選択
  - 社会的地位：上層部は委婉、中層部は現実的、底辺層はストレート
  - 教育度合い：語彙量、文法の正確さ、業界用語の使用
  - 職業背景：専門用語の習慣的流出、業界用語
  - 年齢差：流行語、時代語、世代間ギャップ

### 年齢と言語段階
- 子供：語彙制限、単純な文構造、直接的な欲求表現
- 青年：流行と叛逆のコード切り替え、過激な語気
- 中年：安定した語気、状況に応じた調整、含みを持たせることができる
- 高齢：時代特有の語彙、繰り返し、スロー

### 緊張時・平常時のコード切り替え

全キャラクターに必須。異なる圧力下での話し方の変化は最も個性を表現する。

```
【平常時】「佐藤さん、このプランにはまだ改善の余地があるんじゃないでしょうか？」
【緊張時】「おいおい、これはやばいぞ。俺たちの番だ。」
【極限時】「………（無言／わずかな身体言語）」または『………』
```

同じ人でも圧迫されると、語彙が減り、語気が不安定になり、あるいは口調が変わる。

### 知能と言語表現の不一致

**高知能・寡黙型**（例：ターミネーター、ワトソン）
- 発言は核心を突く、最短経路
- 日常会話は「情報交換」、共感や社交辞令は最小限
- 「おはよう」にも「はい」と答え、その日のスケジュールの確認に移る

**高知能・雄弁型**（例：シャーロック、トニー・スターク）
- 会話に大量の詳細と連想が含まれる
- 聞き手の理解速度に合わせるのが難しい
- 皮肉、たとえ話、ほのめかしを好む

**低知能・可愛い型**（例：ドラえもんののび太、ワンピースのチョッパー）
- 単純な語彙、直接的な欲求表現
- 強い感情の言葉、誇張された比喩
- 固有名詞や概念を間違えやすい

**低知能・策略型**（例：さまざまな作品の「田舎の年長者」）
- ことわざや格言が豊富、口調は安定している
- 行間を読ませる、暗示が得意
- 単純な言葉に複雑な解釈の余地がある

このようなキャラはここには表示されず、ユーザーが自らの創作のために設定ファイルを配置する。
