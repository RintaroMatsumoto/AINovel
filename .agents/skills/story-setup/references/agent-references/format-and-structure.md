> 網文本文の書式規則と段落構造標準。

## 基本原則

### 書式の統一

全巻で一貫した書式を維持：
1. 会話文の句読点統一
2. 地の文の段落字下げ統一（字下げなし / 全角2文字）
3. シーン区切りの記号統一
4. 章タイトルのナンバリング統一
5. 改行ルール統一

### 段落ルール

- 段落は長すぎない（PC画面で 5〜8 行、スマホ画面で 3〜5 行）
- 会話文は独立した段落（「」は単独で一行）
- 長台詞の会話は適宜分割
- 段落は話題の切れ目で変える
- 一つの段落に一つの動作／視点を推奨

### 改行ルール

- 改行後に一行空ける：場面転換、時間の経過、視点変更
- 改行後に空けない：会話の応酬、連続動作、同じ場面内の異なる人物の行動
- 一行空けの連続使用は控える（3 行以上の空白は不可）
- 会話文中の改行：
  - 同じ人物の連続発言は一文一行
  - 異なる人物の発言は改行して別々に書く

### 会話文の書式

**標準形式**：
```
「おはよう。」と彼は言った。
「おはよう。」彼女はあくびをしながら言った。
「今日、遅刻したね。」
「うん……電車が遅れてさ。」
```

**三点リーダーの処理**：
- 三点リーダーを使って言いよどみを表現できるが、多用は禁止
- …（三点）または……（六点）で、それ以上は冗長
- 三点リーダーの後に句点を打たない

**感嘆符の処理**：
- 感嘆符の連続使用は禁止（!! / !!! は不可）
- 感嘆符と疑問符の併用は禁止（!? / ?! は不可）
