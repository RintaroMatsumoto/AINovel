> 本文完成後の品質検査リスト。プロット、キャラクター、文章の各次元をカバーする。

## プロット品質チェック

### プロットの整合性
- [ ] 章のプロットは大綱と合致しているか
- [ ] 章内の因果関係は論理的か
- [ ] 前の章の伏線は回収されたか
- [ ] 新しい伏線は適切に埋め込まれたか
- [ ] 時間線に矛盾はないか

### 展開の合理性
- [ ] キャラクターの行動はその性格に合致しているか
- [ ] 重要な決断には十分な動機があるか
- [ ] 反転は意外だが筋が通っているか
- [ ] 戦闘力設定は一貫しているか
- [ ] 情報の開示タイミングは適切か

## 感情品質チェック

### 爽快ポイントの効果
- [ ] 爽快ポイントの前に十分な抑圧があったか
- [ ] 爽快ポイントの強度は期待に応えているか
- [ ] 爽快ポイントの後の余韻は十分か
- [ ] 虐の度合いは爽の強度と釣り合っているか

### 感情表現
- [ ] 感情の説明ではなく動作で表現しているか
- [ ] 読者の期待を適切にコントロールしているか
- [ ] 情報の非対称性はサスペンスを生んでいるか
- [ ] 感情の起伏には段階があるか

## 品質チェックリスト

### 流れの確認
- [ ] 冒頭はすぐに読者を引き込めるか（三行以内）
- [ ] 会話は自然でキャラクターの性格を反映しているか
- [ ] 描写は詳細で、画面にイメージが浮かぶか
- [ ] 展開はテンポよく、だらだらしていないか
- [ ] 章末で次章を読みたくなるか
