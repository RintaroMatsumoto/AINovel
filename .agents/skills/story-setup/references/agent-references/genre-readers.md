## 男性向け読者分析

### 玄幻読者
- **年齢層**：16-28歳が主力
- **読書シーン**：移動中、寝る前、暇つぶし
- **読書速度**：高速読書、飛ばし読み。設定説明は嫌い
- **求めているもの**：爽快感、スピード感、成長の達成感
- **求めていないもの**：ウダウダした要素、引きずる恋愛要素、説教くさい要素

**好まれる要素**：
```
レベルアップと習得：読者は過程よりも結果を見たい
装備を拾う・秘籍を拾う：サプライズの楽しみ
侮辱と反撃：快感を最大化
美女多数：主人公の能力を証明する
敵を倒す：痛快。倒した後の処理も見たい
```

**嫌われる要素**：
```
序盤で強すぎる：読者の没入感を失わせる
戦闘描写が長すぎる：読者の忍耐力を削ぐ
設定説明が多すぎる：読者を退屈させる
主人公が優柔不断：読者をイライラさせる
```

### 都市読者
- **年齢層**：22-35歳が主力
- **読書シーン**：帰宅後、週末
- **読書速度**：中程度、ビジネスや権謀術数の部分はじっくり読む
- **求めているもの**：リアリティ、爽快感、お金持ち体験
- **求めていないもの**：非現実的な設定、幼稚な敵対

### 仙侠読者
- **年齢層**：25-40歳の長期読者
- **読書シーン**：熟読、自習や作業の合間
- **読書速度**：じっくり読む、世界観の詳細を重視
- **求めているもの**：長大な世界観、道の追求、因縁と因果
- **求めていないもの**：幼稚な対立、つじつまの合わない設定

## 女性向け読者分析

### 言情読者
- **年齢層**：18-30歳が主力
- **読書傾向**：感情の引っ張り、浮き沈みへの没入
- **求めているもの**：感情の盛り上がり（倦怠期→両想い）、CP感
- **求めていないもの**：すれ違いの繰り返し、ただの虐めっ放し

**好まれる要素**：
```
両想い爆発：これまでの蓄積が一気に発散される瞬間
独占欲：独占欲を示す相手
身分の覆る：相手が実はすごい人物だった
```

## クロスオーバー分析

### 男性読者 → 女性向け作品
- 入口：アニメ・ゲーム原作
- 好み：強い女主人公、成長ストーリー、男装設定
- 嫌い：感情のウダウダ、理不尽な虐め

### 女性読者 → 男性向け作品
- 入口：ドラマ化作品、話題作
- 好み：複雑な感情描写、群像劇、CP要素
- 嫌い：女性の軽視、レベル上げばかり

## プラットフォーム別読者プロフィール

### 七猫読者層
- 年齢層：25-50歳
- 読書習慣：音声配信。いわゆる「ながら聴き」
- 好み：長編、スライス・オブ・ライフ
- 特徴：読書に対して寛容。飛ばし読みが多い
- 金銭感覚：広告モデルに慣れている。課金には慎重

### 起点読者層
- 年齢層：20-40歳
- 読書習慣：熟読、章ごとにコメント
- 好み：クオリティ志向。設定とプロットを重視
- 特徴：粘着質。長期間追いかける
- 金銭感覚：課金に慣れている。質にこだわる

### 晋江読者層
- 年齢層：18-35歳
- 読書習慣：感情重視、CP好き
- 好み：感情の引っ張り、キャラの魅力
- 特徴：熱心だが移動しやすい
- 金銭感覚：選んで課金。作品の質による
