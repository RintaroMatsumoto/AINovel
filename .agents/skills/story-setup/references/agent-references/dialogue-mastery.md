> 会話文のコアテクニック。会話で情報を伝え、キャラクターを造形し、感情を推進する方法。

## 会話の役割

```
情報伝達（プロットを進める）
キャラクター造形（性格を示す）
感情推進（親密／疎遠を表現する）
リズム調整（叙事の速度を変える）
```

## 会話のテクニック

### サブテキスト（言外の意味）

キャラクターの本当の意味は言葉の裏に隠れている。表の会話と裏の会話の乖離が大きいほど、ドラマチックで面白くなる。

**表の会話と裏の会話の乖離**：
```
「大丈夫ですか？」（表の関心）
「まだ生きてるよ。」（裏の不満）
```

### 遮りの設計

遮りで会話の迫力を増す：
- 情報遮断：聞き手が重要な情報を遮る
- 感情遮断：話し手が感情を抑えられず声を詰まらせる
- 外部遮断：突然の出来事が会話を中断する

遮りは会話の中で実際に使う。遮る動作も良い：
- 「私、実は——」
- 「言わなくていい。」
- 「違うんだ、これは——」
- 「もういい。」

### 会話のリズム

**リズムのコントロール**：
- 早いリズム：短文の応酬、遮り、語気助詞
- 緩いリズム：長い台詞、沈黙、動作の挿入
- 緊張時：単語（または単音節）の応酬
- リラックス時：助詞で間を持たせる

**長ぜりふの処理**：
- 一つの長台詞は 3 文を超えない
- 超える場合は、遮りや動作で分割する
- 長台詞はキャラの感情が高ぶった時に使用し、日常的には使わない
- 長台詞には必ず感情の理由がある

### 会話の多様性

**語気詞の使い分け**：
同じ意味でも異なる語気が性格を反映する：
- 「うん。」（承認、短い）
- 「うーん……」（ためらい、考慮中）
- 「うん？」（疑問、聞き取れなかった）
- 「うん！」（肯定、興奮）

**話し方の切り替え**：
キャラが異なる相手に対して話し方を変える設定：
- 目上の人に対しては敬語
- 親しい人に対してはフランク
- よそよそしい人に対しては素っ気ない
- 緊張時は早口
- 嘘をつく時は余計な言葉が増える

### 各キャラの話し方

- 語彙の選択（カタカナ語が多い／和語が多い）
- 文の長さ（一言で済ます／長々と説明する）
- 語気の強さ（断定調／曖昧調）
- 修飾の多さ（簡潔／冗長）
- 疑問文のタイプ（開かれた質問／閉じた質問）
