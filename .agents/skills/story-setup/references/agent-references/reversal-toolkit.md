> 反転（どんでん返し）設計の各種手法とテンプレート。読者の予想を裏切るプロット反転技法。

## 反転の基本原理

### 「期待」と「現実」の乖離

```
読者の期待 ≠ 発生した現実
反転の強度 = 期待の強さ × 乖離の大きさ
```

### 反転の誠実さ

読者が振り返った時、反転は合理的でなければならない。「神の一手」ではなく、以前の伏線と矛盾しないこと。

## 反転の分類

### 情報型反転

```
読者が以前に入手した情報が不正確／不完全であることが判明する
核心：情報の非対称性を利用する
```

**例**：
- 善意のキャラが実は黒幕だった
- 死んだと思っていた人が実は生きている
- Aの行動の動機が読者の想像と全く違う

### 立場型反転

```
キャラクターの立場や関係が反転する
核心：固定観念を覆す
```

**例**：
- 敵が実は味方だった
- 守るべき人が実は利用していた
- 味方が裏切ったが、その裏切りに別の意図があった

### 価値型反転

```
善悪、正邪の判断基準が反転する
核心：「正義」の相対性を示す
```

**例**：
- 主人公が追う正義が実は不正義だった
- 敵の行動には実は正当な理由があった
- 社会のルールそのものが間違っていた

### 因果型反転

```
原因と結果の関係が反転する
核心：「結果」から「原因」を再推論する
```

**例**：
- 暗殺事件の真のターゲットは別の人物だった
- Aの死の原因はBの行動ではなくCの謀略だった
- 「結果」は「原因」によって招かれたものではなく、別の「原因」が関連している

## 反転設計の連鎖

### 3段反転テンプレート

```
第1段：一見したところ
第2段：調査により異なる状況が明らかに
第3段：真実は全く異なる（観測者でさえ欺かれていた）
```

### 反転の伏線

各反転の前に十分な伏線が必要（ただし、伏線は自然でなければならない）：
```
伏線A（反転可能性を示す）
伏線B（反転の方向性を制限する）
伏線C（反転後の結論を裏付ける）
```

### 反転の代償

反転がキャラクターに代償を課す：
```
情動代償：反転でキャラの信念が揺らぐ
関係代償：反転でキャラ間の信頼が崩れる
代償代償：反転で重大な結果が生まれる
```
