> 模倣用の情緒モジュール。各情緒目標に特有の文体技法パッケージを提供する。

## 情緒モジュールの使い方

各章で異なる情緒目標に到達するため：
1. 情緒目標の決定
2. 該当するモジュールを参照
3. 技法を採用（適用過多に注意）
4. 情緒目標を達成したかテスト

## 爽文モジュール

### 情緒目標
読者が「気持ちいい」と感じる。

### 文体技法

- 侮辱への反撃型：十分な抑圧（侮辱）→ 痛烈な反撃（爽快）→ 周囲の喝采 → 敗者の悔しさ
- 天賦開示型：疑念 → 実力開示 → 周囲の驚愕 → 主人公の落ち着き
- 逆転型：絶望的状況 → 一瞬の反転 → 完全勝利
- 能力習得型：努力（一文で済ます）→ 突破（詳細描写）→ 実戦テスト（爽快）

### よくあるミス

- 抑圧不足で爽快感が弱い
- 爽快な結果が期待を下回る
- 爽快後の反響が足りない（周囲の驚きが必要）
- 爽快シーンが長すぎる（だらける）

## 虐文モジュール

### 情緒目標
読者がイライラする、キャラをかわいそうに思う。

### 文体技法

- 理不尽な状況：主人公に非がないのに罰せられる
- 誤解の蓄積：主人公は良いことをしているのに非難される
- タイミングの悪さ：すれ違い、説明できない
- 力の差：どうしようもなく打ちのめされる

### よくあるミス

- 虐めが理不尽すぎる（読者がリアリティを感じない）
- 虐めの蓄積が長すぎる（読者が耐えられない）
- 主人公が優柔不断（読者ががっかりする）
- 虐めの種類が単調すぎる

## 甜文モジュール

### 情緒目標
読者がニヤニヤする、キャラにときめく。

### 会話技法

- 無意識の気遣い
- 他人には見せない特別な一面
- 過去の思い出が突然よみがえる
- 感覚的記憶（香り、温度、感触）

### 行動技法

- 特別な呼び方（呼び方の変化）
- 物理的距離の縮め方
- 視線の絡み方
- 沈黙の破り方

### よくあるミス

- 甘さがわざとらしい
- 展開が速すぎる（読者が信じられない）
- キャラの性格と合わない行動
- 甜さの後に虐めが来すぎる（パターン化）

## 恐怖モジュール

### 情緒目標
読者がドキドキする、怖いと感じる。

### 文体技法

- 見えないものほど怖い：全面的に描写せず、断片的に見せる
- 日常の異変：普通の中の異常が一番怖い
- 音と静寂の対比：急に静かになるときが最も怖い
- 視線の恐怖：見られている感じ

### よくあるミス

- 描写しすぎて怖くなくなる
- ジャンプスケア（びっくり）に頼りすぎる
- 恐怖の原因を早く明かしすぎる
- 主人公が強すぎて怖くない
