# 文体プロファイル生成 SOP

## 目的

作品の走査範囲（通常は黄金三章 + 任意の後続章）を読み込んだ後、統一フォーマットの文体プロファイルを生成し、`story-long-analyze` の下流分析フェーズに提供する。

JSON フォーマットの厳密な仕様については `style-profile-protocol.md` を参照。

## 入力

- 作品の走査範囲全文（story-architect agent が読み取ったもの）
- 外部リソースからの読者評価や市場データ（あれば）

## 出力

- 単一ファイル `文体プロファイル_{作品名}.json`
- `style-profile-protocol.md` の全フィールド定義に従う

## 生成手順

### 手順 1：作品タイトル + 基本情報を確認

作品全文からタイトルと著者情報を抽出。なければ `null`。

### 手順 2：走査範囲を特定

実際に読み取った範囲を記録（例：第1〜3章全文 / 第1〜10章全文 + 第20章 / 全 30 章精読）。あいまいな表現を避ける。

### 手順 3：文体分析情報を抽出

下記の次元に沿って特徴を抽出し、簡潔かつ正確な説明を記述：

1. **叙述視点**：一人称/三人称/二人称、叙述者の安定性、視点人物の切り替えパターン
2. **句長リズム**：短文主体か長文主体か、句長の変化リズム、典型的な段落構造
3. **描写密度**：会話/心理/環境描写の比率を概算。説明文が主か、会話が主か、心理描写が主か。
4. **対話形式**：地の文付き会話（XX が言った）/独立会話行/タグの使用か。会話の自然度。
5. **段落構造**：短文多段組み/長文少段組み/混在か。一段落あたりのおおよその文字数分布。
6. **全体文体**：上記の総合印象。簡潔で明瞭な文学批評用語を使用。

### 手順 4：修辞技法を抽出

走査範囲内で高頻度または顕著な修辞技法を抽出：

1. 技法リストを列挙（例：比喩、擬人、誇張、排比、対比、反復等）
2. 全体的な使用頻度を評価（多/中/少）
3. 各技法につき典型的な原文例を 1〜3 個抽出。

### 手順 5：感情リズムを分析

感情曲線を大まかに分割し、以下を記録：

1. 全体的な感情曲線の説明
2. 感情ピーク出現回数とおおよその位置
3. 張弛リズムのパターン
4. 走査範囲を 3〜5 個のリズム区間に分割し、各区間の主感情 + 強度 + 説明を記録。

### 手順 6：フック技法を分析

1. 章末フックのタイプを特定（懸念フック/逆転フック/情報フック/感情フック）
2. 章頭フックのタイプを特定（情景フック/対話フック/環境フック）
3. 代表的なフック例を抽出し、効果を分析
4. フック密度を推定

### 手順 7（オプション）：外部データを取り込む

利用可能な外部データ（読者コメント/ランキング/売上データ等）があれば対応モジュールに記入。なければ null を保持。

### 手順 8：JSON をアセンブルして検証

1. `style-profile-protocol.md` の構造に従い、全フィールドを JSON に入れる
2. JSON フォーマットの正当性を検証（パース可能であること）
3. 指定パスに保存
