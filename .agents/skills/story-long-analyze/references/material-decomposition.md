# 素材分解方法論

`story-long-analyze` パイプラインにおける素材分解のイテレーションモードと設計意図。

---

## 分解粒度制御

### イテレーション数決定ルール

パイプラインは最初から詳細な全文分解を決め打ちせず、走査範囲の長さに応じてイテレーション層の深さを決定する：

| 走査範囲文字数 | 推奨イテレーション数 | 説明 |
|--------------|-------------------|---------|
| < 3000 字 | 1 パス | 一段階ですべて抽出 |
| 3000 〜 10000 字 | 2 パス | 1 パス目：大枠抽出、2 パス目：詳細補完 |
| 10000 〜 30000 字 | 3 パス | 大枠 → 詳細1 → 詳細2 |
| > 30000 字 | 4-5 パス | 範囲分割後、各サブ範囲で 2 パス |

### イテレーション間の調整ルール

- 各パスを開始する前に「前回の出力を確認し、不足/穴を特定してから開始する」
- 最終出力は**事実確認**：各伏線/各キャラ/各爽点が少なくとも 1 回のイテレーションで言及されていることを確認
- イテレーションの増加は品質の直線的な向上を意味しない——最初の 3 パスでカバレッジの 80% 以上を獲得できる

## 分解の「カメラ視点」

文体プロファイルと構造分析以外に、以下の「カメラ視点」でも素材を分解する：

### 読者視点
- 読みながらの感情変化を記録
- いつ没入し、いつ冷めたか
- どの情報が予想通りで、どの情報が驚きだったか

### 創作者視点
- 作者の技法の意図を推測
- 「ここでなぜこの技法を使うのか」
- 「もし私が書くなら、何を参考にできるか」

### 市場視点
- この作品をなぜ推敲（パブリッシング）したのか
- どの爽点がターゲット読者層のニーズに合致しているか
- どのフックがリテンション効果を生んでいるか

## 伏線分解ルール

伏線の最低検出単位は「**章**」：

| 伏線タイプ | 定義 | 例 |
|---------|------|-----|
| 設定伏線 | 世界観/パワーシステムに関する伏線 | 「彼の傷痕は押すと熱くなる」 |
| 対話伏線 | 会話中の情報埋め込み | 「お前はまだ真実を知る時ではない」 |
| 行動伏線 | キャラ行動の異常 | 「彼女は夜な夜なこっそり出かけていく」 |
| 物品伏線 | 特殊物品の出現 | 「机の上の青い宝石が微かに光った」 |

- 複数の章にまたがる伏線が検出された場合、各出現章すべてを記録する
- 伏線回収の検出には**明示的な回収**（説明/対話での直接的伏線回収）と**暗示的回収**（読者の推測による伏線回収）を区別する

## 爽点分解ルール

爽点分解は文体プロファイルを補完するもので、以下のステップで行う：

1. 走査範囲内の全「爽点」をリストアップ
2. 各爽点の前に**期待/危機/抑圧**の伏線があるかを確認
3. 爽点タイプを分類：
   - 逆転爽点（立場/貧富/実力の逆転）
   - 打顔爽点（見下していた相手を見返す）
   - 収穫爽点（努力が報われる、宝物を手に入れる）
   - 感情爽点（誤解が解ける、再会）
4. 爽点強度を評価（1〜10）
