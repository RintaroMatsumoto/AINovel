# パイプライン運用リファレンス

`story-long-analyze` パイプラインの各フェーズにおける具体的な運用ガイドと注意点。SKILL.md のフェーズ定義と組み合わせて使用。

---

## 全体の流れ

```
ユーザー入力（path/URL または直接テキスト）
    ↓
Phase 1：基本情報登録 + 全文取得
    ↓
Phase 2：走査範囲決定（3 段階ルール）
    ↓
Phase 3：文体プロファイル生成
    ↓
Phase 4：構造・プロット・キャラ・伏線の深堀り分析
    ↓
Phase 5：レポート統合（プロットノード + 分析レポート）
    ↓
Phase 6（オプション）：市場分析 + 推奨事項
```

## Phase 1 運用詳細

### 基本情報登録

以下を登録し、`材料/` ディレクトリに保存：

- 作品名、著者（ある場合）
- 読み取りソース（ファイルパス/URL/直接テキスト）
- 読み取り日時
- 全文文字数

### 全文保存

以後の分析のために元テキストを `材料/` ディレクトリに格納：

```
材料/
├── 元テキスト.md    ← 原文全文、Markdown 保持
├── 状態.json        ← パイプラインパラメータ
└── 基本情報.md      ← 作品基本情報
```

## Phase 2 運用詳細

### 3 段階範囲決定ルール

#### 段階 1：黄金三章モード

読者が提供した資料が黄金三章（最初の 3 章）のみ → 範囲は黄金三章。

#### 段階 2：全文走査モード

完全な作品原文が提供され、文字数 ≤ 5 万字 → 全文を走査範囲に設定。

#### 段階 3：全文精読モード

完全な作品原文が提供され、文字数 > 5 万字 → ユーザーと走査範囲を相談して決定。

**相談テンプレート：**

> この作品は {文字数} 字あり、完全な分析には時間がかかります。
> 以下の走査範囲からお選びください：
> 1. 黄金三章のみ（標準）
> 2. 黄金三章 + 任意の 3 章（中間 1 章 + 結末 1 章、全 5 章）
> 3. 全文精読（全 {章数} 章）

### 元テキストを段落/章ごとに分割

読みやすさのため、元テキストを段落または章ごとに分割：

```
材料/
└── 走査範囲.json    ← JSON 配列：[{章番号: 1, 内容: "...", 文字数: 1234}, ...]
```

**JSON フォーマット：**

```json
[
  {
    "章番号": 1,
    "章タイトル": "章タイトル",
    "内容": "段落1\n\n段落2",
    "文字数": 1234,
    "開始ページ": 1
  }
]
```

## Phase 3 運用詳細

### 文体プロファイル生成

`style-profile-generator.md` の手順に従い、走査範囲全文を読み込んだ後 `style-profile-protocol.md` に準拠した JSON を生成。

**出力構造：**

```
参照/走査対象作品/
├── 走査範囲.json
└── 文体プロファイル_走査対象作品.json
```

## Phase 4 運用詳細

### 構造分析

走査範囲から三幕/五段/四部などのストーリー構造を抽出：

- 構造タイプ
- 各区切り位置（章番号）
- 各区切りの機能説明

### プロット分析

```json
{
  "プロット": {
    "概要": "ストーリー概要（100〜200 字）",
    "構造": {
      "タイプ": "因果連鎖/目標達成/謎解き",
      "区切り": [
        {"位置": "第1章", "機能": "導入"},
        {"位置": "第N章", "機能": "クライマックス"}
      ]
    },
    "爽点": [
      {"位置": "第N章", "内容": "", "タイプ": "逆転/打顔/収穫"}
    ]
  }
}
```

### キャラ分析

走査範囲に出現する全キャラクターを抽出：

```json
{
  "キャラ": [
    {
      "名前": "",
      "役割": "主人公/重要脇役/端役",
      "性格ラベル": ["キーワード"],
      "動機": "キャラのコア動機",
      "成長弧": "変化の方向性"
    }
  ]
}
```

### 伏線分析

走査範囲に設置された伏線を抽出：

```json
{
  "伏線": [
    {
      "内容": "伏線の内容",
      "分類": "設定伏線/対話伏線/行動伏線/物品伏線",
      "設置位置": "第N章",
      "状態": "未回収/疑似回収/回収済み"
    }
  ]
}
```

### 世界観/設定抽出

走査範囲に出現する世界観設定を抽出：

```json
{
  "世界観": {
    "タイムライン": "時代背景",
    "パワーシステム": "超能力/武道/魔法等",
    "社会システム": "政治/経済/文化設定",
    "特殊設定": "その他特殊な世界観設定"
  }
}
```

## Phase 5 運用詳細

### プロットノードの生成

Phase 4 の分析結果を時系列順のノード形式で統合：

```json
{
  "ノード": [
    {
      "章番号": 1,
      "ノードタイプ": "導入/発展/反転/クライマックス/結末",
      "コアイベント": "",
      "感情ピーク": true/false,
      "含まれる伏線": [],
      "登場キャラ": [],
      "爽点": []
    }
  ]
}
```

### 分析レポートの統合

Markdown レポートとして出力：

```markdown
# {作品名} 分析レポート

## 基本情報

## 文体分析

## 構造分析

## プロットハイライト

## キャラ分析

## 伏線マップ

## 感情リズム特性

## フック技法分析
```

### 出力構造

```
{作品}/
├── 分析レポート.md
├── プロットノード.json
├── 設定分析.json
├── キャラ分析.json
└── 参照/
    ├── 走査範囲.json
    └── 文体プロファイル_作品名.json
```

## Phase 6 運用詳細（オプション）

### 市場分析

作品と類似した市場のベストセラー作品を比較：

- 類似作品のリスト
- 類似点/相違点
- 市場差別化の可能性

### 改良提案

- 構造調整の提案
- フック密度の最適化
- キャラ弧の充実
- 感情リズム調整

### 出力

```json
{
  "類似作品": [
    {"作品名": "", "類似点": "", "相違点": ""}
  ],
  "改良提案": {
    "構造": [],
    "プロット": [],
    "キャラ": []
  }
}
```

## 注意事項

1. 各フェーズ終了時に `材料/状態.json` のパラメータを更新
2. 全生成ファイルの冒頭に `このファイルは story-long-analyze パイプラインにより自動生成されました` と注記
3. 各フェーズでエラーが発生した場合、エラー情報を記録し、処理を継続可能かユーザーに確認
