# 構造移行マッピングルール（長編）

Phase 3-L 長編構造移行の詳細マッピングルール。`分析庫/{書名}/` の長編分解成果物を長編プロジェクト構造に変換し、`story-long-write` が継続執筆できるようにする。

---

## 長編ターゲットプロジェクト構造

```
{タイトル}/
├── 設定/
│   ├── 世界観.md
│   ├── キャラ.md
│   ├── 関係.md
│   └── 題材定位.md
├── プロット/
│   └── 第X巻_巻タイトル.md ← Phase 3-L で生成される巻綱
├── 本文/
│   ├── 第001章_第X章.md
│   ├── 第002章_第X章.md
│   └── ...
├── 追跡/
│   ├── 伏線.md
│   ├── 時間線.md
│   ├── キャラ状態.md
│   └── コンテキスト.md
└── 参照/（オプション）
```

> 短編移行ルールは `structure-mapping-short.md` を参照。

## 分解成果物のマッピング

| 分解成果物（`分析庫/`） | ターゲットディレクトリ+ファイル | 変換方法 |
|--------------|-------------|----------|
| 原文全文 | `本文/` ディレクトリ | `format-and-structure.md` フォーマット仕様に従って本文を章ごとにファイル出力 |
| 分解レポート.md | `参照/{原書名}/構造分析.md` | 内容に応じて巻綱 `プロット/第X巻_巻タイトル.md` の元情報に書き込み |
| 設定分解（キャラ/世界観/関係） | `設定/` ディレクトリ | `format-and-structure.md` の設定ファイルフォーマット仕様に従って出力 |
| 伏線分析 | `追跡/伏線.md` にマージ | 追跡ファイルフォーマット仕様に従って出力 |
| 時間線 | `追跡/時間線.md` にマージ | 同上 |
| キャラ状態 | `追跡/キャラ状態.md` | `character-state-reverse.md` に従い原文からキャラ状態を逆推 |

## プロット/アウトライン移行ルール

- 分解レポートの構造分析（三幕/五段/四部等）を抽出し、`ストーリー大綱.md` の元情報として書き込む
- プロットノード中の「章タイトル_機能」マッピングから章番号と章タイトルの初期設計を決定
- 目標文字設定に従い、おおよその章計画を割り出す

## 品質チェックリスト

- [ ] 本文が章ごとに正しく分割され、フォーマット仕様に準拠
- [ ] 設定が独立ファイルに正常に移行
- [ ] 追跡ファイルがマージされ、既存データがクリアされていない
- [ ] キャラ状態が逆推完了（必要に応じて）
