# キャラ状態逆推プロトコル

Phase 3-L 長編移行時に、原文から全キャラクターの初期状態と状態変化を逆推するプロトコル。

## 逆推原理

原文の時系列に沿って、各章/段落における全キャラクターの状態を以下の次元で抽出する：

| 状態次元 | 説明 | 例 |
|---------|------|-----|
| 物理的状態 | 健康状態、場所、所持品 | 負傷、病院、遺品 |
| 心理的状態 | 感情、態度、動機 | 絶望、復讐心、愛 |
| 社会的状態 | 人間関係、身分、立場 | 敵対、欺瞞、孤立 |
| 情報状態 | 他者/核心秘密に対する認知 | 知っている、気づいていない、誤解 |
| 能力状態 | 技能、財力、資源 | トレードスキル習得、破産 |

## 逆推ルール

### 1. 出現位置に基づき状態を抽出
- 原文中でキャラが最初に出現する位置でベースライン状態を記録
- キャラが重要な行動/会話を行った位置で状態変化を記録

### 2. 状態変化点を記録
- 物理的状態の変化：受傷、治癒、転居
- 心理的状態の変化：感情の反転、態度の変化
- 社会的状態の変化：関係の確立/断絶/悪化
- 情報状態の変化：核心秘密の暴露、誤解の解消
- 能力状態の変化：成長、衰退

### 3. 出力フォーマット

```markdown
# キャラ状態逆推結果

## {キャラ名}

### ベースライン状態
- 物理的状態：
- 心理的状態：
- 社会的状態：
- 情報状態：
- 能力状態：

### 状態変化時系列
#### {章/位置}
- 物理的状態：{変化前} → {変化後}
- 心理的状態：{変化前} → {変化後}
- 社会的状態：{変化前} → {変化後}
- 情報状態：{変化前} → {変化後}
- 能力状態：{変化前} → {変化後}
- トリガー：{変化原因}
```

> 各キャラクターの状態変化を記録することにより、`追跡/キャラ状態.md` に正確にマッピングする。

## 状態変化が検出されない場合の処理

- キャラクターが最後まで状態変化しない場合 → 状態変化時系列は空のまま、ベースライン状態のみ記録
- 原文中のキャラクター出現が少なく、十分な状態情報が取れない場合 → 該当次元を「不明」とマーク

## 品質チェックリスト

- [ ] 全キャラクターがベースライン状態を記録
- [ ] 状態変化点が記録され、対応する位置が正確
- [ ] 状態変化に明確なトリガー（イベント/会話/行動）が紐づいている
- [ ] キャラ状態が `追跡/キャラ状態.md` のフォーマットに準拠
- [ ] 逆推が検出不能な次元を「不明」と正しくマーク
