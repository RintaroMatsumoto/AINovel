# フォーマット＆ビート構造

Phase 3 出力の本文フォーマット仕様とビート構造テンプレート。

## 本文フォーマット共通仕様

| 仕様項目 | 要件 |
|--------|------|
| 改行 | 段落間は単一改行 `\n`、空行や `\n\n` 不可 |
| 引用符 | 中国語モードではデフォルト `""`、短編知乎プラットフォームでは `「」` 可 |
| インデント | インデントなし、全角/半角スペース不使用 |
| Markdown | 本文段落中では `**` `*` `#` `---` 不使用（見出し区切りマークは除く） |

## 長編フォーマット仕様

### ディレクトリ構造

```
本文/
├── 第001章_章タイトルA.md
├── 第002章_章タイトルB.md
├── 第003章_章タイトルC.md
└── ...
```

### 単一ファイルフォーマット

```markdown
# 第XXX章 章タイトル

{本文段落1}

{本文段落2}

## {各段落の展開…}

{本文段落N}
```

- 章番号 + 章タイトルを `#` 見出しとして使用
- 章内の自然段落区切りには `##` 見出しを使用（オプション）

### ページ設定（追跡/コンテキスト.md）

```markdown
# コンテキスト概要

## 現在位置
- 作品：{作品名}
- 現在章：第XXX章 - {章タイトル}
- 全文字数（予定）：{文字数}
- 現在進捗：{進捗率}%

## 本章の目標
{本章の役割}

## 残りの伏線
{伏線リスト}

## 次章予告
{次章へのつなぎ提案}
```

## 短編フォーマット仕様

### ディレクトリ構造

```
{タイトル}/
├── 設定.md
├── セクションアウトライン.md
├── 本文.md
└── ベンチマーク/{原書名}/
    └── ...
```

### 単一ファイルフォーマット

```markdown
# {タイトル}

###1.
{本文段落1}{改行のみ}
{本文段落2}

###2.
{本文段落3}
```

- セクション区切りには `###N.` 連番を使用
- このフォーマットは短編執筆の標準フォーマット、設定ディレクトリに応じて調整可能

## 設定ファイルフォーマット仕様

### 長編設定ファイル

```markdown
# {ファイル名}

## 項目一
{内容}

## 項目二
{内容}
```

### 短編設定.md

```markdown
# {短編タイトル} 設定

## 基本情報
- タイトル：
- 目標文字数：
- 目標プラットフォーム：

## コアフレームワーク
### 一言梗概
### コア反転
### 感情設計
### キャラクタースケッチ

## ベンチマーク要約
### ストーリー構造
### 感情リズム
### コア反転メカニズム
### 再利用可能なライティング技法
```

## 追跡ファイルのフォーマット

追跡ファイルは `AGENTS.md` に定義された既存の長編プロジェクト追跡フォーマットを参照。`追跡/` ディレクトリの各ファイルは以下のフォーマットに準拠：

- `#` 見出しでトップレベルの区分をマーク
- `##` セクションでサブ区分
- `- ` リストで詳細項目
- 日付フォーマット：`YYYY-MM-DD`

### 追跡/伏線.md

```markdown
# 伏線追跡

## 未回収
### {伏線名}
- タイプ：
- 設置章：
- 予定回収章：
- 状態：未回収

## 回収済み
### {伏線名}
- タイプ：
- 設置章：
- 回収章：
- 状態：回収済み
```

### 追跡/時間線.md

```markdown
# 時間線

## {タイトル}
- {日付/時間}：{イベント}
```

### 追跡/キャラ状態.md

```markdown
# キャラ状態追跡

## {キャラ名}
- 現在状態：
- 状態変化記録：
```

## 品質チェックリスト

### 本文フォーマット共通
- [ ] 段落間は改行 1 つのみ（空行/`\n\n` なし）
- [ ] 引用符が統一（プラットフォームに応じて `""` または `「」`）
- [ ] インデントなし（全角/半角スペース不使用）
- [ ] 本文段落中に Markdown 構文が混入していない
- [ ] セクション見出しと本文内容が一致

### 長編固有
- [ ] ファイル名が `第XXX章_章タイトル.md` に従っている
- [ ] ファイル数が章数と一致
- [ ] 追跡ファイルが完全

### 短編固有
- [ ] セクション区切りが `###N.` 連番に従っている
- [ ] セクション数が元テキストの段落構造と一致
