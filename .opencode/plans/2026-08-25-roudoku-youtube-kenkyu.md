# 調査_朗読系YouTube手法（2026-08-25）

## 調査目的

DayTradeのYouTube展開（現行：テキスト下→上スクロール＋BGM）に、小説朗読系YouTube動画市場の成功手法を取り入れるための調査。

**結論（先出し）**：
1. 現行フォーマット「スクロール＋BGMのみ」は、2026年基準ではYouTube収益化停止リスクが最も高い部類（紙芝居・低工夫映像）に属する。**フォーマット強化が必須**
2. 最成功モデルは雨穴型（独自フォーマット×長尺×メディアミックス）。DayTradeのComfyUIキャラ資産は「独自映像3割ルール」を満たす最大の武器
3. 音声方式は4案比較（第4章）で、テスト動画によるAB検証を経て決定する
4. 週2回投稿の現行計画は多投稿リスクを回避しており安全側。維持する

### 1.1 視聴動機の分類
- **試し読み**：本購入前の品定め（声優朗読系）
- **ながら聴き**：通勤・作業・睡眠BGM代わり（長尺需要の核）
- **没入体験**：一人称物語への引き込み（ホラー・感情ドラマ）
- **コミュニティ**：配信者と作品をめぐる交流（読書実況）

DayTradeのターゲット（文学に開かれた30〜50代＋普段本を読まない若年層）は「没入体験」と「ながら聴き」の複合が最適解。村上文体の一人称内省は音声朗読と相性が良い。

## 2. 成功モデル分析

### 2.1 雨穴モデル（『変な家』シリーズ）

**実績タイムライン**：
- 2020-10: オモコロ記事→YouTube公開
- 2021-07: 書籍化 → 2024-04時点で150万部突破
- 2022-11時点: 動画1000万回再生超
- 2024-03: 映画化（最終興行収入50億円超、世界35カ国）
- 2024: オリコン年間BOOKランキング2冠
- 2025-10: 「完全版変な家」全編無料公開（内容リメイク＋画像約100枚追加、YouTube版142分）

**抽出できる手法**：

| 手法 | 内容 | DayTradeへの適用 |
|------|------|----------------|
| 独自フォーマット | 「間取り図」という他にない題材軸 | 一人称文体×封筒開示＝DayTrade固有の体験設計を前面に |
| 動画→書籍導線 | 動画は導入部のみ。続きは本で | 全文無料公開戦略と両立可（6章参照） |
| 長尺歓迎文化 | コメント欄で「50分でも嬉しい」 | ながら聴き需要を取り込む長尺化（7章） |
| 完全版リメイク再燃 | 既刊を無料公開して話題を再点火 | 第1巻公開後の再燃施策として採用候補 |
| 書籍特典=朗読動画 | 『変な絵』第1章62分朗読動画を特典化 | Kindle/紙版にQRコードで特典動画導線 |
| 小説×動画×音楽 | メディアミックスを初手から設計 | golden_cross_theme.mp3等の既存BGM資産活用 |
| 自作イラスト挿入 | 91枚のイラストを本人制作 | ComfyUI生成済みキャラ画像資産で同等の独自性を確保 |

### 2.2 けんごモデル（TikTok小説紹介30万フォロワー）

| 手法 | 内容 | DayTradeへの適用 |
|------|------|------------------|
| 台本一字一句書き起こし | 読了即台本→撮影→投稿の当日サイクル | Shorts切り抜きの台本規律として採用 |
| ガワを省く | 「東野圭吾の最新作です」ではなく作品の良さだけを伝える | タイトル・概要欄・サムネから作者情報より作品体験を優先 |
| 未読者向け設計 | 小説を読んだことのない層に向けて制作 | AGENTS.mdのターゲット方針と一致済み |

### 2.3 読書実況VTuber経路

- 作家がXリプライ等で応募→配信者が本文を朗読（または黙読実況）→感想が得られる
- 応募超過時は抽選・応募順・投票制など選考方法は様々
- 配信頻度は週1ペースが中程度
- **注意点**：配信参加必須の場合、匿名作家ブランドDouminとの相性要検討。音声のみ参加可能か個別確認が必要
- **評価**：主軸ではなく、公開後の集客オプションとして位置づける

## 3. 収益化リスク（2026年最新データ）

### 3.1 停止チャンネル200CH超の分析（国内100+海外100、2026-06発表）

| 項目 | データ |
|------|--------|
| 停止フォーマット順位 | **①紙芝居（画像スライドショー中心）②ゆっくり解説 ③2ch系 ④反応集 ⑤朗読系** |
| 投稿頻度 | 停止CHの**約80%が日1本以上投稿** |
| 音声スタイル | **機械音声約70%／肉声でも約20%停止** |
| 最悪組合せ | **多投稿×機械音声**（AIスロップ警戒と完全一致） |
| 登録者層 | 1万〜20万の中堅層が約80% |
| 復活率 | 約17%（属人性の高いチャンネルは約30%） |
| 海外の特徴 | 創作系が目立ち、朗読系＋AI映像が多め。復活率わずか約1% |

**公式メールに挙げられた収益化不可例**：「自分で作成していない資料の読み上げ」「違いがほぼない繰り返し」「テンプレート大量量産」「付加価値の少ない画像スライドショー」

### 3.2 特に警戒すべき5パターンのうち該当するもの

> **⑤朗読系×低工夫映像** — 聞き流し需要を狙った超長尺動画。風景素材やAIスライドを延々と流すスタイル

⚠️ **現行案「テキストスクロール＋BGMのみ」はこの判定圏内にある**。対策が事実上の必須要件。

### 3.3 ポリシー改訂（2026年7月）

- 「満足度の低い、または不快なコンテンツ」は収益化不可と明文化
- 判定は個別動画ではなく**チャンネル全体**が対象
- **AI一律禁止ではない**：「AIで独自の物語やキャラクターを制作した動画」「制作者自身の解説や考察を加えた動画」は収益化可能
- シリーズで同じ構成でも、各動画の内容が十分異なれば問題なし

### 3.4 安全設計原則（本プロジェクト採用基準）

1. **独自映像3割ルール**：「そのチャンネルでしか見られない映像」を最低3割以上 → ComfyUIキャラ画像・独自背景ビジュアルで満たす
2. **週2回投稿を維持**：多投稿×機械音声パターンを回避（現行計画のまま）
3. **属人性の担保**：自分の声・独自演出・作家性のいずれかを各動画に入れる
4. **テンプレ回避**：毎回同じBGM開始・同一構成を避ける
5. **1本ごとの価値**：「この章を観る理由」が動画ごとに明確であること

### 3.5 審査落ち時の復旧手段（予備知識）

再審査請求動画制度あり：5分以内・限定公開・冒頭30秒以内にチャンネルURL表示・編集画面の実演・独自価値の口頭説明。**制作過程の記録を残しておくことが保険になる**。

## 4. 音声方針：4案比較

| 案 | 方式 | 収益化リスク | 制作コスト | 品質・表現 | 備考 |
|----|------|------------|-----------|-----------|------|
| A | スクロールのみ改良（ナレーションなし継続） | 高（低工夫映像判定圏） | 低 | 文字体験のみ | 独自映像3割ルールの達成難度が高い |
| B | 自分の声＋加工 | 低（肉声停止20%だが属人性が高いほど復活率も高い） | 中（収録工数が恒常負担） | 声質依存。感情の機微に最も強い | 現行代替案。匿名性は加工で確保可 |
| C | AI音声（VOICEVOX / Irodori-TTS / ElevenLabs） | 中〜高（機械音声70%停止データ。ただし主因は多投稿×テンプレの複合。単独では即死ではない） | 低〜中 | VOICEVOX: 感情スタイル豊富だが文学的内省には不自然さの可能性。ElevenLabs: 最高品質（月5ドル〜） | VOICEVOX/Irodori-TTS はクレジット表記必須 |
| D | ハイブリッド（推奨候補） | 低中 | 中 | 冒頭30秒だけ自分の声（属人性付与）＋本文はキャラ画像入りスクロール強化 | テスト動画18本の既存インフラでAB検証可能 |

### 4.1 AI音声ツール比較（案C内訳）

| ツール | コスト | ライセンス | 特徴 |
|--------|--------|-----------|------|
| VOICEVOX | 完全無料 | 商用OK・クレジット表記必須（CC BY 4.0）・キャラごとの規約確認必要 | 感情スタイル豊富（喜び/悲しみ/ささやき等）。Python組み込み可→ffmpeg MCPパイプラインへ自動統合可能 |
| Irodori-TTS | 無料 | MITライセンス（OSS） | テキストで声の性質を指定できる最先端TTS。Colabで試用可・GPU推奨 |
| ElevenLabs | 月5ドル〜 | プランにより商用可 | 世界最高水準の感情表現。日本語対応 |
| 音読さん | 無料枠あり | 要確認 | ブラウザ完結・登録不要。お試し向け |
| AquesTalk（ゆっくり系） | 商用ライセンス年6,380円〜 | ライセンス必須 | 文学朗読には不向き。非採用推奨 |

### 4.2 決定プロセス（提案）

1. 同じ一章（冒頭500字程度）でA/B/C/D各サンプル動画を試作
2. 没入感・離脱しなさ・「続きが観たい」感で評価
3. 制作工数を実測し、週2ペースが回るか検証
4. 公開後は視聴維持率データで最終判断
