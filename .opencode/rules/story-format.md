# Story Format Rules

本文ファイルの書式ルール。ユーザーが本文ファイルを直接編集する際に自動ロード。

## 絶対禁止

1. **機械的分段・通し大段落の禁止**：段落は演劇的単位・カット・ひと区切りで自然に区切る。固定文字数で強制改行しない。複数の動作や情報を1段落に詰め込まない。完全な推論・雰囲気演出・感情変化の連鎖は長めの段落でも可。
2. **段落間空行の禁止**：隣接段落間は1つの改行 `\n` のみ。空行や連続改行 `\n\n` は禁止。
3. **会話タグの過剰使用の禁止**：会話タグ（「彼は言った」「彼女は答えた」）は誰が話しているか不明な時のみ使用。3連続以上の会話タグは動作で代替する。村上文体では会話タグの単発使用を許容。
4. **描写と内省の自然な連続の許容**：描写は動作または会話を挟みながら行うことを基本とするが、知覚→内省→記憶の流れを自然に連続させるために、2段落以上の純粋な描写や内省も、内容に必然性があれば許容する。
5. **視点移動の禁止**：確定した視点（一人称/限定三人称）から他のキャラの内心に切り替えない。
6. **主語過多の禁止**：同一動作連鎖内で不必要に同一主人公名を連続使用しない。段落頭や主語リセット時は指名し、段落内では代名詞・動作承接・合理的省略を使う。要所で指名する。

## 書式ルール

- 会話は独立行に。コロンまたは動作で導く
- 段落は演劇的単位・カット・感情・動作で区切る
- 章タイトルは `## 第X章 章名` 形式。タイトル後にはMarkdown空行1つ
- 隣接段落間は改行1つのみ、空行や `\n\n` 禁止
- 章間に `---` や区切り線、余分な空白行を使わない

## Examples

### Correct — 演劇的単位で自然に区切る
```
書斎のモニターが四つ。左端の画面で数字が点滅している。
指先がキーボードの上で止まった。エンターキーを押す——それだけの動作に、どれほどの時間がかかったかわからない。
百合子が台所で水を流す音が聞こえる。いつもの夜の音。
```
各段落は1つの動作/情報変化のみを担う。段落間は `\n` のみ。

### Wrong — 複数の拍が1段落に詰まっている
```
書斎のモニターが四つ並んでいて左端の画面で数字が点滅していて指先がキーボードの上で止まってエンターキーを押すだけでどれほどの時間がかかったかわからず百合子が台所で水を流す音が聞こえていた。
```
複数の動作・情報・結果が1段落に混入し、読者は要所で息をつくことができない。

### Correct — 会話は動作で導く（「彼は言った」不要）
```
橘誠が茶碗を机に置いた。
「いったい何が言いたいの？」
百合子は答えず、窓の外を眺めていた。
```
会話は動作と文脈で導く。「彼は言った」「彼女は言った」などのタグは使わない。

### Wrong — 会話タグ使用
```
橘誠が茶碗を机に置いた。
彼女は言った：「いったい何が言いたいの？」
百合子は答えず、彼はそっとため息をついて窓の外を眺めていた。
```
「言った」「嘆いた」は禁止の会話タグ。動作で代替する。

### Correct — 章タイトル後の余分な空行なし
```
## 第二章 暗流

百合子がドアを押し開けると、室内にはすでに三人が座っていた。
橘誠は一番奥の隅に座り、手に一枚のメモを握っていた。
```
章タイトル `##` と本文の間は1空行のみ（Markdown描画のため）。本文段落間に空行なし。

### Wrong — 段落間の余分な空行
```
## 第二章 暗流


百合子がドアを押し開けると、室内にはすでに三人が座っていた。


橘誠は一番奥の隅に座り、手に一枚のメモを握っていた。
```
段落間に空行（連続改行 `\n\n`）が入り、テンポが損なわれる。
