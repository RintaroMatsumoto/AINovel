## 5. プロンプト設計指針

### 制約
- **ComfyUIは日本語テキストを直接レンダリングできない**
- タイトル・作者名は英語でプロンプトに含め、後工程でPhotoshop/Canvaを使って日本語合成する
- ただしSDXLは「Golden Cross」程度の英文テキストなら描画可能

### プロンプト構成（英文）

```
[画風] + [人物] + [構図] + [色調] + [光] + [テキスト] + [品質]
```

例：
```
professional book cover, digital painting style, portrait 2:3 ratio,
a Japanese businessman in dark suit standing alone, back view,
stock market charts in background, golden sunset light,
dramatic lighting, moody atmosphere, high detail,
no watermark, no signature
```

1. **稼働確認**: M2のComfyUIが起動しているか `system_stats` で確認
2. **プロンプト設計**: 3巻それぞれのプロンプトを作成
3. **スクリプト実装**: `scripts/gen_story_cover.py` を作成（`gen_rin_ref_m2.py` が雛形）
4. **画像生成**: 4枚の表紙をComfyUIで生成（約16秒）
5. **後処理**: Photoshop/Canvaで日本語タイトル＋作者名を合成
6. **品質チェック**: 文字が読めるか、構図が適切か

## 7. IPAdapterFaceID による顔一貫性生成

> 習得日: 2026-06-29
> 用途: 一人のキャラの顔を、異なる服装・髪型・構図でも一貫して生成する

### 7.1 原理

通常のtxt2imgはseed固定だけではプロンプト変化（服装・構図の違い）で顔が変化する。
IPAdapterFaceID は以下3段階で顔を固定する：

1. **InsightFace（buffalo_l）**：参照画像から顔の特徴点を抽出しベクトル化
2. **CLIP Vision（ViT-H）**：画像全体のスタイル・文脈を理解
3. **FaceID Plus V2 モデル**：顔ベクトル+CLIP特徴を生成過程に注入し、顔構造を維持したまま服装/髪型/構図を書き換える

### 7.2 推奨パラメータ（SD1.5・検証済み）

| パラメータ | 値 | 備考 |
|-----------|-----|------|
| プリセット | FACEID PLUS V2 | PLUS V1 + LoRAの改良版。SD1.5用 |
| weight | 0.8 | 0.7〜0.9。高すぎると顔に歪み、低すぎると効かない |
| weight_faceidv2 | 0.0 | FaceID V2専用。SD1.5では使わない |
| weight_type | linear | ease-in-outも可。やや強いlinearが安定 |
| embeds_scaling | V only | 顔構造のみ注入（スタイルは注入しない） |
| provider | CPU | InsightFace。GPUは不安定 |
| LoRA強度 | 0.5（標準） | FaceID PLUS V2は自動でLoRAをロード |
| reference | 正面・自然光・無表情が最適 | 顔全体が均一に映っていること |

### 7.3 必要条件（SD1.5）

ファイル名の大文字小文字・ハイフン位置に厳格。Cubiqの `utils.py` が正規表現でマッチングするため。

| ファイル | 配置先 | サイズ |
|---------|--------|-------|
| `ip-adapter-faceid-plusv2_sd15.bin` | `models/ipadapter/` | 150MB |
| `ip-adapter-faceid-plusv2_sd15_lora.safetensors` | `models/loras/` | 49MB |
| `CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors` | `models/clip_vision/` | 2.4GB |

### 7.4 プリセット→ファイル名マッピング（参考）

Cubiq ComfyUI_IPAdapter_plus `utils.py` の `get_ipadapter_file()` より：

| プリセット名 | 期待ファイル名パターン |
|------------|----------------------|
| FACEID | `faceid.sd15.bin` |
| FACEID PLUS - SD1.5 only | `faceid.plus.sd15.bin`（**v1＝非推奨**） |
| **FACEID PLUS V2** | `faceid.plusv2.sd15.bin`（**使用中**） |

**教訓**: プリセット名と実際のファイル名の対応は `utils.py` を直接読むまで確定しない。「FACEID PLUS V2」は `faceid.plusv2.sd15.bin` → `ip-adapter-faceid-plusv2_sd15.bin` と命名規則が異なる。

### 7.5 ファイル命名規則

画像ファイル名は日本語を含めるとComfyUI API経由のダウンロードで文字化けする。
**必ずASCII英数字のみを使用する**：

```
{キャラ英名}_{年齢}_{モデル}_s{seed}_{服装}_{髪型}_{角度}_{連番}.png
```

例：`yuriko_18_yayoi_mix_s9964889205_uniform_bob_front_00001_.png`

### 7.6 処理速度の注意

IPAdapterFaceIDは初回呼び出し時にCLIP Vision（2.4GB）とInsightFaceモデルをロードするため、
最初の1枚は特に遅い（M1 RTX3060で〜5分/枚）。
2枚目以降はキャッシュされるが、それでも通常のtxt2imgより2〜3倍時間がかかる（〜2分/枚）。
スクリプトのタイムアウトは長めに設定する（300秒以上推奨）。
