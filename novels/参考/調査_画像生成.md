## 4. ComfyUI HTTP API

全エンドポイント認証不要。

| メソッド | エンドポイント | 用途 |
|---------|---------------|------|
| POST | `/prompt` | Workflow JSONを投入 → `prompt_id` 取得 |
| GET | `/history/{prompt_id}` | 生成完了をポーリング、出力ファイル名取得 |
| GET | `/view?filename=...&subfolder=...&type=output` | 生成画像をダウンロード |
| GET | `/system_stats` | 起動確認 |

## 5. プロンプト設計指針

### 制約
- **ComfyUIは日本語テキストを直接レンダリングできない**
- タイトル・作者名は英語でプロンプトに含め、後工程でPhotoshop/Canvaを使って日本語合成する
- ただしSDXLは「Golden Cross」程度の英文テキストなら描画可能

### プロンプト構成（英文）

```
[画風] + [人物] + [構図] + [色調] + [光] + [テキスト] + [品質]
```

例：
```
professional book cover, digital painting style, portrait 2:3 ratio,
a Japanese businessman in dark suit standing alone, back view,
stock market charts in background, golden sunset light,
dramatic lighting, moody atmosphere, high detail,
no watermark, no signature
```

## 6. 表紙生成ワークフロー

1. **稼働確認**: M2のComfyUIが起動しているか `system_stats` で確認
2. **プロンプト設計**: 4巻それぞれのプロンプトを作成
3. **スクリプト実装**: `scripts/gen_story_cover.py` を作成（`gen_rin_ref_m2.py` が雛形）
4. **画像生成**: 4枚の表紙をComfyUIで生成（約16秒）
5. **後処理**: Photoshop/Canvaで日本語タイトル＋作者名を合成
6. **品質チェック**: 文字が読めるか、構図が適切か
