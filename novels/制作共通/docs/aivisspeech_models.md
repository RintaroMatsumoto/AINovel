## 凡例

| 項目 | 説明 |
|------|------|
| ファイル名 | `Models/` 下の `.aivmx` ファイル名 |
| 話者名 | `/speakers` API が返す表示名 |
| 声質 | voice_timbre の和訳 |
| スタイル | そのモデルが持つ感情/口調バリエーション |
| Style ID | `/speakers` API から取得した数値ID（`step3_tts.py` の `VOICEVOX_SPEAKER` に指定） |
| 作者 | AivisHub 上の公開者 |
| ライセンス | ACML 1.0 / Custom / CC0 |
| DL数 | AivisHub 上の AIVMX 累計ダウンロード数 |

## 管理コマンド

### コンテナ再起動（モデル追加後）

```powershell
docker restart aivisspeech
```

### モデル一覧取得（API）

```powershell
# 全話者＋Style ID
curl http://100.112.59.35:10101/speakers

# 指定話者で音声合成テスト
curl -s -X POST "http://100.112.59.35:10101/audio_query?speaker=1310138976&text=これはテストです" > query.json
curl -s -H "Content-Type: application/json" -X POST -d @query.json "http://100.112.59.35:10101/synthesis?speaker=1310138976" > test.wav
```

### モデル追加

```powershell
# 新しい .aivmx を配置 → docker restart
copy model.aivmx "%USERPROFILE%\AppData\Roaming\AivisSpeech-Engine\Models\"
docker restart aivisspeech
```
