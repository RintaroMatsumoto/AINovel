## 細綱（第 3 章）

### 第 3 章：静かな水面
- 核心イベント：L1後からL2までの約1ヶ月間。表面上は普通の日常。しかし誠は百合子の顔を無意識に観察するようになる。
- 字数目標：5,000〜6,000 字
- 目標感情：平静＋潜む不安。表向きは何も変わらない日常の中に、かすかな違和感が沈殿する。
- 章首フック：イメージ予兆 — 朝、百合子の手が茶碗を置く。その仕草を誠が見つめている。
- 感情ピーク：夜、トレードの後、引き出しの中の封筒を思い出すが開けない。「気にするな」と言い聞かせる自分の中に、別の声がある。

#### 内容概括（五段式）
- 起因：L1から数日。朝のルーティン。百合子が味噌汁をよそい、栞が制服を着ている。翼が忘れ物をする。いつもの朝。
- 展開：トレードルーム（元書斎）での一日。チャートを眺め、ノートを開く。今日も祖父の教えを守っている。数字は正直だ。
- 転機：夕方、リビングで百合子がテレビを見ている。その横顔を、なぜかじっと見てしまう。18歳の写真と、今の百合子——変わったものと変わらないもの。
- 山場：夜。トレードの記録をつけ終わる。ふと引き出しに手が伸びる——が、開けない。封筒の存在を思い出すが、「考えすぎだ」と自分に言い聞かせる。数字と論理で生きてきた男が、数字にできない感情と初めて向き合う。
- 結末：深夜。百合子はもう寝ている。リビングで一人、祖父のノートを開く。祖父の文字。心構え——「相場も人生も、焦ったら負けだ」。その言葉に妙に救われる。

#### プロット安排（複線）
- 主線進行：封筒の記憶が沈殿しつつ、日常は表面上継続。——破壊の潜伏期間。
- 副線進行：トレードは順調。自分のルールを守っている。——「まだ壊れていない」状態を描く。
- イベント線 / 任務線：朝の家族 → トレード → 夕方の百合子観察 → 引き出しの誘惑 → 祖父のノート
- 感情線 / 関係線：誠→百合子：観察する目に変わり始める。まだ疑いではない——「気になる」程度。しかし以前の無条件の信頼には戻れない。
- 論理線：L1の写真が記憶に残る（原因）→ 無意識に百合子を観察（行動）→ 何も変わっていないように見えるのに、何かが違う（結果）→ 自分を「考えすぎ」と納得させる（一時的解決／問題の先送り）

#### 人物関係と登場順
- 登場順：誠 → 百合子（朝・夕方・就寝前）→ 栞（朝、学校へ）→ 翼（朝、忘れ物）
- 人物関係変化：誠の百合子への視線が「妻」から「観察対象」の要素を帯び始める。まだ愛情はベースにあるが、純粋な信頼に最初の細かいヒビ。
- 視点/情報差：誠の一人称。百合子の内心は一切描かない。百合子が誠の視線の変化に気づいているかどうかも描かない（誠の目からは「いつも通り」に見える）。

#### プロット詳細化
- プロットポイント列：
  1. 朝の家族。いつもの光景。——「正常の維持」
  2. 百合子の手元を見る誠。——「写真の記憶がフィルターになる」
  3. トレードルーム。チャートとノート。祖父の教えを守っている。——「誠のアイデンティティ」
  4. 夕方。百合子の横顔を観察。18歳の写真と比較する自分に気づいて戸惑う。——「無意識の比較」
  5. 夜。トレード記録。引き出しに手が伸びかける。——「誘惑と自制」
  6. 「考えすぎだ」——自己説得。——「理論による感情の封じ込め」
  7. 祖父のノートを開く。「焦ったら負けだ」。——「祖父の言葉による一時的救済」
- 代価の支払い / 収益の獲得：誠は「考えすぎ」で封筒を無視する（代価：問題の先送り）。トレードは安定している（収益：まだ崩れていない）。しかしこの先送りが、後の「もっと早く気づくべきだった」という後悔の種になる。

#### 結末設定とフック
- 結末設定：封筒はまだ引き出しの中。誠は「最初で最後」だと思っている。しかし読者は違う——あの封筒は最初の一通に過ぎなかったのだと。
- 章尾フック：イメージフック — 祖父のノートを閉じる。最後の一文は「焦ったら負けだ」。誠はまだ焦っていない。まだ。——「まだ」という言葉が、来るべき焦りを予感させる。
