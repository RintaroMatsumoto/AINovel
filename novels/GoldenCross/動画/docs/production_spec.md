## 2. 音声

### 2.1 読み上げエンジン

| 項目 | 仕様 |
|------|------|
| エンジン | **AivisSpeech Engine**（M1 Docker） |
| エンドポイント | `http://100.112.59.35:10101` |
| ナレーター声 | **未定**（22モデルの聴き比べ後決定） |
| 読み上げ速度 | **やや遅め**（speedScale=0.85〜0.9） |
| 話速の緩急 | tempoDynamicsScale=1.0（デフォルト） |

### 2.2 ナレーションスタイル

- 1ナレーターで地の文を統一
- キャラ別の声は使わない
- 感情表現は intonationScale で調整（デフォルト1.0から微調整）

## 3. 映像

### 3.1 画面構成

```
┌──────────────────────────┐
│                          │
│       挿絵（全面）        │
│    （暗めオーバーレイ）    │
│                          │
│      ───────────         │
│    ここにテキスト表示     │
│      ───────────         │
│                          │
└──────────────────────────┘
```

| 要素 | 仕様 |
|------|------|
| 背景 | **挿絵を全画面表示**＋暗いオーバーレイ（透明度〜30%） |
| テキスト | 画面中央エリアに白文字、**スムーズ自動スクロール** |
| テキスト表示行数 | **8〜10行**常に表示 |
| フォント | NotoSansJP-VF.ttf |
| フォントサイズ | 36px |
| スクロール速度 | 全文の文字数 ÷ 朗読時間（秒）で計算。常に朗読と同期 |
| 挿絵の配置 | 5〜10枚/章、キーシーンごと。スクロール中も背景は固定 or 切り替え時に差し替え |
| 1枚あたりの表示時間 | 30秒〜2分（文章量による） |

### 3.2 動画生成フロー

```
[1] 挿絵生成 (SDXL on M2) → 5-10枚/章
[2] 各挿絵の表示時間を計算 (chunk単位)
[3] 静止画 + 字幕フレームを生成 (MoviePy)
[4] AivisSpeechで音声合成 (chunk結合)
[5] BGM選曲・当て込み
[6] FFmpegで最終結合
```

## 4. BGM

### 4.1 4トーン選曲

| # | トーン | ファイル | 元タイトル | 使うシーン |
|:-:|:------|---------|-----------|-----------|
| 1 | **穏やか・温かい** | `acoustic52_ast_daily_sound.mp3` | ast daily sound | 家族の食卓、日常、穏やかな朝 |
| 2 | **悲しみ・回想** | `piano37_セピアの風.mp3` | セピアの風 | 百合子の回想、栞の過去、切ない内省 |
| 3 | **不安・緊張** | `piano36_宿命のシナリオ.mp3` | 宿命のシナリオ | 誠の決意、不穏な伏線、封筒の記憶 |
| 4 | **崩壊・衝撃** | `orchestra26_戦いの跡.mp3` | 戦いの跡 | クライマックス、真実の発覚、決定的瞬間 |

### 4.2 BGM切り替えルール

| ルール | 内容 |
|--------|------|
| **1動画あたりの曲数** | 最大4曲（感情トーンの数だけ） |
| **切り替えどき** | シーン転換 or 地の文の区切り |
| **禁止** | 文の途中、会話の途中で変えない |
| **クロスフェード** | 元の曲 1.0秒フェードアウト → 0.5秒無音 → 新曲 1.0秒フェードイン |
| **BGM音量** | ナレーションの20〜30%程度（ナレーションが埋もれない） |
