## 2. 映像仕様（v2）

```
┌────────────────────────────────┐
│      挿絵（全画面表示）          │
│    ＋暗いオーバーレイ約30%       │
│                                │
│   ─────────────────────        │
│     本文テキスト（白）           │
│     8〜10行 常時表示            │
│     下から上へ自動スクロール      │
│   ─────────────────────        │
└────────────────────────────────┘
```

| 要素 | 仕様 |
|------|------|
| 背景 | 挿絵全画面＋暗オーバーレイ約30%。シーン転換時に差し替え（1枚30秒〜2分表示） |
| テキスト | NotoSansJP-VF.ttf 36px 白文字。幅900pxエリア・約21字/行・8〜10行常時表示 |
| 改行 | wrap_jp()：句読点「。！？」優先→「、」→ 字数割り。文の途中で切らない |
| スクロール速度 | **全文字数 ÷ TTS朗読時間（秒）**で計算。常にナレーションと同期 |
| レターボックス | 左右60px・下部オフセット250px |
| タイトルカード | 冒頭「Golden Cross」＋章題（金 #F5D742 52px）。エンド「第X章へ」 |
| 滲み出し層 | **要確認**：藍色テキスト維持 or 挿絵暗転のみ |

## 3. 制作パイプライン（v2）

```
[1] 絵コンテ設計 → 挿絵要件リスト（キャラ×場所×感情トーン×曲割り）
[2] ComfyUI(M1)で挿絵生成 —— キャラ確定シードパイプラインで場面ごとに新規生成
[3] AivisSpeechで本文朗読合成 → audio.wav ＋ timing.json（チャンク時間表）
[4] レンダラ: 挿絵背景＋スクロールテキスト（朗読時間と同期）
[5] BGM 4トーン当て込み（acrossfade d=2、音量0.3）
[6] FFmpeg: TTS音声＋BGMをamixして最終結合
```

- 参照実装: `AIvideo/scripts/prologue/render.py`（プロローグ実績版）
- TTS合成スクリプト: `動画/tts_reference/gen_tts.py`
- プロンプト資産: `動画/tts_reference/gen_goldencross_illust_v2.py`

## 4. 挿絵生成方針（既存画像は使用しない）

- キャラごとの**確定シード値パイプライン**で場面ごとに新規生成：
  - 誠40歳退職前：IPAdapter only / weight 0.45 / CFG 7.5
  - 誠24歳回想：FaceID 0.8 / DetailTweaker 0.2 / CFG 7.0
  - 百合子18歳：Doll 0.5 / FaceID 0.8 / CFG 7.0　20歳：Dual IPAdapter
  - 百合子34歳：PB tired eyes / FaceID 0.3 / CFG 10.0
  - 栞3・14歳／翼11歳／祖父／部長ほか：各設定ファイル参照
- 枚数目安：5〜10枚/章 × 10章 ＝ **50〜100枚**
- 実績プロンプト：`tts_reference/gen_goldencross_illust_v2.py` を流用
