## 細綱（第 3 章）

### 第 3 章
- 核心イベント：翼だけが里親に引き取られる。姉・栞との引き離し。翼は泣き叫ぶが、制度は止まらない。
- 字数目標：[未確定]（内容が求める自然な長さ）
- 目標感情：絶望と見捨てられ感——翼は初めて姉から引き離される。泣き叫んでも誰も止めてくれない。
- 章首フック：ミステリアスな独白 — 「ある日、知らない大人が二人、施設にやってきた。にこにこ笑って、僕のことを『かわいい』と言った。」
- 感情ピーク：施設の玄関で栞にしがみついて泣き叫ぶ翼。職員に引き剥がされる。車が発進する——後部座席から振り返ると、栞が玄関に立って手を振っている。翼が最後に見た姉の姿。

#### 内容概括（五段式）
- 起因：里親候補の夫婦が施設を訪れる。「困っている子供を引き取りたい」——表向きは善良な夫婦。翼を見て「この子がいい」と言う。栞には目もくれない。
- 展開：翼だけが引き取られることになる。栞は施設に残る。翼は「いやだ、姉ちゃんも一緒じゃなきゃいやだ」と泣く。しかし制度は個人単位。きょうだい一緒の引き取りは難しいと言われる。
- 転機：栞が翼に「あなたは行きなさい。ここのほうがきっといいから」と言う。翼には姉が自分を手放そうとしているようにしか聞こえない。実際には栞は翼を施設の地獄から逃がそうとしている——翼にはわからない。
- 山場：引き渡しの日。施設の玄関。翼が栞にしがみついて泣き叫ぶ。栞は泣かない。「大丈夫。私、大丈夫だから」——嘘だ。翼にはわかる。でも翼は子どもで、大人に引き剥がされる。
- 結末：車の中。後部座席から振り返る——栞が玄関に立って小さく手を振っている。それが最後だった。翼は泣き疲れて眠る。新しい家へ。

#### プロット構成（マルチライン）
- 主線進行：翼と栞の物理的分離。翼の世界から最後の盾が消える。
- 副線進行：栞が施設に一人残される。翼の視点からは見えないが、この後すぐに施設長のレイプが始まる（DeadCrossで既出）。
- イベント線 / 任務線：里親訪問→引き取り決定→栞との別れ→車で新しい家へ
- 感情線 / 関係線：翼と栞——物理的分離。だが翼の心の中では「姉に守られる弟」のまま。翼と里親——まだ仮面の段階。
- 論理線：里親の選定 → 翼だけ引き取り → 栞との分離 → 翼の孤立 = 次の地獄への入口

#### 人物関係と登場順
- 登場順：翼→栞→施設職員→里親夫婦（養父・義母）→施設長（短く）
- 人物関係変化：翼と栞——物理的に引き離されるが、心理的絆はむしろ強固に（守れなかった罪悪感の種）。翼と養父・義母——始まったばかりの偽りの関係。
- 視点/情報差：翼は養父母を「やさしそうな人たち」と見ている。読者は二人の正体をまだ知らない（第4章で開示）。栞が施設長にレイプされることを翼は知らない——読者は知っている。

#### プロット詳細化
- プロットポイント列：
  1. 里親夫婦の来訪（翼・栞・養父・義母）——翼を見て「この子がいい」。機能：新しい罠の設置
  2. 引き取りの通告（施設職員・翼）——「君だけ新しい家に行けるんだ」。機能：姉弟分離の宣告
  3. 栞の決断（栞・翼）——「あなたは行きなさい」。機能：栞の自己犠牲。翼には「見捨てられた」と感じられる
  4. 別れの日——玄関での泣き叫び（翼・栞・職員）——引き剥がされる。機能：分離の瞬間。翼の無力の極点
  5. 車中（翼・養父・義母）——振り返る翼。栞の手を振る姿。機能：最後の姉のイメージ
  6. 眠り（翼）——泣き疲れて眠る。機能：新しい世界への無意識の移行
- 代価の支払い / 収益の獲得：翼は最後の守護者を失う。栞は翼を逃がす代わりに自分が施設に残る。後続——翼は「姉を置き去りにした」という罪悪感を一生背負う。

#### 結末設定とフック
- 結末設定：車が止まる。翼が目を覚ます。知らない家の前。「今日からここがお前の家だ」——養父の声。未解決問題——栞はどうなるのか。この「新しい家」は本当に安全なのか。
- 章尾フック：イメージフック — 翼が見た最後の栞の姿。玄関に立って小さく手を振っている。どんどん小さくなる。翼はそれをずっと覚えている。夢の中でも、その後も——ずっと。
