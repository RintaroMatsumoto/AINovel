## 細綱（第 3 章）

### 第 3 章
- 核心イベント：回想。少年院（14→16歳）。いじめ。栞の死を知る——無力感の頂点。先輩（黒崎徹）との出会い。ボクシングとビッグ6トレーニング。体が変わり立場が変わる。出院——先輩は一足先に出所していた。章末で現在（リングの上）へ戻る。
- 字数目標：[未確定]（5,000〜8,000字）
- 目標感情：無力感→悲しみ→小さな光→決意→体の変化による自信。翼の声が「怯え」から「体で世界を測る」声へ変わる過程。栞の死による罪悪感が固まり、それが全編を駆動する。出院時の翼はもはや「泣き虫の弟」ではない。
- 章首：第2章の手の感覚から自然に——少年院の独房。14歳。体が小さく弱い翼。初日からいじめられる。まだ何もできない。
- 章尾フック：身体感覚型。現在のリングの上——グローブの中の手。少年院で鉄格子を掴んで懸垂をしていた手と同じ手だ。第4章の現在へ自然に接続。

#### 内容概括（五段式）
- 起因：少年院（14歳）。翼は体が小さく弱い——院内でひどいいじめにあう。喧嘩もできず、ただ耐えるだけの日々。独房での夜——なぜ自分はここにいるのか。まだ答えはない。
- 展開：15歳の時——院内で姉・栞の死を知る。どうやって死んだかは知らされない（ODとして処理された事実）。翼にできることは何もなかった。無力感がすべてを覆う。そんな折、いじめられている翼を偶然助けたのが先輩（黒崎徹）だった——同じ少年院の先輩受刑者。先輩は「やる気あんのか」とだけ言い、ボクシングの構えを教え始める。
- 転機：先輩の教え——ボクシングの基礎（構え、ジャブ、ストレート、フック、フットワーク）とビッグ6（腕立て、スクワット、鉄格子での懸垂、レッグレイズ、短ブリッジ、壁倒立）。翼は自由時間のすべてをそれに費やす。最初は壁腕立て50回から——3ヶ月後にはフル腕立て。半年後には懸垂と短ブリッジ。体が変わるにつれ、院内のいじめも止む。誰も翼に手を出さなくなる。
- 山場：出院の日（16歳）。先輩はすでに出所している——「出たら俺のところに来い」と言い残して。翼は一人で出院する。もはや入所時の翼ではない——体が変わり、声が変わり、誰にも守られなくても生きていける。しかし心の奥には栞への罪悪感——守れなかった姉。何もできなかった自分。
- 結末：トレーニングの反復動作（懸垂で鉄格子を掴む手、腕立てで床を押す手）が、現在のリングでの身体感覚——グローブの中で拳を握る手——と重なる。時制と光の質が変わり、自然に現在（第4章）へ。

#### プロット構成（マルチライン）
- 主線進行：少年院での翼の変容——いじめられる側から、体を鍛え上げて立場を変える側へ。栞の死による罪悪感の形成。
- 副線進行：先輩との師弟関係の形成——翼の人生で初めての「信頼できる大人」。先輩は説教せず、ただやり方を教える。
- イベント線 / 任務線：少年院入所→いじめ→栞の死の報せ→無力感→先輩との出会い→ボクシングとビッグ6の訓練開始→体の変化→いじめの終焉→出院
- 感情線 / 関係線：翼→いじめ（屈辱→無力）。翼→栞の死（衝撃→罪悪感——生涯消えない傷）。翼→先輩（最初は警戒→信頼→師弟の絆——先輩だけが「やってみせた」）。翼→自分の体（無力な枷→鍛え上げる対象→自信の源泉）
- 論理線：翼が少年院でいじめられる → 栞の死を知り無力感が頂点に → 先輩と出会いボクシングとトレーニングを学ぶ → 体が変わるとともに院内の立場も変わる → 出院 → この経験が「体で世界を測る」翼の生き方の基礎を作る

- 登場順：いじめっ子の受刑者たち（名前[未確定]）→先輩（黒崎徹）——いじめを止めに入る→[未確定：栞の死を伝える職員または他の受刑者]→出院時の職員
