# 文体技法 調査レポート

> 調査日: 2026-06-20
> 目的: DeepLove・ケータイ小説・現代的縦スクロール読書の技法を解体し、ゴールデンクロスの本文執筆に転用する

---

## 1. DeepLove の技法（Yoshi, 2000〜）

### 1-1. 多視点リレー方式

同じ世界を異なる主人公の視点で描く。第1部のサブキャラが後の巻の主人公に昇格する構造。

| DeepLove | ゴールデンクロス |
|----------|------|
| 第1部：アユ → 第2部：義之（アユの恋人） | 第1巻：誠 → 第2巻：栞（誠の娘） |
| 第1部：アユ → 第3部：レイナ（アユの親友） | 第1巻：誠 → 第3巻：翼（誠の息子） |
| 特別編：パオ（犬） | SP：百合子（妻） |

### 1-2. 主人公の死を越えた物語

アユが第1部で死んでも、その存在が全巻に影響を与え続ける。
→ ゴールデンクロスでは誠・百合子の死が栞と翼のすべての行動の原動力になる。

### 1-3. 衝撃展開の連続

ほぼ全章で何らかの衝撃的事件。テンポが非常に速く、読者を飽きさせない。
DeepLove第1部だけで「ケータイ小説七つの大罪」（売春・レイプ・妊娠・薬物・不治の病・自殺・真実の愛）をすべて使った。

### 1-4. 「物語の中にいる人間が、物語を読む」

Yoshiは渋谷の内側から書いたから、渋谷の女の子たちが「これ私の話だ」と拡散した。
ゴールデンクロスも同じ構図：トー横キッズは栞の章を「これ俺の話だ」と思う。BD層は翼の章を。

### 1-5. 名前の継承

レイナが娘に「アユ」と名づけることで、死者の存在が生き続ける。
→ ゴールデンクロスでは誠のトレードノートが「名前の継承」の役割を果たす。

### 1-6. 読者の実体験を物語に織り込む

Yoshiは連載中に読者の実体験メールをストーリーに取り入れた。
→ ゴールデンクロスのYouTube公開後のコメントを展開に反映できる。

## 2. ケータイ小説の核心技法

出典：Wikipedia「ケータイ小説」、本田透『ケータイ小説はじめました』、泉子・K・メイナード他

### 2-1. 文体

| 技法 | 内容 | ゴールデンクロス適用 |
|------|------|---------|
| **短文・改行多め** | 一文一文が短い。改行が「間」を作る | ✅ 採用済み |
| **会話駆動** | 情景描写・心理描写は最小限。セリフと行動で見せる | ✅ 採用済み |
| **横書き** | 動画フォーマットとの一貫性。書籍化後も横書き維持 | ✅ 採用済み |
| **一人称・意識の流れ** | 主人公の主観視点。思ったままを書く | ✅ 採用済み |
| **句点を打たない** | 改行そのものが区切り。歌詞・漫画ふきだしのリズム | 🔶 長セリフ以外で試験採用 |
| **空白ページで「間」** | 画面1ページ分の空白。読者に余韻・呼吸を与える | 🔶 章末の引きの直後に1行空白 |
| **顔文字・記号・半音** | 「ゎ」「ヶ」等。感情の生々しさ | ❌ ゴールデンクロスでは不使用。硬派路線 |
| **ポエム調冒頭** | 具体的固有名詞を削り、読者が自分を投影できる抽象文 | 🔶 各巻冒頭に一行 |
| **人称の混用** | 一人称の語りに三人称の距離感を混ぜる | 🔶 栞・百合子の章で試験 |
| **語り手が読者に話しかける** | 会話のような語り。「ねぇ、聞いてよ」感 | 🔶 百合子SPで使用 |

### 2-2. 内容

| 技法 | 内容 | ゴールデンクロス適用 |
|------|------|---------|
| **少女主人公の恋愛** | ケータイ小説の主力 | ❌ ゴールデンクロスは復讐・サバイバルが中心 |
| **実話系／リアル系** | 実話を元にしたとされる素人作品 | ✅ 実体験に根ざしたリアル（軍鶏・株・BD） |
| **ケータイ小説七つの大罪** | 売春・レイプ・妊娠・薬物・不治の病・自殺・真実の愛 | ✅ レイプ・危険日の意図的妊娠・立ちんぼ・OD・心中（ゴールデンクロス版） |
| **抽象性≒投影余白** | 固有名詞を減らし、読者が自分を投影できる | 🔶 感情表現は抽象的・身体的に |
| **虚無感の心地よさ** | 内面描写のなさが精神的に未発達な層を助ける | ✅ 心理描写は最小限＝文体方針と一致 |

### 2-3. 執筆過程

| 技法 | 内容 | ゴールデンクロス適用 |
|------|------|---------|
| **ケータイで書く** | PCだと一文が長くなる。制約のある端末で書くリズム | 🔶 PCで書くが「ケータイの制約」を意識 |
| **投稿→感想→修正の短サイクル** | サイト上で即時反応を得ながら書く | ✅ YouTube公開後に可能 |

## 3. 現代的応用技法（2024〜2026）

### 3-1. TikTok/Reels 時代の掴み

最初の3秒で離脱するか決まる。
→ **各章の冒頭1〜2文で読者を殴る**。説明的導入禁止。
→ 例：「封筒が届いた。」（いきなり始める）

### 3-2. LINEノベル形式

1話500字・通知で届く・会話のみで進む。
→ **1章を1500字以内**に。読了2〜3分。長くても2000字。
→ 1巻12万字÷1500字＝約80章。説明的な章は排除し、**事件のある場面だけを章にする**。

### 3-3. 縦スクロール没入

Webtoon的。スクロールの勢い＝没入。
→ **改行を「スクロール1回転＝1呼吸」**で設計。
→ 1呼吸＝スマホ画面1スクロール分（約10〜15行）。
→ 1つの感情単位＝1呼吸。その単位で改段落。

### 3-4. 「私の話」投影設計

具体性と抽象性のバランス。
→ **固有名詞（地名・店名）でリアルを**：歌舞伎町・トー横・大久保病院
→ **感情は抽象的・身体的に**：「胸がつぶれそうだった」（×「悲しかった」）

## 4. ゴールデンクロス 巻別 文体戦略

### FIRE：誠の声

- 40歳・理論派トレーダー。数字で考える
- 抑制の文体。「〜だった」「〜だ」で終わる短文
- 感情はトレードのメタファーで（「含み損が膨らんでいくようだった」）
- 封筒が届くまでは静かな日常の積み重ね → 1通ごとに文体が徐々に乱れていく

### デッドクロス：栞の声

- 14→18歳。賢く強いが孤独
- 語彙は知的だが口調はストリート（施設・トー横で獲得した二重言語）
- 父のノートを引用する場面だけ文体が誠に近づく（継承の演出）
- 「人称の混用」試験：栞の一人称の中に、客観的事実を三人称で差し込む

### ブレイクアウト：翼の声

- 11→30歳。怒りと優しさが混ざった粗い文体
- 身体感覚が生々しい：「拳が」「脚が」「背中が」
- 少年院→ホスト→地下格→車椅子。各フェーズで語彙が変わる
- 30歳エピローグでは文体が落ち着き、誠の文体に似てくる（祖父のノートが三代を結ぶ）

### 特別編「ロスカット」：百合子の声

- 34歳。優しく壊れた声
- 「ポエム調冒頭」＋「語り手が読者に話しかける」技法
- 16年分の沈黙が滲む文体。語られなかった言葉の重み
- SPでのみ、一人称の語りの中に「あの人は──」と誠を三人称で呼ぶ（距離感の演出）

## 5. 文体チェックリスト（執筆時・レビュー時）

- [ ] 一文は短いか（1文＝1情報）
- [ ] 段落間の空行はないか（`\n` のみ）
- [ ] 「彼は言った」「彼女は答えた」がないか（動作で代替）
- [ ] 「感じた」「思った」がないか（身体反応で代替）
- [ ] 連続2段以上の純心理描写がないか
- [ ] 章末に教訓・哲理がないか（代わりに一行の引き）
- [ ] 1章1500〜2000字以内か
- [ ] 章の冒頭1〜2文で読者を殴っているか
- [ ] 章ごとの感情目標が明確か（単調になっていないか）
- [ ] キャラごとの声が違うか（名前を伏せて読んで区別できるか）
