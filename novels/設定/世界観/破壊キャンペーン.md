# 破壊キャンペーン

> 金子雅也が仕掛けた、橘誠の精神を8ヶ月かけて破壊する計画的キャンペーン。
> 退社直後から毎月1通、全7通の匿名封筒が届く。

## 基本情報

| 項目 | 内容 |
|------|------|
| 期間 | L1〜L7：毎月1通・全7ヶ月で到着。L7到着後、数日〜2週間で心中。全過程約8ヶ月 |
| 開始 | 誠の退社直後 |
| 差出人 | 匿名。返信先なし。説明・走り書き一切なし |
| 戦略 | 写真だけで「不倫」に見せる。レイプ動画は送らない |
| 全素材 | 百合子18→20歳の約2年分の写真ストック |

## 金子の戦略的意図

- **説明しない**：走り書き・予告・脅迫文は一切なし。写真と日付だけ。誠の想像力が最大の武器になる
- **段階的に過激化**：普通の写真→寝室→裸→体位→妊娠中→録音。誠が「昔の話だ」と自分を慰める隙を与えず、毎月新たな衝撃を加える
- **最後の一撃は聴覚**：L1〜L6まで視覚（写真）で殴り続け、L7だけ聴覚（録音）。違う感覚でとどめを刺す
- **レイプ動画は送らない**：写真だけで「不倫」に見せることが目的。レイプ動画は自宅金庫に温存（後に栞が見つける）
