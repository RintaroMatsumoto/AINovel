# 破壊キャンペーン

> 金子雅也が仕掛けた、橘誠の精神を8ヶ月かけて破壊する計画的キャンペーン。
> 退社直後から毎月1通、全6通の匿名封筒が届く（11月のみ空白月）。

## 基本情報

| 項目 | 内容 |
|------|------|
| 期間 | L1〜L6：毎月1通・全6ヶ月で到着。11月のみ封筒なしの空白月。L6到着後、数日〜2週間で心中。全過程約8ヶ月 |
| 開始 | 誠の退社直後 |
| 差出人 | 匿名。返信先なし。説明・走り書き一切なし |
| 戦略 | 写真だけで「浮気」に見せる。レイプ動画は送らない |
| 全素材 | 百合子18→20歳の約2年分の写真ストック |

## 金子のデータ管理

- **全データはPCに集約**——撮影した写真・動画はすべてデジタルデータとしてPCの暗号化フォルダに保存。被害者ごとにフォルダを分けて管理。
- **写真は自宅プリンターで印刷**——封筒を送るたびに、その都度必要な写真を自宅のインクジェットプリンターで印刷する。印刷時にEXIF情報の撮影日時が自動で画像の縁に小さく印字される。
- **封筒の宛先もプリンター**——宛名も差出人欄もプリンターで印字（差出人欄は空白）。手書きの文字は一切存在しない。筆跡から身元を特定されるリスクを完全に排除している。
- **封筒そのものは量販品**——どこの文具店でも買える茶封筒。切手もコンビニで買える普通切手。すべてが追跡不能なように選ばれている。
- **戦略的一貫性**——金子は大学ヤリサー時代から「記録する男」だった。被害者をフォルダ管理し、日付で分類し、必要な時に必要な素材だけを取り出せるシステムを十数年かけて洗練させてきた。誠に送る封筒も、このシステムから必要な写真を選び、その都度印刷し、プリンターで宛名を打ち出しているだけ——金子にとっては日常的な作業の延長にすぎない。

## 金子の戦略的意図

- **写真の二層構造**：金子はすべての犯行で「自然に見える写真」と「行為の証拠となる写真」の両方を撮影している。同じ日に撮られたものでも、スーツ姿で普通に座っているカットもあれば、下着姿で横たわるカットもある——これにより誠の中に「彼女は意識があったのか、なかったのか」という判断不能な領域が生まれる。自然な写真の存在が、行為の写真を「合意の証拠」に見せかける効果を持つ。

- **説明しない**：走り書き・予告・脅迫文は一切なし。写真と日付だけ。誠の想像力が最大の武器になる
- **段階的に過激化**：普通の写真→寝室→裸→体位→交際期間中の全裸→新小岩アパートの全裸→中出し写真。誠が「昔の話だ」と自分を慰める隙を与えず、毎月新たな衝撃を加える
- **最後は中出し写真**：L6＝托卵の犯行で撮影した中出しの写真。膣から溢れる精液。托卵の痕跡——避妊されていないことが決定的な一撃となる。全6通一貫して写真——戦略の一貫性
- **空白の一ヶ月（11月）**：封筒が来ないことで誠の不安が自壊的に加速する。水面下では、百合子が金子に最後通告を突きつけ、金子が托卵を計画している。読者だけが知る嵐の前の静寂
- **レイプ動画は送らない**：写真だけで「浮気」に見せることが目的。レイプ動画は自宅金庫に温存（後に栞が見つける）
