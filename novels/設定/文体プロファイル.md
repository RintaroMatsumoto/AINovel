# 文体プロファイル

> 2026-06-23 全面改訂。DeepLove 由来のケータイ小説文体から、村上春樹の一人称小説を基調とした内省的文体に転換。

## スタイルタグ
抑制された内省 / 自然な回想 / 一人称没入 / 感覚的描写 / 音楽的リズム

## 7次元パラメーター

| 次元 | 設定 | 値(1-3) |
|------|------|---------|
| 語り距離 | 主人公の思考・記憶・感覚に深く潜る。読者は主人公の内面を通して世界を経験する。内省を恐れず、沈黙と「考える時間」を書く。ただし空虚な一般論や自己分析過多は避ける | 3 |
| 文法リズム | 抑制された長文を許容。一文に複数の情報を含むことを恐れない。ただし冗長ではなく、必要な情報が自然に連なっていく。読点と句点のリズムで「間」を制御する。急がない。スピードより深さ | 2 |
| 感覚密度 | 状況・風景・身体感覚を丁寧に描く。固有名詞（地名・曲名・店名）でリアリティを、抽象的な余白で読者の投影を誘う。描写は「書くべきもの」に絞り、飾りではない | 3 |
| 語彙階層 | 口語を基調としつつ、文学的な語彙も文脈に応じて許容。キャラごとの身分語彙（トレーダー／ストリート／格闘技）は厳守。衒学的語彙・業界用語の過剰使用は避ける | 2 |
| 比喩戦略 | 日常的・身体的な比喩を抑制的に使用。「まるで〜のように」より「〜みたいに」「〜と同じで」の砕けた比喩を選ぶ。陳腐な万能比喩は禁止。誠の章のみトレードのメタファー（「含み損が膨らんでいくようだった」）を抑制的に許容 | 2 |
| 感情表現 | 内省と心理描写を主武器に。「思った」「感じた」を禁じない。ただし「彼は悲しかった」のような一語要約ではなく、「なぜ自分はこんなことを考えているのだろう」と内省する過程を書く。身体反応（「手が震えた」）も併用し、内面と外面の二層で感情を描く | 3 |
| 会話比重 | 会話は必要最小限に。地の文（内省・回想・描写）が主。会話がある場合も一言一言に重みを持たせる。沈黙も会話の一部 | 2 |

値の意味: 1=抑制的（DeepLove的）、2=中庸、3=豊潤（村上的）

## 実行可能な文体指示

### 文と段落
- 一文一情報に縛られない。自然な思考の流れに沿って文を繋ぐ
- 段落は意味のまとまりで区切る。短い段落と長い段落の混在を恐れない
- 隣接段落間は単一改行 `\n` のみ。空行 `\n\n` は章タイトル直後のみ許容
- 章タイトルは `## 第X章` 形式（Markdown h2）。章タイトルと本文の間に1空行

### 内省と心理描写
- 「思った」「感じた」を禁じない。ただし内省は具体的に——何を見て、何を思い出し、なぜそう考えたかを書く
- 直接的心理語（「悲しかった」「嬉しかった」）より、内省の過程を示す（「なぜだろう。あの時はそうは思わなかったのに」）
- 2段落以上の純粋な心理描写も、内容に必然性があれば許容。空虚な感情反復は避ける

### 回想
- **境界マークなし**。現在の動作・感覚をトリガーに自然に過去へ滑り込む
- 回想のトリガーは事前に計画せず、執筆時に自然に発生させる。写真の周縁的感覚（紙質・匂い・光沢・日付の筆跡の凹凸）、数字の並び、日常の音、光の質など——物語が求める瞬間に自然に現れる
- 回想の終了も明示的なマークを使わず、現在の動作や時間経過で自然に戻る

### 会話
- 会話は独立行に
- 「彼は言った」「彼女は答えた」の会話タグは**許容**。ただし全行に付けるのではなく、誰が話しているか不明な時のみ使う
- 動作で会話を導く（「百合子が茶碗を置いた。『あなた、何かあったの？』」）も併用
- 沈黙・言いかけて止まる・間（ま）を活かす。すべてを言葉にしない

### 章構成
- 1章 **5,000〜8,000字** を目安。内容次第で前後
- 章末：総括・教訓・哲理を**禁止**。代わりに余韻（イメージ・情報の断片・静かな動作）で閉じる
- 章冒頭：静かに入る。いつのまにか物語が始まっている。説明的導入を避ける

### 情報開示
- 二層の分割開示。封筒6通（誠視点）＋百合子視点の章で異なる層の真実を明かす
- **誠視点**：読者は誠と**同時に**封筒を開け、誠の誤解を追体験する
- **百合子視点**：読者は誠より**先に**レイプの真実を知り、誠の誤解を見守る歯がゆさを抱える
- 二層の情報差が最も強力な劇的アイロニーを生む。再読に耐える構造

## 巻別文体戦略

### GoldenCross：誠の声
- 参照：村上春樹『国境の南、太陽の西』（ハジメの抑制された中年男性の一人称）＋『色彩を持たない多崎つくると、彼の巡礼の年』（段階的真実解明の声）
- 40歳・理論派トレーダー。数字と論理で世界を把握する。抑制された長文。内省は深いが感情的ではない
- 封筒を開けるたびに文体が徐々に変化——抑制の綻びが内省の質的変化として現れる。最終的に句読点の乱れと短い断片へ
- 音楽はシーンの中に自然に存在し、後からそれが記憶の情感を繋いでいたことに気づく——「回想のトリガー」として事前配置されるものではない
- 誠の一人称の二層構造：キャラ自身は感情をラベリングせず数字で世界を捉えるが、ナレーション（地の文）は内省の過程を描く。「数字で捉える癖」と「内省する語り手」の二層が文体の基盤

### DeadCross：栞の声
- 参照：金原ひとみ『蛇にピアス』（身体感覚×ストリートの声）＋桐野夏生『グロテスク』（冷徹な観察眼）＋桜庭一樹『砂糖菓子の弾丸は撃ちぬけない』（被虐待少女の沈黙）
- 14→18歳。二重言語——名門私立のお嬢様言葉とトー横のストリート言葉が状況に応じて切り替わる
- 父のノートを読む場面だけ、誠の文体（抑制された長文・「──だろう」）が地の文に自然に流れ込む。栞自身はその変化に気づいていない
- 怒っている時が一番落ち着いている。冷徹な観察眼が地の文に現れる。感情を直接書かず、観察で語る
- 身体的：痛み、空腹、寒さ、客の手の感触——身体感覚を通して世界を把握する

### Breakout：翼の声
- 参照：村上春樹『ねじまき鳥クロニクル』（岡田亨の井戸に降りる身体感覚）＋『騎士団長殺し』（地下ピットへの降下と再生）
- 11→30歳。各フェーズで声が変わる
- 幼少期（11〜14歳）：怯えと依存。短い文。「ごめんなさい」「やめて」。姉に守られるだけの弟
- 怒りと暴力（14〜20歳）：「──しろ」「──すんな」命令形と否定形。身体感覚で語る——「拳が痛ぇ」「脚が」「息が」。世界を体で測る
- 沈黙と再生（20〜30歳）：半身不随。動かない下半身。静かな内省。誠の文体に近づく——数字と相場の言葉を覚え、祖父のノートが三代を結ぶ。エピローグでは子どもの前でのみ優しい声
- 「穴」「降下」「浮上」の身体感覚が全編を貫くメタファー

## 錨定作者

- **村上春樹『国境の南、太陽の西』（1992）**：中年男性の抑制された一人称。「突然現れる過去の女」が封筒と同型。成功と空虚の並置。294ページの凝縮された崩壊の物語
- **村上春樹『色彩を持たない多崎つくると、彼の巡礼の年』（2013）**：16年前の絶縁の理由を一人ずつ訪ねて段階的に解明。封筒6通の情報分割開示の構造モデル。リスト『巡礼の年』による音楽的統一
- **村上春樹『ノルウェイの森』（1987）**：村上一人称の結晶。音楽トリガーによる回想。喪失の基調音。37歳の現在から18年前を振り返る枠構造
- **村上春樹『ねじまき鳥クロニクル』（1994-95）**：井戸に降りる身体感覚。妻の失踪から日常の裏側の闇への降下。3部構成のテンポ設計
- **村上春樹『騎士団長殺し』（2017）**：屋根裏での「発見」から非日常の侵食。「穴」のメタファー。中年男性の喪失と再生
- **金原ひとみ『蛇にピアス』（2003）**：身体感覚に根ざしたストリートの声（栞の声の参照）
- **桐野夏生『グロテスク』（2003）**：社会の外側からの冷徹な観察眼と復讐の心理（栞の声の参照）
- **桜庭一樹『砂糖菓子の弾丸は撃ちぬけない』（2007）**：被虐待少女の沈黙と内面世界（栞の声の参照）

文体は村上春樹の一人称小説（特に『国境の南、太陽の西』と『多崎つくる』）を基調とし、金原ひとみ・桐野夏生・桜庭一樹の技法を栞編に限定的に導入する。

## 禁止領域

- **陳腐な万能比喩**（「波のように」「稲妻のように」「光のように」）—— 使うなら具体的な日常比喩に
- **章末の総括・教訓・哲理**（「彼はようやく理解した…」「この夜、誰も眠れなかった」）—— 余韻で閉じる
- **空虚な内省**（「彼は悲しかった」で終わる一語要約の感情描写）—— 内省は具体的に、過程を書く
- **情報の一気開示**（1章で真実をすべて明かす）—— 分割開示。層状に配置
- **全キャラ同一口調**（各キャラの7次元言語スタイルに従う）
- **説明的な会話**（キャラが自分の動機や背景を説明する）—— 沈黙と行動で示す
- **取引手法の記述**（特定の取引手法・テクニカル指標・売買ロジックを一切記述しない。祖父のノートはテクニカルな手法ではなく投資の心構えを説く羅針盤であり、各世代が自らの力で時代に適合させた。物語の主軸はキャラの感情と運命）
