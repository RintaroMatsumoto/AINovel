# 桐生 翔（きりゅう しょう） — 主人公③

## 基本情報
- 年齢：11歳（両親死亡時）→20歳（タイトルマッチ時）
- 性格：純粋だったが、家族を失い荒れる。根は優しい。

## 経緯
- 11歳：両親の自死。姉・栞と共に施設へ。
- 裕福な家庭で育った二人は、施設で浮いた存在だった。栞が名門私立に通っていたことがばれ、姉は陰湿ないじめの的に。
- しっかり者の姉は必死にあらがっていた。しかし翔は**いつも泣いてばかり**——何もできなかった。姉はいつも「大丈夫、私が守るから」と翔を抱きしめていた。
- 施設でしばらく過ごすが、翔だけ里親に引き取られる。姉は施設に残される。引き離される瞬間、翔は泣き叫んだ——姉を守れなかった。
- 新しい家庭。最初は優しかった「新しい父」と「義母」。
- しかしすぐに本性を現す——父は小児性愛者だった。義母は知っていたが、見て見ぬふり。
- 繰り返しレイプされる。逃げ場のない日々。
- 14歳のある日——もう耐えられず、父を**殺人未遂級の重傷**を負わせる（頭蓋骨骨折・脳挫傷・重体）。
- 逮捕。家庭裁判所へ送致。少年審判——翔は凌辱されたことを**一言も語らなかった**。「そんなこと言いたくない」。
- 義母は真実を知っていたが、夫の性癖が露見するのを恐れ、翔をかばわず「理由なき暴力」と証言。
- 裁判所は翔を「動機不明の凶悪な傷害事件」と判断。**少年院送致・超長期処遇（2年）**。
- しかし体が小さく弱かったため、院内で**ひどいいじめにあう**。喧嘩もできず、ただ耐えるだけの日々。
- 15歳の時、院内で**姉・栞の死**を知る。何もできなかった自分。無力感がすべてを覆う。
- そんな折、偶然、ボクシング経験者の先輩受刑者に助けられる。
- 先輩が教えてくれたのは2つ——**ボクシングの基礎**と**体の鍛え方**だった。
- ボクシング：構え、ジャブ、ストレート、フック、フットワーク。相手はいらない。型の反復。
- 体づくり：腕立て・スクワット・鉄格子での懸垂・レッグレイズ・短ブリッジ・壁倒立。ビッグ6すべて。自分の体だけが器具だった。ゆっくり、正確に。
- 翔は自由時間のすべてをそれに費やした。最初は壁腕立て50回から。3ヶ月後にはフル腕立て。半年後には懸垂と短ブリッジ。
- 体が変わるにつれ、院内のいじめも止んだ。誰も翔に手を出さなくなった。強くなり、立場が変わる。16歳で出院。
- 先輩は一足先に出所していた。売れっ子ホストにのし上がり、「出たら俺のところに来い」と言ってくれていた。
- 翔はその言葉通り、先輩のもとへ。いつの間にかイケメン高身長に育っていた翔も、すぐにホストとして成功する。かなりの売り上げを叩き出し、女性遊びも激しくなっていった。
- だが問題児だった。店で喧嘩、町で喧嘩——手がつけられない。少年院で鍛えた体は誰にも止められなかった。
- 格闘技から足を洗っていた先輩だが、翔が入所中からトレーニングを続けているのを知る。「お前はこっちじゃなくて、あっちだ」
- 先輩の勧めで地下格闘技へ。初戦から圧勝。連戦連勝で、次第に傲慢になっていく。ついに現チャンピオンの**リョウ**への挑戦権を得る。
- 20歳：タイトルマッチ。相手は現チャンピオンの**リョウ**。リョウは翔を恐れ、会場へ向かう翔に複数人の武装した刺客を差し向ける。翔は撃退するも拳と肋骨を負傷。満身創痍のままリングへ。
- 翔は苦戦しながらも善戦。しかし追い込まれたリョウが**反則**を放つ。翔がうずくまった瞬間、リョウは後頭部を踏みつけとどめを刺す。審判は反則を認識せず、リョウの勝利が宣言される。
- 病院に緊急搬送。数日後、意識が戻る——**下半身が動かない**。
- 仲間だと思っていた者も、女たちも、誰も見舞いに来なかった。あれだけ傲慢に振る舞った報いだった。
- 試合中の事故として処理され、治療費も出ない。絶望の中、死を決意する——が、下半身が言うことを聞かず、**自殺にすら失敗する**。死ぬことさえできない。
- そんなある日、一人の弁護士が訪ねてきた——姉・栞の**遺産管財人**だった。遺品の中に父・誠一の**トレードノート**。
- ノートを開く。祖父の教え。父の走り書き。父が負けた理由が「メンタルの崩壊」だと書かれている。栞はこれを読んでトレードを始めた。そして今、翔の手にある。動かない体で、翔は祖父の言葉を初めて理解する。
- ノートを手がかりに、翔は独学でトレードの勉強を始める。
- しばらくして、ある日——バツが悪そうに現れたのは、あの先輩だった。
- 傲慢になっていた翔に怒りもあった。それでもやっぱり力になりたい——先輩はそう言った。
- 金もなく体も不自由な翔は、素直に感謝した。相場の話、父の話、栞の話。先輩は黙って聞いていた。
- 翔が書籍やノートパソコンの差し入れを頼むと、先輩は何も言わずに引き受けた。
- ホストの殺伐とした世界に疲れていた先輩は、いつしか良き理解者となり、翔の夢を静かに応援するようになる。

## 最終的な決着
- 車椅子のままトレードを始める。動けない体が、かえって相場を見つめる集中力を研ぎ澄ませた。
- 栞の遺産を元手に、格闘技で培ったメンタルをトレードに注ぎ込む。
- **10年後、30歳。** トレードで資産を築いた翔は、自ら児童養護施設を建てる。
- 自分と姉が味わった地獄を、二度と誰にも味わわせないために。
- 立派な施設の前で、子供たちに囲まれる車椅子の翔。
- その車椅子を押すのは——先輩だった。
- 「桐生さん、ありがとう」——その一言にすべてが詰まっている。
