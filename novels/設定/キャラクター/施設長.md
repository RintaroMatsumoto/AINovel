# 施設長 — 栞をレイプした男

## 基本情報
- 名前：（仮）
- 年齢：50代〜60代
- 職業：児童養護施設の施設長
- 表向きは「困った子供たちを救う立派な人物」

## 本性
- 施設の権力を利用して女子児童に手を出す。
- 栞に近づく際、力ずくではなく**甘い言葉**を使った。「私なら弟君を救ってやれる」——栞の愛情を逆手に取った操作だった。
- いじめや施設職員の嫌がらせで精神的に追い詰められた栞は、弟を守るために抵抗できなかった。

## 栞への影響
- この体験が栞の心に深い傷を残す
- 施設を脱走する直接の原因
- 「男は結局そういうもの」という諦念を植え付ける

## 物語上の役割
- 栞のどん底の一部。社会的な「守られるべき立場」の人間による裏切り。
- 翼はこの事実を後日知ることになる。
- 施設長自身は直接の復讐対象にはならない——「世の中には裁かれない悪がいる」ことを象徴。

## 言語スタイル（7次元）

| 次元 | 内容 |
|------|------|
| **口癖・慣用語** | 「私を信じなさい」「君のためだ」。子どもには「──くん」「──さん」と呼びかけ、必ず微笑む。栞に「弟君を救ってやれる」と言った時も同じ笑顔だった |
| **話すリズム** | ゆっくり。穏やか。決して急がない。怒らない。相手の不安を「間」で溶かしていく。逃げ道を塞ぐように優しい |
| **情報選好** | 制度と権限の言葉。「児童福祉法では」「私の権限で」「特別に」──善意という名の檻で相手を囲む。専門用語で子どもを委縮させ、その後に「でも、私がなんとかする」と救いの手を差し伸べる |
| **立場** | 完全なる善人。自分を一瞬たりとも疑わない。「困った子どもたちを救っている」という信念が、罪悪感を一切排除している。だからレイプも「救済」だった |
| **性格語気** | 常に優しい。声のトーンが決して変わらない──ここが一番怖い。怒鳴る男より、微笑みながら支配する男のほうが深い闇を持っている |
| **身分語彙** | 教育者・福祉の専門家。外面は完璧。第三者には「彼女は情緒が不安定で」など、被害者を「問題のある子」にすり替える語彙を持っている |
| **進捗態度** | 最初→「ゆっくり慣れればいい」包み込む優しさ。栞が追い詰められた時→「弟君を救ってやれる」初めて本音が漏れる。逃げられた後→「残念だ」心からの言葉。本気で残念がっている |
