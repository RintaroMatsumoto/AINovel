# 橘 栞（たちばな しおり） — 主人公②

## 基本情報
- 年齢：14歳（両親死亡時）→18歳（死亡時）
- 学校：私立の名門中高一貫校に通うお嬢様
- 成績：優秀。常に学年上位
- 性格：しっかり者、強い意志、孤独を抱える
- 父・誠のトレード姿を尊敬していた。
- 両親の前ではいい子。父のトレード成功を心から誇りに思っている。

## 両親死亡前の生活
- 私立の名門中高一貫校に通う。裕福な家庭で何不自由なく育つ。
- 成績は優秀で、教師からの評価も高い。将来は難関大学進学を期待されている。
- 父・誠を尊敬。食卓で交わされるトレードの話に興味を持ち、株式用語にも詳しい。
- 母・百合子とは仲が良いが、どこかで母の「暗さ」を感じ取っている——しかし深く考えないようにしている。
- 弟・翼とは年の差はあるが仲が良い。面倒見の良い姉。
- **すべては14歳のあの日まで——**

## 経緯
- 14歳：両親の首つり死体を発見。
- 両親の死後、弟・翼と共に児童養護施設に預けられる。
- 裕福な家庭で何不自由なく育った栞と翼は、他の入所児童とは**何もかもが違っていた**——言葉遣い、服装、持ち物。浮いた存在だった。
- 栞が**名門私立中学に通っていたことがばれる**と、妬みと嫉妬が一気に牙をむく。「お嬢様がなんでここにいるの？」陰湿ないじめが始まった。
- しっかり者の栞は必死にあらがった。しかし翼はいつも泣いてばかり——姉は弟を抱きしめながら、「大丈夫、私が守るから」と繰り返した。
- いじめは子供たちだけではなかった。**施設の職員による嫌がらせ**も続いていた。大人たちもまた、よそ者を許さなかった。
- ある日、施設長が栞に近づいてきた。「私なら弟君を救ってやれる」——甘い言葉だった。
- 弟を守るため——栞は抵抗できなかった。施設長にレイプされる。
- 施設で弟と一緒にいることだけが心の支えだった。
- しかし翼だけが里親に引き取られることになる。
- 一人取り残された栞。翼を引き離された絶望。
- 施設長のレイプが続き、もう耐えられない。
- 施設を飛び出し、新宿・歌舞伎町へ。所持金ゼロ。スマホなし。コネなし。
- トー横（東宝ビル裏路地）に流れ着く。同世代のトーヨコキッズがたむろしていた。
- 最初の数日、何も食べられず路地で夜を明かした。年上のトー横の女が缶コーヒーをくれた——「家、ないの？」。ネットカフェ代を借り、初めてシャワーを浴びる。
- 「金、いるでしょ。立ちなよ」——教えられて立ちんぼを始める。最初の客。知らない男のホテル。恐怖で震えた。
- 歌舞伎町での源氏名は「ねね」。立ちんぼの世界で本名を名乗る者はいない——それが彼女の最初の匿名の盾だった。
- 数日後、巡回していたケツモチの**ジン**が声をかけてくる。「お前、新入りか。誰のシマで立ってんだ。一人でここに立つと死ぬぞ」——客トラブルから守ってくれた。警察より信用できる大人が初めて現れた。
- ジンは栞の稼ぎの半分を取る。「場所代。当然だろ」。それでも守ってくれていると思っていた——翼を守れなかった罪悪感を抱える栞は、守られる側に回ることで自分を許そうとしていた。
- 「泊まるところはある。俺の部屋で寝ろ。路上よりマシだろ」——ジンが借りたアパートの一室。鍵はジンが管理。逃げ場のない同棲が始まった。
- 栞は幼い頃、あのフランス人形の背中に金貨が入っているのを知っていた。しかし施設を飛び出した時、遺品は倉庫に鍵のかかったまま。何も持って出られなかった。仕方なく体を売った。それが現実だった。
- ある夜、ホテルの客が株取引の自慢話をしていた。父の背中がよぎる。機に向かい、ノートを開く姿。忘れかけていた記憶が蘇る——あの人形にはノートも入っていた。金貨だけじゃない。**父が使わなかったあのノートが。**
- 遺品は施設の倉庫に眠っているはず。栞は深夜、施設に忍び込む。倉庫の鍵を壊し、段ボールを漁り、ついに**あのフランス人形**を見つける。施設長に見つかる前に、人形ごと抱えて逃げ出した。
- ジンと同棲を始める。逃げ場のない支配関係——しかし同時に、保護でもあった。
- 聡明な栞は図書館へ通い、株取引の書籍を片っ端から読み漁る。読み尽くした後、父のノートと照合し、完全に理解する——父が負けたのは手法ではなく、**メンタルが崩れたから**だ。
- 未成年で口座を開設できない栞はジンに頼む。めんどくさがられたが口座を作ってもらい、金貨を換金してノートPCを購入。その残りが最初の証拠金だ。立ちんぼの金は生活費に消える。ジン名義の口座で取引を開始。
- 30万→100万→300万→1000万。すべて自分の分析。父の銘柄ではない。
- 含み益が増えるにつれ、ジンの態度が変わる。「これ、デカくできるんじゃねぇか」——搾取者から共同経営者面へ。
- 客の中に金子（父の同僚・敵）が現れる。金払いのいい男。ホテルへ。だが男は何もしなかった。煙草を吸い、じっと見つめ、「……橘誠の娘だな。父の元同僚だ。確かめに来た」と言い、「お前の母さんも、なかなかだったよ」と呟いて帰っていった。栞の背筋が凍る。
- 母は入社後すぐ父と結婚したはず。同僚が母を「そういう風に」知っている——何かがおかしい。
- 調査を開始。**父の会社を張り込み、金子の後をつけて住所を把握。**後日、金子の留守中に自宅へ侵入。家中を探索し、**狂気的なコレクションルーム**を発見——壁一面のレイプ動画。その中に母・百合子のフォルダがあることを突き止める。
- 母が十数年にわたって支配されていた事実を知る。そして──**金子が自分の実の父であること**に気づく。あの夜、ホテルで自分を買った男が、実の父親だった。何もされなかった。でも買われた。その事実だけで吐き気が止まらない。
- 怒りと復讐心が頂点に達する。
- ジンと共に金子への復讐を画策し、拷問、殺害する。しかしジンはこの殺人を共犯の楔に——「お前も人殺しだ」。
- ジンの支配から逃れようと、栞が別れを告げる。
- 最後の夜。ジンは地下格闘技の試合に勝利する。栞もその闘いぶりは嫌いではなかった。祝杯のレストラン——栞が離席した隙に、ジンはグラスに睡眠薬を混入。母が金子に奪われたのと同じ手口だった。
- 意識を失った栞を自宅に連れ帰り、さらに致死量を投与。空の薬瓶を置き、**オーバードーズによる事故死を偽装**する。外傷ゼロ。警察はトー横少女のODとして処理。誰も疑わなかった。

## 運命
第七部でジンに殺される。母と同じ睡眠薬——同じ無力化、同じ「なかったこと」にされた死。
父親と同じく「這い上がった先で命を絶たれる」。
しかし彼女の遺したノートが、翼の最後の希望になる。

## 言語スタイル（7次元）

| 次元 | 内容 |
|------|------|
| **口癖・慣用語** | 「──でしょ」断定を避ける。心の中では「──だ」と言い切る。トー横では「──しねぇ」「──じゃねぇ」。父のノートを読んでいる時だけ「──だろう」と誠の口調になる。自分では気づいていない |
| **話すリズム** | 短い。考えるより先に動く。内省は後回し。名門校時代は整った言葉だったが、施設→トー横で削げ落ちた。一人でノートを読んでいる時だけ独白が長くなる |
| **情報選好** | 気づかないうちに言葉が変わっている。施設で覚えた。生きるために。父のノートを読んでいる時だけ声が静かになる。数字に強い。金の話になると目つきが変わる |
| **立場** | 父を殺した男。母を壊した男。それだけ考えていれば、他はどうでもいい。弟だけは守りたかった。守れなかった。誰も頼らない |
| **身分語彙** | お嬢様→品の良い女子中学生（敬語あり）。施設→恐怖で言葉が減る。トー横→ストリート、でも時々お嬢様の言葉が出て浮く。トレーダー→数字と株用語、父のノートの文体が混ざる |
| **性格語気** | 怒っている時が一番落ち着いている。何をすべきかはっきり見えるから。観察が鋭い。人の嘘をすぐ見抜く。芯が強く、賢い。しかし脆さを誰にも見せない |
| **進捗態度** | 14歳・遺体発見→声が出ない。施設→翼のために強がる。一人では泣く。立ちんぼ→感情を閉じる。トレーダー→数字が栞を強くする。真実を知る→吐き気の後の冷たい怒り。復讐〜死→自分が誰の子かより「何をするか」だけ |
