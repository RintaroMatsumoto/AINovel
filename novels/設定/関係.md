# 関係マップ

## 表の家族
```
橘 誠（父）── 橘 百合子（母）
         │
     ┌───┴───┐
橘 栞（長女）  橘 翼（長男）
```

## 双方の実家（絶縁状態）
```
誠側：父（元公務員→妻の死後新興宗教→出家・音信不通）
        母（誠が高校二年生の時に病死）

百合子側：母（専業主婦→父の死後パート＋スナック。酒癖悪く客・彼氏を連れ込む）── 絶縁
        父（百合子が小学五年生の時に病死）
```
- 誠も百合子も実家に頼れない。これが金子支配下の百合子が誰にも相談できなかった遠因。
- 誠の「自分の手で温かい家庭を」という執着は、母の死で失った幸せな家庭への渇望。

## 真実の血縁
```
金子 雅也 ──── 百合子（十数年にわたる強制関係）
  │
  ├── 栞の実父（百合子だけが知る真実）
  ├── 翼は誠の実子
   └── 誠は第二部で知り、絶望の果てに百合子を問い詰める→百合子が自死→誠も後追い自死
```
- 金子は栞が自分の子だと確信している。危険日に意図的に妊娠させた。
- 翼はこの真実を知らないまま。栞が自分の実父を知るのは第五部。

## 敵
```
金子 雅也
  │
  ├── 百合子：嘘の誘い→レイプ→十数年の脅迫支配。栞は金子の子。
  ├── 誠：小出しの写真で精神破壊→栞の真実で絶望→百合子を問い詰める→百合子が自死→誠も後追い自死。自分の子を孤児にした。
  ├── 栞：立ちんぼの噂を聞き客として現れる→真相を知られる→復讐のきっかけに
  └── 翼：誠の実子。しかし関わる気はない。

神崎 大輔（ケツモチ）── 栞の共犯者→搾取→殺害

施設長 ── 栞（施設でレイプ。翼が里親に出された後、脱走）

里親（養父）── 翼（里子に。繰り返しレイプ→翼が半殺し→少年院）
```

## 遺産相続の流れ（法的設定）
```
栞死亡（18歳・未婚・子なし）
  → 法定相続人：弟・翼のみ（民法889条）
  → 翼は15歳・少年院在院中
  → 家庭裁判所が「相続財産管理人」（弁護士）を選任
  → 管理人：証券口座・遺品（トレードノート含む）を保管・管理
  → 翼18歳（成年）になるが地下格闘技の世界で所在不明
  → 管理人、約2年間捜索
  → 翼20歳、タイトルマッチ後、病院で接触成功
```

## 連鎖
```
金子の犯行（百合子18歳）
  → 継続的支配（16年間・百合子18→34）
    → 誠破滅（小出し写真＋栞の真実）
    → 誠、百合子を問い詰める→百合子が自死→誠も後追い自死（栞14・翼11）
      → 栞・翼の地獄
        → 栞：施設→脱走→立ちんぼ→トレード→金子殺害→ジンに殺害（18歳）
         → 翼：里親→少年院→地下格→ジンの反則で半身不随→遺産管財人→祖父のノート→トレード→車椅子の資産家→30歳で児童養護施設建設
           → 翼30歳、車椅子で施設建設。復讐の連鎖を断ち切る
```
