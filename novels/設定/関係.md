# 関係マップ

## 表の家族
```
桐生 誠一（父）── 桐生 和代（母）
         │
     ┌───┴───┐
桐生 栞（長女）  桐生 翔（長男）
```

## 双方の実家（絶縁状態）
```
誠一側：父（元公務員→妻の死後新興宗教→出家・音信不通）
        母（誠一が高校二年生の時に病死）

和代側：母（専業主婦→父の死後パート＋スナック。酒癖悪く客・彼氏を連れ込む）── 絶縁
        父（和代が小学五年生の時に病死）
```
- 誠一も和代も実家に頼れない。これが西村支配下の和代が誰にも相談できなかった遠因。
- 誠一の「自分の手で温かい家庭を」という執着は、母の死で失った幸せな家庭への渇望。

## 真実の血縁
```
西村 健吾 ──── 和代（十数年にわたる強制関係）
  │
  ├── 翔の実父（和代だけが知る真実）
  ├── 栞は誠一の実子
   └── 誠一は第二部で知り、絶望の果てに和代を問い詰める→和代が自死→誠一も後追い自死
```
- 西村は翔が自分の子だと確信に近い認識を持っている。
- 翔はこの真実を知らないまま。

## 敵
```
西村 健吾
  │
  ├── 和代：嘘の誘い→レイプ→十数年の脅迫支配。翔は西村の子。
  ├── 誠一：小出しのビデオで精神破壊→翔の真実で絶望→和代を問い詰める→和代が自死→誠一も後追い自死。自分の子を孤児にした。
  ├── 栞：立ちんぼの噂を聞き客として現れる→真相を知られる→復讐のきっかけに
  └── 翔：自分の実子。しかし関わる気はない。

加藤 リョウ（ケツモチ）── 栞の共犯者→搾取→殺害

施設長 ── 栞（施設でレイプ。翔が里親に出された後、脱走）

里親（養父）── 翔（里子に。繰り返しレイプ→翔が半殺し→少年院）
```

## 遺産相続の流れ（法的設定）
```
栞死亡（18歳・未婚・子なし）
  → 法定相続人：弟・翔のみ（民法889条）
  → 翔は15歳・少年院在院中
  → 家庭裁判所が「相続財産管理人」（弁護士）を選任
  → 管理人：証券口座・遺品（トレードノート含む）を保管・管理
  → 翔18歳（成年）になるが地下格闘技の世界で所在不明
  → 管理人、約2年間捜索
  → 翔20歳、タイトルマッチ後、病院で接触成功
```

## 連鎖
```
西村の犯行（和代18歳）
  → 継続的支配（16年間・和代18→34）
    → 誠一破滅（小出しビデオ＋翔の真実）
    → 誠一、和代を問い詰める→和代が自死→誠一も後追い自死（栞14・翔11）
      → 栞・翔の地獄
        → 栞：施設→脱走→立ちんぼ→トレード→西村殺害→リョウに殺害（18歳）
         → 翔：里親→少年院→地下格→リョウの反則で半身不随→遺産管財人→祖父のノート→トレード→車椅子の資産家→30歳で児童養護施設建設
           → 翔30歳、車椅子で施設建設。復讐の連鎖を断ち切る
```
