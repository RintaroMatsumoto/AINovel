# 第一卷：FIRE 卷纲

## 大纲四検

### ① 本卷交付什么情緒？什么劇情模式能可靠交付？
- **情緒**：幸福が音を立てて崩れる恐怖 → 絶望 → 胸に残る痛み
- **劇情模式**：幸福な日常の積み重ね × 読者だけが知る真実（フラッシュバック）の二層構造 → 封筒による段階的破壊 → 心中
- **対標DeepLove**：「七つの大罪」相当（レイプ・危険日の意図的妊娠・立ちんぼ相当・OD・心中）を全投入

### ② 本卷核心冲突是什么？
- 誠 vs 金子（敵）── だが誠は金子の存在を知らない
- 誠 vs 真実 ── 知りたい／知りたくない
- 誠 vs 自分 ── 9ヶ月の破壊で祖父の教えを捨て、自分を見失う

### ③ 卷節奏
- 上昇トレンド（Ch1-5）：緩やかな日常 → Ch5で封筒到着＝急転
- DeadCross（Ch6-12）：月1通のペース。Ch8で二階建て、Ch10で14年ぶり接触、Ch11で録音＝頂点
- 幕切れ（Ch13-14）：一気に落下。Ch13で心中、Ch14で発見

## 爽点節奏

FIREは爽点ではなく痛みを売る巻。読者が感じるべきは：
- Ch1-4：「この家族、いいな」── 失う予感
- Ch5：「来た」── 最初の衝撃
- Ch6-10：「やめてくれ」── 崩壊を見守る苦しさ
- Ch11：「嘘だ」── 真実の重さ
- Ch13-14：「……」── 言葉を失う幕切れ

## 情緒弧線

誠の感情：平穏 → 不安 → 恐怖 → 怒り → 絶望 → 死
読者の感情：幸福の疑似体験 → 真実を知る恐怖（フラッシュバック）→ 崩壊を見守る無力感 → 幕切れの痛み

## 人物弧線

- **誠**：理性的・抑制的なトレーダー → 封筒で徐々に崩壊 → 祖父の教えを捨て信用取引に手を出す → 真実を知り絶望 → 百合子の死で全てを理解 → 後追い自死
- **百合子**：優しく沈黙する妻 → 誠の冷たさに戸惑い傷つく → 全てを告白 → 死で証明
- **栞**（巻末のみ登場）：幸福な14歳の優等生 → 両親の遺体を発見
- **翼**（巻末のみ登場）：11歳の弟。姉に守られる存在

## 反転

FIREに爽快な反転はない。唯一の「反転」は読者の認識の反転：
- 「幸福な家族」→「最初から壊れていた家族」
- 「誠の実子」→「栞は金子の子」
- 「不倫」→「16年にわたる支配とレイプ」
