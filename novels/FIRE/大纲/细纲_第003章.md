## 细纲（第3章）

### 第3章：幸せの設計図
- 核心事件：退職届提出。金子の意味深な接触。帰宅後の家族4人の食卓。栞がFIREに興味。夜、百合子との二人きりの時間。フラッシュバックで百合子が警察に相談するも相手にされない場面。
- 字数目标：1800字
- 目标情绪：幸福の絶頂——読者はこの家族を愛し始める。同時に金子の犯行と警察の無力さが怒りを呼ぶ。
- 章首钩子：退職届を差し出す手（日常の終わり＝新章の始まり）
- 爽点：なし（幸福の積み重ね。機能は「失う痛み」のための土台）

#### 内容概括（五段式）
- 起因：誠、上司に退職届を提出。円満退職の手続き。
- 发展：昼休み、金子が近づく。「家族を大事にしろよ」。栞の話をわざわざ振る——不自然な関心。
- 转折：帰宅。家族4人の食卓。百合子の手料理。栞の笑顔。翼の無邪気さ。完璧な夜。
- 高潮：フラッシュバック——レイプ翌朝の百合子。警察に行くが薄ら笑いであしらわれる。「酔った上でのことなら……」。誰も助けてくれなかった。
- 结尾：子供たちが寝たあと、誠と百合子が二人で過ごす静かな時間。

#### 情节安排（多线）
- 主线推进：退職完了。家族の幸福を最大限に描く。
- 辅线推进：金子の不自然な言動（F001）。フラッシュバックで百合子の孤立（警察の無力さ）。
- 事件线 / 任务线：退職届提出 → 金子の接触 → 帰宅 → 家族の食卓 → フラッシュバック → 夫婦の時間
- 感情线 / 关系线：誠「ありがとうな。支えてくれて」→百合子の笑顔の裏に一瞬の翳り（F002）
- 逻辑线：退職届提出で日常が「終わり」→ 金子の不穏な動き → 幸福な食卓（読者が守りたくなる）→ フラッシュバックで読者にだけ警察の無力さを見せる → 百合子の微かな翳り（読者だけが理由を知っている）

#### 人物关系和出场顺序
- 出场顺序：誠 → 上司 → 同僚たち → 金子 → 百合子 → 栞 → 翼 → フラッシュバック（百合子18歳・警察官）
- 人物关系变化：誠と会社の関係が「社員」から「元社員」に。金子が退職を機に動き始める。
- 视角/信息差：誠は金子の言葉の違和感に気づかない。読者はフラッシュバックで百合子の孤立を知る。誠が「支えてくれてありがとう」と言うほど、読者の胸は締め付けられる。
