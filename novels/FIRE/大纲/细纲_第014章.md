## 细纲（第14章）

### 第14章：遺された者
- 核心事件：栞（14歳）が帰宅し、両親の遺体を発見する。混乱の中、機の上の封筒の束に気づく。まだ全てを理解できないが、何かがおかしいと感じる。翼が帰宅する前に封筒を自分の鞄にしまう——デッドクロスへの橋渡し。
- 字数目標：2000字
- 目標情緒：喪失と混乱。14歳の少女が両親の死の現場に立ち尽くす。そして微かな違和感——物語は次の巻へ。
- 章首鉤子：栞の「ただいま」。返事はない。
- 爽点：なし（幕切れ。デッドクロスへの導入）

#### 内容概括（五段式）
- 起因：栞が学校から帰宅。「ただいま」——返事がない。静かすぎる家。
- 発展：リビングは空っぽ。キッチンも。靴が脱ぎっぱなし——父の靴。寝室のドアへ向かう。
- 転折：寝室。母がベッドに。父が——。栞の絶叫。電話。救急車。警察。手が震える。声が出ない。
- 高潮：リビングのテーブルに、差出人不明の封筒の束。開封済み。中を覗く——母の写真。知らない男。USB。栞は何かがおかしいと感じる。
- 結尾：翼の帰宅前に、栞は封筒を自分の鞄にしまう。決意の表情——まだ14歳。でも、もう「守られる子」ではない。

#### 情節安排（多線）
- 主線推進：FIREの結末——栞による遺体発見。そして「違和感」が次の巻の種を蒔く。
- 辅線推進：翼への配慮——栞は弟を守ろうとする最初の行動をとる。
- 事件線 / 任务線：帰宅 → 発見 → 通報 → 封筒の発見 → 封筒を隠す
- 感情線 / 関係線：栞の「守られる子」から「守る者」への最初の変化。両親の死が栞の人生を変える瞬間。
- 逻辑線：帰宅 → 異変に気づく → 発見 → 衝撃 → 封筒発見（違和感の種）→ 翼のために隠す → 次巻へ

#### 人物関係和出場顺序
- 出場顺序：栞 → 百合子（故人）→ 誠（故人）→ （栞の想像の中の翼）
- 人物関係変化：栞は一瞬で孤児になる。両親を失い、弟を守る立場に。
- 视角/信息差：栞は封筒の中身を見て違和感を覚えるが、まだ真実には届かない。読者は全てを知っている——この情報差がデッドクロスの駆動力になる。
