# 日本家計財務調査 — 現代日本（202X）小説背景資料

## 研究サマリ

本調査は、現代日本（202X年代）を舞台とする小説の背景資料として、40歳の元サラリーマン（課長クラス、年収800〜1000万円）が副業トレーダーとして成功し、完全退職して専業トレーダーとなった主人公の家庭財務状況をリアルに描くために必要な3つのトピック——家計管理モデル、カーローン費用、私立中学学費——を調査したものである。調査結果は、総務省統計局「家計調査」、日本銀行「生活意識に関するアンケート」、各金融機関の公表資料、文部科学省「子供の学習費調査」等の公開データに基づき、小説の舞台設定として十分な精度で一般性のある数値を提供する。

## キー発見

### 1. 日本の家庭における家計管理モデル

#### 1.1 伝統的サラリーマン家庭の管理パターン

日本のサラリーマン家庭では、大きく分けて以下の3つのパターンがある：

**パターンA：妻が全管理（財布の紐を握る）** — 最も一般的。夫の給与は妻名義のメイン口座に振り込まれ、妻が生活費すべてを管理。夫は月々一定額の「お小遣い」を受け取る。

**パターンB：夫がメイン管理** — 夫が給与口座を管理し、毎月一定額を妻に「生活費」として渡す。

**パターンC：共同管理・役割分担** — 夫婦で話し合いながら管理。口座は別々だが、生活費用の共同口座（名義は夫または妻の単独名義。日本には法的な「共同口座」制度は存在しない）に毎月一定額を入金する。

**この小説における推奨設定**：主人公（誠）が会社員時代はパターンA（妻・百合子が生活費を管理、誠は月々のお小遣い制）。副業トレードで構築した資産は誠個人名義の別口座で管理（妻は大まかな金額は知っているが詳細は把握していない）。退職後は誠がメイン管理に移行しつつ、生活費は妻に渡し続けている過渡期の状態——ここに夫婦間の金銭的緊張が生まれる設定にできる。

#### 1.2 口座構造

日本では法的な「夫婦共同口座」は存在しない。一般的な口座構成：

- **夫名義のメイン口座（給与振込口座）**：給与受取、住宅ローン引落、公共料金引落
- **妻名義の生活費用口座**：食費・日用品など日常支出
- **夫名義の証券口座**：トレード用
- **子ども名義の貯蓄口座**：将来の教育費用（妻が管理するケースが多い）

#### 1.3 個人事業主（専業トレーダー）への移行による変化

会社員から個人事業主（個人事業主／雑所得申告者）になると、以下を**自分で管理**する必要がある：

| 項目 | 会社員時代 | 個人事業主 |
|------|-----------|-----------|
| **所得税** | 源泉徴収（会社が天引き） | 確定申告で年1回納付＋予定納税（年2回） |
| **住民税** | 特別徴収（給与から天引き） | 普通徴収（年4回の納付書で自分で払う） |
| **年金** | 厚生年金（会社と折半） | 国民年金（月額約16,520円、全額自己負担）＋付加年金／国民年金基金は任意 |
| **健康保険** | 協会けんぽ／組合健保（会社と折半） | 国民健康保険（前年の所得に応じて計算。所得800万円の場合、年額約50〜70万円程度） |
| **雇用保険** | 加入（会社負担あり） | 非加入 |
| **経費管理** | 年末調整で会社が処理 | 自分で経費計算・領収書管理・記帳が必要 |

**重要な小説的ポイント**：退職直後の誠は、毎月の給与がなくなることへの不安、健康保険料の高さへの驚き、確定申告の煩雑さなどを経験する。これらはキャラクターの内面描写に使える。

#### 1.4 4人家族・関東郊外の月間生活費

総務省「家計調査」（2024年、二人以上世帯）に基づく、4人家族（夫婦＋子ども2人）の関東地方における月間支出の目安：

| 費目 | 月額（概算） | 備考 |
|------|------------|------|
| 食費 | ¥90,000〜120,000 | 外食込み |
| 住居費（住宅ローン） | ¥100,000〜150,000 | 郊外の一戸建て、35年ローン、借入3,500〜4,500万円程度 |
| 光熱水道費 | ¥25,000〜35,000 | 季節により変動 |
| 通信費 | ¥20,000〜30,000 | スマホ4台＋自宅ネット |
| 教育費（詳細後述） | ¥70,000〜100,000 | 私立中＋公立小。塾代込み |
| 交通費 | ¥15,000〜25,000 | ガソリン代＋電車通学定期代 |
| 日用品・衣料 | ¥30,000〜50,000 | |
| 保険 | ¥30,000〜40,000 | 生命保険＋自動車保険＋火災保険 |
| 自動車維持費（ローン除く） | ¥20,000〜30,000 | 駐車場＋税金＋車検積立＋ガソリン |

### 2. カーローン費用

#### 2.1 対象車種の価格帯

トヨタ・ヴォクシー、ホンダ・ステップワゴンは、日本のファミリー向けミニバンの代表格（Mクラス）。

| 車種 | 新車価格帯（税込） |
|------|------------------|
| トヨタ・ヴォクシー | ¥3,200,000〜4,100,000 |
| ホンダ・ステップワゴン | ¥3,100,000〜4,000,000 |

中間グレード（両側パワースライドドア、安全装備付き）で **約350〜380万円** が現実的な購入価格。

#### 2.2 カーローンの典型条件

日本のカーローン（銀行系・ディーラー系）：

| 項目 | 内容 |
|------|------|
| 金利 | 銀行系：年1.5%〜3.5%（変動・固定あり）、ディーラー系：年3.0%〜5.0% |
| 借入期間 | 3年、5年、7年が一般的（最長10年の商品も） |
| 頭金 | 0円〜車両価格の30%程度 |
| ボーナス併用払い | 年2回のボーナス時に増額返済するプランが一般的 |

#### 2.3 月額返済シミュレーション

**前提**：車両価格360万円、頭金60万円、借入300万円、金利3.0%（固定）

| 返済期間 | 月額返済 | ボーナス加算（年2回） | 実質月負担 |
|---------|---------|---------------------|-----------|
| 3年 | ¥87,300 | なし | ¥87,300 |
| 5年 | ¥53,900 | なし | ¥53,900 |
| 7年 | ¥39,600 | なし | ¥39,600 |
| 5年（ボ併用） | ¥43,200 | ¥150,000/回 | ¥68,200換算 |

**小説の推奨設定**：主人公（誠）は金利に敏感なトレーダーなので、銀行系ローンで5年固定・月額 **約5.4万円** を選んでいる設定が自然。ボーナス払い併用にすると「退職後ボーナスがなくて支払いが厳しい」というプロットポイントにも使える（実際にはボーナス払い分は貯蓄から充当するので破綻はしないが、心理的負担になる）。

**出典**：銀行・ディーラーの公表金利、および中古車価格相場データ。具体的な金利は各社ウェブサイトのシミュレーションに基づく。

### 3. 私立中学（私立中学校）学費

#### 3.1 学費の構造

日本の私立中学校の費用は以下のように構成される：

| 費目 | 内容 | 支払時期 |
|------|------|---------|
| **入学金** | 入学時に一度だけ支払う | 合格発表後〜入学前（1〜2月） |
| **授業料** | 毎月または学期ごとに支払う教育の基本料金 | 月払い／前期一括／後期一括 |
| **施設費（施設設備費）** | 校舎維持・設備のための費用 | 授業料と同時期 |
| **教育充実費** | 特別プログラム・ICT機器などの費用 | 授業料と同時期 |
| **給食費** | 給食がある学校の場合（中学では弁当の学校も多い） | 月払い |
| **PTA会費・後援会費** | 任意だが実質強制 | 年1回または学期ごと |
| **修学旅行積立** | 3年次の国内・海外修学旅行費 | 月々積立 |
| **制服・体操着** | 入学時（指定品） | 入学前 |
| **副教材費** | 教科書（無償）以外の教材 | 学期ごと |

#### 3.2 中堅私立中学の年間費用（目安）

**文部科学省「子供の学習費調査」（令和5年度）** 等に基づく、中〜上位の私立中学（いわゆる偏差値55〜65程度の学校）の費用目安：

| 費目 | 金額（年間） | 支払いタイミング |
|------|------------|-----------------|
| 入学金（初年度のみ） | ¥250,000〜350,000 | 合格後（1〜2月）一括 |
| 授業料 | ¥480,000〜600,000 | 前期（4月）¥240,000〜300,000＋後期（10月）同額、または月払い¥40,000〜50,000 × 12 |
| 施設費 | ¥150,000〜200,000 | 前期一括または前期＋後期分割 |
| 教育充実費 | ¥50,000〜100,000 | 年一括または前期・後期 |
| 給食費（任意） | ¥40,000〜60,000 | 月払い¥4,000〜5,000 × 10ヶ月 |
| PTA・後援会費 | ¥20,000〜30,000 | 年一括 |
| 修学旅行積立 | ¥60,000〜120,000 | 月払い¥5,000〜10,000 |
| 制服・体操着（初年度のみ） | ¥80,000〜120,000 | 入学前 |
| 副教材費 | ¥30,000〜50,000 | 学期ごと |
| **初年度合計** | **約¥1,100,000〜1,500,000** | |
| **2年次以降合計** | **約¥830,000〜1,100,000** | |

#### 3.3 支払いのタイミングと現実的な資金計画

**入学前（1月〜3月）に必要な資金**：
- 入学金：¥250,000〜350,000
- 制服・体操着：¥80,000〜120,000
- 前期授業料（一括払いの場合）：¥240,000〜300,000
- 前期施設費・諸費用：¥100,000〜150,000
- **合計：約¥670,000〜920,000（入学前に一気に必要）**

**4月以降の月々負担**（月払いの場合の目安）：
- 授業料：¥40,000〜50,000
- 給食費：¥4,000〜5,000
- 修学旅行積立：¥5,000〜10,000
- 塾代（私立中でも通塾は一般的）：¥20,000〜30,000
- **月額合計：約¥70,000〜95,000**

#### 3.4 小説における実用的な設定

主人公の長女（栞、14歳）は私立中学2年生。学費は以下のように設定するとリアル：

- 初年度に入学金30万円＋前期学費等45万円＝75万円を支払い済み
- 現在（2年次）の年間費用：授業料＋施設費等で約100万円
- 月々の引落額：約45,000円（授業料＋諸費の月払い）＋塾代25,000円

**出典**：文部科学省「子供の学習費調査」、各私立中学の公式ウェブサイト募集要項（2024年度）。数値は中堅校の平均的な範囲内。

## 信頼度説明

- **総合的信頼度：中〜高**
- **家計管理モデル**：信頼度 **高**。日本の家庭における金銭管理パターンは社会学的に広く研究されており、各種アンケート調査で一貫した結果が得られている。
- **生活費の数値**：信頼度 **中〜高**。総務省「家計調査」に基づくが、具体的な支出額は世帯属性や地域によって変動する。小説設定の範囲では十分な精度。
- **カーローン費用**：信頼度 **高**。金利や月額返済額は公開情報に基づく数学的計算のため、高い精度を持つ。
- **私立中学学費**：信頼度 **中〜高**。学校ごとの差異が大きいが、提示した範囲は中堅校の一般的な相場を反映している。
- **潜在的論争点**：生活費の「標準」は「家計調査」の平均値であり、実際の家計は収入や価値観によって大きく異なる。

## キー事実抽出（執筆素材）

1. **夫婦の金銭的緊張**：サラリーマン時代は「妻が財布を握り、夫は月5万円程度のお小遣い」という伝統的パターン。トレード資産1億円は夫名義の別口座。退職後は収入の不規則性から夫婦間の金銭管理を再交渉する必要が生じる——これは夫婦関係のサブプロットに使える。

2. **退職直後の現実的ショック**：会社員時代は天引きされていた国民健康保険料（年額50〜70万円）と国民年金（月16,520円）を自分で支払う必要がある。この「見えないコスト」の発見は、誠の「自由になったはずなのに」という感覚に具体性を与える。

3. **住宅ローンの重み**：郊外一戸建て、借入残高約2,500〜3,000万円、月返済10〜12万円。全額返済するか、金利変動リスクをヘッジしながら運用益でカバーするか——誠のトレーダーとしての判断を描く場面に使える。

4. **私立中学の「まとまった支払い」**：入学前に約75万円の一括支出、毎月の引落約4.5万円＋塾代2.5万円。これらの数字は、誠の資産（1億円）があっても「流動的な生活費」としての家計の逼迫感を演出するのに使える。

5. **カーローンの残債**：新車購入から2〜3年経過、残債約200〜250万円、月5.4万円。退職後は「ボーナス払いがない」ことによる心理的圧迫が、ささやかだが具体的な不安として描ける。

## 注意事項

- 上記数値は202X年代（概ね2023〜2026年）の一般的な相場を反映。インフレや政策変更により変動の可能性あり。
- 実際の小説では、具体的な金額を頻繁に出すよりも、「住宅ローンの残高を見て溜息をつく」「学費の振込用紙を見つめる」といったディテールとして使用するのが効果的。
- 本調査で提示した数字は、主人公の資産（1億円）が「資産としては大きいが、家族4人の生活と教育を支えるには決して余裕ではない」という緊張感を支える素材として使用できる。
