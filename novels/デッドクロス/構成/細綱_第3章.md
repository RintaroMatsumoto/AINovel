## 細綱（第3章）

- 核心イベント：施設長が「弟君を救ってやれる」と接近→レイプ。翼だけ里親に引き取られる。一人取り残された栞。脱走を決意。最初の底。感情を閉じる声の始まり。
- 字数目標：[未確定]（内容が求める自然な長さ）
- 目標感情：恐怖→絶望→感情の閉鎖。栞が「感情を外に出さない」ことで自分を守り始める転換点。
- 章首：施設長に呼び出される栞。個室。穏やかな笑顔。お茶が出される。「話をしよう」
- 感情ピーク：翼が里親に引き取られる場面——翼が泣き叫ぶ。栞は「大丈夫」と言う。しかしそれは嘘だった。二人は引き離され、栞は一人になる。

#### 内容概括（五段式）
- 起因：施設長の接近——第2章で撒かれた伏線が動き出す。「私なら弟君を救ってやれる」。栞の最大の弱点（翼を守りたい）を突いた言葉。
- 展開：施設長の「面談」が定期的になる。最初は翼のための手続きの話。しかし次第に個人的な領域へ。手が肩に。栞は抵抗できない——翼のために。
- 転機：レイプ。施設長の個室。力ずくではない——拒否すれば翼を守れないという含意。栞は感情を閉じる。体と心を切り離す——それが唯一の防御だった。
- 山場：翼の里親引き取りの知らせ。やった——翼だけ救われる。しかし栞は置き去りにされる。翼が泣き叫ぶ。「お姉ちゃんも一緒に！」——引き離される二人。栞は「大丈夫」と言う。声は出ていたが、感情はなかった。
- 結末：一人になった栞。施設の部屋。翼のいないベッド。施設長のレイプは続く。脱走を決意する——もうここにはいられない。

#### プロット構成（マルチライン）
- 主線進行：施設長の接近→レイプ→翼の引き離し→脱走決意。
- 副線進行：翼を「守る」ことが、かえって栞を危険に晒すという皮肉。
- イベント線 / 任務線：施設長の呼び出し→「弟君を救ってやれる」→定期的「面談」→レイプ→翼の里親話→引き離し→一人→脱走準備。
- 感情線 / 関係線：栞→翼（「守るために耐える」→「守った結果、置き去りにされる」）／栞→施設長（恐怖と無力）／栞→自分の感情（閉鎖——感じないことで生き延びる）。
- 論理線：施設長の接近（第2章伏線回収） → 「翼のため」という操作 → レイプ → 翼だけ救われる → 一人取り残される → 脱走決意。

#### 人物関係と登場順
- 登場順：施設長 → 栞（語り手）→ 翼 → 里親（新しい養父母——外見だけ。翼の地獄は栞の知らないところで始まる）→ 施設職員。
- 人物関係変化：栞→施設長：微かな違和感（第2章）→明確な加害者。栞→翼：「守る」から「守った結果引き離される」へ。栞→自分：感情を閉じる防衛機制の発動。
- 視点/情報差：栞は翼が「救われた」と思っている——里親の本性を知らない。読者（設定から）は翼がこれからレイプ地獄に落ちることを知っている——栞の「翼だけでも」という安堵が、読者には痛ましい誤解に映る。施設長は自分を「救済者」と信じて疑わない（最も恐ろしい種類の悪）。

#### プロット詳細化
- プロットポイント列：
  1. 施設長の呼び出し。個室のお茶。穏やかな笑顔——第2章の伏線回収（機能：接近の始まり／善意の仮面の持続）
  2. 「弟君を救ってやれる」——栞の弱点を完璧に突く言葉（機能：操作の核心。栞に拒否権を奪う）
  3. 定期的「面談」の日常化。施設長の手が肩に——境界の侵食（機能：段階的な支配の確立）
  4. レイプ。栞の内面——感情を閉じる。体と心を切り離す（機能：栞の声の変化の起点／防衛機制の発動）
  5. 翼の里親話。施設長が「手配した」と言う——レイプの「見返り」かのように（機能：支配の完了／栞の屈辱の頂点）
  6. 引き離しの場面。翼が泣き叫ぶ。栞の「大丈夫」——声は出ているが中身がない（機能：感情ピーク／栞の声の決定的変化）
  7. 一人の夜。翼のいないベッド。施設長の「面談」は続く（機能：絶望の底／脱走動機の確立）
  8. 脱走の決意——小さな鞄に詰めるもの。窓の外。夜（機能：第4章への接続／受動から能動への微かな芽）
- 代価の支払い / 収益の獲得：栞は性的尊厳を奪われ、翼との絆を物理的に断たれる。施設長は支配欲を満たす（収益）。翼は里親という「出口」を得る——しかしそれは別の地獄の入り口だった。

#### 結末設定とフック
- 結末設定：栞は脱走を決意。もう失うものはない。施設を出る。どこへ行くかもわからないまま。
- 章尾フック：未完了動作フック——窓を開ける栞。外の空気。後ろを振り返らない。施設の廊下で、施設長の足音が遠ざかっている。
