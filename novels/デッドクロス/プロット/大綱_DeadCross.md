# DeadCross 巻綱

## 核心情報
- 章範囲：モノローグ＋第1〜13章
- 字数目標：[未確定]（字数固定枠廃止。内容が求める自然な長さ。最終章はクライマックスを一気に書くため長くなることを許容する）
- 本巻定位：展開＋山場（三部作の第二巻。栞の転落から這い上がり、復讐と死まで。GoldenCrossの余波から始まり、Breakoutへ継承する）

## 核心的対立
橘栞（14歳）が両親の遺体発見からすべてを失い、施設・トー横・立ちんぼの底辺を経て、父のノートを頼りにトレーダーとして這い上がる。しかし母を破滅させた金子雅也が客として現れ、栞は自らの出生の真実と母への犯行を知る。復讐を遂げるも、共犯者ジンに殺される。這い上がりと破滅を同時に駆動するのは、金子の支配の連鎖——母から娘へと受け継がれた暴力の系譜である。

## 感情弧線
- テンプレート：W形（多段波——谷→山→谷→山→最終崩落）
- 選択理由：4年間の物語は単一の上昇/下降ではなく、複数の環境転換（施設／トー横／トレード／復讐）を経る。各段階で感情の山谷があり、最終波（復讐と死）が最大振幅となる。V形（這い上がり）と逆V形（破滅）の複合。モノローグの幸福な日常が、第1章の崩落との落差を最大化する。

## 語りの特異構造

### モノローグ——「映像としての幸福」
GoldenCross と同様、本巻もモノローグから始まる。「後にすべてが崩壊する幸福の頂点」を映像として描く。栞14歳の日常——名門私立の放課後、食卓での父のトレード話、翼との他愛ないやりとり、母の「暗さ」を感じながらも考えないようにしている自分。具体的な台詞や所作は narrative-writer に委ね、構造だけを示す。

### 一人称没入／栞の声の段階的変化
本巻は全編を通じて栞の一人称。章題は `## 第X章` の番号のみ（モノローグは章番号なし）。栞の声は物語の進行に伴って自然に変化する——下記は方向性の示唆であり、章の境界で機械的に切り替わるものではない。

| 章 | 栞の声の方向性 |
|------|---------|
| モノローグ | 整ったお嬢様の言葉。父への尊敬と母への微かな違和感が混在。幸福の無自覚 |
| 第1章 | 困惑から声が出なくなるまで。退社直後は普通の観察。父の変貌に言葉が追いつかない。遺体発見——声を失う。短い断片。身体感覚だけが地の文に残る |
| 第2-3章 | 翼のために強がる。一人では泣く。施設長の前では言葉が減る。レイプ——感情を閉じる |
| 第4-6章 | ストリート言葉。源氏名「ねね」。短い文。冷めた観察。空腹・寒さ・客の手——身体感覚で語る |
| 第7-8章 | 人形奪還の決意と緊張。ノートを読む場面だけ誠の文体（「──だろう」「──はずだ」の推論調、抑制された長文）が地の文に自然に流れ込む——栞自身はその変化に気づいていない |
| 第9-10章 | 数字と株の語彙。冷静な判断。ジンの変化への冷徹な観察眼。怒っていない時のほうが実は危うい |
| 第11-12章 | 吐き気の後の冷たい怒り。感情を直接書かず、観察と身体感覚で語る。怒っている時が一番落ち着いている——冷徹な観察眼が地の文を支配する |
| 第13章 | 行動の記述が主。内省は最小限。最後の瞬間、一瞬だけ幼い日の記憶がよぎる |

> 実際の執筆時には narrative-writer が自然な声の移行を見つける。上記は方向性の示唆であり、固定的な縛りではない。

### 劇的アイロニー——GoldenCrossとの二層情報差
- **読者は知っている／栞は知らない**：
  - 金子が百合子をレイプし16年間支配した張本人であり、封筒キャンペーンで両親を死に追いやったこと（GoldenCross 第3-7章）
  - 栞が金子の実子であること（GoldenCross 滲み出し層④・L7音声）
  - 翼が里親のもとで何を経験するか（本巻では栞視点のため一切描かれない。第3巻Breakoutで開示）
- **栞が知っている／読者は本巻で初めて知る**：
  - 施設でのレイプの詳細
  - トー横・立ちんぼの現実
  - ノートを読んで栞が掴んだ「父が負けた理由」
  - 金子の自宅のコレクションルームの全貌
- **栞が知っていて、読者もGoldenCrossで知っているが、栞自身は結びつけられていない**：
  - 父の退社後の変貌——読者は封筒キャンペーンの影響と知っているが、栞は理由がわからないまま観察している。第12章で真実を知った時、栞の中で第1章の記憶が遡及的に意味を持つ

### 回想の技法
- 境界マーク（`***`等）は一切使わない
- 現在の身体感覚をトリガーに自然に過去へ滑り込む——空腹→施設の食事、寒さ→路上の夜、客の手の感触→施設長の手、株の数字→父の背中、客の煙草の匂い→[未確定]
- 父のノートを読む場面だけ、現在の栞の一人称に誠の文体が自然に滲み込む——栞自身は気づかないまま、父の言葉を自分の言葉として吸収していく
- モノローグ自体が回想の起点——第12章で真実を知った時、モノローグの幸福な食卓の情景が別の意味を帯びて読者の記憶に蘇る

## 特筆すべき設計判断

- **モノローグ**：映像としての幸福を描く。栞14歳の普通の一日。名門私立の放課後、父のトレード話に耳を傾ける食卓、翼の他愛ない言動、母の「暗さ」を感じながらも「考えないようにしている」栞の自己防衛。後にすべてが崩壊する落差を作る。具体的な台詞やシーンは narrative-writer に委ねる
- **第1章**：誠の退社から遺体発見まで——GoldenCrossでは描かれなかった「残された家族の8ヶ月」を栞の視点から。父の変貌、母のパート、食卓の沈黙。栞は理由を知らないまま観察する。そして遺体発見。GoldenCross最終章のラストカット（「子どもたち→人形」）から地続きでありながら、栞の目を通して「発見」を追体験する
- **第2-3章**：施設の地獄を2章で描く。第2章は環境（いじめ・孤立）の確立、第3章は施設長の接近→レイプ→翼の引き離し。施設長は力ずくではなく甘い言葉で——「弟君を救ってやれる」がレイプの前振りだと後からわかる構造
- **第4章**：脱走からトー横までを一気に。年上の女との邂逅——悪人でも善人でもなく、トー横の現実そのもの。缶コーヒーと「立ちなよ」の一言。サバイバル知識は善意でも悪意でもなく、ただ受け継がれていく
- **第5-6章**：ジンの支配構造を2章かけて確立。第5章で出会いと同棲開始、第6章で日常の諦念と、そこに割り込む父の記憶。株の話をする客——この客は後々の伏線にはならない、ただの「きっかけ」
- **第7章**：人形奪還。全編で唯一の「潜入」シーン。緊張と解放。施設長に気づかれそうになる——しかし逃げ切る。ここで栞は初めて「自分の意志で何かを取り戻す」
- **第8章**：ノートを読む章。父の文体が栞の地の文に流れ込む——この技法は本章で最も顕著に用いる。以降は必要な場面で抑制的に
- **第9-10章**：トレード成長を2章に分ける。第9章は成長そのもの（5万→30万→100万→300万）、第10章は1000万達成とジンの質的変化。数字だけの章にはしない——ジンの態度の変化が並走する
- **第11章**：金子との遭遇。ホテルの一室。金子は何もしない——煙草を吸い、じっと見つめ、言葉だけ残して帰る。その「何もしなさ」がかえって不気味。金子の油断——栞を小娘と侮った陶酔が、口を滑らせる
- **第12章**：調査と真実。張り込み→自宅侵入→コレクションルーム発見。GoldenCrossの滲み出し層で読者がすでに知っている金子の正体と栞の血縁——しかし栞の目で「初めて知る」衝撃を描く。劇的アイロニーの解放点。母の「暗さ」の正体、父の変貌の理由——すべてが遡及的に意味を持つ
- **第13章**：金子殺害→ジンの共犯の楔→別れ→ジンによる殺害。クライマックスから結末まで一気に。最後の夜——地下格の勝利を祝うレストラン。ジンが睡眠薬を混入する場面は、母・百合子が金子にされたのと同じ手口。栞は母と同じ方法で無力化され、同じように「なかったこと」にされる。外傷ゼロ。警察はトー横少女のODとして処理。人形とノートは管財人弁護士を通じて翼へ——第3巻Breakoutへの継承

## 禁止事項（再確認）
- 章タイトルは付けない（`## 第X章` 番号のみ。モノローグは章番号なし）
- 境界マーク（`***`等）での回想区切り禁止
- 章末の総括・教訓・哲理禁止（余韻で閉じる）
- 取引手法の記述禁止
- 陳腐な万能比喩禁止
- 回想のトリガーを事前に章ごとに割り当てない（上記の方向性は narrative-writer への示唆であり、固定的な割り当てではない）
- 文体の変化段階を事前に計画しない（上記の「栞の声の方向性」は示唆であり、章の境界で機械的に切り替えるものではない）
- ノートは人形の背中にある。物理的には一切登場しない（第7章の人形奪還と第8章のノートを読む場面を除く）
- 設定にない具体的文言を創作しない
- 設定ファイルの情報を機械的に細綱にコピペするな
- 細綱は設計図——台詞・所作・物品・詩的描写は narrative-writer の領域
- GoldenCross の内容をコピーするな。これは別の巻、別の語り手だ
