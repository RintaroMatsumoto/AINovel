# DeadCross 巻綱

## 核心情報
- 章範囲：プロローグ＋第1〜11章＋エピローグ
- 字数目標：[未確定]（字数固定枠廃止。内容が求める自然な長さ。最終章はクライマックスを一気に書くため長くなることを許容する）
- 本巻定位：展開＋山場（三部作の第二巻。栞の転落から這い上がり、復讐と死まで。GoldenCrossの余波から始まり、Breakoutへ継承する。11＋プロローグに圧縮）

## 核心的対立
橘栞（14→18歳）が両親の遺体発見からすべてを失い、施設・トー横・立ちんぼの底辺を経て、父のノートを頼りにトレーダーとして這い上がる。しかし母を破滅させた金子雅也が客として現れ、栞は自らの出生の真実と母への犯行を知る。復讐を遂げるも、共犯者ジンに殺される。這い上がりと破滅を同時に駆動するのは、金子の支配の連鎖——母から娘へと受け継がれた暴力の系譜である。

## 感情弧線
- テンプレート：W形（多段波——谷→山→谷→山→最終崩落）
- 選択理由：4年間の物語は単一の上昇/下降ではなく、複数の環境転換（施設／トー横／トレード／復讐）を経る。各段階で感情の山谷があり、最終波（復讐と死）が最大振幅となる。V形（這い上がり）と逆V形（破滅）の複合。プロローグの幸福な日常が、第1章の崩落との落差を最大化する。

## 語りの特異構造

### プロローグ——「映像としての幸福」
GoldenCross と同様、本巻もプロローグから始まる。「後にすべてが崩壊する幸福の頂点」を映像として描く。栞14歳の日常——名門私立の放課後、食卓での父のトレード話、翼との他愛ないやりとり、母の「暗さ」を感じながらも考えないようにしている自分。

### 一人称没入／栞の声の段階的変化
本巻は全編を通じて栞の一人称。栞の声は物語の進行に伴って自然に変化する——下記は方向性の示唆であり、章の境界で機械的に切り替わるものではない。

| 章 | 栞の声の方向性 |
|------|---------|
| プロローグ | 整ったお嬢様の言葉。父への尊敬と母への微かな違和感が混在。幸福の無自覚 |
| 第1章 | 困惑から声が出なくなるまで。退社直後は普通の観察。父の変貌に言葉が追いつかない。遺体発見——声を失う。短い断片。身体感覚だけが地の文に残る |
| 第2-3章 | 翼のために強がる。一人では泣く。施設長の前では言葉が減る。レイプ——感情を閉じる |
| 第4-5章 | ストリート言葉。源氏名「ねね」。短い文。冷めた観察。空腹・寒さ・客の手——身体感覚で語る |
| 第6-7章 | 人形奪還の決意と緊張。ノートを読む場面だけ誠の文体（「──だろう」「──はずだ」の推論調、内省に沈み込む長文）が地の文に自然に流れ込む——栞自身はその変化に気づいていない |
| 第8章 | 数字と株の語彙。冷静な判断。ジンの変化への冷徹な観察眼。怒っていない時のほうが実は危うい |
| 第9-10章 | 吐き気の後の冷たい怒り。感情を直接書かず、観察と身体感覚で語る。怒っている時が一番落ち着いている |
| 第11章 | 行動の記述が主。内省は最小限。最後の瞬間、一瞬だけ幼い日の記憶がよぎる |

### 劇的アイロニー——GoldenCrossとの二層情報差
- **読者は知っている／栞は知らない**：
  - 金子が百合子をレイプし16年間支配した張本人であり、封筒キャンペーンで両親を死に追いやったこと
  - 栞が金子の実子であること（GoldenCross 滲み出し層④・L6中出し写真）
  - 翼が里親のもとで何を経験するか（本巻では栞視点のため一切描かれない）
- **栞が知っている／読者は本巻で初めて知る**：
  - 施設でのレイプの詳細
  - トー横・立ちんぼの現実
  - ノートを読んで栞が掴んだ「父が負けた本当の理由」
  - 金子の自宅コレクションルームの全貌
- **栞が知っていて、読者もGoldenCrossで知っているが、栞自身は結びつけられていない**：
  - 父の退社後の変貌——読者は封筒キャンペーンの影響と知っているが、栞は理由がわからないまま観察。第10章で真実を知った時、第1章の記憶が遡及的に意味を持つ

## 特筆すべき設計判断

- **プロローグ**：映像としての幸福を描く。栞14歳の普通の一日。後にすべてが崩壊する落差を作る。GoldenCrossプロローグと同構造——同じ家、同じ食卓、別の視点
- **第1章**：退社後8ヶ月の家庭崩壊から遺体発見まで。GoldenCross第1-7章の時間を栞の目線で圧縮。栞は理由を知らないまま観察する
- **第2章**：施設の無機質な制度的残酷さ——職員の冷たさ、いじめ、孤立。施設長が巡回で足を止める（伏線）。この章の冷たさが、Ch3のレイプを「必然」に感じさせる基盤を作る
- **第3章**：施設長の接近→「弟君を救ってやれる」→レイプ。翼だけ里親へ。最初の底。感情を閉じる声の始まり
- **第4章**：脱走→トー横→年上の女→初めての立ちんぼ。最も静かで人間的な瞬間——サバイバル知識は善意でも悪意でもなく、ただ受け継がれる
- **第5章**：ジンとの出会い＋立ちんぼ日常確立＋記憶蘇り（旧Ch6を吸収）。立ちんぼ日常が確立された後、ある客の株の話から父の記憶が蘇る——「麻痺した日常に差し込む光」。ここからCh6潜入への動機が生まれる
- **第6章**：深夜の施設潜入。倉庫で人形発見。施設長に見つかりそうになりながら脱出。栞が初めて自分の意志で何かを取り戻す——受動から能動への転換点
- **第7章**：ノートを読む——父の文体が栞の声に流れ込む（栞は気づかない）。本巻の芸術的核心。図書館通い。ジン名義で口座開設。証拠金5万円で初取引。ノートを人形の背中に戻す（誠と同じ動作の無自覚な反復）
- **第8章**：トレード成長——5万→1000万（旧Ch9+10を統合）。数字が栞を強くする。ジンの態度変質——搾取者から共同経営者面へ段階的に。栞は冷徹に観察。末尾に「出口が必要だ」
- **第9章**：金子が客として現れる。何もしない——煙草を吸い、じっと見つめ、言葉だけ。「橘誠の娘だな」「お前の母さんも、なかなかだったよ」。全三部の劇的アイロニー爆発。栞、調査を決意
- **第10章**：調査開始→張り込み→自宅侵入→コレクションルーム発見→母のフォルダ→実父と確信。全三部の情報クライマックス。GoldenCross滲み出し層で読者が既知の真実を、栞の目で「初めて知る」衝撃
- **第11章**：金子殺害→共犯の楔→別れ→ジンによる殺害。最後の夜——レストランでジンが睡眠薬混入。母と同じ手口で無力化され、同じように「なかったこと」にされる。人形とノートが管財人弁護士を通じて翼へ——三代継承
