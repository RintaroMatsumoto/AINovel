# 伏筆管理

**回収先**：特別編「デッドクロス」（和代視点で全三部の真実を開示）
**読者だけが知る真実**：翔は西村の実子。和代だけが知る。誠一は第二部で知り自殺の動機に。栞は第五部で知る。翔は知らないまま。

## 第一部「ゴールデンクロス」（誠一編）の複線

| ID | 伏線 | 埋設箇所 | 意図 | 重要度 |
|----|------|---------|------|--------|
| F001 | 西村が翔だけを異常に気にかける描写。家族行事や会社のイベントで翔をじっと見ている | 第一部 幸福な日常パート | 「なぜ西村は翔にだけ関心があるのか」という違和感 | 中 |
| F002 | 「翔はお前似だな」と言われた誠一が「いや、和代似だよ」と返す。ほんの一拍の間 | 第一部 家族の食卓シーン | 翔が誠一に似ていないことに読者が気づく | 小 |
| F003 | 誠一の回想：西村と同期入社の頃。西村が「お前の教育係の子、かわいいな」と言うシーン | 第一部 フラッシュバック | 西村が最初から和代を狙っていた伏線 | 中 |
| F004 | 西村が誠一の退社パーティーで「家族を大事にしろよ」と意味深に笑う | 第一部 退社シーン | 既にある通り。さらに含みを持たせる | 高 |
| F005 | 誠一が和代から「翔のこと、本当に愛してる？」と聞かれ、「当たり前だ」と答える。和代の表情 | 第一部 夫婦の日常 | 和代の罪悪感の表れ | 高 |
| F006 | 映像の最後の一撃として届く証拠——DNAか何かで翔が自分の子でない証明 | 第二部 クライマックス | 誠一を絶望させる決定的な事実 | 高 |
| F007 | 誠一が和代を殺す直前の台詞「なぜ俺に言わなかった……なぜ今まで……」 | 第三部 幕切れ | 誠一が何かを「知った」ことが伝わる | 高 |

| F008 | 西村の自宅に眠るレイプ動画の中に、栞の写真アルバムとは別に「翔だけの写真」がこっそり保管されている | 第五部 調査シーン | 西村が翔を自分の子として記録していた | 高 |
| F009 | 栞が母の妊娠時期と翔の誕生日を照合し、ある資料で違和感に気づく | 第五部 調査シーン | 栞が翔の出生の真相に気づく瞬間 | 高 |
| F010 | 栞が見つけた母の日記の断片：「もし誠一が知ったら……この子を愛せなくなる」 | 第五部 調査シーン | 和代の恐怖の具体的な中身 | 高 |
| F011 | 栞が西村を拷問する際、西村が栞に「お前の弟はな……」と笑いながら言いかけて止める | 第六部 拷問シーン | 読者に「何を言おうとした？」と思わせる | 高 |
| F012 | 栞がリョウに殺される直前、栞が独白「翔には言えない。このまま知らずに生きてほしい」 | 第七部 栞の死 | 栞が真実を隠したまま死ぬ選択 | 高 |

## 第三部「ブレイクアウト」（翔編）の複線

| ID | 伏線 | 埋設箇所 | 意図 | 重要度 |
|----|------|---------|------|--------|
| F013 | 翔が自分の顔を鏡で見るシーン。写真に写る父・誠一と自分の顔が似ていないことに何となく気づく | 第八部 | 読者への小さな違和感。翔自身は深く考えない | 小 |
| F014 | リョウが初めて翔を見た時の反応：「……誰かに似てると思った」 | 第九部 邂逅 | リョウが西村を知っているので「似ている」と感じる | 中 |
| F015 | 相続財産管理人（弁護士）の書類の中に、栞のメモ「母は全てを抱えて死んだ——このことは翔に知られてはいけない」 | 第九部 書類シーン | 栞が真実を隠していた証拠 | 高 |
| F016 | 父のトレードノートの最終ページ——誠一が書き殴った文字「なぜ、翔が……」で途切れている | 第十部 父のノート | 誠一の最期の叫びの断片。読者はこの時点では意味が分からない | 高 |
| F017 | リングで対峙するリョウが翔に囁く「お前があの人（西村）の子だって、栞は知ってたんだぜ」 | 第十部 リング決着 | 翔がリング上で初めて真実を知る瞬間——ただし翔は信じない | 高 |

| F003・F004 | 西村が誠一を的教育係から外させた真相。西村の計画性 |
| F005・F007 | 和代が誠一に真実を話せなかった17年間の心理 |
| F006 | 誠一が最後に知った「翔が自分の子でない」という事実——和代は誠一に知られた瞬間の光景を思い出す |
