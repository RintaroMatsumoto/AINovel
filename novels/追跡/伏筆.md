# 伏筆管理

**回収先**：特別編「ロスカット」（百合子視点で全三部の真実を開示）
**読者だけが知る真実**：翼は加藤の実子。百合子だけが知る。誠は第二部で知り自殺の動機に。栞は第五部で知る。翼は知らないまま。

## 第一部「ゴールデンクロス」（誠編）の複線

| ID | 伏線 | 埋設箇所 | 意図 | 重要度 |
|----|------|---------|------|--------|
| F001 | 加藤が翼だけを異常に気にかける描写。家族行事や会社のイベントで翼をじっと見ている | 第一部 幸福な日常パート | 「なぜ加藤は翼にだけ関心があるのか」という違和感 | 中 |
| F002 | 「翼はお前似だな」と言われた誠が「いや、百合子似だよ」と返す。ほんの一拍の間 | 第一部 家族の食卓シーン | 翼が誠に似ていないことに読者が気づく | 小 |
| F003 | 誠の回想：加藤と同期入社の頃。加藤が「お前の教育係の子、かわいいな」と言うシーン | 第一部 フラッシュバック | 加藤が最初から百合子を狙っていた伏線 | 中 |
| F004 | 加藤が誠の退社パーティーで「家族を大事にしろよ」と意味深に笑う | 第一部 退社シーン | 既にある通り。さらに含みを持たせる | 高 |
| F005 | 誠が百合子から「翼のこと、本当に愛してる？」と聞かれ、「当たり前だ」と答える。百合子の表情 | 第一部 夫婦の日常 | 百合子の罪悪感の表れ | 高 |
| F006 | 映像の最後の一撃として届く証拠——DNAか何かで翼が自分の子でない証明 | 第二部 クライマックス | 誠を絶望させる決定的な事実 | 高 |
| F007 | 誠が百合子を問い詰める台詞「なぜ俺に言わなかった……なぜ今まで……」——百合子はすべてを語るが、誠は信じられない | 第三部 幕切れ | 誠が何かを「知った」ことが伝わる。しかし9ヶ月の破壊で壊れた誠は真実を受け止められない | 高 |

|----|------|---------|------|--------|
| F008 | 加藤の自宅に眠るレイプ動画の中に、栞の写真アルバムとは別に「翼だけの写真」がこっそり保管されている | 第五部 調査シーン | 加藤が翼を自分の子として記録していた | 高 |
| F009 | 栞が母の妊娠時期と翼の誕生日を照合し、ある資料で違和感に気づく | 第五部 調査シーン | 栞が翼の出生の真相に気づく瞬間 | 高 |
| F010 | 栞が見つけた母の日記の断片：「もし誠が知ったら……この子を愛せなくなる」 | 第五部 調査シーン | 百合子の恐怖の具体的な中身 | 高 |
| F011 | 栞が加藤を拷問する際、加藤が栞に「お前の弟はな……」と笑いながら言いかけて止める | 第六部 拷問シーン | 読者に「何を言おうとした？」と思わせる | 高 |
| F012 | 栞がジンに殺される直前、栞が独白「翼には言えない。このまま知らずに生きてほしい」 | 第七部 栞の死 | 栞が真実を隠したまま死ぬ選択 | 高 |

## 第三部「ブレイクアウト」（翼編）の複線

|----|------|---------|------|--------|

## 特別編「ロスカット」での回収

| 回収する伏線 | 特別編での開示内容 |
|------------|-----------------|
| F001・F002 | 百合子が翼を妊娠した時の確信——「この子は加藤の子だ」 |
| F003・F004 | 加藤が誠を的教育係から外させた真相。加藤の計画性 |
| F005・F007 | 百合子が誠に真実を話せなかった16年間の心理 |
| F006 | 誠が最後に知った「翼が自分の子でない」という事実——百合子は誠に知られた瞬間の光景を思い出す |
| F008〜F012 | 栞が調査で知った全て——百合子は「娘に知られてしまった」と知るのは死後 |
| F013〜F016 | 翼だけは真実を知らない——百合子はそれで良かったと思う。しかし読者は全伏線を回収する |
